# 亞伯拉罕後裔寄居受苦的預言

## 定義

創世記15:13-14記載神預告亞伯拉罕的後裔要寄居別人的地，服事那地的人並受苦，後來神要懲罰那國，使他們帶著財物出來。出埃及記1章以以色列在埃及遭強迫勞役與殺嬰政策，呈現這預言中「寄居、服事、受苦」的歷史落實。

## 主題發展

四份來源都把第13至14節的苦役指回同一個異象。CT 在第13節說得最直接：「埃及人嚴嚴的使以色列人作工」——「本節正應驗了神先前所作的預言（創15:13）」；第14節再補一句：「早在亞伯拉罕時代，神就已預告以色列人將在埃及受苦。」GT 丁良才《出埃及記註釋》引同一處，並把申4:20 的「鐵爐」二字並列在旁。BH 也把督工與苦役讀為同一預言的應驗：這奴役成就了神對亞伯拉罕所說的，他的後裔要在別人的地上寄居、為奴、受苦四百年。

KC 用的是異象裡的另一個意象：「埃及開始成為亞伯拉罕異象中的『冒煙的爐』（創15:12-21；參申4:20）。但神也開始成就祂在同一個異象中所作的應許。」——同一個異象既預告苦難，也預告出離，兩者被綁在一起。

GT《聖經精讀本》把這四百年讀成有目的的時段：神「不會忘記和族長們所立的約，到了時候一定會成就」，而「在埃及的400年是神把雅各家族養育成以色列的時間，同時也是神訓練立約百姓的時間」。同一份註解在另一處把時距寫作「500多年前神對亞伯拉罕的預言（創15:13,14）的成就」，與四百年的說法並存。
