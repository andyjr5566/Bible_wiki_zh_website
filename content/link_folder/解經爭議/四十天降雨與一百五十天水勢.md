# 四十天降雨與一百五十天水勢

## 定義

創世記7:12以 אַרְבָּעִים（H705，「四十」）記大雨降下的日數；7:24則以 חֲמִשִּׁים（H2572，「五十」）加 וּמְאַת（H3967，「和一百」），說水勢在地上增強一百五十天。兩個數字分別描述降雨期與水勢浩大的整段期間，後者包括最初四十天。

## 主題發展

第8章記水勢到一百五十天末了漸消，方舟於七月十七日停在亞拉臘山上。若進一步換算月份與中間日期，必須說明採用的月長、起訖日是否含首尾等曆法假設。
