# 希伯崙

## 定義

CT 給的原文字義是「同盟，聯合，交通，友誼」，原名基列亞巴（書14:15），位於猶大山地，在耶路撒冷以南或西南三十公里上下（各家數字略有出入，見下）。創13:18 亞伯蘭與羅得分離後，搬到希伯崙幔利的橡樹居住並築壇；希伯崙、基列亞巴、幔利在族長敘事裡指同一片地方。亞伯拉罕在這裡買地葬妻（創23章），此地成為族長家族的祖墳（創25:9；49:29-32）。

約書亞記裡，希伯崙先是被攻取的城（書10:36-37），後來給了迦勒為業（書14:13-15），又成為河西南方的逃城（書20:7）和祭司的城（書21:11-13）。

### 約書亞記

<!-- accumulation:約書亞記:10:start -->
#### [[06 約書亞記/第10章|第10章]]
- 本章重點：第3、5、23節希伯崙王何咸列於五王；第36至37節以色列人從伊磯倫上希伯崙去，奪了希伯崙和屬希伯崙的諸城邑。CT 原文字義給「希伯崙」聯合，說它位於耶路撒冷西南方三十公里、伊磯倫的東方，並說第37節的「與王」大概是指繼任的王，因原來的希伯崙王何咸已經被殺。GT《研經資料》說字義是「聯合」、「同盟」，是目前的 Tell er~Ruemideh，亞伯拉罕曾在此築壇（創13:18），大衛作王的前七年以該城為猶大國首都（撒下5:5），並說書15:13~14 說是迦勒趕出當地的亞納族人；GT《華爾頓約書亞記背景注釋》說由於晚銅器時代的文化層尚未在希伯崙發現，考古學不能提供什麼約書亞和以色列人滅城的資料，因為現代希伯崙市建於古城原址之上；GT《綜合解讀》與 GT《啟導本》都說南方戰役中被殺的希伯崙王可能是繼任者。BH 說希伯崙是與亞伯拉罕、以撒、雅各相連的古老要城，後來成為迦勒的產業，再後來成為大衛第一個王都。
- 與本章關聯：本章的希伯崙出現兩次而且身分不同：第3至23節是五王聯軍的成員，第36至39節是南征清單裡的一座城，兩處的王還可能不是同一個人。它也是南征路線由低地折回山地的那一站。

#### [[06 約書亞記/第14章|第14章]]
- 本章重點：第13-15節約書亞將希伯崙給迦勒為業，「直到今日」；希伯崙從前名叫基列亞巴。GT《研經資料》說它在耶路撒冷南方30公里左右，亞伯拉罕曾在此築壇（創13:18），大衛作王的前七年以它為首都；KC 把希伯崙解作相交，又說這城與死亡相連（撒拉葬在那裡）。
- 與本章關聯：本章希伯崙從被攻取的城（書10）變成一個人的產業；GT《啟導本》預告它後來成為利未城與逃城（書21:11、20:7）。

- 本章重點：第13節基列亞巴就是希伯崙，第14節迦勒從那裡趕出亞衲族的三個族長，第54節希伯崙列在山地城單。GT《綜合解讀》說希伯崙是猶大山地的主要城市，是亞伯拉罕、撒拉、以撒、雅各埋葬的地方，大衛曾在這裡作猶大王七年半（撒下2:11）。KC 說迦勒取了意為「city of giants」（巨人之城）的基列亞巴，把它變成意為「fellowship」（交通）的希伯崙。

## 主題發展

### 位置：來源給的方位與距離並不一致

| 來源 | 方位與距離 |
|---|---|
| CT（創23） | 位於耶路撒冷之西南 |
| GT 丁良才《創世紀註釋》（創23） | 耶路撒冷以南五十餘里，比地中海高出三百零四丈 |
| GT《串珠聖經註釋》（創13） | 耶路撒冷以南三十二公里（二十英里） |
| GT《創世記雷氏研讀本》（創13） | 耶路撒冷以南二十二英里（三十五公里） |
| GT《啟導本聖經創世記註釋》（創13） | 耶路撒冷以南三十餘公里 |
| GT《舊約背景註釋》（創13） | 耶路撒冷西南約十九哩，別是巴東北二十三哩 |

方位有正南與西南兩說，距離從十九哩到二十二哩不等。

### 它為什麼重要

GT《舊約背景註釋》給的是地理與經濟的理由：希伯崙城位於猶大山地（海拔約三千三百呎），是通往東面之拉吉和北面耶路撒冷兩條古道會集之處，「地位重要，自古一直有人居住」；當地的泉水和井水，足以種植橄欖、葡萄，以及應付創世記二十三章所形容的那種半農牧經濟的需要。它並指出築壇之舉把本城變為後世的宗教中心，而族長後來在此埋葬「更加強了它在政治上的重要性」（可見於大衛的史事：撒下二1-7、十五7-12）。

背景註釋另記一項年代線索：聖經說希伯崙「比埃及的鎖安城早七年」被建造（民十三22），據考證是主前十七世紀。GT 丁良才則註明這城最古（民十三22）。

### 三個名字

希伯崙、基列亞巴、幔利三名在族長敘事裡指同一片地方。CT 註希伯崙的字義是「同盟，友誼」，並說它「後和幔利混為一城」；[[基列亞巴]]是它的古稱（書十四15），到約書亞的時候又復稱原名（書十四15；十五13、54）。GT《啟導本聖經創世記註釋》把三名並列，並指幔利是當時一個著名人物（創十四13），聖經常用「幔利的橡樹」來指這個地方。

### 族長的祖墳

亞伯拉罕在此買地葬妻（創二十三1-20），此地遂成家族祖墳：亞伯拉罕（創二十五9）、以撒與利百加、雅各與利亞（創四十九29-32）皆葬於此。啟導本並指以撒、雅各大部分時間都住在希伯崙（創三十七至四十五章），而「帳棚」與「祭壇」是他們生活的重要標記。

### 約書亞記：從迦勒的產業到逃城

約書亞記裡的希伯崙先是迦勒的城：書14 迦勒求得希伯崙，書15:13 經文說基列亞巴就是希伯崙。到書20:7，以色列人「在猶大山地分定基列亞巴（基列亞巴就是希伯崙）」，它成了河西南方的逃城。GT《聖經精讀本》說希伯崙原屬迦勒，被選作逃城時，迦勒甘心把它讓給了利未支派（書15:13；21:11）；GT《串珠》在思想問題裡把這件事和書19 猶大把多餘的地讓給西緬並列。
