# 🚀 快速入門

> 第一次來嗎？這頁用 5 分鐘帶你認識本站的核心功能。

## 這個網站是什麼？

這是一個**繁體中文聖經研讀知識庫**，把聖經經文、多家註釋（CT/GT/KC/BH）、原文研讀、神學主題、人物地點、跨書卷互文，全部串成可點擊的維基網絡。

讀經時遇到任何詞、人名、地點、概念，只要點一下就能看到完整的背景資料，**不用跳出閱讀畫面**。

## 3 步開始

### 1️⃣ 選一個起點

- **想讀一章經文** → 從左側「探索」選書卷 → 點章節
- **想查一個主題** → 按 `Ctrl/⌘ + K` 搜尋（例如「神的榮耀」「逾越節」「摩西」）
- **想隨意探索** → 從首頁「按書卷研讀」任選一卷開始

### 2️⃣ 認識 4 個核心互動

| 動作 | 怎麼做 | 效果 |
|---|---|---|
| **點 wiki-link** | 經文中的 `[[條目]]` 或藍色連結 | 跳到該主題頁 |
| **hover 預覽** | 滑鼠停在 wiki-link 上 | 浮現小預覽（不用跳頁） |
| **反向連結** | 頁面右側「Backlinks」 | 看哪些頁面連到這裡 |
| **搜尋** | `Ctrl/⌘ + K` | 全文搜尋；加 `#` 前綴篩標籤 |

### 3️⃣ 深入研讀

每個條目頁底部都有「來源依據」，附上原始網址讓你回溯查證。深度研讀者可以從這裡追到原文（希伯來文 H-number）、四家註釋的詳細解釋。

| 熱鍵 | 功能 |

| `?` | 顯示全站熱鍵面板 |

| 點 📖 | 閱讀模式（去除側邊欄） |

## 常見問題

### 我是手機使用者怎麼辦？

本站響應式設計支援行動裝置。橫向滑動看右側目錄，點左上漢堡選單開啟「探索」。完整行動版指南見 [INSTALL_MOBILE](../INSTALL_MOBILE.md)。

### 內容只到民數記，後面呢？

申命記到啟示錄正在建置中。已完成：創世記、出埃及記、利未記、民數記（共 153 章）。

### 我可以編輯內容嗎？

可以！本站是開源專案，clone vault 後用 Obsidian 編輯。詳見 [INSTALL_COMPUTER](../INSTALL_COMPUTER.md)。
