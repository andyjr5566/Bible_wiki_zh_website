# ⌨️ 熱鍵與功能速查

> 在任何一頁按 `?`（或點右下角的問號）打開**說明中心**：互動導覽、熱鍵與教學文章都在裡面。

<button class="bwz-btn" type="button" data-tour-help="true">打開說明中心</button>

## 全域熱鍵

| 熱鍵 | 功能 |
|---|---|
| `Ctrl/⌘ + K` | 開啟／關閉搜尋 |
| `?` | 打開／關閉說明中心 |
| `Esc` | 關閉搜尋或說明中心；互動導覽進行中則暫停導覽 |

## 搜尋

打開搜尋後輸入關鍵字或一段描述，結果會同時列出兩種比對：

| 標籤 | 意思 |
|---|---|
| **AI 語意** + 百分比 | 依意思比對，字面不同但概念相近的條目也會出現 |
| **精準比對** | 標題或內文真的出現這幾個字（至少 2 個字才會比對） |

操作方式：`↑` `↓` 選擇結果，`Enter` 前往，滑鼠停在結果上會在右側顯示內容預覽。

以下技術性頁面不會出現在搜尋結果中：`index`、`readme`、`install-computer`、`install-mobile`、`license`、`changelog`、`contributing`、`code-of-conduct`。

## 畫面元件

### 左側

| 元件 | 功能 |
|---|---|
| **搜尋** | 開啟搜尋面板 |
| **明暗模式** | 亮色／暗色切換 |
| **紙質／素色**（「紙」「素」印章圖示） | 切換古典紙質底色或純白／純黑底色 |
| **閱讀模式** | 淡出兩側欄，專注閱讀 |
| **探索** | 樹狀目錄；點書卷會直接進入該卷的「全書目錄及綱要」 |

### 內文區

| 元件 | 功能 |
|---|---|
| **麵包屑** | 顯示目前頁面的位置（首頁不顯示） |
| **屬性** | 條目的別名等資訊 |
| **章節導覽** | 章節頁頂端的「前一章／回目錄／下一章」 |

### 右側

| 元件 | 功能 |
|---|---|
| **關係圖譜** | 目前頁面和哪些條目相連；右上角圖示可展開全站圖譜 |
| **目錄** | 由頁面的小標題自動產生 |
| **反向連結** | 所有連到目前頁面的頁面 |

### 互動行為

| 動作 | 效果 |
|---|---|
| 滑鼠停在連結上（電腦） | 浮出條目預覽，不用換頁 |
| 點連結 | 跳到目標頁，不整頁重新載入 |
| 瀏覽器返回 | 回到上一頁原本讀到的位置 |

## 手機版差異

- 左上角選單打開「探索」，搜尋與工具列在頂部
- 沒有懸停預覽，直接點連結進條目
- 關係圖譜、目錄、反向連結移到內文下方
- 可以把網站加入主畫面，像 App 一樣使用，見 [INSTALL_MOBILE](../INSTALL_MOBILE.md)
