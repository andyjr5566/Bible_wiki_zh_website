# 你且由著我（ra.phah）

## 定義

第14節神對摩西說的第一句話是「你且由著我」。STEP 顯示這個動詞是 רָפָה（ra.phah，H7503，簡要詞典義 to slacken），本節作 He.ref，morphology 標為 HVhv2ms，也就是使役語幹的命令式；後面接的是 mi.Me./ni（從我）。CT 的〔原文字義〕給的中文是「下沉，放鬆」，文意註解則直接說它的意思是不要為他們求情。

這句話的奇特之處在於說話的人是神。KC 讀出其中的意味，說神彷彿是在向摩西請求容許他毀滅這百姓；BH 也指出這是對摩西代求職分的一種考驗，並把它接到中保這個主題上。兩家都注意到同一件事：神在動手之前，先把手交到了一個人的挽留裡。

摩西的回應寫在後面幾節。他沒有接受第14節下半那個提議——使你的後裔比他們成為更大更強的國——而是俯伏四十晝夜為百姓求情。CT 在第25節的〔話中之光〕說摩西不重看他的後裔得昌大，他為了神的名和神的榮耀向神求恩典，而他的禱告摸著了神的心。GT 章末的思想問題也直接問讀者：摩西為何沒有接納神的提議。

第19節記下結果：耶和華那次又應允了摩西。CT 說明摩西所怕的是神在大發烈怒之餘真的把以色列人滅絕了，而神答應了這位中保的請求。

- 本章重點：第14節「你且由著我」STEP 為 רָפָה（ra.phah，H7503，簡要詞典義 to slacken），詞形 HVhv2ms（使役語幹命令式）；CT 的原文字義給「下沉，放鬆」，並解為不要為他們求情。KC 說神彷彿在請求摩西的容許，BH 說這是對摩西代求職分的考驗；摩西沒有接受第14節下半的提議，而是俯伏四十晝夜代求，第19節說耶和華那次又應允了他。
- 與本章關聯：這一句是本章金牛犢段落的樞紐：它把滅絕的判決與摩西的代求接在一起，也讓第25至29節那篇祈禱有了必要性。
