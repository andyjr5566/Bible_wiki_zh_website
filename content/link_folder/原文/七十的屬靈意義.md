# 七十的屬靈意義

## 定義

創十共列出七十個宗族，聖經中「七十」象徵**完全**。七十這數字在多處經文中出現，代表全體。

## 按書卷累積

### 創世記

<!-- accumulation:創世記:10:start -->
#### [[01 創世記/第10章|第10章]]
- 本章重點：CT、GT《串珠聖經註釋》與 GT《舊約背景註釋》三家各自數出七十個宗族；CT 據此註「『七十』象徵『完全』」。
- 與本章關聯：《舊約背景註釋》把這個數目與創四十六27（雅各一家入埃及）、出二十四9 與結八11（七十長老）、士八30（基甸的兒子）、王下十1（亞哈的兒子）及烏加列諸神並列，說明七十是表達「全體」的體例，而不是統計結果。

### 民數記

<!-- accumulation:民數記:29:start -->
#### [[04 民數記/第29章|第29章]]
- 本章重點：住棚節七日的公牛從十三隻逐日遞減到七隻，GT 丁良才算出「每天減去一隻，到七天有七隻，共有七十只」，GT《聖經精讀本》也列出算式 13＋12＋11＋10＋9＋8＋7。
- 與本章關聯：GT《聖經精讀本》把這個總數讀成「表示對神完全的奉獻和忠心」；這是七十作為完全數目在節期獻祭上的一次出現。

## 主題發展

### 創十的七十宗族

三份來源各自獨立地數出同一個數目：CT 說「本章共列了七十個宗族」並註「『七十』象徵『完全』」；GT《串珠聖經註釋》說「作者在本章只記下挪亞七十個後代」；GT《舊約背景註釋》說「本段所列的民族共有七十個」。

- 代表洪水後全人類的**完整性**
- 萬國的分配與數目都在神的主權之下

### 七十作為「全體」的其他用例

GT《舊約背景註釋》〈創十2～29 個人、父系、政治的名字〉不只給出數目，還把它放進一組平行用例，說明七十在古代近東與聖經中反覆用來代表全體：

| 出處 | 七十指什麼 |
|---|---|
| 創四十六27 | 雅各一家進入埃及的人口 |
| 出二十四9 | 國家代表的數目（七十長老） |
| 結八11 | 同為七十長老 |
| 士八30 | 基甸兒子的數目 |
| 王下十1 | 亞哈兒子的數目 |
| 烏加列文獻 | 烏加列諸神的數目 |

背景註釋因此說明「萬國圖」列數挪亞後裔名字的用意，「是要反映整體的人類，並且在地緣政治的分割和賓主的關係上，給人簡要的印象」——七十在這裡不是統計結果，而是表達完整性的體例（見[[列國表]]）。

本條目也牽涉的經文：創46:27：雅各一家進入埃及七十人；出1:5；出24:9：七十長老；民11:16：七十長老；路10:1-2：主差遣七十人。
