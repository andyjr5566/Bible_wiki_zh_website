# 惟願（mi yi.ten）

## 定義

申命記5:29，神聽完百姓求摩西代聽的話之後說：「惟願他們存這樣的心敬畏我，常遵守我的一切誡命，使他們和他們的子孫永遠得福。」

這個「惟願」在原文是兩個字。STEP 顯示是 mi-（H4310，字典的意思是「who?」，誰）接 yi.Ten（H5414Q，字典的意思是「to give: if only!」，給；但願），字面是誰會給。字典為這個編號直接記下 if only 這個譯法，可見它在希伯來文裡是一種固定的願望語，不是真的在問誰。同一節的「心」是 le.vav（H3824，後加『他們的』字尾，字典的意思是「heart」，心），「敬畏」是 yir.ah（H3372H，前面接介詞 le，字典的意思是「to fear: revere」，敬畏）。

**註釋家怎麼理解這句願望。** CT 指出這裡的『這樣的心』是害怕惹神發怒的心，並在話中之光裡說，神惟願以色列人存這樣的心敬畏祂——由衷地尊敬祂、順服祂；照規定做事，與發自內心而做很不相同。GT《聖經精讀本──申命記註解》的解釋方向一致：在神面前總要持守以恐懼震驚的心甘願順服所有話語的心志。

KC 讀出的是神那一邊的情感：耶和華悅納百姓的態度，肯定他們所說的，並表達祂的心願，就是要他們遵守祂的誡命；祂的心向著祂的百姓，切望他們持續的福樂。BH 則提醒不要把這裡的敬畏讀成驚恐：這份敬畏是對神的能力有所認識、並委身於順服，並非恐怖。

**神說話的位置。** 申5:28 神才剛說百姓所說的都是，申5:29 緊接著就用這個願望語。同一段裡先有肯定，後有心願；註釋家對申5:25-27 那份請求的評價分歧（見[[百姓懼怕神的顯現]]），申5:29 這句話正是神自己給的評語。

### 申命記

<!-- accumulation:申命記:5:start -->
#### [[05 申命記/第5章|第5章]]
- 本章重點：第29節「惟願他們存這樣的心敬畏我」的「惟願」，STEP 是 mi-（H4310，who?）＋yi.Ten（H5414Q，字典的意思是「to give: if only!」），字面是誰會給，屬希伯來文的願望語；同節「心」le.vav（H3824）、「敬畏」ya.re（H3372H，字典的意思是「to fear: revere」（敬畏））。CT 解「這樣的心」為害怕惹神發怒的心；GT《精讀本》說是甘願順服的心志；BH 指出這敬畏不是恐怖。
- 與本章關聯：這句願望緊接在第28節「他們所說的都是」之後。神先肯定百姓求中保的話，再說出祂真正要的東西——不是一次的表態，而是持續存留的一顆心。第30至31節接著把百姓打發回帳棚、把摩西留在自己身邊，安排就是照這個心願來的。
