# 方舟的豫表

## 定義

方舟的豫表是註釋把挪亞所造的方舟讀成基督的預表：人在神所預備的方舟裡經過審判，得保全生命。創6:14 說方舟用歌斐木造，分一間一間地造，裡外抹上松香；創7:17-18 洪水氾濫，把方舟漂起；創8:4 方舟停在亞拉臘山上。CT、KC 與 BH 把方舟的各項細節連於基督的救贖、遮蓋，以及信徒在基督裡的安全。

STEP 在創6:14 標出『方舟』（תֵּבָה，H8392）、『隔間』（קִנִּים，H7064，字面是『巢』），並用動詞『遮蓋』（וְכָפַרְתָּ，H3722B）和名詞『松香／瀝青』（בַּכֹּפֶר，H3724B）描述防水安排。

## 主題發展

### 方舟豫表基督八方面

| 項目 | 說明 | 靈意豫表 |
|---|---|---|
| 歌斐木 | 富樹脂柏木，耐水浸蝕 | 基督堅固完美的人性 |
| 分一間一間造 | 內部隔間 | 基督是各種人的安息 |
| 抹松香 | 柏油/瀝青防水 | 基督寶血的救贖功效 |
| 尺寸 | 300×50×30 肘 | 基督的完備豐滿 |
| 透光處 | 上邊高一肘 | 基督是世界的光 |
| 門 | 門開旁邊 | 基督可親可近，是通神之門路 |
| 三層 | 上、中、下 | 對基督經歷的不同程度 |
| 松香原文 | STEP 分別標出動詞「遮蓋」（H3722B）與名詞「松香」（H3724B）；CT、KC進一步把相近詞根連於贖罪／挽回 | 基督的救贖 |

### 神學意義／研讀意義

- 在方舟裡＝在基督裡，得保全生命
- 方舟內外的分別：惟有進入方舟者得救——CT 說除了基督以外別無拯救（徒四12）
- 洪水豫表審判（太廿四39）和受浸的水（彼前三20-21）
- 方舟也豫表教會——在基督裡一同經過審判
