# 「摩押」名字含義

## 定義

「摩押」是羅得大女兒所生之子的名字，也是摩押人的祖名。註釋通常按創19:37的出生敘事，把名字解作「從父親而來」或「由父而生」，使名字保存其父系來源的雙關。

## 按書卷累積

### 創世記

<!-- accumulation:創世記:19:start -->
#### [[01 創世記/第19章|第19章]]
- 本章重點：羅得大女兒使父親醉酒後與他同寢，生子命名摩押。
- 與本章關聯：名字與「從父親存留後裔」的計畫相連，並引出摩押人與亞伯拉罕家族的親族關係。

## 主題發展

名字的敘事雙關相當清楚，但精確語源重建仍有不同拼法與解釋；整理時宜說「通常按敘事解作」，避免宣稱只有一種語源分析。

摩押人的後來歷史不能只由這個起源故事概括。路得是摩押女子，後來進入大衛家系，顯示個人的信仰與品格不由族群起源機械決定。

### 各家給的譯法

| 來源 | 所給譯法 |
|---|---|
| CT | 「由父而生，父親的水」 |
| GT《串珠聖經註釋》 | 「從父親來的」 |
| GT《啟導本聖經創世記註釋》 | 「由父而生」 |
| GT《創世記雷氏研讀本》 | 「從父親而來的」 |
| GT《聖經精讀本──創世記註解》 | 「由於父親」 |
| BH | "from the father" |

六家的方向一致：名字保存了父系來源這個事實。CT 另給的「父親的水」是同一組子音的另一種切分，本條目記下但不採為主要義。

### 名字的功能

GT《聖經精讀本──創世記註解》把這個命名的效果講得最重：摩押與亞捫這兩個名字表示近親相奸，「**等於把父親的恥辱永留後世**」。詩83:8 稱兩族為「羅得子孫」，沿用的正是同一條線；GT《串珠聖經註釋》把兩名合起來下結論：「二名都表明這兩個兒是出自父親羅得。」

需要與族名區分：本條目處理的是創19:37 的人名，與摩押作為地名、族名在後續經卷中的用法不是同一件事（見[[摩押人]]）。
