# 弟兄賣身為奴不可像奴僕看待

## 定義

利未記25:39-43：以色列弟兄若窮到把自己賣了，買他的人「不可叫他像奴僕服事你」，要待他「像雇工人和寄居的一樣」，服事到禧年為止，而且「不可嚴嚴地轄管他」。

**「將自己賣給你」這幾個字是關鍵。** 丁良才特別要讀者注意：「強迫人做奴僕或強取人的兒女做奴婢是不合律法的」，並舉先知門徒的妻子（王下4:1）、西底家時（耶34:8-17）與尼希米時的百姓（尼5:3-5）為當時實際發生過的窘境。

**理由寫在 v42：「因為他們是我的僕人。」** 丁良才由此列出神領以色列人出埃及的六種目的：使他們得釋放、使他們得自由、將迦南地賜給他們為業、叫他們做神的僕人、彰顯神的大能與美德、使以色列人引導萬國的人歸向神。KC 的說法一致——所有以色列人都是耶和華的僕人，都從埃及被贖出來得自由，所以誰也不可苛待別人、趁人之危。

**「不可嚴嚴地轄管」在原文與埃及對照。** 丁良才：「就是不可苦待他，像埃及人苦待以色列人一樣（出1:13）。」串珠：「即虐待他，要他不停作苦工。」BH 也指出這個詞含有嚴苛壓迫之意，並把這條規定連回出埃及記20:2——神自己曾把以色列從奴役中領出來。

**禧年會提前終止年限。** 丁良才：按出埃及記21:2 做奴僕以六年為滿，「但在期內若遇禧年，雖然限期未滿，這等僕人也要得釋放」；主人在他得自由時「不可使他空手而去，乃要照神所賜的福將食物給他」（申15:12-18）。他並直說這些條例「本是要阻止富戶的暴行，戒除他們的吝嗇，但他們還是屢次違背」（耶34:8-17）。

**外邦奴僕另有一套。** v44-46 允許從四圍的國中買奴僕婢女，且可遺留給子孫、不受禧年限制。丁良才在此處寫下一段長註，把當時的奴婢制度攤開來看——來源有戰俘、無力償還盜取財物者、販奴買來的、家生的、親友餽贈的、父母遺留的，尋常價值三十至五十舍客勒；他的結論是「摩西的律法只能漸漸減輕其中的害處，不能立即除掉這惡俗，乃因以色列人心硬」。他並列出律法實際設下的限制：拐帶人口的必被治死（出21:16）；主人若使奴婢受不能復原的傷損，奴婢即得自由（出21:26-27）；主人刑罰奴婢甚至致死要受罰（出21:20-21）。BH 也強調這與周圍文化中的奴隸制不同，是「一種契約性的僕役」而非嚴格意義的奴隸。

- 本章重點：v39-46 以色列弟兄自賣為奴不可當作奴僕看待，要像雇工人和寄居的一樣，服事到禧年，不可嚴嚴地轄管；理由是「因為他們是我的僕人，是我從埃及地領出來的」。外邦奴僕則可從四圍的國中買，並遺留給子孫、不受禧年限制。
- 與本章關聯：丁良才強調「將自己賣給你」幾個字——強迫為奴或強取兒女為奴婢不合律法，並列出神領以色列出埃及的六種目的、以及禧年會提前終止六年期限。他在 v44 寫下一段完整的奴婢制度背景，結論是「摩西的律法只能漸漸減輕其中的害處，不能立即除掉這惡俗，乃因以色列人心硬」。BH 亦指出這是契約性僕役而非嚴格意義的奴隸。

## 主題發展

這條律例與出埃及記21:2-11 的六年期限、申命記15:12-18 的釋放規定合成一組，而本章加上的是禧年這個上限——無論服事幾年，到禧年一律終止。GT《舊約聖經背景註釋》指出以色列律法「力求防止有人欠債累積到非為奴不可的程度」，禁止收息的規定在絕大部分情況下都是對窮人有幫助的。

KC 把它轉成新約的處境：基督徒作主人的必須明白自己在天上也有一位主人（西4:1），所以自己同樣是僕人；而「有一位是你們的夫子，你們都是弟兄」（太23:8）。
