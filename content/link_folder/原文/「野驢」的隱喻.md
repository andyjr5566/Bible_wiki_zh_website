# 「野驢」的隱喻

## 定義

耶和華使者豫言以實瑪利「為人必像野驢」。野驢象徵自由、兇猛、不服管轄、在曠野漂泊的性情。豫表宗教徒的特點：不受管束，彼此嫉妒分爭。

## 主題發展

### 五份來源，兩個相反的方向

創十六12「他為人必像野驢」，各家給的評價分裂得很徹底：

| 來源 | 讀法 |
|---|---|
| GT 丁良才《創世紀註釋》 | 負面：「住在曠野，自由，兇猛，不法，不安寧，難管轄」，並列舉伯十一12、二十四5、三十九5-8、詩一〇四11、賽三十二14、耶二24、但五21、何八9 為佐證 |
| CT | 負面：「離開常人居住之地，在曠野四處漂泊，無拘無束，並且對別人懷有敵意，性情兇暴，不服管轄」 |
| GT《串珠聖經註釋》 | 中性偏負：「象徵衝動、獨立和野性」 |
| BH | 中性：獨立而未經馴服的沙漠動物，指向遊牧、自由的生活方式與其居所 |
| GT《創世記雷氏研讀本》 | **正面**：「這綽號是一種稱讚，因為這種幾乎不能馴服的野驢是一種受稱讚和珍貴的動物」 |

雷氏是唯一的反方，而且不是措辭較軟，是方向相反。這一句怎麼讀，直接決定第12節是預告一種受咒詛的性情，還是描述一種被賞識的野性。

### 兩邊都可以引到約伯記三十九章

值得注意的是，丁良才與 GT《聖經精讀本》都引伯三十九5-8 的野驢描寫，但取用的重點不同。丁良才取「無人管轄」的一面；精讀本取生活形態的一面，用來說明以實瑪利後裔的樣貌——貝都因人「打消定居生活的念頭，蔑視文明生活，騎著馬，拿著長槍賓士在廣闊的自然中，並以此為生」。約伯記那段本身確實兼有兩種語氣：野驢不受羈勒，也因此不聽趕牲口的喝聲。

### KC：名字與性情的張力

KC 從敘事結構讀這個比喻：使者先指定名字「以實瑪利」（神聽見），隨即說「他為人必像野驢」——「他的性情將不符合他的名字」。KC 並把野驢讀成馱重的牲口卻要把重擔甩掉的形象，用以比喻在律法之下卻不理會律法的以色列。這是 KC 自身的預表讀法，屬解釋層次，不是字義。

### 「住在眾弟兄的東邊」

丁良才與 CT 都註「東邊」原文作「對面」。GT《串珠聖經註釋》據此讀作關係語：「原是『在眾弟兄的前面』，即和眾弟兄有一種敵對的關係。」GT《創世記雷氏研讀本》則明說兩解並存不作裁決——可能指地理方位，也可能指衝突關係。
