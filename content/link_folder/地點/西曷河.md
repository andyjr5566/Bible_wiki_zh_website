# 西曷河

## 定義

書13:3「從埃及前的西曷河往北，直到以革倫的境界，就算屬迦南人之地」。未得之地的清單由這條河起算，它是南邊的起點。STEP 顯示是 ha./shi.Chor（H7883G，簡要詞典義 shi.chor: Shihor）。CT 與 GT《約書亞記研經資料》給的字義都是「黑暗」。

**是哪一條水道，各家說法不一。** 爭點在於它是尼羅河最東邊的支流，還是西乃半島東北角的「埃及小河」：

| 來源 | 判斷 |
|---|---|
| CT | 埃及與以色列人領地的邊界小河，「有謂尼羅河的東面支流，有謂即埃及小河」 |
| GT《約書亞記雷氏研讀本》 | 可能指尼羅河或埃及河（艾亞利詩河道，Wadi el~Arish）最東面的支流 |
| GT《啟導本》 | 以色列國與埃及邊界的埃及小河（民34:5） |
| GT《串珠聖經注釋》 | 有時指尼羅河盡東的支流（賽23:3），有時指埃及小河（書15:4），這裡可能是後者 |
| GT《約書亞記研經資料》 | 埃及東邊的一條河流或運河，是尼羅河的支流（賽23:3、耶2:18） |
| GT《約書亞記綜合解讀》 | 就是埃及小河 |

GT《串珠》的說法最能解釋為什麼會有兩派：同一個名字在聖經不同地方可能指不同的水道，判斷要看上下文。在本節，GT《啟導本》、《串珠》、《綜合解讀》都傾向埃及小河，CT 則兩說並列、不下判斷。

**它在這段經文裡的作用。** BH 說西曷河標出以色列靠近埃及的西南邊界，而埃及正是以色列從前受奴役之地；神所應許的產業從埃及的邊界往北穿過迦南，顯出這份賞賜有多廣。

## 按書卷累積

### 約書亞記

<!-- accumulation:約書亞記:13:start -->
#### [[06 約書亞記/第13章|第13章]]
- 本章重點：第3節「從埃及前的西曷河往北，直到以革倫的境界」。STEP 為 ha./shi.Chor（H7883G）。CT 兩說並列（尼羅河東面支流或埃及小河）；GT《啟導本》、《串珠》、《綜合解讀》認為這裡是埃及小河；GT《雷氏研讀本》、《研經資料》說是尼羅河最東面的支流。
- 與本章關聯：本章以它為未得之地清單的南端起點：從這條河往北到以革倫的沿海一帶，雖由非利士人佔據，仍「算屬迦南人之地」。
