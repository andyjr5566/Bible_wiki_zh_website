# 除罪水

## 定義

潔淨利未人的第一個動作是「用除罪水彈在他們身上」（v7）。

**這個詞只出現這一次。** CT 說得很明白：「『除罪水』全部聖經僅此一次提到這詞」，並列出兩種推測：「(1)指『除污穢水』（參民19:9）；(2)指洗濯盆裡的水。」

| 來源 | 傾向 |
|---|---|
| CT | 兩說並列，未下判斷 |
| GT《啟導本》 | 「很可能是後者」，即洗濯盆的水（出30:18） |
| GT 丁良才 | 兩說並列，未下判斷 |
| GT《聖經精讀本》 | 明確主張是紅母牛灰調成的水（民19:9） |
| GT 李道生《舊約聖經問題總解》 | 兩說並列，並指出「無論是名為除罪水……或是洗濯盆的水，其用處都是在表示為人除去罪汙，潔淨身體」 |
| BH | 傾向紅母牛（民19），並把灑水讀為新約洗禮的先聲 |

**動作是「彈」而不是「洗」，這一點 KC 特別強調。** 潔淨「不在於洗滌，而在於灑」；灑的意思是把所灑之物的價值轉移到被灑者身上——「藉著被灑，他就落在那件事的能力之下」。他並澄清一個容易誤讀的地方：這裡用潔淨的水，不是因為利未人犯了罪，而是需要對主耶穌除罪之工有一份特別的意識。

#### [[04 民數記/第8章|第8章]]
- 本章重點：本章第7節「用除罪水彈在他們身上」。CT 指出這個詞全聖經僅此一次，並列出「除污穢水（民19:9）」與「洗濯盆的水」兩種推測；GT《啟導本》傾向後者，GT《聖經精讀本》與 BH 傾向前者。KC 強調動作是灑而不是洗。
- 與本章關聯：為利未人潔淨禮的第一個動作留下一個未定的解經問題；STEP 顯示原文字面是「chat.tat 的水」，而 chat.tat 在本章第8、12節正是「贖罪祭」。

## 主題發展

STEP 原文資料為這場爭論提供了一項可查證的語言事實。第7節「除罪水」在原文是兩個字：mei（H4325G，詞典形 ma.yim，詞典義 water）配上 cha.Tat（H2403I，詞典形 chat.tat），STEP 給本節的語境譯義是 sin offering。==字面就是「chat.tat 的水」。==

同一個 base Strong（H2403）在本章總共只出現三次，另外兩次都在第8節與第12節，而那兩處和合本正是譯作「贖罪祭」。換句話說，除罪水的第二個字，就是同章兩次出現的贖罪祭那個字。GT《聖經精讀本》讀為紅母牛灰調成的水，理由正落在這一層——民19:9 的水本來就是焚燒贖罪祭紅母牛的灰調成的。

同節「彈」是 ha.Zeh（H5137A，詞典形 na.zah，詞典義 to sprinkle），Hiphil 命令式，與 KC 所說「不在於洗滌，而在於灑」相合。
