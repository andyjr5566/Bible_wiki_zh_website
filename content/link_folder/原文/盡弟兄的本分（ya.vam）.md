# 盡弟兄的本分（ya.vam）

## 定義

申25:5 與申25:7 兩次出現「盡弟兄的本分」。中文讀起來像一句解釋，原文卻是一個專門的字。

### 一個字根，三個詞

STEP 顯示這幾節用的是同一個字根的三種形態：

- 申25:5「他丈夫的兄弟」是 ya.vam（H2993），字典的意思是「brother-in-law」（丈夫的兄弟），名詞，後面帶第三人稱陰性字尾。
- 申25:5「當盡弟兄的本分」是 ya.vam（H2992），字典的意思是「be brother-in-law」（作丈夫的兄弟），動詞，前面帶連接詞、後面帶第三人稱陰性字尾，本節的語境義是為她盡丈夫兄弟的本分。申25:7「不給我盡弟兄的本分」是同一個動詞的另一個形式（後面帶第一人稱字尾）。
- 申25:7 與申25:9「他哥哥的妻」是 ye.ve.met（H2994），字典的意思是「sister-in-law」（兄弟的妻），名詞，後面帶第三人稱字尾。

也就是說，希伯來文替這個關係造了一整組專用詞：丈夫的兄弟叫 yavam，他該做的事就叫 yavam（動詞），而該被他娶的那位嫂子叫 yevemet。中文得用「盡弟兄的本分」六個字來翻，原文只要一個動詞。CT 的原文字義給「本分」的解釋是應盡的義務。

### 拉丁文那邊也是同一套

同一個結構在拉丁文裡重演了一次。GT《申命記雷氏研讀本》指出，叔娶寡嫂的制度源自拉丁文 levirate，原意是丈夫的兄弟。GT《聖經精讀本──申命記註解》說的一樣：這裡 Levir 指丈夫的兄弟，所謂繼代結婚就是若已成婚的男子沒有留下後嗣就死去，其兄弟就有義務與嫂子結婚。

KC 直接用這個詞當標題，說申25:5 和申25:7 講的就是丈夫兄弟的本分。BH 也說，levir 的責任是娶這位寡婦，並為死去的兄弟生下後裔。

### 為什麼要有專門的字

一件事被造出專用詞，通常代表它在那個社會裡是固定的制度。申25:7 的兩個否定詞把這一點顯出來：STEP 顯示寡嫂控訴時說的是 me.'Ein（H3985 ma.en，他拒絕了），而申25:7 結尾又說 lo' 'a.Vah（H14 a.vah，他不肯），申25:8 那人自己的回答則是不願意娶她。同一件事在三節裡用三個不同的否定說法反覆講——那是有義務而可以不履行。

申25:7 寡嫂控訴的內容也用了制度語言：她說他不肯 qum（H6965I，使役語態，使之立起，前面帶介系詞）他哥哥的 shem（H8034，名）在以色列中。CT 的文意註解解釋『興起…名字』指名字得以繼續存立、獲得堅立。這正是申25:6 那句話的反面——免得他的名在以色列中塗抹了。

- 本章重點：第5節與第7節的「盡弟兄的本分」原文是一組同字根的專用詞。STEP：ya.vam（H2993 ya.vam: brother-in-law，名詞，她丈夫的兄弟）、ya.vam 與 ya.vam（H2992 ya.vam: be brother-in-law，動詞）、ye.ve.met（H2994 ye.ve.met: sister-in-law，他哥哥的妻）；另有 me.'Ein（H3985 他拒絕了）、lo' 'a.Vah（H14 他不肯）、qum（H6965I 使…立起）＋shem（H8034 名）。CT 的原文字義說「本分」是應盡的義務，並解釋『興起…名字』指名字得以繼續存立；GT《雷氏》與《精讀本》都指出拉丁文 levir 同樣是丈夫的兄弟；KC 用丈夫兄弟的本分作第5至10節的標題；BH 說 levir 的責任是娶寡婦並為死去的兄弟生下後裔。
