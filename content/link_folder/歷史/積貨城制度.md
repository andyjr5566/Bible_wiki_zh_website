# 積貨城制度

## 定義

「積貨城制度」是約瑟在埃及七個豐年期間建立的國家級糧食儲備與分配體系（創41:34-36, 48-49, 56）。核心機制：(1) 徵收五分之一稅（20%）；(2) 收購餘糧；(3) 分散儲存於各城（就地倉庫）；(4) 饑荒時官方統一糶糧。此制度使埃及成為古近東饑荒中唯一有糧之地。

## 主題發展

《舊約背景註釋》：積貨城是「有長遠眼光、了解饑荒必然性而謀求對策之富強國家的特徵」。每區域設積貨城於位置適中地點。BH 就制度的兩個設計說明了理由：糧食分存各城，使「每座城都有自己的存糧，降低了饑荒引發的遷徙與動亂」；而約瑟選擇賣糧而非免費發放，是「管理資源、維持秩序的經濟策略」，確保供應可以持續。GT《舊約背景註釋》則說明徵收與建倉是同一套計策：「約瑟為面對饑荒所提供的計策，豐年時每年儲藏五分之一的收成，然後在有需要時分配給百姓。建築倉庫也是這妙計的一部分」（出1:11；王上9:19）。KC 把這件事轉成屬靈的功課：「我們也當在屬靈豐盛的年間為自己的魂積蓄糧食」——藉著參加傳講並解明神話語的聚會，也藉著個人讀經，「這樣就能充滿我們心思意念的庫房」，並說這在年輕時尤其要緊（傳12:1）。
