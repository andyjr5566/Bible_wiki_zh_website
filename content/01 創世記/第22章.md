## 本章整理

上一章亞伯拉罕在別是巴與亞比米勒立約，求告耶和華永生神（創21:33）。這一章神試驗亞伯拉罕，要他把獨生的兒子以撒獻為燔祭（第1-2節）；亞伯拉罕清早起來，三日後到了指示的地方（第3-8節），伸手拿刀時，耶和華的使者阻止他，神預備了公羊代替（第9-14節）。神隨後指著自己起誓，重申賜福的應許（第15-19節）；本章最後記下拿鶴的家譜，其中有利百加（第20-24節）。

### 神的試驗（1-2節）

「這些事以後」，神要試驗亞伯拉罕（第1節；נִסָּה，H5254G；[[神試驗亞伯拉罕]]）。這時以撒已經長大，可以背著燔祭用的柴爬山（《聖經精讀本──創世記註解》）。『試驗』暗示神藉這次經驗叫亞伯拉罕成長和得益（申8:16），魔鬼試探人卻是想毀滅人（雅1:15；彼前5:8）（《串珠聖經註釋》）。《精讀本》把聖經裡的試驗分成兩種：撒但的試探（temptation）要把人推向墮落，[[神的試驗|神的試驗（test）]]則是對信仰的驗證；《創世記雷氏研讀本》說，神絕不會出於惡意去試探任何人（參雅1:13）。

神是無所不知的，不用試驗就知道亞伯拉罕的心。丁良才說，神這樣做要表明三件事：亞伯拉罕信心的實在；他敬畏主，並非愛兒子過於愛主；並使他因信心受試煉，得著稱讚、尊貴和榮耀（彼前1:7）。

神說：「你帶著你的兒子，就是你獨生的兒子，你所愛的以撒，往摩利亞地去」（第2節）。這是三重漸進的說法：要的是人，是兒子；這兒子是他一百歲時生的、世上任何東西都無法交換的；他又是以實瑪利離開後唯一的骨肉，等了二十五年的立約之子（《精讀本》）。KC 也說，神一層一層地說出來：「你的兒子」（בִּנְךָ，H1121A），「你獨生的兒子」（יְחִידְךָ，H3173），「你所愛的」（אָהַבְתָּ，H157G），最後才說出名字「以撒」（יִצְחָק，H3327），就是他的喜笑。

「愛」（אָהַב，H157G）字在這裡是聖經第一次出現，用來形容父親與兒子的關係，指向父神與愛子的關係（KC；太3:17；約3:16）。KC 說，神問的實際功課是：你更信我所賜給你的，還是更信我自己？

> [!note] KC
> 你更信我所賜給你的，還是更信我自己？——這是亞伯拉罕與我們都要學的功課。

這段歷史可以從三層來看：字面上是一位父親經歷嚴厲的信心試驗；也可以看成神獻上愛子的圖畫（[[亞伯拉罕豫表父神]]）；還有預言的應用，就是獻祭帶來的祝福（KC）。這是創世記的第四次獻祭，前三次是神、亞伯和挪亞所獻（KC）。《啟導本聖經創世記註釋》說，亞伯拉罕一生有四次重要的抉擇，每次都捨棄一樣本來很看重的事物：離開本地本族（創12:1）、與姪兒羅得分手（創13:1-18）、在以撒和以實瑪利間作抉擇（創21:14），最後是奉獻獨生兒子以撒。

神吩咐他往「摩利亞地」（אֶרֶץ הַמֹּרִיָּה，H776G、H4179；[[摩利亞地]]），在神所指示的山上，把以撒獻為「燔祭」（לְעֹלָה，H5930A；[[燔祭]]）。所羅門在摩利亞山上建造聖殿（代下3:1；丁良才、《串珠》、《雷氏研讀本》、李道生）。丁良才說，主耶穌被釘十字架的地方離這山不遠（路23:33）；李道生說據說各各他山即是古時的摩利亞山。

摩利亞山在哪裡，各家沒有定論。李道生說年代久遠，難以確指，候選有基利心山或錫安山，後來是耶布斯人亞勞拿的禾場，大衛在那裡築壇，止住瘟疫（撒下24:18-25；代下3:1）。《舊約背景註釋》說，本段唯一的線索是距離別是巴三日的路程，但這日數也可能只是虛數，經文也沒有提方向；耶路撒冷附近山頭有樹林，用不著帶木柴，名字相同較可能是巧合，未必是同一個地方。旅程約有八十公里（《雷氏研讀本》、《精讀本》）。驢子能忍受重擔和長期缺水，自古就是長途的馱畜（《舊約背景註釋》；[[驢]]）。

古代近東有以兒童為祭的風俗（[[古代近東獻兒女為祭]]）。腓尼基和北非迦太基等地的文獻都描述以兒童為祭的儀式，目的是保證將來多產，所以神的要求對亞伯拉罕來說並不陌生；但這件事也提供了以牲畜代替人作祭物的模式，清楚地把以色列從其他文化中劃分出來（《舊約背景註釋》）。考古學家在基色城的邱壇附近，挖出盛著嬰孩朽骨的粗大陶罐，是獻給亞斯他錄的，房屋基址下也有同樣的罐子（丁良才）。舊約時代有獻人為祭的做法，但不是敬虔之人的所為（《雷氏研讀本》）。

那麼，律法禁止人祭，神為何要亞伯拉罕獻以撒？賈斯樂郝威（《聖經難解經文詮釋手冊》〈命題41〉）給了四條理由：神根本沒有意思要亞伯拉罕殺兒子，第12節的阻止就是證明；利未記所禁的，是把兒女獻給摩洛等外邦神，獻給耶和華不同；亞伯拉罕相信神會使以撒從死裡復活（來11:17-19）；耶和華掌控一切生命，有權賞賜也有權收取。艾基斯（《舊約聖經難題彙編》）說，這事的重心在於亞伯拉罕作為年事已高的父親，是否甘心把唯一的兒子獻給神；他並指出，士師記十一章耶弗他之女的情形也用了『燔祭』一詞，意思是終身奉獻歸神，不是殺死。

### 亞伯拉罕的順服（3-8節）

亞伯拉罕清早起來，備上驢，帶著兩個僕人和他兒子以撒，劈好燔祭的柴，起身往神所指示的地方去了（第3節；[[清早起來]]）。清早表示他即時順服（《雷氏研讀本》）。CT 把他順服的程度列為五項：不與神理論，不為自己辯護，不為以撒求情，不與撒拉商量，清早起來立即行動。

《精讀本》說，若說亞伯拉罕以喜悅的心接受了命令，這是無視父愛的解釋；那一夜他很可能整夜不眠，內心經歷了許多矛盾：神很早就提醒挪亞生命的尊嚴（創9:4-6），今天為何要求他用外邦人野蠻的風俗獻人祭？為何要收回多次起誓的應許、好不容易出生的繼承人？但他克服了所有的矛盾，再一次順從神的旨意。

到了第三日，亞伯拉罕舉目遠遠地看見那地方（第4節；[[第三日]]）。這表示路程花了兩天以上，對亞伯拉罕是心靈上的考驗（CT）；從接受指示算起已是第四日，與出埃及記12:3 在逾越節前四天預備宰殺羊羔的規定一致（《精讀本》）。KC 說，『第三日』是談到復活的日子（太16:21；路24:46；林前15:3-4）。

亞伯拉罕對僕人說：「我與童子往那裡去拜一拜，就回到你們這裡來」（第5節）。這話顯明他的信心（丁良才）；他相信獻上以撒之後，神能叫他復活（來11:17-19；《啟導本》、《雷氏研讀本》）（[[神能叫人從死裡復活（來十一17-19）]]）。KC 說，希伯來書十一章對舊約信徒多記他們憑信所做的事，唯獨對亞伯拉罕記下他心裡所深信的：『他以為神還能叫人從死裡復活』（來11:19）；他周圍沒有死人復活的先例，是認識神、思想神的應許，才得出這個結論。『童子』在希伯來文可指青年人，猶太歷史家約瑟夫甚至認為以撒那時已二十五歲（《串珠》；丁良才也有猶太人傳說二十五歲的說法）。

亞伯拉罕把燔祭的柴放在他兒子以撒身上，自己手裡拿著火與刀，於是二人同行（第6節）。以撒問：「燔祭的羊羔在哪裡呢？」（第7節）亞伯拉罕說：「我兒，神必自己預備作燔祭的羊羔」（第8節；יִרְאֶה，H7200；הַשֶּׂה，H7716）。亞伯拉罕在此不知不覺說了預言（約1:29；丁良才）。這提問雖出自父子親情，也是當今所有人焦急的提問，施洗約翰對前來受洗的基督說：「看哪，神的羔羊」（約1:29；《精讀本》）。『神必自己預備』是亞伯拉罕一生的箴言，也是一切在苦痛絕望中的人的盼望（《啟導本》）。

經文在第6節與第8節兩次說「於是二人同行」，顯明父子同心，聖父聖子也照樣同心成全救人的大工（丁良才；約10:30），也指向父與子同行（KC；約8:29）。以撒對亞伯拉罕的信心和亞伯拉罕對以撒的體恤是很顯著的（《雷氏研讀本》）。

### 築壇與神的介入（9-14節）

到了神所指示的地方，亞伯拉罕在那裡築壇，擺好柴，捆綁他的兒子以撒，放在壇的柴上（第9節），伸手拿刀（הַמַּאֲכֶלֶת，H3979），要殺他的兒子（第10節）。KC 說，經文總是寫他獻了以撒，從來沒有說他『好像』獻了；他的每個動作都不倉促，是審慎、有目標的，到這時我們沒有再聽到以撒說一句話。CT 說，伸手拿刀表明這不是裝裝樣子，而是作到最後一步。以撒精力旺盛，完全可以擺脫年邁父親的捆綁，他卻憑著對父親的信賴和對神的信靠，安靜地交出自己的身體，正如基督無聲地讓人捆綁自己（賽53:7；太26:47-56）（《精讀本》）。

[[耶和華的使者]]（מַלְאַךְ יְהוָה，H4397H、H3068G）從天上呼叫：「亞伯拉罕！亞伯拉罕！」（第11節）。『耶和華的使者』就是神自己（丁良才、CT）；KC 說，這是主耶穌。CT 說，神等到亞伯拉罕伸手拿刀的時候才出聲阻止，因為神知道那有勇氣拿起刀的手，必不會在餘下的過程中躊躇。

使者說：「你不可在這童子身上下手。一點不可害他！現在我知道你是敬畏神的了；因為你沒有將你的兒子，就是你獨生的兒子，留下不給我」（第12節；יְרֵא אֱלֹהִים，H3373、H430G；[[敬畏神]]）。『現在我知道』會讓人問，神事先不知道嗎？賈斯樂郝威（〈命題43〉）說，神以『認知』知道一切，與神以『實證』知道事實是兩回事；亞伯拉罕以行動證明了神早已知道的事，就像數學老師說要試試看49的開平方是多少，演算後宣佈答案是7，雖然老師早就知道。KC 說，這試驗要把亞伯拉罕心裡的信心顯給人看，耶和華本來就知道。

雅各書2:21-24 說亞伯拉罕獻以撒是因行為稱義，信心與行為並行，信心因行為才得成全（[[因行為稱義（雅二21-24）]]；KC）。『獨生的兒子』一詞，賈斯樂郝威（〈命題42〉）說，創25章所提的眾子是庶出，以實瑪利也不能算為神所應許的繼承後裔，『獨生』可以看成『心愛的』、特別的兒子（約1:18；3:16）；神也說過「從以撒生的，才要稱為你的後裔」（創21:12）。

亞伯拉罕舉目觀看，不料，有一隻公羊（אַיִל，H352A；[[公羊]]），兩角扣在稠密的小樹中，他就取了那隻公羊來，獻為燔祭，「代替他的兒子」（第13節；תַּחַת בְּנוֹ，H8478、H1121A；[[公羊代贖]]）。像夏甲看見水井一樣（創21:19），亞伯拉罕看見公羊，神早有預備（《啟導本》）。公羊代替以撒而被獻，說明神的羔羊替代的犧牲（約1:29；《雷氏研讀本》）；《精讀本》說，聖經從此是『代替的歷史』，無數無殘疾的動物代替人的罪而死，指向十字架上基督的代贖。

替代性獻祭的概念在古代近東並不如想像中普及：一般的獻祭不是向神明提供禮物，就是與之建立交通的關係，即使在以色列，買贖長子和逾越節也是主要的例外（《舊約背景註釋》）。CT 的靈意讀法是，公羊預表主耶穌是『神的羔羊』，為世人的罪作了代贖；『角被扣住』預表祂甘心樂意被拘限在人性裡，而不從十字架上下來（太27:40）。

亞伯拉罕給那地方起名叫「耶和華以勒」（第14節；יְהוָה יִרְאֶה，H3068G、H7200；[[耶和華以勒]]），意思是耶和華必預備（《雷氏研讀本》）。這名字可能是根據第8節取的，表示神時常看顧信徒的所需，並提前預備（《精讀本》）。「直到今日人還說：在耶和華的山上必有預備」（יֵרָאֶה，H7200），丁良才說，這成了人在患難中彼此安慰、互相勉勵的俗語，內地會也以這幾個字為標幟。

### 神指著自己起誓賜福（15-19節）

耶和華的使者第二次從天上呼叫亞伯拉罕，說：「我便指著自己起誓」（第15-16節；בִּי נִשְׁבַּעְתִּי，H9907、H7650；[[指著自己起誓]]）。人起誓都指著比自己大的，神沒有比祂更大的可以指著起誓，所以指著自己起誓（來6:13-17；《串珠》）；《精讀本》說，神用自己永恆的生命擔保這個誓言，只要神存在，這個誓言就有效。這是試驗結束後再次確認的祝福，也是最終賜給亞伯拉罕的應許（《精讀本》）。

祝福的內容是：必賜大福；子孫如天上的星、海邊的沙；子孫必得著仇敵的城門；地上萬國都必因你的後裔得福（第17-18節）。KC 說，『海邊的沙』指亞伯拉罕肉身的後裔以色列，『天上的星』指教會的信徒，是他屬靈的後裔；《雷氏研讀本》說肉眼能數算的星約有三千顆，而亞伯拉罕後裔的數目像沙土一樣，幾乎無法數算。

『仇敵的城門』（שַׁעַר אֹיְבָיו，H8179G、H341），既得城門，也就得了全城（丁良才）；字面是佔領仇敵的城池，更深的屬靈意義是將來信他的屬靈後裔，通過彌賽亞用福音征服這個世界，制服所有黑暗勢力（加3:7-9、14；《精讀本》）。《雷氏研讀本》說，這是預期他們會在約書亞帶領下征服迦南。KC 說，萬國得福要等到千年的和平國度，列國那時通過以色列得福。『後裔』（בְזַרְעֲךָ，H2233A）是單數，指基督（加3:16；丁良才、《精讀本》）。

丁良才把亞伯拉罕一生的捨與得整理成七項：

| 他所捨棄的 | 神所應許的 |
|---|---|
| 自己的祖國（創12:1） | 成為一個大國（創12:2） |
| 自己的親戚（創12:1） | 有極大的名聲（創12:2） |
| 自己的父家（創12:1） | 萬族都因他得福（創12:3） |
| 自己的地土（創12:1） | 將迦南地賜他為業（創13:15） |
| 王的賞賜（創14:23） | 神自己作他的賞賜（創15:1） |
| 以實瑪利（創21:14） | 賜以撒為他的後裔（創21:12） |
| 捨兒子的心（本章3節） | 使他的子孫繁多（本章17節） |

### 以撒與基督的豫表對照

本章被讀成豫表（[[以撒豫表基督]]、[[亞伯拉罕豫表父神]]）：亞伯拉罕獻子預表神獻子，以撒預表主耶穌（CT、丁良才）。本文是舊約的各各他事件，與四百年後摩西的獻祭制度同出一脈，預表了兩千年後基督的十字架事件（《精讀本》）。

| 以撒 | 基督 |
|---|---|
| 父親獨生且所愛的兒子（創22:2） | 父神所愛的獨生子（約3:16；太3:17） |
| 親自背負燔祭的柴（創22:6） | 背著自己的十字架走向刑場（約19:17） |
| 任憑捆綁、不掙扎（創22:9） | 甘心捨命（約10:18；賽53:7） |
| 被放在壇上、至死順服（創22:9-10） | 存心順服以至於死（腓2:8） |
| 歷經三日彷彿從死裡得回（創22:4；來11:19） | 第三日真實復活（路24:46；林前15:4） |

### 拿鶴家譜與神的預備（20-24節）

亞伯拉罕回到別是巴居住（第19節；[[別是巴]]）。此後有人告訴亞伯拉罕，他的兄弟[[拿鶴]]的妻子[[密迦]]給拿鶴生了八個兒子：長子烏斯、布斯、基母利、基薛、哈瑣、必達、益拉和[[彼土利]]；他的妾流瑪也生了四個兒子（第20-24節）。丁良才說，拿鶴有八個嫡子和四個庶子，這樣拿鶴、以實瑪利（創25:13-16）和雅各（創35:23-27）都各有十二個兒子。

這份名單說明利百加的來歷（丁良才）：彼土利生了利百加（第23節），利百加後來成為以撒的妻子（《雷氏研讀本》），這是第24章以撒娶妻的伏筆（《啟導本》）。《啟導本》說，亞伯拉罕得到神重申的應許，又聽到兄弟在故鄉的消息，可能因此決定派僕人返鄉為子擇媳（創24:4）。《精讀本》說，這段插入的家譜，是因為拿鶴家族與亞伯拉罕家族是近親，並與繼承與神立約的以撒、雅各等人的血統有關。CT 在這份名單下記了名字的原文字義，如密迦『王后』、拿鶴『鼾睡』、彼土利『神的住處』、利百加『以美迷人』。

KC 說，利百加在這裡出現，是因為以撒的婚姻建立在死而復活的根基之上，正如教會作為羔羊的新婦，是建立在基督死而復活的根基上。CT 在〈神的預備〉列出六項：以撒是神所預備的祭物，摩利亞是神作出預備的地方，亞伯拉罕以信心仰望神的預備，耶和華以勒是實際經歷神的預備，應許賜大福是得著神所預備的福，利百加是神所預備的新婦。

丁良才說，神指著自己起誓，以色列人一切的好處都是借著這誓來的（創24:7；26:3；50:24；出13:5；路1:73；徒7:17），亞伯拉罕此後雖然仍活了五十多年，聖書沒有記載神再顯現於他。

《舊約背景註釋》說，別是巴被視為以色列南面的邊界，位於尼革北部的是巴遺址，考古學家在此挖掘到王國時代到波斯時代有人定居的證據，找不到族長時代的文物，經文也沒有說別是巴是有城牆的城邑。

### 試驗之後（全章）

本章從神的試驗開始，到亞伯拉罕在別是巴居住、拿鶴家譜被帶進來為止。亞伯拉罕順服到伸手拿刀，神在最後一刻出聲阻止，預備了公羊，也再次指著自己起誓（第12-18節）。KC 說，這一章表明神的應許是建立在死而復活的基督上，以撒是這裡的預表；CT 說，神所要的是亞伯拉罕真的敬畏神，甘心把最寶貴的獻上。利百加的家譜為第24章以撒娶妻作了預備（《啟導本》）。
