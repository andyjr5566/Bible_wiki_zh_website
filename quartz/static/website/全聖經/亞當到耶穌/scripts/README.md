# 多音字朗讀波形檢查

這組工具用 Windows 的指定語音朗讀候選文字，再比較 WAV 的頻譜包絡。它適合檢查經文人名等多音字的朗讀差異。

## 準備 cases.tsv

使用 UTF-8 編碼，每列三欄，以 Tab 分隔；不需要標題列。第一欄是原詞，第二欄是以直線符號分隔的替代寫法，第三欄是可留空的經文整句。提供整句時，句子必須含有原詞，替代寫法會逐一代入同一句比較。

例如：

    塞特    腮特|色特    亞當生了塞特。

實際檔案中的三欄之間請使用 Tab 字元。

## 執行

在 repo 根目錄執行：

    python appendix/website/全聖經/亞當到耶穌/scripts/tts_polyphone.py --cases cases.tsv --out result.tsv

結果會同時印在畫面上並寫入 result.tsv。預設使用 Microsoft Hanhan Desktop 語音，亦可用 --voice 指定其他已安裝語音。加上 --wav-dir 路徑可保留中間 WAV；未指定時，檔案會放在系統暫存資料夾並於結束時清除。

## 解讀結果

每列依序列出原詞、最相似的候選寫法、各候選的相似度分數及判定。標為「清楚」時，分數來自詞本身；標為「整句判定」或「拿不準」且有整句時，分數來自整句比較。第一名領先至少 0.02 時標為「清楚」。詞本身的分數差距較小時，工具會把原詞與替代寫法放回整句再比較；整句分數拉開時標為「整句判定」，仍接近或沒有整句時標為「拿不準」。

若結果顯示語音把詞唸成不合經文語境的候選，請在 src/data/speech-fixes.ts 加入修正，只調整送給語音的文字；畫面顯示的經文維持原文。

## 方法限制

頻譜比較只能回答「這次合成的波形比較像哪一個候選」，不能提供音標，也不能證明候選的讀音就是正確讀音。替代寫法應挑選常見、語音引擎熟悉，而且與目標讀音同音的字；選錯候選會讓結果失去意義。語速、語調、句子上下文與合成變化也會影響分數，因此「拿不準」需要人工判斷。
