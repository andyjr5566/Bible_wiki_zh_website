# 立約的儀式

## 定義

創世記第十五章的立約儀式：神要亞伯蘭取一隻三年的母牛、一隻三年的母山羊、一隻三年的公綿羊，以及一隻斑鳩、一隻雛鴿（9節）；三隻大型牲畜各從頭到尾劈成兩半，一半對著一半擺列，只有鳥沒有劈開（10節）。日落天黑之後，冒煙的爐與燒著的火把從肉塊中經過（17節），神就與亞伯蘭立了約。

需要留意兩個常見誤述：其一，經文說的是「三年」不是五年——GT 丁良才《創世紀註釋》註「三年表示精力完成的意思」，CT 註「三年表示少壯、青春」，GT《啟導本聖經創世記註釋》則從實務說明「三年是大多數獻祭用的牲畜成熟的年期」；其二，五樣祭牲不全是母畜——第三隻明說是公綿羊。CT 與丁良才都指出，後來以色列人向神所獻的祭物正是以這五樣動物為主（利未記一至五章），而斑鳩與雛鴿是供力量不夠的人獻祭之用（利五7）。

## 主題發展

### 古代近東的切約習俗

這不是聖經獨有的儀式。GT《舊約背景註釋》列出四類外證，並且各有不同用途：

| 文獻／地區 | 這個儀式的用途 |
|---|---|
| 主前第二千年紀赫人文獻 | 記載類似的步驟，作潔淨之用 |
| 主前第一千年紀部分亞蘭條約 | 用這儀式來咒詛叛盟之人 |
| 馬里文獻 | 描述成立條約的典禮，包括宰殺牲畜 |
| 阿拉拉赫文獻 | 同上 |

背景註釋因此把走過祭牲所構成的小徑理解為雙重象徵行動：既執行土地的盟約應許，也咒詛叛盟者。但它接著留下一句罕見的坦白——「自我咒詛對神究竟有什麼意義，解經家卻難以確定」。這句自承困難值得保留：把神經過肉塊直接讀成「神對自己下咒詛」，是一個解釋，不是已解決的定論。

聖經內部的對照見耶三十四18-19。GT 丁良才、CT、GT《創世記雷氏研讀本》都引該處說明這個儀式的意思是「願那違約者也受到這樣的對待」。丁良才另補一個細節：立約者從肉塊中經過之後，那肉還要被獻上為祭，並由立約的人同吃（創二十一27，耶三十四18-19）。

### 三種立約形式

GT《聖經精讀本──創世記註解》把本章的做法放進更大的分類，指出聖經出現的三種合法立約是：

| 形式 | 出處 |
|---|---|
| 血約 | 耶34:18,19 |
| 鹽約 | 民18:19；代下13:5 |
| 鞋（shoes）約 | 得4:7 |

創十五章屬第一種。聖經精讀本並列出這個儀式「兩種合理的見解」：①它是起誓的儀式，在血、痛苦與死亡面前決志，寧死也要遵守所簽定的條文；②被劈成兩半的動物指立約的雙方，一同從中間走過表示兩人的一致，表明和解與統一的整體意識。兩種見解的分別在於：前者以劈開的牲畜為懲罰的預演，後者以之為雙方合一的象徵。

### 為什麼鳥不劈開

三份來源給了三種理由，難度依次遞增：CT 說「可能因為鳥太小」（利一17）；丁良才說以色列人後來獻祭時也照這規矩行（利一17）；GT《聖經精讀本──創世記註解》則指出日後在摩西律法中鳥同樣沒有被撕開，而是整個焚燒（利一14-17）。三說指向同一件事——不劈鳥不是本章的特例，而是後來祭制中一貫的作法。
