# 逾越（Pesach）

## 定義

出12:11「這是耶和華的逾越節（פֶּסַח，H6453）」、12:13「我一見這血，就越過（וּפָסַחְתִּי，H6452A）你們去」、12:27「越過（פָּסַח，H6452A）以色列人的房屋」——名詞 פֶּסַח（*pesach*，H6453）與動詞 פָּסַח（*pasach*，H6452A）在 STEP 原文詞表中緊密對應，本節 context gloss 分別為「Passover（逾越節／逾越羔羊）」與「to pass over（越過）」。BH 指出「越過」正是「逾越節」一名的由來。

**這個字到底是什麼意思，至今沒有定論。** GT《中文聖經註釋》把幾種說法一併列出：有人認為源自迦勒底文，意思是「和解或撫慰」，但這節禮的整個過程「似乎與獻祭與神和解或撫慰神心無大關涉」；另有人認為是借用埃及文，意思是「擊打」，但「宗教熱誠極深的希伯來人，是否會將一個重要的節期以埃及文來作紀念，卻是一個疑問」；也有學者用賽31:5 的「護」或「保守」來解釋，指這節期的禮儀主要在求神的護佑；還有學者以撒下4:4 的「腿瘸」和王上18:26 的「踊跳」作解，說神在見到門楣有血的時候，「就像單腿瘸了的人跳躍般的越門而過」——「現代的各譯本多從此義」。

**GT《丁道爾》的處理最謹慎。** 它指出這個動詞在王上18:21 是「跛行」之義（「你們心持兩意要到幾時呢」直譯是「你們一拐一拐地走在兩個立場之間要到幾時呢」），同根的形容詞在舊約中往往解作「瘸腿」，因此「有學者胡亂臆測，說這字原來是指一種『跛步舞』」。但它立刻把重點拉回來：「這字不論用得是否合乎字源學，還是不過是個雙關語，對以色列而言總是『越過』或『跳過』的意思；形容神此時在歷史中行事，使以色列得免災禍。」

**GT《舊約聖經背景註釋》另提一個讀法**：「中文『逾越』或英語 Passover 的翻譯，都不能充分表達希伯來原文的意思。從以賽亞書三十一5，可以看出這個動詞有保護的意思……本節不是描繪耶和華『越過』門戶，而是說祂在門口護衛，不容滅命的天使進入（參12:23）。」——若取這一說，門框門楣上的血就有「潔淨門戶，預備神之臨在」的功用。

### 出埃及記

- 本章重點：這個字在本章出現三次——第11節是名詞（「耶和華的逾越節」），第13、27節是動詞（「越過」）。GT《丁道爾》指出第13節是「全本舊約對這節期名字惟一的解釋」。
- 與本章關聯：GT《丁道爾》把名詞與動詞的先後說清楚：「希伯來文 pesah 一詞本身，大概主要是指祭物，其次才是指以這祭物為中心的節期。因此直譯應作『這是耶和華的逾越羔羊』。」

## 主題發展

**這個字後來怎麼發展，新約自己接了下去。** KC 把「越過」這個字義直接接到十字架上：門框上的血意味著審判已經在此發生過——「凡有基督的血遮蓋人的罪之處，神的審判就越過那人；這也正與『逾越』（Passover）這個字有關，因為它的意思就是『越過』」。KC 接著把這個等式寫得更直白：「若我們相信基督，我們的逾越節羔羊，已經替我們被殺，那麼我們的生活理當成為一個不容罪（酵的象徵）存在的筵席。」CT〔靈意註解〕引的是同一段經文——「我們逾越節的羔羊基督已經被殺獻祭了」（林前五7）。GT《啟導本聖經腳註》把這個轉換講成一組對應：「羊羔的血須塗在門上，以保護一家不受災害；基督的血也遮蓋我們的罪，作我們永遠的贖罪祭」（來十11；約壹一7）。
