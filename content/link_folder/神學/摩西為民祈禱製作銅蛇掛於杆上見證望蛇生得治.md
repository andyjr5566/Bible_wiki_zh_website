# 摩西為民祈禱製作銅蛇掛於杆上見證望蛇生得治

## 定義

在希伯來律例與神蹟解厄的歷史紀錄中，於南蠻旱漠被火蛇慘痛大害追剿至崩的以色列百姓，終識認口舌傲慢對戰天主的大惡而群奔投赴長宰摩西座前，垂顏悔怨苦籲乞請向天老祈止殃害；慈祥為父的靈王摩西寬意代請，耶和華奇謀並非當即施放術法剪盡全谷惡虺，反而付下超越億秋靈理的奧妙偉言——密旨把具有火蛇恐怖厲態卻絕無半毫炎性與死骸劇毒的明鍛金亮「銅蛇」，揚烈擎於筆立高升的「旗杆」之巔；全軍無論垂困將卒，單靠誠念「一望」是揚立的吉象，立刻生靈復春、蛇毒頓盡得治；斯事為長世宣揚不滅的預表榮威：被釘掛高升神木的耶穌基督承擔罪容毫無犯罪，向舉目仰盼的苦沉靈性沛下惟此一路的起死新康大活。

- 本章重點：因遭猛龍噬斃悔過苦伏摩西代哀，天王出諭手製赤耀純金銅蛇掛立高杆頂端，遍地被毒眾生一舉目盼望立起得救新榮。
