# 巴蘭詩歌中的亞述指哪一個

## 定義

民數記24:22、24 兩次提到亞述。STEP 顯示原文是 'a.Shur（H804G），morphology 標為 HNpl（專有地名），簡要義域是 ash.shur: Assyria。但這個名字在本章到底指誰，四套來源給出五種互相衝突的答案。

| 來源 | 判定 |
|---|---|
| CT | 包括亞述和巴比倫兩國；亞述先滅北國，巴比倫約百年後滅南國 |
| GT 丁良才《民數記註釋》 | 「就是亞述和巴比倫的總稱」 |
| GT《民數記串珠聖經註釋》 | 或作亞書利，是迦南的一族，不是把以色列擄去的大國 |
| GT《啟導本聖經註釋》 | 住在西奈半島北部的小部落亞塞爾，後來為腓尼基人所滅 |
| GT《舊約聖經背景註釋》 | 最有可能是創世記二十五18 中與以實瑪利族有關的亞述 |
| BH | 古代近東的亞述帝國 |

**分歧的關鍵是年代。** GT《舊約聖經背景註釋》把理由講得最清楚：「這名所指的不太可能是主前第七、八世紀時，雄霸全古代近東的新亞述帝國。因為這樣一來，這 * 神諭的焦點（甚或其寫作日期）就變得太後期了。」它同時也不接受另一個極端：亞伯拉罕和基土拉所生的亞書利族（創二十五3）「似乎不會大到能夠擊敗基尼的地步」。

**串珠站在「小族」那一邊。** GT《民數記串珠聖經註釋》寫得很直接：「「亞述」：或作亞書利（創25:3; 撒下2:9），是迦南的一族，而不是把以色列擄去外邦的大國。」

**丁良才與 CT 站在「帝國」那一邊**，並且把亞述與巴比倫合看：CT 說「『亞述』亞述與巴比倫同屬迦勒底人，故在此包括亞述和巴比倫兩國」，還舉出波斯國的王也被稱為亞述王（拉六22）作為名稱可以延伸使用的例子。

**STEP 幫不上這個忙。** 它能確認的只有詞形與專名標記；亞述在本章指哪一個政治實體，屬於歷史判斷，不是 morphology 能決定的。

## 按書卷累積

### 民數記

<!-- accumulation:民數記:24:start -->
#### [[04 民數記/第24章|第24章]]
- 本章重點：民數記24:22、24 的「亞述」，四套來源給出新亞述帝國、亞書利、亞塞爾、亞述加巴比倫等五種互相衝突的判定。
- 與本章關聯：這是本章最實在的一場爭論，關係到整篇詩歌的年代定位。GT《舊約聖經背景註釋》指出若讀成新亞述帝國，神諭的焦點與寫作日期就變得太晚；串珠則主張是迦南的一族亞書利。STEP 只能確認 H804G 的專名標記，判斷仍在註釋層。
