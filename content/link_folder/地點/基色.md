# 基色

## 定義

基色不在五王聯軍裡，也不在約書亞的進軍路線上。它出現在書10:33，是因為基色王荷蘭主動上來幫助拉吉，結果連人帶軍被殺。經文只說王和他的民被擊殺，沒有說城被攻取。

### 位置

CT 的原文字義給「基色」部分、「荷蘭」崇高的，並說基色位於耶路撒冷西北約二十九公里，而經文用『上來』表示基色的地勢比拉吉低。GT《約書亞記研經資料》說字義是「部分」，遺址為 Tell el Jezer（耶塞廢邱），位於西方往耶路撒冷的要道、距離約30公里。GT《綜合解讀》說基色扼守亞雅崙谷西面的入口。

### 考古與文獻

GT《華爾頓約書亞記背景注釋》說基色的遺址是哲色遺址（Tell Jezer），占地三十三英畝、位於亞雅崙谷西端，距離本段的軍隊集結地二十五至三十哩；並說其軍隊雖失敗、城卻未被攻取，法老梅雷他攻取諸城的名單中包括了基色，它也是亞馬拿書函中最重要的迦南城市之一、文獻中有十封信件是君王雅帕胡寫給法老的。

### 城還在

GT《綜合解讀》說基色王前來幫助拉吉所以約書亞消滅了他們，但並沒有立刻前去攻佔他的城市。GT《啟導本》說基色是南部諸城中最強大的城邑，並提到後來這座城被埃及人攻取、當作所羅門王的婚禮之禮。BH 說書10 並沒有說基色本身被攻取，基色有一段時間仍是迦南人的地。

- 本章重點：第33節「那時基色王荷蘭上來幫助拉吉，約書亞就把他和他的民都擊殺了，沒有留下一個」。CT 原文字義給「基色」部分、「荷蘭」崇高的，說基色位於耶路撒冷西北約二十九公里，並說『上來』表示基色的地勢比拉吉低。GT《研經資料》說遺址為 Tell el Jezer、位於西方往耶路撒冷的要道；GT《華爾頓約書亞記背景注釋》說基色占地三十三英畝、位於亞雅崙谷西端，其軍隊雖失敗、城卻未被攻取，法老梅雷他攻取諸城的名單中包括了基色，它也是亞馬拿書函中最重要的迦南城市之一；GT《綜合解讀》說基色扼守亞雅崙谷西面的入口、並不在約書亞進軍的路線上；GT《啟導本》說基色是南部諸城中最強大的城邑。BH 說書10 沒有說基色本身被攻取。
- 與本章關聯：本章唯一一個王被殺、城卻沒有被攻下的例子。它插在拉吉那一段中間，說明南征清單的重點是打垮各城的統治力量，不是逐一佔領城池。

#### [[06 約書亞記/第12章|第12章]]
- 本章重點：第12節「一個是基色王」。CT 說基色位於耶路撒冷西北約二十九公里，原文字義是「部分」。
- 與本章關聯：BH 說基色的位置俯瞰沿海平原與山地之間的主要交通與貿易路線；它的王何蘭在約書亞的戰役中前來幫助拉吉，結果與他的軍兵一同被殺（書10:33）——迦南的援軍救不了在神審判之下的城。
