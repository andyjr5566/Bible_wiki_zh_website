## 本章整理

### 四王與五王的戰爭（1-12節）

這段經文記載了聖經裡的第一場戰爭。由[[基大老瑪]]所領導的東方四國聯盟，控制了約但河平原的五座城市長達十二年；到了第十三年，這五座城市決定聯手背叛。於是，東方四王在第十四年沿著外約但和南地的軍事路線出兵討伐，最後在[[西訂谷]]擊敗了五王，並且把所多瑪和蛾摩拉洗劫一空。這個過程反映了古代城邦的一種政治模式：強國靠著收取貢品來維持宗主國的地位，一旦小國背叛，就會遭到殘酷的軍事鎮壓。GT《聖經精讀本》補充說明了這場背叛的背景：巴勒斯坦地區許多弱小的國家，很早就被美索不達米亞一帶的強國給控制了，這些被征服的國家每年都必須上繳固定數量的貢品。西訂谷的五王迫於無奈連續進貢了十二年，可能到了第十三年覺得受夠了，才聯合起來拒絕進貢；精讀本也判斷，他們發起這場叛變的動機「並不是因為他們自己變得強大了，而是出於貪婪和驕傲」。

```mermaid
    G --> H["西訂谷<br/>（四王與五王展開決戰）"]
```

我們要注意的是，經文只給了地名的順序，並沒有詳細交代軍隊行進的方向，所以各家註釋書所還原出來的路線不太一樣：GT《舊約背景註釋》認為四王是順著「王道」——也就是約但河谷東邊那條主要的南北大道——從北往南一路打下來，到了亞喀巴灣一帶之後，再轉向西北去攻打加低斯巴尼亞；GT《串珠聖經註釋》卻說聯軍「首先北上進軍大馬色，然後轉向約但河東岸，又南下到加低斯，最後再北上和五王交戰」；而 GT《創世記雷氏研讀本》則提出另一種說法，認為入侵的路線是向西北穿過南地，然後再折返回到西訂谷。這三種說法在起點和轉折路線上雖然有衝突，但它們都看出了同一個戰略邏輯：東方四王先是清除約但河東岸和南地各個部落的勢力，為的是要切斷五王可能的外援和退路，最後才把五王逼進西訂谷進行決戰。GT《舊約背景註釋》也指出，像這種依照時間順序來編排行軍路程的寫法，正是古代中東地區記錄歷史文獻的一貫格式。

這四位國王的名字和地區，都很符合古代中東的語言環境；但到目前為止，我們還沒有辦法可靠地證實「暗拉非」就是歷史上那位著名的「漢摩拉比」國王，也沒有辦法在現存的古代君王名單中，把這四位國王一個一個對號入座。關於這一點，各家註釋書的意見分歧很大：GT 丁良才直接把1901年在書珊城出土的那塊刻有二百八十五條律法的黑色大石碑，當作是暗拉非所制定的法典，還稱讚裡面的內容「大半都是很文明的規定」；GT 李道生的《舊約聖經問題總解》雖然也提到了這塊石碑，卻指出巴比倫歷代國王的名單裡根本沒有暗拉非這個名字，雖然許多歷史學家認為暗拉非就是漢摩拉比，但這個說法「仍然缺乏足夠的證據」；GT《創世記雷氏研讀本》則是從年代學的角度直接否決了這個可能性，認為「他不可能是罕摩拉比，因為罕摩拉比是年代比較晚期的人」。我們在整理這些資料的時候，應該把「這塊石碑確實存在」與「這塊石碑的主人是不是暗拉非」這兩件事分開來看，詳細討論可以參考[[創世記14章四王的歷史辨識]]。

聖經特別說明，西訂谷就是現在的[[鹽海]]（死海），並且那裡有許多的石漆坑。死海地區從古時候開始就以出產瀝青而聞名，BH 指出這些天然的瀝青礦床在古代被用來做防水材料和建築用途，是非常有價值的資源。至於第10節那句「有掉在坑裡的」該怎麼解釋，各家註釋的看法分成了兩派，而且差異不小：GT《串珠聖經註釋》把石漆解釋為「一種黏性物質，就像是修補馬路用的柏油一樣」，任何人和馬掉進去就會被黏住無法逃脫，CT 與 BH 也都是把它讀成「跌進坑裡遇難」；但是 GT《舊約背景註釋》卻從原文的用字反推——這裡翻譯成「坑」的那個字，跟舊約其他地方用來形容「水井」的字是同一個字，這種字通常是指人工挖掘出來的地方。因此，背景註釋認為西訂谷因為有許多開採瀝青的礦坑，反而成了五王戰敗時的避難所：「他們是『自己躲進坑裡去』，而不是『不小心掉進坑裡去』」。經文本身留下的線索，似乎也支持後者的說法是合理的：因為到了第17節，所多瑪王居然還活著，甚至出來迎接亞伯蘭。不過，CT 根據同一節經文所作的靈修觀察，並不受這個翻譯分歧的影響——五王當初選在西訂谷擺開陣勢，本來是想藉著地形的險要來打勝仗，結果反而害自己陷入了絕境，這正是「人所依仗的東西，往往反而成了人自己的陷阱」。詳細說明可以參考「石漆」條目。

STEP 原文資料顯示，這一小段話在原文裡是寫作「一坑又一坑的石漆」；接著用的動詞 וַיִּפְּלוּ（H5307G），意思就是「他們落下」。這正是中文和合本翻譯為「許多石漆坑」和「有掉在坑裡的」最直接的文字依據；至於背景註釋所提出的「避難」讀法，則是在這個字面意思之上，結合了後來所多瑪王依然存活的情節，所作的一種場景還原。

### 羅得被擄與亞伯蘭追救（12-16節）

在上一章（第13章），聖經只說羅得漸漸挪移帳棚直到所多瑪；但在這一章，聖經已經直接說他「正住在所多瑪」了。當這座城市戰敗的時候，他跟著他所有的財產一起被敵人擄走，這顯示他當初選擇住在哪裡，現在就必須承擔那座城市的政治風險；這是[[羅得的世俗選擇與後果]]的真實延續。至於把羅得被擄這件事，直接說成是神對他貪愛世界的懲罰，這是後來的註釋書根據敘事的發展所作的神學解釋，經文本身並沒有直接這樣宣告。

> [!quote] KC
> 我們若因世界的享樂吸引而選擇住在世界裏、照它的樣式生活，就不要指望能逃過它的苦楚。

這是聖經裡第一次稱呼亞伯蘭為「[[希伯來人]]」。這個稱呼可能跟他的祖先「希伯」有關，也可能意思是「越過大河的人」或「從河那邊來的人」；還有些學者把它跟古代文獻中提到的「Habiru（哈比魯人）」拿來作比較；GT《啟導本》還指出，這個稱呼一開始其實是非以色列人給他們取的，裡面帶有一點輕蔑的意思，這就像是新約時代「基督徒」這個稱號一開始的由來一樣。各種說法之間的關係目前還有很多討論，詳細內容可以參考[[「希伯來人」的意義]]。

得知消息後，亞伯蘭帶領著自己家裡出生、受過專業訓練的三百一十八名壯丁，聯合了幔利、以實各、亞乃這三位盟友，一起去追擊敵人。這個人數在當時到底算不算多？註釋書給出了實際的考古證據：GT《串珠聖經註釋》指出，根據埃及亞瑪那地區出土的主前1400年信件記載，當時兩個國家交戰的軍隊人數，有時候只有二十到五十人而已；GT《舊約背景註釋》更指出，用來形容這批「壯丁」的那個特殊字眼，在舊約聖經其他地方再也沒有出現過，但卻出現在主前十五世紀的一封古代信件裡，並且判斷這樣一支由家丁組成的軍隊，絕對有實力去對抗當時當地任何一支武裝部隊。丁良才則從這三百一十八個男丁反推，認為亞伯蘭的家裡一定有一千多人，「可見他當時已經是個大富翁，甚至有了一方之霸的氣勢」。這三百一十八人只算亞伯蘭自己家裡的壯丁，並沒有把盟友的人數算進去，所以我們不能用這個數字來計算他們當時的全部兵力，詳細說明可以參考「三百一十八人」條目。

原文資料把這批壯丁的兩項身分並排在一起寫：他們是受過訓練的人（H2593），也是在他家中出生的人。這說明這批人絕對不是危急時臨時花錢雇來的傭兵，而是亞伯蘭家裡平時就已經受過嚴格軍事訓練的忠心成員；第13節另外把幔利三兄弟稱為跟亞伯蘭「結盟」的夥伴，所以盟友確實不包含在那三百一十八人裡面。

亞伯蘭在夜間把部隊分成幾路發動攻擊，一路從但追到了大馬士革北邊的何把，成功把所有的人口和財物全都搶了回來。第15節和合本翻譯為「大馬色[[面東定向的左右方位|左邊]]的何把」，丁良才特別註明「左邊就是北邊」，這也是呼應了創世記13:9的方位習慣——古代以色列人是面對著日出的東方來決定方向的，所以左邊就是北邊、右邊就是南邊；呂振中的譯本就直接把它翻譯成「大馬色北邊」，這兩種翻譯指的其實是同一個方向。至於何把到底離大馬士革有多遠，註釋書給的數字相差了十倍以上：GT《串珠聖經註釋》說在大馬士革以北「約二百三十公里（一百五十哩）」，但丁良才卻說「相差大約只有二三十里路」。既然經文沒有給出確切的距離，我們就把這兩種說法並列出來參考就好。中文的註釋書從這段英勇的故事裡，整理出了[[亞伯蘭的愛心與勇氣]]：他對人有愛心、對神有信心，並且深信神一定會為他爭戰（見出14:14）。KC 還指出了亞伯蘭在戰術上的高明——他把部隊分開，從不同的方向同時發動攻擊，這會讓他的小部隊看起來像是一支龐大的軍隊，而且他還懂得選擇在夜間進行突襲；GT《舊約背景註釋》也說，這種夜間突襲的戰術，早在士師時代的埃及文獻和赫人的典籍裡，就已經可以找到真實的案例了。

第12節與第16節還透過原文動詞的巧妙運用，把整場營救行動寫成了一次完美的逆轉勝：東方四王「帶走」了羅得和他的「財物」，而亞伯蘭則是「帶回」了「全部的財物」，接著又用同一個動詞再次強調他「帶回」了羅得和他的財物。聖經作者不是只說亞伯蘭打贏了，而是清清楚楚地交代：敵人奪走了什麼，亞伯蘭就原封不動地把它們全部帶回來了。

### 麥基洗德：撒冷王與至高神祭司（17-20節）

[[麥基洗德]]這個人同時擁有兩個身分：他既是撒冷王，也是至高神的祭司。他的名字在希伯來書7:2被解釋為「公義王」（請參考[[「麥基洗德」名字含義]]），而[[撒冷]]這個地方的名字則跟「平安」有關（請參考[[「撒冷」名字含義]]）。撒冷通常被學者認為就是後來的耶路撒冷，不過背景資料也保存了另一種少數人的看法，認為它可能位在示劍附近。GT《啟導本》指出，這是聖經第一次提到耶路撒冷，並且引用了十九世紀末在埃及出土的亞馬拿泥版（這是主前十五世紀埃及法老跟巴勒斯坦等地國王的通信紀錄），證實了耶路撒冷這座城市在亞伯蘭的時代早就已經存在了；GT《創世記雷氏研讀本》也另外舉出了大約主前2300年的特勒瑪迪克泥版，裡面同樣記載了耶路撒冷和幾百個其他的地名與人名。

創世記把麥基洗德當作一個有血有肉的歷史人物來描寫——他出場迎接、開口說話、為人祝福、並且接受了十分之一的奉獻。後來在猶太人的傳統裡，有些人認為他就是挪亞的兒子閃，也有些人認為他是天使或是基督在舊約的顯現；但創世記本身並沒有提供這些神奇的身分。GT 賈斯樂郝威的《聖經難解經文詮釋手冊》把這件事解釋得很清楚：把他看成天使或是基督的顯現是不可能的，因為希伯來書的作者是把麥基洗德當作基督的「預表」，而在創世記裡，他完全是以一個平凡普通歷史人物的姿態出現，用一般人正常的舉止和態度在跟亞伯蘭對話。詩篇110:4與希伯來書第7章是以他來當作基督同時擁有君王與祭司職分的預表（請參考[[麥基洗德與基督豫表]]），並不是說他本人就是基督；詳細討論可以參考[[麥基洗德的身分]]。

至於麥基洗德帶出來的「餅和酒」到底代表什麼功能？各家註釋書給出了四種不同層次的解讀，而且彼此之間還有一些拉扯：
1. 最表面的字面層次是軍需補給：CT 說這是為了「慰勞凱旋歸來的軍隊」，丁良才也引用了聖經中其他用食物迎接趕路者的例子（見創23:34、撒上17:17、尼13:2）。
2. 第二個層次是政治上的意義：GT《舊約背景註釋》指出，大家一起享受宴席，通常代表雙方簽訂了和平協議，赫人的條約裡就曾提到打仗時必須供應盟友食物；因此，麥基洗德帶著食物來，是急著想要跟亞伯蘭這支剛剛打了大勝仗的軍隊建立友好的關係，而「亞伯蘭則藉著送上十分之一的戰利品來表示降服，等於是間接承認了麥基洗德在當地的地位」。
3. 第三個層次是屬靈的供應：CT 在靈意註解中說，餅能給人滋養和力量，酒能讓人舒暢和受到激勵。
4. 第四個層次才是關於聖餐的預表。但 KC 明確反對把這裡的餅和酒直接等同於新約的主餐。我們在閱讀時，應該把這些神學解讀跟這頓飯在當時的實際慰勞功能分開來看，詳細討論請參考[[麥基洗德的餅和酒是否預表聖餐]]。

第19到20節在原文裡，連續用了三次同一個代表「祝福」的字根（H1288），把這三句話緊緊連在一起：麥基洗德「祝福」亞伯蘭，宣告亞伯蘭是「蒙福」的，最後再宣告賜下這場勝利的至高神「當受稱頌」。這表示這份祝福並沒有停在亞伯蘭身上，最後還是迴向了那位賜下福氣與勝利的神。

麥基洗德宣告，是至高神把敵人交在亞伯蘭手中，他把這場勝利的榮耀完全歸給了神。他對神所使用的稱號「至高的神」（原文是 El Elyon），GT《舊約背景註釋》指出，這是古代迦南文學裡對主神「伊勒」的一種普遍稱呼；GT《啟導本》也說「至高神」是古代迦南一帶對主神常用的稱號。但是，亞伯蘭在第22節回覆的時候，卻刻意把這個稱號直接加上了「耶和華」的名字；這等於是他當著兩位外邦國王的面，勇敢見證了他所信仰的獨一真神。STEP 原文資料顯示，第19節和第22節都完整使用了「至高的神，創造（或擁有）天地的主」這串稱號；亞伯蘭在第22節只是在最前面清楚加上了「耶和華」。這句稱號裡用來形容神的那個動詞（H7069），同時包含了「取得」和「擁有」的意思，這剛好解釋了為什麼中文聖經有時翻譯成「[[天地的主]]」，有時又翻譯成「創造天地的主」。

亞伯蘭把他所奪回來的戰利品，拿出了[[十分之一]]送給麥基洗德；希伯來書7:4證實這確實是戰利品的十分之一，並且從「麥基洗德為亞伯蘭祝福」以及「亞伯蘭向麥基洗德納十分之一」這兩件事，來論證麥基洗德的地位其實是高於亞伯拉罕的。GT《聖經精讀本》補充了這個制度的歷史背景：十分之一原本是當時的人們，為了供養那些在神廟裡服事的人，而自發性拿走家產或農作物十分之一來上繳的一種稅金。這在當時是一種不成文的習俗，也廣泛流行在閃族文化圈以外的地方；直到後來，它才在摩西的律法中正式成為有明文規定的法律。所以，亞伯蘭奉獻十分之一這件事遠遠早於摩西律法，我們不能因此就把這章經文說成是神在當時就已經頒布了普遍的什一奉獻規定。

### 拒絕所多瑪王的財物（21-24節）

所多瑪王向亞伯蘭提出了一個條件：只要把人還給他，所有的財物都讓亞伯蘭帶走。GT 丁良才指出，這個提議其實完全符合當時的風俗習慣——打贏的人拿走財物，原本的主人把人帶回去。但是，亞伯蘭卻已經向「[[天地的主]]、[[至高的神]]耶和華」起誓，他連一根線、一根鞋帶都不願意拿；他給的理由很清楚：他不希望所多瑪王以後到處跟別人炫耀，說是所多瑪王使他致富的；詳細討論請參考[[亞伯蘭拒絕所多瑪財物]]。亞伯蘭不僅把麥基洗德口中的那位至高神，明確地指認為耶和華，他更刻意把自己的財富來源，跟罪惡的所多瑪王完全切斷。GT《創世記雷氏研讀本》從政治後果的角度，補充了另一個層次的考量：亞伯拉罕之所以拒絕收下這些財物，是怕自己以後會對所多瑪王欠下任何人情，以免所多瑪王將來想要重新奪回當地霸主地位的時候，會逼迫亞伯拉罕作他的附屬國。GT《舊約背景註釋》甚至大膽推測，他們雙方的這場談判「可能還包括了一份把這些條件正式寫下來的書面合約」，並且認為那份合約的格式很可能就跟這章經文的編排方式一樣，甚至它可能就是寫成這章經文的原始素材。

KC 和其他中文註釋書，把這兩位國王先後出來迎接亞伯蘭的過程，解讀為一種「[[得勝後的試探]]」：亞伯蘭先是領受了屬神的祝福，接著馬上就要面對巨大財富的誘惑。這是一種從故事先後順序所引申出來的屬靈應用。不過，經文自己明說的拒絕理由，依然是為了避免讓所多瑪王搶走了使他富足的名聲。

| | 麥基洗德（撒冷王） | 所多瑪王 |
|---|---|---|
| 身分 | 至高神的祭司 | 罪惡之城的國王 |
| 他帶來了什麼 | 帶著餅和酒，以及對神的祝福 | 提出「人歸我，財物歸你」的誘人條件 |
| 亞伯蘭的回應 | 恭敬地獻上戰利品的十分之一 | 連一根線、一根鞋帶都堅持不拿 |

亞伯蘭雖然為自己發了誓，放棄了龐大的戰利品，但他並沒有剝奪他那三位盟友（亞乃、以實各、幔利）應得的那一份獎賞，他也承認自己手下的僕人已經吃掉的那份食物。這顯示他把個人的信仰誓言，與別人應有的權利分得非常清楚。GT《聖經精讀本》把這一節經文讀成了一個對基督徒的警告：信徒最容易犯的錯誤，就是拿自己的信仰標準去強迫別人，甚至定別人的罪；一個真正的信徒，應該像亞伯蘭一樣，懂得去保障別人正當的自由和權利。原文的對話也把這條界線畫得非常清楚：第21節所多瑪王說「把人口給我」、「財物你自己拿」；但第24節亞伯蘭卻回答「讓他們拿他們自己的那一份」。這裡的「人口」在原文指的是被擄走的人，並不是抽象的「靈魂」；亞伯蘭拒絕的只是他自己那一份所得，他並沒有越俎代庖去替他的戰友拒絕。

丁良才把整章關於亞伯蘭的表現歸納成了八大優點，讓我們可以一次看清他分散在各節經文裡的品格：

| 品格 | 出現在哪一節 |
|---|---|
| 忠心 | 第13、24節 |
| 愛心 | 第14節 |
| 膽量 | 第14節 |
| 聰明 | 第15節 |
| 寬宏 | 第16節 |
| 虔誠 | 第18-20節 |
| 樂施 | 第20節最後一句 |
| 節制 | 第21-23節 |

GT《啟導本》用一句話，漂亮地總結了這章經文在整卷創世記裡的重要位置：這是聖經歷史的主流發展，第一次與外邦歷史產生了交錯；而「亞伯蘭雖然活在這個世界上，卻不屬於這個世界；他會為了家人去戰鬥殺敵、也會跟外邦人結盟，但他心裡時刻掛念的，依然是神對他的交託」。KC 的提醒則更加貼近我們的生活：得勝的時刻，往往也是最危險的時刻——亞伯蘭正是因為沒有選擇與世界妥協聯合，他才能夠真正地勝過世界（見約翰一書5:4）。
