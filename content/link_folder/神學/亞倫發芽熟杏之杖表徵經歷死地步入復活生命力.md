# 亞倫發芽熟杏之杖表徵經歷死地步入復活生命力

## 定義

原本自枝葉盛怒枯竭死斷的手把殘木，在經歷了一夜安放於天主聖顏見證之前後，能於次朝奇異般迸露青青新兆、綻破芬白英姿並垂成圓滿的甜密豐實杏仁果粒；這一壯大奇想與無匹真像深厚表意著：事得造物上天真正奉持跟蒙認權祿之原貌，決不可妄賴屬血肉自然的才能思才強攻奪權，必須真實自降扎下虛空世亡黑谷，始在復活至高聖恩大能與長存新生聖榮下展發無法攻奪的真純侍者天工。

#### [[04 民數記/第17章|第17章]]
- 本章重點：老舊乾竭權杖經過一宵暗谷長安而迎光發動三代繁茂生息（出芽結杏），展發復活豐盛生命大跡。
- 與本章關聯：向萬世昭宣上帝國度底裡之榮貴職掌決不可依恃血氣鬥勇豪語搶佔，純憑陷於苦營經歷死與復活後天恩所灌溉成全之生命偉力。
