# 蓬頭散髮（表羞辱與蒙罪嫌）

## 定義

民數記五章18節：「祭司要叫那婦人蓬頭散髮，站在耶和華面前。」

STEP 原文資料顯示這四個中文字在原文是三個詞：動詞 פָּרַע（pa.ra，H6544B），STEP 的 context gloss 作「he will let loose」；受詞是 רֹאשׁ（rosh，H7218A，詞典義 head）；中間還有「那婦人」。CT 的原文字義正好把這三個詞逐一列出：「蓬頭散髮」放鬆（首字）、婦人（次字）、頭頂（末字）。

這個動作代表什麼，四份來源給了四種讀法：

| 來源 | 讀法 |
|---|---|
| CT | 若果屬實乃是羞辱自己，因頭髮是女人的榮耀（林前11:15）；另有人認為表示妻子不順服丈夫作頭的權柄 |
| GT 丁良才 | 「乃是表明羞恥的意思」 |
| GT《舊約聖經背景註釋》 | 在其他經文中這是哀哭的表示，女子要採取哀哭的姿態直到主的判語顯明 |
| KC | 長頭髮是奉獻的記號（林前11:15），解開是因為她的奉獻正被質疑（參利13:45） |

BH 的說法接近背景註釋：解開頭髮在古代以色列文化中是哀悼或蒙羞的記號，象徵這婦人此刻的脆弱處境，也象徵真相即將被揭開。

## 主題發展

CT 的〔話中之光〕把這個動作放進整場儀式的目的裡：「蓬頭散髮就是站在蒙羞的地位上，等候神來給她表白，一面使自己恢復名譽，一面也使丈夫卸下心中的重擔，目的要把神的百姓恢復到平靜與安息裡。」

值得注意的是這個姿態是暫時的：判語一出，若她清白，羞辱的姿態就結束，取而代之的是「免受這災，且要懷孕」（v28）。換句話說，蓬頭散髮本身不是刑罰，是等候判決期間的一種姿態。
