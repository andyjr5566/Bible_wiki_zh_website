# 剃頭刀不可過頭（拿細耳人長髮）

## 定義

第二條禁令：「在他一切許願離俗的日子，不可用剃頭刀剃頭，要由髮綹長長了」（v5）。CT 說明「用剃頭刀剃頭」指剔除頭髮的全部或一部，「髮綹」指結髮成辮子。

長髮在這裡是可以看見的標記。第7節把它說得很清楚：「因為那離俗歸神的憑據是在他頭上。」BH 稱它為 consecration 的外在記號，作用與割禮、洗禮這類可見的記號相同，是誓願本身持續的提醒。

**長髮到底代表什麼**，各家給的答案並不一致，GT 內部就有兩種：

| 來源 | 讀法 |
|---|---|
| GT 丁良才（說法一） | 力量的奉獻。以色列人以為茂盛的頭髮顯明完全的體力（撒下14:25-26），也以禿頭為瑕疵；留長髮「是表明他們把一切的精神力量全獻於主」 |
| GT 丁良才（說法二） | 為主受辱。「也有人以為是表明他們情願為主受羞辱的意思（林前十一14），不隨世界的潮流和看法」 |
| CT | 為主受辱。「男人若有長頭髮，便是他的羞辱」，但拿細耳人「甘心以辱為榮」 |
| KC | 交出權柄。男人代表神在地上的權柄，長髮是倚靠與順服的記號；「在人眼中這不是尊榮的位置，在神眼中卻是」 |
| GT《聖經精讀本》 | 承認主權。頭象徵在這人之上有主掌管他（林前11:3-10），留髮「表示承認神的主權，並要絕對順服神的命令」 |

這條禁令與林前11:14 的張力，見[[拿細耳人長髮與保羅禁令的張力]]。

CT 另提醒一件容易誤讀的事：留長髮不等於不修邊幅。「不是雜亂無章，不修邊幅，而是整潔的表明聖潔。接受羞辱是心志上的事，整潔是生活上的事。」

### 民數記

#### [[04 民數記/第6章|第6章]]
- 本章重點：本章第5節與第7節規定離俗期間不可剃頭，長髮是離俗歸神的可見憑據。四套來源對長髮的意義並不一致：GT 丁良才並列「獻上力量」與「為主受辱」兩說，CT 取受辱、KC 取交出權柄、GT《聖經精讀本》取承認主權。
- 與本章關聯：以外在記號表徵內在奉獻，同時成為新舊約之間一處具體張力（林前11:14）；參孫的失敗使這條禁令在士師記留下最明顯的反面例證。

## 主題發展

參孫是這條禁令最著名也最反面的例子。KC 指出「參孫作為拿細耳人的力量在於頭髮」，而「倚靠順服的位置一向就是有力量的位置」；當他不再倚靠神而倚靠一個女人時，力量隨頭髮一起失去（士16:17-21）。CT 把參孫的結局列得更完整：與外邦人聯姻、飲酒、縱慾、接觸死獅及死人，以至剪了頭髮，至終被剜雙眼。

KC 還注意到剃髮之後的下一句：頭髮剃掉以後「也開始重新長出來」（士16:22），所以剃髮既是失去記號，也是恢復的起點。

STEP 原文資料顯示，第5節的「頭」是 ro.Sh/o（H7218A，詞典形 rosh），第9、11、18節也都用同一個字；而「離俗」在第5節與第7節是同一個名詞 ne.zer（H5145）。「離俗歸神的憑據是在他頭上」在原文裡就是這兩個字擺在一起。
