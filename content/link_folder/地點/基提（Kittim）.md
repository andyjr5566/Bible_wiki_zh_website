# 基提（Kittim）

## 定義

民數記24:24：「必有人乘船從基提界而來，苦害亞述，苦害希伯」。

**STEP 給的三個字。** 「基提」是 ki.Tim（H3794H，簡要義域 kit.ti: Cyprus），morphology 是 HNpl；「船」是 ve./Tzim（H6716，簡要義域 tsi: ship）；而和合本的「界」在原文其實是 mi./Yad（H3027K，簡要義域 yad: hand），字面是「從基提的手」。

**這是哪裡。** GT《舊約聖經背景註釋》給了最完整的說明：「這是塞浦路斯島的古稱（創十4），以基提翁（Kition）城為名。在後期文獻（昆蘭〔Qumran〕等）中，基提一名泛指航海諸國（但十一30）或羅馬人。至於本節，則有人提出是指『海上民族』──即主前一二○○年左右入侵近東的混合民族（包括非利士人）。」

**指的是哪一群人，各家不同。**

| 來源 | 判定 |
|---|---|
| CT | 希臘人，指向亞歷山大征服近東 |
| GT《啟導本聖經註釋》 | 極可能為腓尼基人，後被大衛王打敗 |
| GT《民數記串珠聖經註釋》 | 非利士人，主前一千二百年佔據埃及和迦南沿岸 |
| GT 丁良才《民數記註釋》 | 地中海以西各國的代表，先希臘後羅馬 |
| KC | 不只賽普勒斯島居民，還包括地中海西側諸強權，羅馬在內 |
| BH | 腓尼基人或希臘人一類的航海民族 |

**共同點。** 各家對族群的判定不同，但方向一致：從海上來的勢力要壓過陸上的帝國，而它自己最後也要沉淪——這正是本節結尾「他也必至沉淪」。STEP 顯示這句結尾與第20節論亞瑪力的結尾是同一組字：'a.Dei 'o.Ved（H5704＋H8）。

## 按書卷累積

### 民數記

<!-- accumulation:民數記:24:start -->
#### [[04 民數記/第24章|第24章]]
- 本章重點：民數記24:24「必有人乘船從基提界而來」，基提是塞浦路斯島古稱，各家對所指族群有希臘、腓尼基、非利士、羅馬等判定。
- 與本章關聯：這是巴蘭第四篇詩歌最後一段，也是全部七篇詩歌的收尾。STEP 顯示「界」在原文是「手」（H3027K），而本節結尾「他也必至沉淪」與第20節論亞瑪力的結尾用的是同一組字。GT《背景註釋》指出基提以基提翁城為名，在後期文獻中泛指航海諸國。
