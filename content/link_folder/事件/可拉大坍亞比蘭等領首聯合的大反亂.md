# 可拉大坍亞比蘭等領首聯合的大反亂

## 定義

這場發生於神選災區的內部巨禍並非臨時的口角偶發，而是深度沉澱於以色列全營政治與宗教權益暗鬥的猛烈爆炸。哥轄子孫可拉作為神聖抬櫃苦幹的繼任骨幹，對同為以斯哈近親、但在祭儀主殿獨自居位被高奉的亞倫一支極盡懷疑與深恨；加上大屬流便一宗的法路二臣大坍與亞比蘭，心懷故土長子產業名分慘喪於早代祖輩的不安憤怒，雙方由於帳棚俱棲居停設於南方會營同一地域（民二10；三29），趁此私下交結高喊革命，集結在民間素有顯爵名望的大聚落首領二百五十人共同出手，打出所謂平民靈性解套的平等大旗去撕剿神選先賢。此一凶案是肉性極深處以偽靈光作藉口，直接叛擊並否定天地君神所差遣治理的嚴謹靈治秩儀。
