# 十二支派首領之杖按著名冊交付驗證

## 定義

耶和華神指示摩西從以色列十二支派的所有領班首領手中，依循宗長代表各收取手杖一根（共計十二根），並且要求將各人的真實名號清晰寫作在專用杖柄上面。藉由公開無二的手杖收納，把一場因狂妄挑戰權力與流血大變促生而成的人心質疑，鄭重帶領進入永恆至真公眾法座之前，聽候上帝定旨無誤的核心試判與挑選確認。

- 本章重點：十二支派代表按氏族各持一枝木杖寫入代表宗祖人名，以平定事宰官職的橫論與猜嫉。
- 與本章關聯：此為平定神權爭執的和平實物見證儀式起點，象徵人欲放棄口端兵亂，恭將榮衰生息恭敬奉上天君判斷。
