# 來源、重建界線與內容交付規格

此檔案是 Luna 的核對契約與研究清單，不是已核准的網站正文。庫根 `AGENTS.md` 的證據與 production 邊界仍適用。涉及無法判斷的解讀時交總控，不靠模型常識生成結論。

## 來源如何進入網站

R01 建立 `docs/research/SOURCES.md` 與 `docs/research/CLAIMS.md`（新建），R03 才把核准項目編入新的 typed evidence 資料。每條可見事實必須有 claim ID；一個器物整體顯示「經文明載」不能涵蓋整個模型外觀。

來源臺帳每列必填：source ID、標題／作者／機構、資料類別、正式本機路徑或已開啟驗證的 URL、檢視日期、節號／頁碼／段落、原始檔 SHA-256（本機資料）、權利／引用方式、能支援的範圍、不能推及的範圍、狀態。無法讀取的頁面標 unverified，不能當 approved source。

主張臺帳每列必填：claim ID、網站短句或模型部件、entity ID、來源 ID 及精確定位、資料型別、適用時段／儀式分支、核對結論、未知項、對應測試或畫面。狀態限定 draft／verified／unresolved／rejected；runtime 只讀 verified 的歷史主張。Unresolved 可作「經文未詳載／存在不同理解」的說明，但不能預設選一個造型。

| 資料型別 | 可如何使用 | 明確界線 |
| --- | --- | --- |
| 正式經文字文 | 庫根 `raw_scripture/<書名>/第N章.txt` 抽取範圍 | 不用 AI 改寫原文；查章格式、行數與節數後才建立行號對映 |
| 專案註釋 | manifest 宣告的有效 raw_data，依內容工作流核對 | 散文解讀與原文證據各有角色；本批不改該 production |
| 考古原始報告／館藏 | 有年代、出土地／catalog ID、作者、頁碼的具體記錄 | 只支援該遺物及時地；相似器物不是摩西會幕實物 |
| 學術詮釋 | 明確作者與分歧，資料欄單獨標示 | 不把推論投票成經文明載 |
| 現代重建／AI 圖 | 構圖、說明方式研究 | 不能支援歷史主張；未知面貌不用美術細節填滿 |
| 計量／渲染選擇 | 肘換算、鏡頭秒數、金屬 roughness 等工程設定 | 標示為換算假設／教學呈現，不聲稱古人採用該精確數字 |

現行 ConfidenceLevel、來源種類與審核狀態是三件不同的事。R03 可擴充 enum，但要資料遷移、更新所有 consumers；不得在舊型別中硬塞新值，或把 unknown 當 reconstructed 自動透過。

## 程序資料必須拆到什麼程度

每個 step 描述一個可停下來理解的行動：誰、在何區、對什麼器具／材料、做什麼、經文範圍、前後依賴。角色或地點改變時拆步；經文明列分支時做 branch，不用單一「開始→完成」兩步敷衍。資料需同時記錄角色責任與視覺 cue；只有來源未指定的人稱動作，可以標未能確定，不硬派給祭司或利未人。

R02 為每個程序產出表：`stepId | branchId | actorRole | locationId | objectIds | actionClaimIds | scriptureRefs | garmentState | nextStepIds | displayCue | unresolved`。經文順序是語義依賴；鏡頭停留秒數、角色移動插值是教學安排。燔祭的牛、羊、鳥分支不得自動串連成同一獻祭；贖罪日多段幔內行為也不能因 UI 方便折成一次自由漫遊。

禁止新增真實人聲「神說」、虛構祭司對話、祈禱、唱誦、群眾儀式。可配無人聲且經授權的操作提示聲，預設靜音。非寫實血液標記仍需資料告訴使用者動作與位置，不用火焰特效代替所有儀式。

## 可延續的研究與已開啟的新線索

既有 `docs/SCRIPTURE_RESEARCH.md` 列出文字與 TheTorah 研究文章；`REFERENCE_MATERIAL.md` 列使用者 PDF/PPTX。這些是下一步來源入口，不代表每個連結與每張圖均已複核。R01 需閱讀實際內容、記頁碼與權利，保留原檔。

2026-09-10 已開啟：

- [Sukenik 等（2021），Timna 紫染織物原始研究](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0245897)。論文摘要記載 Site 34 樣本來自鐵器時代、定年在西元前11世紀末至10世紀初；可作染料技術與年代比較。不可據此把模型某個 RGB 或祭司衣服宣稱為出埃及時的確定色樣。R01 若使用，讀方法／圖說並記具體位置。
- [Tel Aviv University：Central Timna Valley Project](https://www.tau.ac.il/~ebenyose/CTV/current/index.html)。研究計畫入口，供查詢正式發掘報告；網站目錄頁本身不證明某個會幕構件。後一次工具開啟失敗，不靠可用性推論史實。
- [The Tabernacle in Its Ancient Near Eastern Context](https://www.thetorah.com/article/the-tabernacle-in-its-ancient-near-eastern-context)。既有研究文章已確認能開啟，列為學術解讀；若採用其比較必再讀對應段落與引註，不視為出土會幕的證明。

不設「一定要湊滿若干考古來源」的透過條件。要設的是每個採用的考古主張都有實物／報告、年代與適用範圍；對無證據細節明確寫未能確定。至少完成一個有實際原始研究支援的材料／工藝比較條目，教會讀者何謂比較證據；不能只寫空泛免責宣告。

## 內容驗收不能由機械測試代替

人類可讀的 claim 臺帳須和 runtime 的可見主張對照；進度記錄逐項 verified 數字及未解項。測試負責缺 ID、缺引用、原文抽取錯位、分支斷鏈、未核准資料外洩。總控負責引用是否支援說法、年代是否錯置、影象是否與說明矛盾。工程代理不得改 raw_scripture 或來源規則使錯誤內容透過。
