# 公牛逐日遞減的原因之爭

## 定義

住棚節的公牛從十三隻一路減到七隻，經文本身一個字的理由都沒給。四套註釋填這個空白的方式差距很大。

**GT《舊約聖經背景註釋》給兩個實務上的可能，而且自己標明只是可能：**「所獻公牛的數目在節期中每日遞減。理由可能是反映時間的過去，或免得國家最貴重的牲口過度損耗。」

**KingComments 讀成預言性的圖畫。** 它先解釋為什麼從十三隻起頭——十三比十四少一，而十四說出雙倍的完全，「因為即使在和平的國度裡，對基督的認識也達不到那個完全」；接著說「即使在這個節期裡，我們也從祭物數目遞減的圖畫中看見：隨著和平國度的時日過去，人對基督之祭的賞識會漸漸減退」，並把它比作啟示錄二至三章七封書信從以弗所的離棄起初的愛、到老底嘉的不冷不熱。它同時保留了一個底線：遞減最多只到第七日的七隻公牛為止，因為七這個數目說出那工作本身完全的價值。

**BibleHub 讀成完成。** 它在第六日的註解裡說，祭物數目每日遞減「象徵神供應的完成與成全」。

**GT《聖經精讀本》不解釋遞減，只解釋總數。** 它把七天的公牛加總成七十隻，說這「表示對神完全的奉獻和忠心」。

**CT 完全不給理由。** 它在 v13 只記下數字怎麼變：「其中公牛犢從第一日的十三隻，逐日遞減一隻，亦即第二日獻十二隻，第三日獻十一隻，如此類推」，後面每一日的註解都是「請參閱13節註解」。

同一個現象被讀成牲口的實務成本、對基督賞識的減退、神供應的成全、與對神的完全忠心——四種讀法各自有各自的落點，經文沒有替其中任何一種背書。
