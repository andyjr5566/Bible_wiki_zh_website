# 基利心山與以巴路山

## 定義

申11:29 把祝福與咒詛各分配給一座山：「你就要將祝福的話陳明在基利心山上，將咒詛的話陳明在以巴路山上。」STEP 顯示兩個地名是 הַר גְּרִזִים（har ge.ri.Zim，H1630）與 הַר עֵיבָל（har 'ei.Val，H5858C）。

**兩山的位置。** CT 說基利心山地處示劍之南，全山林木茂盛，象徵有福氣；以巴路山與基利心山對峙，兩山之間為極深的裂谷，山頂光禿荒涼，象徵禍患。GT《申命記雷氏研讀本》給的數字是兩座高約三千英尺（914 米）的山，位於巴勒斯坦地、示劍的兩邊，中間是一個極深的裂谷。GT《啟導本聖經申命記註釋》說兩山位於示劍城南北，海拔達九百公尺。

**為什麼是這樣分配，各家給的理由不同。**

| 來源 | 理由 | | --- | --- | | CT | 基利心山林木茂盛象徵有福氣，以巴路山山頂光禿荒涼象徵禍患 | | GT《啟導本聖經申命記註釋》 | 基利心山在示劍之南屬右手的一邊為福氣所在，以巴路山在示劍之北屬左手一邊為禍患所在；並補上茂盛是福、荒涼乃禍 | | GT《聖經精讀本──申命記註解》 | 列出三種說法：陽光照耀與否、樹木茂盛與否、東西方位；並說各家眾說紛紜 | | KC | 基利心在南面，是溫暖與光的那一邊；以巴路在北面，是寒冷與黑暗的那一邊 |

**這個安排後來真的執行了。** GT《聖經精讀本──申命記註解》說在征服迦南以後，這樣的指示在約書亞的主導下得以實行（書8:30-35）。GT《申命記串珠聖經註釋》把儀式的樣子寫出來：以色列十二個支派要分成兩組，六支派站在一個山上，利未人對違背律法者宣告咒詛、對遵從律法者宣告祝福，人民則同聲回應阿們。CT 與 GT《申命記雷氏研讀本》都指出詳盡的內容記在申命記第二十七、二十八章。

GT《聖經精讀本──申命記註解》另提一個位置上的意義：此二山不僅位於迦南地的中心地帶，而且是亞伯拉罕移居迦南地之後第一次築壇之處（創12:6、7）。

- 本章重點：第29-30節。STEP：har ge.ri.Zim（H1630）、har 'ei.Val（H5858C）。CT 說基利心在示劍之南林木茂盛象徵有福、以巴路光禿荒涼象徵禍患；GT《雷氏》給高約三千英尺與極深裂谷；GT《啟導本》以南北左右手解釋分配；GT《聖經精讀本》列出三種說法並說各家眾說紛紜、又指出此地是亞伯拉罕第一次築壇之處（創12:6、7）；GT《串珠》寫出十二支派分立兩山的儀式；KC 從南面的光暖與北面的冷暗解釋。

#### [[05 申命記/第27章|第27章]]
- 本章重點：第4節指定石頭與壇立在以巴路山，第12至13節指定六個支派站基利心山祝福、六個支派站以巴路山宣布咒詛。STEP：be./Har（H2022G）'ei.Val（H5858C）。CT：以巴路山距離約但河淺灘僅約29公里，它與基利心山對峙，兩山之間為極深的裂谷，以巴路山頂光禿荒涼，象徵禍患；至於基利心山，距約但河約48公里，地處示劍之南，全山林木茂盛，象徵有福氣。GT《啟導本聖經申命記註釋》：「林木茂盛的基利心山在南，是福氣的象徵；牛山濯濯的以巴路山在北，象徵禍患。」BH 說兩山在示劍附近形成一個天然的圓形劇場。KC 指出以巴路山在本章兩個主題裡都居中心。

## 主題發展

申命記十一章29節下的是命令：你要將祝福的話陳明在基利心山上，將咒詛的話陳明在以巴路山上。申命記二十七章給的是這道命令的執行細節——哪六個支派站哪一座山、誰在中間、由誰開口、百姓怎麼回答。

GT《申命記串珠聖經註釋》描述現場：祭司和利未人先向站在基利心山上的六個支派說祝福的話，然後向站在以巴路山上的六個支派說咒詛的話，人民都同聲回應阿們。GT《申命記雷氏研讀本》補上中間那一塊：利未人站在中間的山谷。BH 說這兩座山在示劍附近形成一個天然的圓形劇場。

值得注意的是兩山在本章的份量並不對等。立石、墁石灰、築壇、獻祭這一整套動作，申27:4-7 全都指定在以巴路山——也就是宣告咒詛的那一座。KC 因此說以巴路山在本章兩個主題裡都居中心。==命令是兩座山各分一半，執行起來卻是咒詛那一座承擔了全部的重量。==
