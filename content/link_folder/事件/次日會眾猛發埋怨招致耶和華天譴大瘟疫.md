# 次日會眾猛發埋怨招致耶和華天譴大瘟疫

## 定義

曠野故事再闢悲沉之幽暗斷章：就在萬民睜眼親覩地口怒碎吞人和天上玄光燒爛香首的才經通霄，以色列這班屢蒙垂撫之萬千廣大會民毫無敬悟懼罪之念，隔晨又結大群反殺湧上會幕台庭，口噴濁狂罪言直吼摩西與亞倫是「殺戮你們耶和華的百姓了！」此一身分顛對將荒唐之頂衝破：他們甘去認大逆背道可拉為正主慈兵，卻把執行公道、落救眾人於血淵之外的名忠受派巨使罵為血刑殺匠！此舉是意欲以千大數量之橫蠻去直接霸綁、洗除至神至理和刑令。耶和華怒霆不忍，殿雲滾覆立將駭目死亡大瘟疫橫掃眾中，極急奔斃一萬四千七百條盲叫妄言狂魂。這慘歷史長響急告：上帝拒受群情歪見試弄或群數綁架，對逆理頑心無休宣縱必報疾馳如飆殺伐。
