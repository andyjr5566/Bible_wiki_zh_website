# 監_坑_地牢_dungeon

## 定義

創世記40:15約瑟說「叫他們把我下在監裡」。CT 的原文字義註明：這個「監」字作「坑，地牢（dungeon）」，「與本章其他各節的『監』字原文不同」——也就是說，約瑟自述時所用的字，和敘事者稱那所看守所時所用的字並不一樣。CT 另在同兩節指出，約瑟在十四、十五節共提到七個「我」字，「表明他此時還沒有學好向己死的功課，所以他還不能出監，仍須等候」。

- 本章重點：CT 原文字義指出15節的「監」作「坑、地牢」，與本章其他各節的「監」字原文不同——約瑟向酒政申冤時，用的是比敘事用語更沉重的字。
- 與本章關聯：CT 在同一段另指出十四、十五節連用七個「我」字，「表明他此時還沒有學好向己死的功課，所以他還不能出監」；這兩點都落在約瑟自陳身世的同一句話裡。

## 主題發展

本章「監」字並非自始至終同一個原文詞：CT 只在第15節下註明此字作「坑、地牢（dungeon）」，並明說與其他各節不同。這個差別出現在約瑟唯一一次為自己申訴的話裡——第14節他求的也只是「救我出這監牢」；CT 就此評論：他「只求能過正常的生活，而不求地位和報復伸冤」。
