# 潔淨與不潔淨：利未記 11–15 章互動導覽

我們用營中的一家人（虛構）為例子，一章看他們碰到一件事：死蜥蜴掉進瓦罐、生孩子、皮膚起斑、回到營裡、身體的漏症。規矩一律附經節；註釋家的分歧集中在最後一幕「各家怎麼讀」。

八幕全部完成：序幕、第 11–15 章（每章一段 3D 故事，加上故事下面的互動內容）、總覽、各家怎麼讀。

## 開發

建置一律在 **PowerShell** 跑（Git Bash 下 Windows 應用程式控制會擋 rollup 的原生模組）：

```powershell
npm run dev       # http://127.0.0.1:3012
npm run build     # 型別檢查 + 資料閘門 + vite build → dist/
```

網址是 hash 路由：`#/intro`、`#/c11` … `#/c15`、`#/overview`、`#/voices`、`#/about`。`#/voices/girl` 這樣可以直接打開「各家怎麼讀」的某一題。

## 視覺（2026-10 新版）

`src/edition.css` 疊在其他樣式之後，只改呈現、不動內容：頂端導覽是一條夜色的路，八幕是路上的站；每章開頭有大的章號；三種聲音三種字：經文與標題用明體、說明與註釋家用黑體、故事裡那一家人說的話用手寫體（芫荽 Iansui），一看就知道是示意情境。

用 Blender 5.0 做的素材：
- `public/images/camp-dusk-*.jpg`：序幕封面，黃昏的營地，會幕上方雲中有火（出40:38）。院子沿用 `courtyard.glb`，帳棚與雲柱是示意。按「轉動 3D 營地」才載入原本的 3D 場景。
- `public/images/fly/f_0001–0100.webp`：序幕「能走多近」的捲動鏡頭，從營外沿著營中的路走進院門、停在會幕門口；五站對應 `RETURN`（利14:3-20），由 `src/ui/flythrough.ts` 依捲動位置換格。減少動態時改成五張靜止畫面。
- `public/models/clay-jar.glb`：第 11 章「死了掉進來怎麼辦」選瓦罐時播放的碎裂動畫（利11:33），由 `src/three/jar.ts` 播放；減少動態時直接停在碎片落地的畫面。
- `public/models/family.glb`（`scripts/blender/build_family.py`，Blender 5.2）：3D 故事裡的父親、母親、女兒和祭司。有臉、鬍子、頭巾、腰帶、袖子和手；每人分成身體、右手臂（原點在肩膀）、可拿下的頭巾三件，`camp.ts` 的 `figure()` 照原本的骨架組回去，動作程式不變。
- `public/models/home.glb`（`scripts/blender/build_home.py`）：這一家的帳棚（門朝西、門前有地毯）、帶蓋的寬口瓦罐與預先切好的 22 片碎片、翻肚的死蜥蜴。碎片怎麼飛由 `camp.ts` 的 `shatterPaths()` 用固定亂數預先算好，播放、快轉、跳步看到的結果一樣。

兩支腳本都在自己的場景裡建模並匯出（`use_active_scene=True`），用 Blender MCP 執行：`python send.py build_family.py`。

## 3D

`src/three/camp.ts`：營地（會幕院子沿用利未記 1–9 章網站的 `courtyard.glb`）、帳棚、這一家人、晝夜、不潔淨的標示圈。營地大小與帳棚數目是示意，不按比例。

每一步的動作寫在 `Beat.cues`：鏡頭（`cam`、`follow`）、走路（`walk`）、道具（`prop`）、動作（`act`：坐下、躺下、摸、撕衣、灑血、掀蓋、摔瓦罐…）、對話（`say`）、時間快轉（`count`：太陽月亮在天上繞圈，不用畫面明暗閃爍）、日落（`sunset`：太陽在鏡頭前方沉下去）。

運鏡與節奏的規則：
- 走路整條路線（含 `via`）一次走完。短路程照正常步速；長路程開頭、結尾各約一秒照正常步速，中間高速移動（不跳過）。跟拍鏡頭直接跟住人，走得越快升得越高、拉得越遠，不穿過帳棚和院子的幔子。
- 鏡頭飛行依距離 1.2–3 秒，遠距離中途往上拱；換場、距離很遠時用 `cam` 的 `cut: true` 直接切換。
- 鏡頭「看的點」要放在人的高度附近（約 1–3），不然人會掉到畫面下緣外。
- 對話用側面斜拍，兩個人的臉都要看得到；說話的人背後不要站別人（泡泡會像是別人在說）。
- 字幕閱讀時間：故事一秒約九個字、經文摘句一秒約十四個字，和動畫同時起算。
- 手機直式畫面左右比較窄：`view()` 依畫面比例沿視線把鏡頭往後拉（最多 1.6 倍），近景不會把人切到畫外。
- 進出會幕院子不跟拍穿過門帘：進去時先切到會幕門口等，一家人從鏡頭後方走進畫面；回程一開始就切到路上的對話鏡頭，一家人從遠處的院門走過來。
- 躺下（`lie`）是先坐下、再繞臀部往後躺平，頭枕在墊子的枕頭上；起身照原路倒回去。
- 墊子碰到後的光暈是貼著墊子的長方框，座位是小圓圈，免得和站在旁邊的人的光圈疊在一起；對話泡泡的小尖角也算進名牌的避讓範圍。
- 五章最後一步都是女兒提問，故事下面接「某人回答女兒」（`answerBridge`），直接回答那個問題，內容只寫經文說的。

使用者按下的播放、序幕跟著捲動走的鏡頭（`flythrough.ts`）、第 11 章按下去的分欄與打破瓦器，都只看本站的「減少動態」開關（`animOff`）；裝飾性的自動旋轉與開場動畫才跟著作業系統的偏好（`motionOff`）。
