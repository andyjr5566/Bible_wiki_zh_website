# 十一天的路程

## 定義

申命記1:2 是一句括號裡的旁註：「從何烈山經過西珥山到加低斯巴尼亞有十一天的路程。」放在這裡不是為了報路況。

**十一天 vs 三十八年。** 四套註釋都指向同一組對比：

| 來源 | 說法 |
|---|---|
| CT | 「以色列人共花了三十八年的時間，直到老一代的都倒斃在巴蘭和尋的曠野中」 |
| GT《啟導本》 | 「這一段只須十一天的短短路程，以色列人因為不信神有力量領他們進迦南，居然走了38年」 |
| GT《聖經精讀本》 | 「這令我們想起以色列竟然為了這麼短的路程而花費了40年，指出了不順服的代價何等可怕」 |
| KC | 十一天走得完的路，因著不信花了四十年（從出埃及算到進迦南） |
| BH | 十一天的路程提醒人，不信靠神的應許要付出什麼代價 |

三十八年與四十年不是兩家在吵，是同一段路的兩種切法，而 GT 自己就把兩者接起來了。《雷氏研讀本》：「『出埃及第四十年』，其中兩年停留在西乃山和前往加低斯巴尼亞，其餘三十八年飄流在曠野（二14）。」《啟導本》算法相同。CT 在同一節底下兩個數字都用過——〔文意註解〕寫三十八年，〔話中之光〕寫四十年。KC 明說他的四十年是「從出埃及算到進迦南」。

**路線上的兩個地名。** CT 說「『經過西珥山』指繞過以東地的邊緣」；GT 說何烈山即西奈山，加低斯巴尼亞則是「距別是巴南約70公里」的綠洲，是迦南的南疆入口。GT《雷氏研讀本》與《串珠》另給一個數字：別是巴西南面約五十英里（80公里），與《啟導本》的 70 公里略有出入。BH 沒有給距離，只說這裡是窺探迦南的出發點，也是以色列人做決定與受試驗的地方。

**KC 對「四十」這個數字的讀法。** KC 說四十講的是試驗與察驗，是一段心思與品格被檢驗的時間；並且指出對今天的讀者而言，這不會是字面的四十年，也不是字面的曠野。

## 按書卷累積

### 申命記

<!-- accumulation:申命記:1:start -->
#### [[05 申命記/第1章|第1章]]
- 本章重點：第2節的括號旁註：何烈山經西珥山到加低斯巴尼亞只要十一天。CT 與 GT《啟導本》對照的是實際走了三十八年，KC 與 BH 對照的是出埃及到進迦南的四十年。GT《聖經精讀本》：「指出了不順服的代價何等可怕。由此可知，遵行神旨意，才是人生最美好的生活。」
- 與本章關聯：這句旁註是全書第一段歷史回顧的定調。摩西還沒開始講律法（第5節才開始），先讓新一代看見一個數字上的落差——十一天的距離走了三十八年。第46節「於是你們在加低斯住了許多日子」與這裡首尾呼應。
