# 利未人總數的三百之差

## 定義

民數記第三章給了利未三族各自的人數，也給了一個總數，兩者對不起來：

| 家族 | 一個月以外男子 | 出處 |
|---|---|---|
| 革順 | 7,500 | v22 |
| 哥轄 | 8,600 | v28 |
| 米拉利 | 6,200 | v34 |
| 三族相加 | 22,300 | — |
| 經文所記總數 | 22,000 | v39 |

差額是三百。四份 GT 子來源與 CT 分成兩派解釋。

**一派說是抄寫之誤。** CT 直接給版本證據：「若將革順、哥轄、米拉利的數目（參22，28，34節）加起來應為二萬二千三百名，相差三百名，《希臘文七十士譯本》哥轄族是八千三百名，而非八千六百名。」GT《啟導本》給出同一結論並說明字形上的理由：「這多出來的300人來自抄寫的錯誤。28節哥轄族的總男丁數應為8300」，因為希伯來文的「三」與「六」兩個字「甚易誤抄」。

**另一派說那三百人是利未人自己的長子。** GT《丁良才註釋》說：「這三百名大概是利未人頭生的男子，所以不能代替別人。」GT《聖經精讀本》講得更完整：原本以色列的長子是分別為聖歸耶和華的，而利未支派的長子同樣歸耶和華，「所以不能代替其他支派的長子」——既然不能拿來代替，自然就不列進那個用來對換的總數裡。

**GT《民數記串珠聖經註釋》兩派都記，然後選了前一派。** 它先寫下猶太拉比的說法（三百名是利未人長子之數），接著指出這個算法的弱點：「但這個計算方法未有在15節預先聲明，本章也沒有記載點算利未人長子的指示」，因此判斷「較佳的解釋是：28節的『六』字可能是『三』字抄寫之誤，因這兩個數字在希伯來文只相差一個字母」。

兩派的差別不只是算術。抄寫說認為經文本來就一致，是傳抄出了問題；長子說認為22,000 是一個刻意扣除後的數字，扣除的理由本身帶著神學意義——連代替者自己的長子也仍舊歸神。

## 按書卷累積

### 民數記

<!-- accumulation:民數記:3:start -->
#### [[04 民數記/第3章|第3章]]
- 本章重點：三族分數相加為22,300，v39 的總數卻是22,000，差三百；CT 與啟導本主張抄寫之誤（七十士譯本作8,300），丁良才與精讀本主張那是利未人自己的長子，串珠並列兩說後傾向抄寫之誤。
- 與本章關聯：這個差額直接影響下一段的計算：以色列頭生男子22,273 減去利未人22,000，餘273 人要付贖銀（v46-51）。
