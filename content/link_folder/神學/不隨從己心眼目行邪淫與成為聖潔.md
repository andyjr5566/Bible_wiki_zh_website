# 不隨從己心眼目行邪淫與成為聖潔

## 定義

為何上帝費心要群眾終日衣佩那耀天眼目的藍紗和衣角繸絲？其最終目的直穿本性根部的軟敗之痛：「好叫你們看見就紀念遵行耶和華一切的命令，不隨從自己的心意、眼目行邪淫，像你們素常一樣。」人內在深鎖的最大狂淵便是在荒途自持好驕，耳聰神鈍卻憑放縱情誘的主觀眼目和偏流貪欲的蠢欲私意去勾纏假幸或虛榮鬼相（靈明上實如變節娼淫）。而藍邊衣戒的視看警召正是力遏此災：扯落己欲心鎖，換入常存主訓的明晰歸附；當真道長縈耳目心懷時，全生命必豁出穢泥，「成為聖潔，歸與你們的上帝」。
