# 寧錄

## 定義

古實的兒子，世上英雄之首，英勇的獵戶（創十8-12）。原文字義各家所記略有出入：CT 註「反叛，有膽量，強壯」，GT《串珠聖經註釋》註「本是『背叛』之意」，GT《啟導本聖經創世記註釋》則說是「強壯者」或「反叛者」。他的國從示拿地的巴別起頭，是聖經所提的第一個國。CT 與 KC 把他讀作對抗神、以強力建國的典型；這是註釋的解釋，經文本身沒有給他這個稱號。

## 主題發展

### 寧錄的六項特徵

| 特徵 | 經文 | 屬靈意義 |
|------|------|----------|
| 名字 | 8節 | 「寧錄」意**背叛**→不法的人（帖後二8） |
| 能力 | 8節 | 世上英雄之首→大有能力（帖後二9） |
| 性情 | 9節 | 獵戶→兇暴殘忍（啟十三15） |
| 態度 | 9節 | 「在耶和華面前」英勇→**目中無神**、狂傲（帖後二4） |
| 工作 | 10節 | 國起頭是**巴別**→對抗並混亂神的國度 |
| 作法 | 11-12節 | 征服、建造黑暗權勢、聯合成大勢力範圍 |

### 寧錄的國度

- **巴別**（巴力的大門、混亂）→ 巴比倫的前身
- **以力、亞甲、甲尼** → 都在[[示拿地]]（巴比倫平原）
- 這是聖經內所提的**第一個國**
- 擴展至亞述：建造[[尼尼微]]、利河伯、迦拉、利鮮

### 他是不是巴別塔的建造者？來源正面衝突

經文只說「他國的起頭是巴別」（10節），沒有說他造塔。四份來源在這一點上分成兩邊，且分歧相當尖銳：

| 來源 | 立場 |
|---|---|
| GT《啟導本聖經創世記註釋》 | 直接斷定「甯錄曾建造巴別塔（十一1～9），又往亞述建國」 |
| GT《聖經精讀本──創世記註解》 | 訴諸外證：「史學家約瑟夫主張，煽動人們建造巴別塔的是寧錄」 |
| GT《創世記雷氏研讀本》 | 「寧錄的活動起初集中於示拿（巴比倫），並且包括第十一章1至9節所記述的建造巴別塔」 |
| GT《舊約背景註釋》 | 明確否定：部分教父接受了晚期猶太傳統，視他為巴別塔的建築者和拜偶像的創始人，「**但這是完全沒有聖經根據的看法**」 |

分歧的實質是**傳統與經文的關係**：前三家把後世猶太傳統當作可用的補充材料，背景註釋則要求區分經文所載與傳統所增。兩種取向都不能由創十本身裁決，因為本章只把巴別列為他國度的起頭城市之一。

### 歷史人物的鑑定：三說並存

- GT《舊約背景註釋》記載解經家長年嘗試把寧錄鑑定為已知人物，如**杜庫提寧努他一世**（士師時代的一位亞述王）或美索不達米亞神祇**寧努他**（戰神與獵戶的守護者，神話中他追蹤好幾隻異獸，或擊敗或殺死）。但它同時排除神祇說：「按照創世記的記載，寧錄很明顯是位人類的英雄，不是神祇，亦不是半人半神。」
- GT《串珠聖經註釋》提出另一個人選：「不少學者認為甯錄乃是主前二三○○年的亞述王撒珥根。」
- 背景註釋不作人物指認，改作**時代對應**：寧錄的國度從美索不達米亞南部（10節）擴張到北部（11節），「與近東史上第一個帝國亞甲德（Agade）王朝的發展大致相同」，該王朝的撒珥根與納蘭辛（約主前2300年）「都是古代最英武的君王」。它並指出以力（即烏魯克）也屬寧錄的王國，這城曾被吉加墨斯所統治，是蘇美最古老最重要的文化中心之一。

### 屬靈教訓

- 撒但常利用神所棄絕的人，使他作反抗神的首領
- 世人自古崇拜英雄，但信徒不可過於高舉才幹的領袖
- 神所看重的不是「英勇的獵戶」，而是敬畏神、與神同行的人
- 凡動刀的，必死在刀下（太廿六52）
- 建造神國度的人都是**牧者**，為羊捨命（約十11、14）

### 與敵基督的豫表

寧錄是大罪人（敵基督）的豫表：
- 帖後二8：不法的人
- 啟十三：獸的權柄
- 史家約瑟夫主張他煽動建造巴別塔
