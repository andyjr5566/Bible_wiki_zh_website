# 攻艾城失敗的原因

## 定義

書7:2-5 是約書亞記前半部唯一一場敗仗：三千人上去攻艾城，反而在艾城人面前逃跑，被殺三十六人。四套註釋都在同一個問題上停留：為什麼會輸？各家給的答案不完全一樣，可以並排看。

### 各家歸納的原因

| 提出者 | 列出的原因 |
|---|---|
| GT《啟導本聖經約書亞記註釋》 | 三條：亞干犯罪連累全民（這是主因）；約書亞見艾城不大，只派遣少數軍隊攻城，犯了輕敵的錯誤；以色列人攻城前不像在耶利哥戰役中尋求神的指引，但憑探子的話作出決定 |
| GT《聖經精讀本──約書亞記註解》 | 亞干隱藏戰利品的罪惡，以及百姓陶醉於勝利、驕傲地從戰而沒有求問耶和華 |
| CT | 輕敵不是主因，主要原因是以色列軍隊的元帥在這次攻擊戰中沒有發出命令；主帥的沉默使以色列的進攻艾城沒有根據，而主帥不發聲是因為以色列人拒絕服從神的權柄 |
| GT《丁道爾聖經注釋》 | 這場戰役的描述可謂獨一無二，只有這裡沒有提到約書亞在率領，他們沒有尋求神明確的帶領就作出了決定 |
| KC | 約書亞下令時沒有求問耶和華，而且是從耶利哥而不是從吉甲打發人出去 |
| BH | 沒有記載約書亞在攻艾之前求問耶和華；這場敗仗顯出以色列一旦容讓背逆存在，就不能理所當然地支取立約的祝福 |

### 「人少」這個判斷本身就錯了

探子回報說「眾民不必都上去，只要二三千人上去就能攻取艾城；不必勞累眾民都去，因為那裡的人少」（書7:3）。CT 說這是輕敵的表示，並回頭用書8:25 校正：艾城的居民有一萬二千人。CT 在話中之光把兩代探子放在一起看——三十八年前窺探迦南的十個探子過於自卑，認為自己就如蚱蜢一樣（民13:33）；現在這些探子卻過於自信，認為不必勞累眾民都去。

### 得勝之後最危險

幾家都注意到失敗緊接在大勝之後。KC 說耶利哥的城牆不是靠人的能力倒下的，是靠對神能力的信心，他們用一個星期學到得勝不在乎自己而在乎神，但這個印象維持得很短；KC 又說我們常在自己眼中的小問題上假裝不需要禱告，忘了小問題背後藏著巨大的權勢。CT 在話中之光說得更貼身：常常在公眾面前一個極大的勝利，卻帶來私人生活裡的跌倒。

這一章的診斷最後不是由人給的。書7:10-12 神自己回答：問題不在戰術，在營中有當滅的物（見 [[一人犯罪全營受累]]）。

## 按書卷累積

### 約書亞記

<!-- accumulation:約書亞記:7:start -->
#### [[06 約書亞記/第7章|第7章]]
- 本章重點：第2至5節。GT《啟導本》列出三條原因：亞干犯罪連累全民（主因）、約書亞見艾城不大只派遣少數軍隊攻城（輕敵）、攻城前不像在耶利哥戰役中尋求神的指引而但憑探子的話作決定；GT《聖經精讀本》列兩點：亞干隱藏戰利品的罪惡，以及百姓陶醉於勝利、驕傲地從戰而沒有求問耶和華。CT 說輕敵不是主因，主要原因是以色列軍隊的元帥在這次攻擊戰中沒有發出命令，主帥的沉默使進攻沒有根據，而主帥不發聲是因為以色列人拒絕服從神的權柄；CT 又說「只要二三千人上去」是輕敵的表示，實際上艾城的居民有一萬二千人（書8:25），並把這些探子與三十八年前過於自卑的十個探子（民13:33）對照。GT《丁道爾聖經注釋》說這場戰役的描述可謂獨一無二，只有這裡沒有提到約書亞在率領。KC 說約書亞下令時沒有求問耶和華，而且是從耶利哥而不是從吉甲打發人出去，並說我們常在自己眼中的小問題上假裝不需要禱告。BH 說沒有記載約書亞在攻艾之前求問耶和華，這場敗仗顯出以色列一旦容讓背逆存在，就不能理所當然地支取立約的祝福。
- 與本章關聯：本章把敗因問了兩次——先由人問（第7至9節約書亞的哀求），再由神答（第10至15節）。各家歸納的戰術原因都成立，但經文自己給的答案落在營中的罪上。
