# 🔍 如何查一個主題

> 用「**神的榮耀**」當範例，示範 4 種查主題的方法。

想先實際操作一次？<button class="bwz-btn" type="button" data-tour-open="true">▶ 開始互動導覽</button>

## 方法 1：搜尋（最直接）

**熱鍵**：`Ctrl/⌘ + K`，或點左上角的「搜尋」

1. 打開搜尋，輸入「神的榮耀」
2. 結果會同時列出兩種比對：
   - **AI 語意**：依意思比對，字面不同但概念相近的條目也會出現，旁邊顯示相似度
   - **精準比對**：標題或內文真的出現這幾個字（至少輸入 2 個字才會比對）
3. 用 `↑` `↓` 選擇、`Enter` 前往，或直接點結果

**適合**：知道要找什麼詞，或只知道大概的概念時。

**試試語意搜尋**：輸入一段描述，例如「神與人同住」「羔羊之血」，看看會找到哪些字面不同、意思相近的條目。

## 方法 2：從分類資料夾找

**位置**：左側「探索」→ `link_folder`

條目依類型分在 11 個資料夾裡：

| 資料夾 | 收什麼 |
|---|---|
| 人物、地點 | 例如摩西、亞倫；埃及、西乃山 |
| 主題、神學 | 例如會幕院子；神的榮耀 |
| 歷史、事件、背景、文化 | 例如逾越節、逾越節羔羊 |
| 原文 | 希伯來文詞彙，例如逾越（Pesach） |
| 互文 | 經文彼此引用、呼應的關係 |
| 解經爭議 | 註釋家看法不同的地方 |

**適合**：想瀏覽某一類有哪些條目時。「神的榮耀」就在 `link_folder/神學/` 裡。

## 方法 3：讀條目頁的「按書卷累積」

打開 [[神的榮耀]] 條目：

1. **定義**：這個主題是什麼
2. **按書卷累積**：依書卷、章節列出它出現的地方，例如出埃及記第 14、24、29、33、34 章，每章各有「本章重點」與「與本章關聯」
3. **主題發展**：跨章節的脈絡整理
4. **相關條目**、**來源依據**

**適合**：想一次看完一個主題在聖經中的發展。

## 方法 4：反向連結（看誰提到它）

**位置**：電腦版在頁面右側「反向連結」，手機版在頁面下方

反向連結會列出所有**連到這個條目**的頁面。以「神的榮耀」為例，會看到出埃及記第 33 章（摩西求見神的榮耀）等章節，以及其他提到它的條目。

右側的**關係圖譜**則把這些連結畫成網絡圖，點右上角的圖示可以展開成全站圖譜。

**適合**：想知道一個概念在哪些經文脈絡中出現。

## 組合起來用

深度查一個主題的推薦路徑：

```
1. 搜尋「神的榮耀」→ 進入條目
2. 讀「按書卷累積」→ 看它在各書卷怎麼出現
3. 看反向連結 → 找到提到它的章節
4. 進到章節 → 對照經文與「本章整理」
5. 從經文裡的連結 → 跳到相關人物、地點、原文
```
