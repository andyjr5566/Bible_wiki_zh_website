# 民數記第七章的時序與編排

## 定義

本章第1節說「摩西立完了帳幕」，把時間拉回出埃及後第二年正月初一日（出40:17），比民數記第1章的二月初一還早一個月。整卷書到這裡忽然往回跳。

**這件事本身各家都注意到了，理由卻給得不一樣。**

| 來源 | 為什麼放在這裡 |
|---|---|
| GT 丁良才 | 「本章的事，原該列在利八10節以後，不過記在此處，免得有防礙於記載西奈山垂律法的事。」 |
| GT《啟導本》 | 作者希望民數記「可以集中講獻祭和祭司的按立」，先在1至6章敘述出發前的準備與利未人分工，之後才介紹十二支派奉獻禮物——「不僅層次分明，也讓讀者可以分外明白獻禮物一事的重要性」 |
| GT《民數記串珠聖經註釋》 | 給了三個理由：車牛分配必須接在利未子孫職務之後才講得通；律法禮儀若按日記方式記敘「便會破壞律法的整體性及實踐的一致性」；奉獻是「以神為中心的生活最高超的回應」，編營所代表的心意要在奉獻的行動中顯明 |
| KC | 這樣的安排「完全合乎民數記這卷書」，並列出完整的事件序列 |

GT《民數記串珠聖經註釋》另指出膏抹帳幕一事「已於利8:10-11記述；這裡複述」，一方面表明時間與1至6章不同，另一方面表明聖潔與奉獻的關係。

#### [[04 民數記/第7章|第7章]]
- 本章重點：本章第1節把時間拉回出埃及第二年正月初一日（出40:17），早於民1:1 的二月初一，全卷在此處往回跳。GT 丁良才、《啟導本》、《民數記串珠聖經註釋》與 KC 各自給了不同的編排理由，KC 並列出正月初一到二月二十日起行的完整事件序列。
- 與本章關聯：為民數記1至10章的時間錯位提供解釋框架，並定位本章在「起行前四件預備」中的位置。

## 主題發展

KC 把西乃曠野這段日子的事件排成一條完整的時間線，讓人看得出本章插在哪裡：

| 日期 | 事件 |
|---|---|
| 正月初一 | 帳幕立完（出40:2）；獻祭條例；為壇獻供物（民7:3）；祭司承接聖職（利8:1） |
| 正月初八 | 祭司的奉獻完成（利9:1） |
| 正月十二 | 為壇的供物獻完（民7:78）；潔淨利未人（民8:5） |
| 正月十四 | 第二次逾越節（民9:2） |
| 二月初一 | 開始數點人口（民1:1） |
| 二月十四 | 不潔之人的逾越節（民9:11） |
| 二月二十 | 雲彩收上，起行（民10:11） |

照這條線，本章的十二天奉獻與民數記第1章的數點是不同月份的事，而第8章潔淨利未人緊接在奉獻結束的同一天。

GT《民數記串珠聖經註釋》從全卷結構補上另一層：以色列人起行前還有幾件事要作——為祭壇行奉獻禮（7）、潔淨利未人（8）、守第二次逾越節（9）、製造銀號（10）——本章是這一串預備的第一件。
