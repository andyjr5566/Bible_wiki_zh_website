# 順服神勝過君王命令

## 定義

當人的命令直接要求違背神的旨意、殺害無辜者時，順服神具有更高優先次序。出埃及記1章的收生婆因敬畏神，不照法老命令殺死男嬰；這不是否定一切地上權柄，而是在權柄命人作惡時拒絕參與。

## 主題發展

CT 把判準說在最前面：「敬畏神的人，以神的意旨為其生活行為的最高準則；當人的吩咐違背神的心意時，順從神，不順從人，是應當的」（徒5:29）；解第17節「不照埃及王的吩咐行」時也只有一句話——「意指聽從神，不聽從人」（徒4:19）。KC 用同一節經文描述收生婆：她們「順從神，不順從人」（徒5:29），而神「把她們為祂子民所做的，看作是為祂自己做的」。

GT 丁良才《出埃及記註釋》把這條原則排成一串聖經先例：「人所吩咐的，若違逆神的旨意，我們絕不可聽從。」

| 人物 | 抗拒的對象 | 出處 |
|---|---|---|
| 約瑟 | 主母 | 創39:9 |
| 約拿單 | 父親掃羅 | 撒上19:1、5 |
| 亞撒利雅 | 烏西雅王 | 代下26:11、17-21 |
| 末底改 | 亞哈隨魯王 | 斯3:12 |
| 但以理的三個朋友 | 尼布甲尼撒王 | 但3:13-15、16-18 |
| 但以理 | 大利烏王 | 但6:10、13 |
| 彼得 | 官長 | 徒4:13-18、19-20 |
| 使徒 | 公會 | 徒5:28-29 |

同一段也記下一個反例：「雅各卻聽從了他母親的話」（創27:5-10）。GT《靈修版聖經註釋》舉的例子相近：「以斯帖和末底改（斯3:2；4:13-16）、沙得拉、米煞、亞伯尼歌（但3:16-18）等，都是英勇無畏的人，做了當做的事」，並提醒「跟隨潮流、服從多數，並不一定是對的」。

界線在哪裡，GT 賈斯樂郝威《聖經難解經文詮釋手冊》講得最清楚：「神要我們遵守政府的權柄，但祂也命令我們不可殺人（出20:13）。保護無辜的生命比服從政府的義務更重要。當有權柄的政府要我們奪取無辜的生命時，我們應當拒絕。」
