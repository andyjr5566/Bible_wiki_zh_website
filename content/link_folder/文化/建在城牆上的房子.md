# 建在城牆上的房子

## 定義

書2:15 交代了喇合能把探子縋出城的原因：「因他的房子是在城牆邊上，他也住在城牆上。」

### 原文用了兩個「牆」字

STEP 顯示是 be./Kir ha./cho.Mah（H7023 簡要詞典義 qir: wall，加 H2346G 簡要詞典義 cho.mah: wall），下半句是 u./va./cho.Mah hi' yo.Sha.vet。前一個字指房屋的牆，後一個字指城牆。

### 考古資料

各家都引考古，說法在細節上不完全一樣。

| 來源 | 說法 |
|---|---|
| CT | 考古學家的考據證實，當時的確有民房建築在城牆內緣邊上 |
| GT《啟導本聖經約書亞記註釋》 | 從考古學者挖掘耶利哥城所得資料，當地人確有在城牆上建屋居住的事；有的城牆中空，裡頭且有間隔 |
| GT《聖經精讀本──約書亞記註解》 | 據英國考古學家賈斯湯（Garstang）1930-1936 年所發掘的耶利哥城遺址，當時的耶利哥城被相距4-5米的兩層城牆所環繞 |
| GT《約書亞記綜合解讀》 | 耶利哥遺址的城牆有內外兩層，1900年代德國考古學家在北端內外牆之間挖掘到了房屋，屋背倚著外牆的內側 |
| GT《舊約背景註釋》（華爾頓） | 考古學家在耶利哥挖掘到房屋建於內外牆之間墁了灰泥的護堤上面，屋背倚著外郭的內側 |
| GT《靈修版聖經註釋》 | 許多城邑有兩道城牆，其間相隔約有3.5至4.5公尺，兩道牆頂上可以用木料建造房子 |

兩道牆的間距，《聖經精讀本》給的是4-5米，《靈修版》給的是3.5至4.5公尺；發掘者也分成英國的賈斯湯與 1900 年代的德國隊。這些是各家自己的引述，本章經文只說她的房子在城牆邊上。

### 為什麼要這樣蓋

CT 與華爾頓給的理由相同，而且是雙向的：這樣做一面增加城牆的厚度和支撐、有利於城防，一面房屋的牆壁有牢固城牆的依靠、也有利於民房的堅固。GT《聖經精讀本》另外指出這種雙層城牆使城內的面積大幅度縮小，因此有些人在兩道城牆之間放置大樑而建造房屋。

### 它在本章的作用

書2:7 城門已經關了，探子按常法出不去。BH 說喇合的家位於城市的外緣防線，使人能不經守衛的城門而逃到耶利哥之外，這個位置讓她在探子的任務裡扮演了神所安排的角色。GT《研經資料》另外記下一個版本差異：書2:15 這段敘述在七十士譯本並沒有此附註。

- 本章重點：第15節「因他的房子是在城牆邊上，他也住在城牆上」，STEP 為 be./Kir ha./cho.Mah（H7023 qir: wall 加 H2346G cho.mah: wall），原文用了兩個不同的「牆」字。CT 說考古學家的考據證實當時的確有民房建築在城牆內緣邊上，一面增加城牆的厚度和支撐，一面房屋的牆壁有牢固城牆的依靠；GT《啟導本》說有的城牆中空、裡頭且有間隔；GT《聖經精讀本》引英國考古學家賈斯湯1930-1936年的發掘，說耶利哥城被相距4-5米的兩層城牆所環繞，有些人在兩道城牆之間放置大樑而建造房屋；GT《綜合解讀》說1900年代德國考古學家在北端內外牆之間挖掘到了房屋；GT《舊約背景註釋》的華爾頓說房屋建於內外牆之間墁了灰泥的護堤上面；GT《靈修版聖經註釋》說兩道城牆相隔約3.5至4.5公尺。BH 說這個位置使人能不經守衛的城門逃出城外。GT《研經資料》記下書2:15 這段敘述在七十士譯本並沒有此附註。

#### [[06 約書亞記/第6章|第6章]]
- 本章重點：第20節城牆塌陷，第22至23節兩個探子卻進得了喇合的家把她全家帶出來。GT《雷氏研讀本》說喇合房子所在的城牆並沒有倒塌；GT《啟導本》說耶利哥城牆高約9公尺，城牆應聲倒塌，但建在城牆上喇合的房子無恙，全家和「一切的親眷」都獲救；GT《串珠》說喇合的房子雖在城牆上，但由於神的保守，顯然並沒有像城牆其他部分那樣倒塌下來；GT《研經資料》說聖經並沒有特別說明或記載喇合的家如何得救，有學者認為這完全是神的保守，如同出9:26 神降冰雹在埃及人身上時、居住歌珊的以色列人那邊卻沒有下。CT 說耶利哥城牆約有十公尺高、且是雙重城牆，若非神的作為不容易多處塌陷，而妓女喇合的家所在的城牆卻完好無恙。KC 說喇合房子所在的那一段城牆被存留下來。
- 與本章關聯：書2 這個建築細節是探子的出路，本章它變成一個例外：整道城牆倒了，只有那一段沒有倒。

## 主題發展

這個建築細節在書2 與書6 分別派上兩種用場。書2:15 它是出路——房子在城牆邊上，探子才能用繩子從窗戶縋下去。書6:20 城牆塌陷之後，它變成一個例外：書6:22-23 兩個探子還進得去那間房子，把喇合全家帶出來。

各家對這個例外的說法一致，理由則都指向神的保守。GT《雷氏研讀本》說喇合房子所在的城牆並沒有倒塌；GT《啟導本》說城牆應聲倒塌，但建在城牆上喇合的房子無恙；GT《串珠》說由於神的保守，顯然並沒有像城牆其他部分那樣倒塌下來；CT 說耶利哥城牆約有十公尺高、且是雙重城牆，若非神的作為不容易多處塌陷，而她家所在的城牆卻完好無恙。GT《研經資料》則坦白說聖經並沒有特別說明或記載這件事是怎麼發生的。
