# 男女不可易服的條例

## 定義

申命記第二十二章第5節：「婦女不可穿戴男子所穿戴的，男子也不可穿婦女的衣服，因為這樣行都是耶和華─你神所憎惡的。」一節話，兩個方向，禁的是同一件事：把性別的外在標記換過來。

### 兩個「衣服」在原文不是同一個字

STEP 顯示前半句的「所穿戴的」是 khe.li（H3627），簡要詞典義是 ke.li: article/utensil；後半句的「衣服」則是 sim.Lat（H8071），簡要詞典義是 sim.lah: mantle。前一個字的義域比後一個寬得多。

GT 艾基斯《舊約聖經難題彙編》整段討論的正是這一點：keli「是比較含糊的用字，有時候解作「器皿」、「容器」，有時候解釋為「設備」或「器具」，亦可能理解為「武器」甚或「裝飾品」」，但依上下文，此字眼所代表的是「衣服」；至於 simlah，他說「這字本解作斗篷，但在當時已可應用於指幾乎全部的衣物，只要能包著身體的就成了」。GT《申命記串珠聖經註釋》與《聖經精讀本》都採同一個寬義：串珠說「衣服」在此泛指一切衣著飾物，精讀本說它「不僅指衣物,而且統稱所有種類的器具、服飾等穿戴在外的事物」。

### 為什麼禁：四種角度並陳

| 角度 | 出處與說法 |
| --- | --- |
| 當時男女服裝太像 | GT《申命記雷氏研讀本》：「在當時的社會，男性和女性的服裝十分相似，因此不同性別作不同的穿戴是很重要的，這樣可以防止易裝癖或同性戀。」 |
| 迦南異教儀式 | GT《啟導本聖經申命記註釋》：「迦南異教拜神的儀式中，男女易服，雌雄莫辨，涉及淫猥；立例禁止或因此。」GT《串珠》也說在迦南地的偶像敬拜中往往混淆男女衣飾來引誘人犯罪（利18:22） |
| 創造的次序 | GT《聖經精讀本》說根本上是為了過順應神之神聖創造秩序的聖潔生活，因為神獨特而有區別地創造了男女；BH 也把這條接回創世記1章27節神造男造女 |
| 分別的原則 | CT：「本節的原則是「分別」(利二十26)。」他接著說男女在神面前地位平等，「在基督耶穌裡都成為一了」(加三28)，但「「平等」、「合一」並不是「相同」」 |

KC 把重點放在外面看得見的那一面：他說這裡講的是在世界中的行為、神的創造次序，加拉太書三章28節講的則是在基督裡、在神面前的地位，兩者層次不同；並引提摩太前書二章8至14節說神要祂家中的男女在舉止上有分別。BH 用的字是 detestable，並指出這個字在希伯來文脈絡裡常用來指拜偶像或性方面的可憎行為。

### 一句留給今天的判語

艾基斯自己把應用的邊界說得很清楚：「在不同年代裡，無論男性或女性的服裝都有顯著的改變，因此，我們不能單憑上述一句簡單的經文而訂立嚴峻的原則。」但他同時強調神在這節裡用的是最重的字眼，並把結論放在態度上——男女都要欣賞及尊重自己的性別，不應取用異性的角色或異性的打扮。CT 的話中之光走得更遠一些，認為現代人或許會譏誚這個定規落伍，但分別的原則一有迷糊的傾向，就會引進犯罪的事實。

## 按書卷累積

### 申命記

<!-- accumulation:申命記:22:start -->
#### [[05 申命記/第22章|第22章]]
- 本章重點：第5節禁止男女互換服飾，理由是「這樣行都是耶和華─你神所憎惡的」。STEP 顯示前半句用 khe.li（H3627，ke.li: article/utensil），後半句用 sim.Lat（H8071，sim.lah: mantle），兩字義域寬窄不同；「憎惡的」是 to.'a.Vat（H8441）。GT 艾基斯《舊約聖經難題彙編》逐字討論 keli 與 simlah 的義域；GT《申命記雷氏研讀本》說當時男女服裝十分相似；GT《啟導本》指向迦南異教儀式的男女易服；GT《聖經精讀本》與 BH 都把根據放在創造的男女之別；CT 歸到「分別」的原則；KC 把在世界中的行為與在基督裡的地位分成兩個層次來讀。
- 與本章關聯：這一節夾在憐恤鄰舍（1-4節）與愛惜生態（6-7節）之間，看似突兀，其實與第9至11節的禁止混雜同屬一組：神所分開的，人不可混。CT 與 KC 都把它與第9至11節放在同一個原則底下讀。
