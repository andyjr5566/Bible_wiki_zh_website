# 摩西之歌的分段與年代

## 定義

出十五1-18 這首詩的分段方式與寫作年代，本章的來源給出好幾種互不相同的答案。GT《啟導本聖經腳註》 稱它為「海之歌」，又名「摩西的凱歌」或「蘆葦海之歌」，並說它是「摩西五經中最出色的一首史詩」。 分段上：GT 丁良才《出埃及記註釋》分三段（1-5、6-10、11-18），並記另有註釋家分兩大段； GT《中文聖經註釋》分四小段（1下-2 個人感恩、3-12 團體頌讚、13-16 外邦驚惶、17-18 栽植與作王）； GT《串珠聖經註釋》分前後兩半（1-12 稱讚神在過紅海顯出的能力、13-18 稱讚神帶領他們進入迦南）； GT《丁道爾聖經註釋》也分兩段但界線相同；GT《啟導本》則作 1-11、12-17、18。

- 本章重點：出十五1-18 的分段、體裁與年代，本章來源各執一詞：分段有三段（丁良才）、四段（《中文聖經註釋》）、 兩段（《串珠》《丁道爾》）、1-11／12-17／18（《啟導本》）四種；體裁有得勝詩、感恩詩、登基詩、 祈禱詞四說（《中文聖經註釋》）；v13-18 是預言（CT 的「完成式預言／未來式預言」、《丁道爾》的 「先知式完成時態」）還是聖殿建立後的加筆（《中文聖經註釋》），兩派對立，各以「非利士的居民」（v14） 與「你手所建立的聖所」（v17）為據。
- 與本章關聯：這場爭論決定了摩西之歌後半（v13-18）該讀成摩西當日的信心宣告，還是後世崇拜儀式的追加—— 也連帶決定了「神的聖所」究竟指西乃的山、整片迦南地，還是錫安山的聖殿。

## 主題發展

**這首詩是什麼體裁，也沒有共識。** GT《中文聖經註釋》一口氣列了四種主張：有人認為是得勝的詩歌， 因為緊接前章末兩節；有人認為是感恩詩，因為不單感謝過紅海的拯救，也感謝神帶領贖民進入迦南； 另有人認為是君王的登基詩或頌讚神為王的詩歌，因為 18 節提到「耶和華必作王，直到永永遠遠」； 又有人把它當作祈禱詞，因為第6、11、16 節都有重疊語句，正如應答的祈禱一樣。
**v13-18 是預言，還是後來加上去的。** 這是本章最大的分歧。CT 主張是預言，並給出一套讀法：13-16 節 是「完成式預言」，17-18 節是「未來式預言」，它在 v14、v15、v16 下各附一則備註申明這一點。 GT《丁道爾聖經註釋》用的是同一個立場、不同的術語：「貫徹全段的過去式大概是『先知式完成時態』， 即是將未曾發生的事件，當作既成的事實描述。這做法從前十分常見，舊約先知書中尤其普遍。」 GT《每日研經叢書》也從時態切入，指出希伯來文的「完成式」在預言經文中經常是「預言完成式」， 並舉以賽亞書九2-7 為最熟悉的例子。GT《聖經精讀本──出埃及記註解》說得最短：「把將來的事件用完成式來 表示的原因是，堅信這件事情必然成就。」 但 GT《中文聖經註釋》主張是後期加筆：「由這節起至18節，明顯的與出埃及和過紅海的歷史事件無關。 乃是進佔迦南和在錫安山建築聖殿後的歷史背景。較早的註釋家多用『預言』來解釋這幾節經文。其實， 這首詩歌卻是在迦南地，聖殿建立後，在節慶崇拜儀式中使用此詩歌時，逐漸加上去的。」
**兩條年代證據。** 一是 v14 的「非利士的居民」。GT《中文聖經註釋》說：「以色列人出埃及過紅海時， 非利士人還居住在海島上，尚未進佔其後稱為非利士地……故此，這節經文絕不可能是摩西時代所寫的。」 GT《丁道爾聖經註釋》給了年份：「主前一一八八年非利士人抵達迦南以前，這地不可能有此名稱，因此這句話 起碼當來自入侵迦南以後。」二是 v17 的「你手所建立的聖所」。GT《中文聖經註釋》認為指耶路撒冷的聖殿， GT《舊約聖經背景註釋》也說「山、產業、住處、聖所一同出現，顯示所指的是錫安山──耶路撒冷」。 但 GT《丁道爾聖經註釋》兩處都反駁：「這些平行的語句又證明本節未必直指錫安山或所羅門的聖殿，因而有 可能是早至摩西時代的作品」，並指更遠古的拉斯珊拉泥版已經有類似的語言。它同樣用語言學為早期辯護： 「強而有力的韻律，簡潔而深奧的思想，富有古風的語言，都顯示這歌是早期的作品」，並舉出多處古式動詞 字尾為證。
**摩西之歌與米利暗之歌孰先孰後。** GT《丁道爾聖經註釋》承認難以斷定：「究竟是米利暗和她的女聲合唱團 在跳舞之後唱出全首摩西的歌，還是摩西的歌從神學角度闡釋了米利暗之歌的主題，實在難以斷定。」 GT《中文聖經註釋》傾向後者，理由是句式：v1 下的首句是個人的認信，「這在以色列的宗教史上，是屬於後期 的」；v21 卻是第二人稱複數的命令式，「這種向集體的團體要求，在以色列的宗教史上，是屬於較早期的」。 GT《啟導本聖經腳註》也說「此歌可能為1～18節長歌的歌題」。
