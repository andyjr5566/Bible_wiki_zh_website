# 神約定之妻

## 定義

創世記二十四14 僕人求神顯明「你所預定給你僕人以撒的妻」，第44節重述時作「耶和華給我主人兒子所預定的妻」。第50節拉班和彼土利的回答則是這個主題在本章的結論：「這事乃出於耶和華，我們不能向你說好說歹。」這個主題講的是婚姻中神的主權與引領，但本章同時保留了人的參與——第58節利百加自己說「我去」。

## 主題發展

### 「這事乃出於耶和華」

第50節是全章的樞紐。CT 說：「信徒遇事一看出是出於神，就應當順服」；GT《聖經精讀本──創世記註解》說神是通過拉班和彼土利的嘴，「明確表明以撒的婚事是神預定和護理的結果」，並列出這件事能順利完成的三個條件——亞伯拉罕堅固的信仰（7節）、老僕人火熱的使命感（33節）、拿鶴後裔最基本的敬虔。

KC 的讀法保留了一點餘地：他們說不出好歹，意思是「他們不能加添也不能減少，改變不了什麼」（比較民二十四13）；而「他們的允諾看來與其說是出於熱心，不如說是出於不得已」——第55節挽留十天正印證了這一點。

### 神的預定與人的決定並存

本章沒有把人的意願讀掉。第57-58節家人叫利百加來問「你和這人同去嗎」，她說「我去」。

CT 說這話表明她有決斷力：她雖未見過以撒，卻相信老僕人的話、內心起了嚮往，因此熱切地盼望去到他那裏（比較彼前一8）。GT《舊約背景註釋》則指出這一步在當時其實不尋常——古時女子在重要事務中甚少有作決定的份，利百加對自己的婚事本來不得置喙（50-51節）；她之所以被諮詢，「可能是因為她在這種特殊情況底下離開家庭的保護，是要冒頗大危險之故」。GT《聖經精讀本──創世記註解》說得更明確：家人叫她來，「不是問她是否同意結婚，而是把馬上離開還是遲後離開的決定權交在利百加手上」。

分寸因此清楚：神的預定顯明在整條路上（記號、時機、血統），而利百加所決定的是那一段路要不要現在就走。精讀本把這個決定的份量說到底：因這決定，「她在成為新族長妻子的同時，也成為基督家譜中的一員」。

### 擇偶的兩個條件

亞伯拉罕給的條件是否定式的——不可娶迦南女子（3節）、不可帶以撒回本地（6、8節）。CT 把前者的理由歸於信仰：迦南各族拜偶像，恐後裔被誘離真神（比較王上十一2；申七3-4；林後六14）。GT 李道生《舊約聖經問題總解》把應用寫得最長，並舉以掃娶外邦女子使以撒和利百加心裡愁煩為反證（創二十六34-35、二十七46）。

但 GT《舊約背景註釋》提出的動機不同，值得並陳：它把這種「內族通婚」的動機分成宗教、社會、種族三類，並判斷本處「似乎是種族因素，因為經文沒有表示拉班、利百加、拉結的信仰，與亞伯拉罕一家有什麼共通之處」；真正的關鍵是與神所立的約需要亞伯拉罕一家不被迦南這個大熔爐所同化。這個讀法提醒：把第3節直接解成「擇偶首在信仰純潔」是後代的應用，而創三十一19 拉班家中的家神像正是一項反證。
