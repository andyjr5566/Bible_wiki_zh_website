# 迦南地的居民分佈

## 定義

第29節用一句話把迦南地的族群按地形分了三塊：「亞瑪力人住在南地；赫人、耶布斯人、亞摩利人住在山地；迦南人住在海邊並約但河旁。」

| 族群 | 位置 | 來歷（依 GT《舊約聖經背景註釋》） |
| :--- | :--- | :--- |
| 亞瑪力人 | 南地 | 亞伯拉罕的後裔，屬以掃一系（創三十六15），主前第二千年紀下半葉在尼革與西乃地區居住的遊牧或半遊牧民族 |
| 赫人 | 山地 | 「著名的赫人來自安那托利亞，即今日的土耳其」；在敘利亞與迦南定居的部族同樣稱赫人，「這兩種赫人可能有血緣關係，但亦可能無關」——迦南赫人有閃族語名字，安那托利亞赫人的名字屬印歐語系 |
| 耶布斯人 | 山地 | 在耶路撒冷一帶居住，「只有聖經才提過他們，並且所提供的資料也很少」 |
| 亞摩利人 | 山地 | 在美索不達米亞稱為阿穆魯或馬爾圖人，「早於主前第三千年紀中期，已經出現在信史之中」；「亞摩利」可以指地方（西方人），也可以指民族 |
| 迦南人 | 海邊與約但河旁 | 「住在有牆城邑的主要居民，但他們似乎不是此地的原住民」 |

**「迦南人」這個詞有大小兩種用法。** GT 丁良才：「這三個字有兩層意思：1有時單指著住在猶太國之迦南的後裔；2有時卻是幾族人的總稱。」

**埃及史料提供了旁證。** GT《舊約聖經背景註釋》：「在亞馬拿書函中（主前第二千年紀中期），這地區的君王自稱為基納努，同時代的埃及碑文用的也是這名字。」它並舉出一份名單：「亞門霍特普二世（主前十五世紀）某次戰役的俘虜名單，分別列出迦南人、阿皮魯人（無地業或離鄉別井的人）、沙蘇人（有時被視為與聖經中之米甸人和亞瑪力人有關聯的遊牧民族）、胡魯人（胡利人）的數目。」

**城邑的規模。** GT《靈修版聖經註釋》：「探子提到的堅固城邑是由高牆圍建，牆寬6.1公尺，高7.6公尺，其上有衛兵站崗，遠眺全境。」BH 也說迦南城邑「常建在高處並有堅固城牆，耶利哥與夏瑣的考古發掘可以印證」。

## 按書卷累積

### 民數記

<!-- accumulation:民數記:13:start -->
#### [[04 民數記/第13章|第13章]]
- 本章重點：第29節按地形把迦南地的居民分成三區。GT《舊約聖經背景註釋》用整段逐一說明五族的來歷與史料位置，包括赫人的安那托利亞來源、亞摩利人在主前第三千年紀的信史紀錄、亞馬拿書函中「基納努」的自稱，以及亞門霍特普二世俘虜名單分列的四類人。
- 與本章關聯：這一節是探子報告裡唯一不帶情緒的部分——它只陳述誰住在哪裡。但它的位置很關鍵：它緊接在第28節那句「然而」之後，等於把恐懼具體化成一份名單。把這份名單放回當時的史料裡看，這些族群確實存在、確實有城邑，探子說的是實話；問題不在資料，而在結論。
