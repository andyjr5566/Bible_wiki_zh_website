2. 六日要做工，第七日乃為聖日，當向耶和華守為[[安息日|安息聖日]]。凡這日之內做工的，必把他治死。
3. 當[[安息日]]，不可在你們一切的住處生火。
4. 摩西對以色列全會眾說：耶和華所吩咐的是這樣：
5. 你們中間要拿禮物獻給耶和華，凡[[甘心樂意的奉獻|樂意獻的]]可以拿耶和華的禮物來，就是金、銀、銅，
6. 藍色、紫色、朱紅色線，細麻，山羊毛，
7. 染紅的公羊皮，海狗皮，[[皂莢木]]，
8. 點燈的油，並做膏油和香的香料，
9. 紅瑪瑙與別樣的寶石，可以鑲嵌在[[以弗得]]和[[胸牌（決斷胸牌）|胸牌]]上。
10. 你們中間凡心裡有智慧的都要來做耶和華一切所吩咐的：
11. 就是[[會幕（帳幕整體）|帳幕和帳幕的罩棚]]，並帳幕的蓋、鉤子、板、閂、柱子、帶卯的座，
12. 櫃和櫃的槓，[[施恩座]]和遮掩櫃的幔子，
13. 桌子和桌子的槓與桌子的一切器具，並[[陳設餅桌子|陳設餅]]，
14. 燈臺和燈臺的器具，燈盞並點燈的油，
15. 香壇和壇的槓，膏油和馨香的香料，並[[會幕（帳幕整體）|帳幕]]門口的簾子，
16. 燔祭壇和壇的銅網，壇的槓並壇的一切器具，洗濯盆和盆座，
17. 院子的帷子和帷子的柱子，帶卯的座和院子的門簾，
18. [[橛子與繩子的預表|帳幕的橛子並院子的橛子，和這兩處的繩子]]，
19. 精工做的禮服和祭司亞倫並他兒子在聖所用以供祭司職分的聖衣。
20. 以色列全會眾從摩西面前退去。
21. 凡[[甘心樂意的奉獻|心裡受感和甘心樂意的]]都拿耶和華的禮物來，用以做[[會幕（帳幕整體）|會幕]]和其中一切的使用，又用以做聖衣。
22. 凡心裡樂意獻禮物的，連男帶女，各將金器，就是胸前針、耳環（或作：鼻環）、打印的戒指，和手釧帶來獻給耶和華。
23. 凡有藍色、紫色、朱紅色線，細麻，山羊毛，染紅的公羊皮，海狗皮的，都拿了來；
24. 凡獻銀子和銅給耶和華為禮物的都拿了來；凡有[[皂莢木]]可做什麼使用的也拿了來。
25. [[婦女參與建造會幕|凡心中有智慧的婦女親手紡線]]，把所紡的藍色、紫色、朱紅色線，和細麻都拿了來。
26. [[婦女參與建造會幕|凡有智慧、心裡受感的婦女]]就紡山羊毛。
27. 眾官長把紅瑪瑙和別樣的寶石，可以鑲嵌在[[以弗得]]與[[胸牌（決斷胸牌）|胸牌]]上的，都拿了來；
28. 又拿香料做香，拿油點燈，做膏油。
29. 以色列人，無論男女，凡[[甘心樂意的奉獻|甘心樂意獻禮物]]給耶和華的，都將禮物拿來，做耶和華藉摩西所吩咐的一切工。
30. 摩西對以色列人說：[[猶大支派]]中，[[戶珥]]的孫子、烏利的兒子[[比撒列（Bezalel）|比撒列]]，耶和華已經提他的名召他，
31. 又[[蒙靈充滿的智慧恩賜（比撒列、亞何利亞伯）|以神的靈充滿了他]]，使他有智慧、聰明、知識，能做各樣的工，
32. 能想出巧工，用金、銀、銅製造各物，
33. 又能刻寶石，可以鑲嵌，能雕刻木頭，能做各樣的巧工。
34. 耶和華又使他，和[[但支派]]中亞希撒抹的兒子[[亞何利亞伯（Oholiab）|亞何利亞伯]]，心裡靈明，能教導人。
35. [[蒙靈充滿的智慧恩賜（比撒列、亞何利亞伯）|耶和華使他們的心滿有智慧]]，能做各樣的工，無論是雕刻的工，巧匠的工，用藍色、紫色、朱紅色線，和細麻、繡花的工，並機匠的工，他們都能做，也能想出奇巧的工。

## 本章整理

> [!important] 會幕的描述從頭再來一次——而這正是重點
>
> [[出35-40 逐字複述出25-31|出35-40 幾乎是出25-31 的重述]]，讀來像重複。KC 指出這個「重複」本身就是信息：
>
> ==「在這一章，會幕的描述又開始了。這顯出出埃及記32-34章中人的罪，並沒有除去、甚至沒有減少神的恩典。儘管人是什麼樣、做了什麼，神仍成就祂的定旨。==
>
> ==百姓已經顯明了：一條通往神的路是何等必要。而會幕如今臨到一群墮落的百姓中間。」==
>
> 至於材料清單為什麼要一字不差再列一遍，KC 也給了理由：==「這不是無謂的重複。神重複一件事的時候，就使那件事對祂有多重要顯得更清楚，我們也就領會它對祂的價值。」==

CT 為出埃及記後半段劃出的四段結構，正好說明本章的位置：

| 段落 | 內容 |
| :--- | :--- |
| 出25:1-31:18 | 神在山上指示會幕的建造 |
| **出35:1-36:7** | **摩西轉達神的話，以色列人回應（本章所在）** |
| 出36:8-39:43 | 建造會幕的實際施工 |
| 出40:1-38 | 完工後立起會幕 |

GT《啟導本聖經腳註》描述這段重述有多徹底：「大半為逐字逐句的複述，只不過把動詞從未來式改為過去式，例如『你要用十幅幔子作帳幕』（出26:1），現在改為『他們…用十幅幔子作帳幕』（出36:8）。有一小部分為節略或增添。增添部分在35到36章特別多。」GT《丁道爾聖經註釋》則否定「意外重複」之說：「這是不可能的，因為還有一些重要資料加插在內，材料也有些調動。重複若然存在，也都是故意的，==所點出的教訓是摩西忠心實踐神的指示==。」

### 重申安息日律例（v1-3）

[[全會眾（kol ha-edah）|摩西招聚以色列全會眾]]，把[[山上的樣式]]正式向他們宣達。GT 丁良才指出這一節「續三十一18節」——摩西前次下山並沒有給百姓述說神指示造會幕的事，「因為他們造金牛犢，干犯了主的烈怒」；他並注意到一個細節：「摩西前次上山約書亞也在山上，第二次只有摩西一人。」CT 把「全會眾」的分量展開：這是「殉道者司提反稱他們為『曠野的會』（參徒7:38）」的那群人——「一群蒙神救贖並呼召，從世界（埃及所豫表的）裏出來……又建造會幕的人」。

但摩西開口說的第一件事不是會幕，是[[安息日]]。

> [!question] 為什麼[[安息日與會幕工程的關係|安息日的條例被放在會幕清單的最前面]]？
>
> GT《丁道爾聖經註釋》指出這個位置是刻意的，而且與出31 恰好相反：
>
> ==「安息日的律法在此位於整個段落的開始，在第三十一章卻是該段落的結語。毫無疑問這是故意安排。若然，我們可以看出一個明顯的結論：以色列縱然捲在建造帳幕的熱潮中，仍然不可稍忘守這聖日。」==
>
> GT《串珠聖經註釋》給的是約的理由：「這裡再提安息日是十分適合的，因神已重新訂約，而安息日就是約的標記（出31:16）。」GT《聖經精讀本》給的是位階的理由：「因為安息日概括代表所有立約內容，==是百姓應遵守的最基本的條例==，所以摩西在這裡先提到了安息日。」
>
> 丁良才把這件事說得最實際：「百姓興工造會幕以先，摩西提醒他們，==就是在造會幕的工作上也必須守安息日==。」

本章另加了一條全舊約獨有的禁令：[[安息日不可生火|「當安息日，不可在你們一切的住處生火」]]。GT《串珠聖經註釋》指出「這條例很獨特，沒有在舊約別處出現」，而它的所指有三種讀法：CT 與《啟導本聖經腳註》以出16:23 為據，認為是烹煮三餐的火；GT《丁道爾聖經注釋》記下海厄特的提議——「這條禁令針對的，可能是建造聖所金工所用的火」，而《串珠》把這一層說到底：「==甚至為建造會幕生火化金屬，在該日也不容許==」；GT《聖經精讀本》則主張重點在態度：「可能這是為了讓人不是消極地照字面意思遵守安息日，而是能夠積極的、發自內心地遵守。」

[[古代近東安息日|後世的執行]]也留下了痕跡。GT《舊約聖經背景註釋》：「後世猶太教拉比律法的判決，規定必須在安息日之前點燈，免得房屋陷於黑暗。但在安息日時卻不可為這火加添燃料。」GT《中文聖經註釋》描述至今的實況：「直至今日，正統的以色列人家中在安息日是不生火的，連接亮電燈都算為違犯安息日的例。他們在安息日的會堂崇拜也不收奉獻的，因為他們在安息日是不能沾銀錢或紙幣的。」至於「凡這日之內作工的，必把他治死」這樣的刑度何以可行，GT《聖經精讀本》指出是政體使然：「由於當時的以色列是政治、宗教一體化的神政國家，所以完全可能做到這一點。」

### 材料、工人與三種心（v4-19）

摩西向全會眾提出的要求分兩類：材料與人才。而丁良才注意到本章對人的描述始終扣在「心」上，並把它分成三等：

| | 條件 | 出現處 | 誰可以 |
| :--- | :--- | :--- | :--- |
| 一 | 凡心裡**樂意獻**的 | 5、22、29節 | 人人 |
| 二 | 凡心裡**有智慧**的 | 10、25、35節，出36:1、2、8 | 有手藝的人（含紡線的婦女） |
| 三 | 凡心裡**受感**的 | 21、26節，出36:2 | 被神感動的人 |

丁良才並把三者的分工說明白：「眾人都能獻禮物（5-7），==唯獨有智慧的才能做神所吩咐的工==，但這話也包括紡線的婦女（25）。」他另從百姓那一面歸納出誠心的三樣證據：「（一）他們願意聽從；（二）他們願意供獻；（三）他們願意做工。」

[[心裡有智慧|「心裡有智慧」]]這個詞值得單獨看。CT 的〔原文字義〕給的是「智慧的，精明的，有技巧的」，指「一切能夠製作會幕和附屬器具的工匠」；GT《丁道爾聖經注釋》指出這是譯法差異：「一切『能幹』的人都可以參加建築（==英譯多作『能幹』；和合本直譯作『心裡有智慧』==）。」——中文保留字面，英譯取其所指。

至於[[甘心樂意的奉獻|奉獻的原則]]，CT 把它說成一種身分：「『你們中間』，是指蒙神救出埃及的人說的。神不是向外人要禮物……==奉獻是聖徒的一項權利==，屬神的聖徒，才可以有資格向神奉獻。」而它的性質是自願的：「奉獻是『樂意獻的』，不是勉強的；你不甘心樂意拿來，沒有人向你強行收取。」

第11-19節列出的是會幕零件的完整清單，從[[會幕（帳幕整體）|帳幕本體]]、至聖所的約櫃與[[施恩座]]、聖所的[[陳設餅桌子]]與金燈臺、外院的燔祭壇與洗濯盆，一直到[[以弗得]]、[[胸牌（決斷胸牌）]]等祭司聖衣。KC 為第12節「遮掩櫃的幔子」補了一個出處：那是民4:5 所說的幔子——起營時亞倫和他兒子要取下它蓋在法櫃上。

> [!note] 會幕的器具人所共見，惟有[[橛子與繩子的預表|橛子]]看不見
>
> CT 在第18節的話中之光寫了本章最長的一段默想，而它的起點只是清單上一個不起眼的項目：
>
> ==「會幕中的器具人所共見，惟有橛子人看不見深埋地中，卻擔起支持會幕之工作。世人均想坐首席，做領袖，居高位指揮別人，少有人甘心隱藏。橛子為高舉基督，卻願意埋藏自己。」==
>
> 它連橛子的形狀都讀出意思來：「橛子的形式是一面尖，一面禿。尖的一方面可深入地下。橛子禿之方面，可最受重擊，在教會中不論你做事快或慢，言論大或小，均會招來弟兄之指摘攻擊，==但屬主的人卻如橛子般，堪經重擊==。」
>
> 繩子則讀成另一件事：「會幕院子的銅柱，每根用兩條繩子來固定，==一條在院裡，一條在院外==。這些繩子好像是向神雙份的大愛……我們寶貴的救主，因著這愛被綁在受審判的位置——十字架上。」而 CT 隨即指出今天缺的是哪一半：「許多人受復活的基督吸引是因為他的榮耀與權能；這些固然美好與寶貴，==可是很少有人受吸引去尋求在基督的受苦與降卑上與他聯合==。」

### 百姓的回應（v20-29）

全會眾從摩西面前退去，隨即是全書最熱烈的一段奉獻。丁良才把百姓的捐法歸納成六層：

| | 特徵 | 依據 |
| :--- | :--- | :--- |
| 一 | 甘心樂意 | 21節（參林後9:7） |
| 二 | 按著所有 | 23-29節 |
| 三 | 人人都捐 | — |
| 四 | 豐豐富富 | 出36:5-7 |
| 五 | 足夠有餘 | 出36:7 |
| 六 | 獻給真神 | 23-24節（參可12:41-44） |

同一位作者也誠實地指出這熱潮不是全體：「百姓心裡多半受了感動，本句卻顯明還有人沒有受感（22、29）。」

> [!important] 他們拿去造金牛犢的金環，已經回不來了
>
> 這是 KC 讀本章最扎人的一筆，也是他把出32 與出35 接起來的地方。
>
> 出32:3「百姓就都摘下他們耳上的金環，拿來給亞倫」——那些金環進了火，成了牛犢。而出35:22 百姓再一次帶來「胸前針、耳環、打印的戒指」獻給耶和華。
>
> KC 的觀察很短，卻很重：
>
> ==「在出埃及記32章，他們拿他們的首飾去造金牛犢。那些首飾他們已經失去了，如今很遺憾地獻不出來。」==
>
> 然後他把這句話轉向我們：==「照樣，我們給了世界的東西，就在主的事奉上失去了。」==
>
> ——奉獻的清單上，永遠有一格是空的。那一格不是不肯給，是**已經沒有了**。

[[婦女參與建造會幕|婦女的參與]]在本章有兩節專門的記載（25-26節）。GT 丁良才從當時的分工說明她們為何做這一項：「在埃及國==女人多紡線，染布，男人多織布，繡花==。」GT《聖經精讀本》則指出這件事在當時社會裡的分量：「『智慧的』一詞的希伯來文與10節中的『智慧』是同一個意思。==當時的女人不記在家譜裡，但神賜給她們和男人同等的恩賜==，使她們也能作神的工作。」

> [!note] KC：她們有男人所沒有的特別資質
>
> KC 對女人在這工作上的分量說得很正面：「女人完全有分於為會幕作的工。==她們有男人所沒有的特別資質。她們也常常對什麼合乎神的心意有更好的感覺。==」
>
> 他舉的例子是馬利亞：「門徒中沒有一個人作過像馬利亞所作的事。她膏了主耶穌的腳（約12:3）。==她也為此得著祂特別的題說==（太26:13）。」

另一端是[[以色列人的官長|眾官長]]獻上的紅瑪瑙與寶石（27節）。丁良才記下他們身分的兩種推測：「有人以為這些官長是百姓的長老（出3:16，4:29，24:9），也有人以為是十二支派的首領（民1:16，7:2）。」GT《丁道爾聖經註釋》把整章的分工收成一句：「女人可以紡線（箴31:13），官長比較富有，可以帶來寶石和香料。==人人都有分為耶和華建造聖所，若不是各盡其職，工作也不能完成==（參弗4:16）。」GT《串珠聖經註釋》同樣指出奉獻名單「包括不同階層的以色列人……這證明會幕的完成，每一個人的參與都是重要的」。

### 兩位巧匠（v30-35）

摩西宣告神已提名召[[比撒列（Bezalel）|比撒列]]——[[猶大支派]]中[[戶珥]]的孫子、烏利的兒子，並[[但支派]]中亞希撒抹的兒子[[亞何利亞伯（Oholiab）|亞何利亞伯]]。CT 說明為何要連父祖一起報：「通常聖經中同名不同人的情形相當普遍，因此在提到某一位特定的人時，往往附帶提到他的父親和祖父是誰，以避免發生混淆。」

[[蒙靈充滿的智慧恩賜（比撒列、亞何利亞伯）|神的靈充滿了他]]，「使他有智慧、聰明、知識」。CT 把這三者分開：「『智慧』偏重於對事物的創見；『聰明』偏重於對事物的領悟；『知識』指對事物學習和經歷的累積。」丁良才則指出這三樣帶出三種結果：「（一）能做各工（31）；（二）能想巧法（32）；（三）能教導人（34）。」而末一項是本章相對出31 新增的——GT《啟導本聖經腳註》特別點明：「34節提到比撒列和亞何利亞伯怎樣受感教導其他工匠，==這是前面所無的==。」

CT 在此下了一句很要緊的分辨：==「神呼召有恩賜的人，用他們的恩賜事奉他，但絕對不是靠他們的恩賜，乃是靠著『神的靈充滿』。」==

> [!important] 創意是神給的，但怎麼用創意不歸人自己決定
>
> 比撒列與亞何利亞伯所領受的創意，KC 劃了一條很清楚的界線：
>
> ==「祂賜下創意，卻不把怎樣使用它留給人自己。他們在創意中所設計的，必須源於神的靈的工作。問題不在於它是否合乎人的口味，而在於它是否合乎神是誰。」==
>
> 他並指出這條原則一路延伸：建殿時「所羅門也沒有留下任何想像的餘地」——大衛把樣式交給他（代上28:11-12）；==「地方教會也是一樣。為著教會的聚集，主已經給了清楚的指示，我們不可以按自己的判斷去更改、甚至去忽略」==（林前11:23、14:37）。

丁良才把「雕刻的工、巧匠的工、繡花的工、機匠的工」分派給兩人：「『雕刻的工』——這是比撒列所做之工的總稱；『巧匠的工』——就是亞何利亞伯所製造之帳幕的幔子、內幔、以弗得和胸牌等」。CT 對此留了餘地：「有不少解經家認為比撒列擅長金屬類細工，亞何利亞伯則擅長織繡工，不過，==兩人既是工頭，對於製作會幕和相關器具的各樣工作技巧，應當都具相當程度的熟練==。」

### 這份清單上的東西，在古代近東是什麼

BH 為第5-9 節的材料清單補上了物料本身的背景，而這些背景讓「甘心樂意的奉獻」有了價錢。

- **紫色**——BH 指出這個顏色取自骨螺，稀有而昂貴，在古代近東象徵財富與貴族身分；**藍色**常與諸天和神的啟示相連，民15:38-39 正吩咐以色列人衣邊的繸子上要有一條藍細帶子，作記念神誡命之用；**朱紅**則與犧牲和贖罪相連。
- **細麻**在古時是奢侈布料，多用於祭司衣袍與聖所；而**山羊毛**是常見得多的材料，日常用來做帳篷與家用器物。BH 由這個對比讀出一件事：兩種材料並列在同一份清單上，顯出神的同在既有祂的聖潔，也向祂的百姓可親近。
- **[[皂莢木]]**耐久抗腐，而皂莢樹在西乃一帶隨處可見——對一支正在曠野行進的隊伍，這是最實際的選材。
- **橄欖油**在古代近東是貴重物資，同時用於烹煮、醫藥與照明；在會幕裡它專供點燈，而燈要在耶和華面前常常點著。
- **金、銀、銅**在古代近東常用於宗教與王室用途，本身即代表財富與地位。BH 另指出銀在會幕裡與贖罪相連——出30:11-16 的贖罪銀正是用銀舍客勒收的。

而[[安息日不可生火|不可生火]]這條禁令，BH 也放回同一個處境裡看：在古代近東，火是烹煮、取暖與各種工作的必需品，禁止生火因此等於要求一種徹底的停工與倚靠；這也使以色列人的敬拜與生活方式，明顯有別於四圍不守這樣一個安息日的列國。

### 跨章脈絡

本章的位置決定了它的意義：出25-31 的指示被出32 打斷，出33-34 恢復了[[神的同在]]與約，本章則是重新開工。CT 注意到本章與出25 的奉獻有一項差別：「二十五章所說的都是建造物料的奉獻，而三十五章的奉獻，除了物料以外，我們還看見有另外的奉獻，那就是==人的奉獻==。全合起來，我們看見兩類的奉獻，==一個是獻上人的所有，一個是獻上人的自己==。」

而 CT 在燈檯那一節留下的一句，可以當作本章對讀者的問題：「今天教會不患無基督徒，患在發光的基督徒太少。」
