# 尼羅河與埃及農業

## 定義

尼羅河是埃及農業的唯一命脈。古埃及降雨極少，全部農業仰賴尼羅河每年氾濫帶來的水源與肥沃淤泥。創世記41章法老夢境中七肥牛、七瘦牛從河上來（創41:2-3, 18-19），七穗從一莖長出（創41:5, 22），皆直接對應尼羅河水位決定的農業豐荒。

## 主題發展

丁良才記下一則很具體的傳說，把尼羅河與豐荒的關係量化了：「傳說尼羅河若只漲溢十二肘，就成了荒年；十三肘，眾人要受饑餓；十四肘眾人就歡喜；十五肘，莊稼就可收；十六肘，就是豐年；若漲得更高，就成了水災。」他並解釋埃及的雨水稀少，「那地的田禾多憑著尼羅河水的漲溢而得澆灌」（摩8:8）。GT《聖經精讀本》同說這條河「水的情況，決定埃及農業是否豐收」。法老夢中的牛正是從這條河裡上來——CT 的背景註解說明，尼羅河一帶的牛隻「喜歡浸在水中，只將頭頸露在水面上，以躲避烈日和蒼蠅」，這也是夢境何以如此寫實的緣故。
