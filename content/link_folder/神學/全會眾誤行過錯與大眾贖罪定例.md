# 全會眾誤行過錯與大眾贖罪定例

## 定義

聖經透澈關懷人心因為未洞察全盤律法或因為認知漏差而捲入群眾不守耶和華命令之巨大疏虞，故於第15章安畫明訓：凡全團營在無心忽而不曉中闖落錯誤的沉痾，當經見悟出時，須毫不猶疑驅領純幼的一匹壯碩公牛犢直火作全然奉納之燔祭與等分油素祭奠祭，另外不可省捨地斬牽一匹肥綿公山羊行血作徹底贖罪免過禮；大祭司憑此雙儀親於施慈靈駕的公宰面前代眾代叩求解，上帝便明言「他們就必蒙宥許饒容」，因為是誠而誤陷所致。

- 本章重點：設立集體性的神恩解罪救濟系統，群體性無意背失得奉上一公牛為全投熱愛火燔與一手多毛公山羊贖清無知瑕疵而穩穩蒙准恩赦。
- 與本章關聯：展顯集體神學倫理上過犯與代罪赦刑的寬大庇翼：不只重在贖洗塵瑕，更加藉上燔祭表達眾志成城痛悔悔轉並重新順向遵道的嚴謹歸心。
