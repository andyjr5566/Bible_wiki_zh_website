# 摩西是否未求問耶和華就允准

## 定義

民數記32 全章沒有一句話是從耶和華曉諭摩西開始的。摩西責備、立條件、分地，都是他自己開口。三套註釋注意到了這件事，各自給了不同的解釋。

| 來源 | 說法 |
|---|---|
| CT | 摩西的回話顯然沒有先求問神 |
| GT 串珠 | 摩西並無尋求神的指示，只按他對律法的瞭解作決定；神未清楚曉諭即等於默許 |
| GT《聖經精讀本》 | 摩西以神代理者的權柄與神所賜的智慧直接分配，沒有用拈鬮 |
| KC | 這不是照拈鬮分的；他把他們自己選的地給了他們 |
| BH | 沒有提出這個問題 |

CT 在第20節下了一句短評：「摩西的回話顯然沒有先求問神。」

GT《民數記串珠聖經註釋》把這件事接到上一章的許願條例上：「但本段似乎顯示，摩西並無尋求神的指示，只按他對律法的瞭解作出決定，並向祭司以利亞撒、約書亞和眾族長宣佈（28）」，又說「這事按起願的條例處理（參30章注），神既未有清楚曉諭，即等於默許，兩支派須履行起願的承諾（29），這事才蒙神悅納」。

GT《聖經精讀本》換了一個角度看同一件事：「摩西以神中保者的權柄,把約旦河東的土地分給流便、迦得子孫和瑪拿西半個支派的人。原本土地分配是通過拈鬮,以神的主權決定(26:55),但是摩西這次並沒有用這個方法,而是以神代理者的權柄和神所賜的智慧直接分配了土地。」

KC 指出的是同一個對照，但語氣是遺憾的：這不是像在應許之地那樣照拈鬮分的；摩西把他們自己選的地給了他們，而在那地裡每個支派得到的是神所選的分。

BH 逐節註解沒有提出摩西是否求問神這個問題。它在第20節的說法是摩西常常擔任神與百姓之間的中保，並把他的回答讀成他對支派間合一與順服的關切。

### 民數記

<!-- accumulation:民數記:32:start -->
#### [[04 民數記/第32章|第32章]]
- 本章重點：第20、33節：全章沒有一句話是從耶和華曉諭摩西開始的。CT 說摩西的回話顯然沒有先求問神；GT 串珠說他只按對律法的瞭解作決定、神未清楚曉諭即等於默許；GT《聖經精讀本》說他是以神代理者的權柄直接分配、沒有用拈鬮；KC 指出這不是照拈鬮分的；BH 沒有提出這個問題。
- 與本章關聯：這一點直接連到分地方式：民26:55 定的是拈鬮，本章卻是摩西直接分配，兩者的差別是幾套註釋判斷這件事性質的主要依據。
