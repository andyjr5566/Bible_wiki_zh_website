# 以色列人缺水爭鬧與摩西負氣杖擊磐石兩下之失

## 定義

在中東曠野遷徒程途中，會眾再駐加低斯之時逢遇井溪枯旱乏水，新生代民眾如同被懲之前民皆然，群情洶湧而聚合攻擊領導使僕，深恨何沒共殞在昔日苦瘟沉灰中；神主悲仁賜令摩西攜取昔昔震威手杖與兄同迎枯巖，「吩咐」是固石大放浩湯喜流；豈料摩西遭激負性而心潮失律，未仰王誠宣告主德，反而怒叱「背叛者豈我為爾推泉」，且率情揮揚杖頭一連兩下敲殛巨岩；雖上帝慈憫果出滾滾奔泉以解愚氓乾苦，然如此輕藐尊言之驕怒與逾制殛殺，宣告了歷史上領袖越權不顧主見證的浩劫巨憾。
