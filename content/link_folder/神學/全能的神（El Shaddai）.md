# 全能的神（El Shaddai）

## 定義

「全能的神」（El Shaddai）是神在創世記十七章對亞伯拉罕的自稱。原文可能意為「全有」、「全豐」、「站在山上的全能者」。舊約出現48次，在約伯記使用最頻繁（31次）。

## 主題發展

### 字源：三種說法，外加一句罕見的自承不確定

各家對「沙代」的來歷給出互不相容的解釋，值得逐一列名而不必調和：

| 來源 | 字源說法 |
|---|---|
| CT | 「有母親胸奶的神，意即全豐、全足、全有的神」——由「胸」的意象推出供應的豐足 |
| GT《啟導本聖經創世記註釋》 | 「此字有『全有』的意思，說明神的豐盛和無窮無盡的供應」 |
| GT《創世記雷氏研讀本》 | 「Shaddai 源於一個解作『山』的相關用字，因而把神描繪成一位站在山上的、無法抵抗的全能者」 |
| GT《串珠聖經註釋》 | 不談字源，只給語義：「原意是『不可抵禦的能力』」 |
| GT《聖經精讀本──創世記註解》 | 同樣不談字源，把它定位為神的第三種自稱：「伊羅欣」是創造治理天地的名稱，「耶和華」是立約救贖的名稱，「伊勒沙代」是「超越自然規律、具有能力成就應許的大能神的稱呼」 |

**GT《舊約背景註釋》則對整件事持保留**，而且措辭少見地直接：這名字在舊約中頗為常見（48次），「只是**傳統的翻譯比臆測好不了多少**」。它接著給出可查的外證與最主流的學說：

- 舊約以外只出現過一次——士師時代一尊埃及雕像上有「沙代亞米」（Shaddai-Ammi）之名；
- 代爾阿拉（Deir 'Allah）的碑文中，可能也提及過名叫沙代的活物；
- 「學者最常提出的解釋，是認為『沙代』與巴比倫語的『沙杜』（sadu，意即『草原、大山』）有關」。

值得注意的是，雷氏的「山」說與背景註釋所記的主流學說（sadu＝草原、大山）方向一致，而 CT 的「胸奶」說走的是另一條路。兩說不能同時為真，但都在來源中留有明文，宜並列。

### 出現的分佈與時代

GT《啟導本》整理了使用的時代分佈：西乃律法頒佈前，以色列人用此詞稱呼神；聖經中用這名最多的是《約伯記》（「全能者」一名用了31次）；《出埃及記》第6章以後，因為著重記述以色列民怎樣作與神立約的選民，「所以用『耶和華』取代了『全能的神』」。GT《聖經精讀本》補上這名字出現的三個關鍵場合：安慰雅各（創三十五11）、使摩西確信（出六3）、尋找痛苦中的約伯（伯四十1）。

### 為什麼在這一章用這個名字

GT 丁良才給的理由最直接：「神用這話，為要激發亞伯蘭的信心」，並引創十八14、耶三十二17、太十九26 為同型。GT《聖經精讀本》從時間點讀出同樣的意思：九十九歲「表明亞伯蘭對後裔的期望已完全斷絕，人絕望的時刻，正是神動工的時間」。KC 則注意到稱謂的轉換本身：這裡用的不是「耶和華神」，因為這一次的重點不是祂對亞伯蘭而言是誰，而是**祂自己是誰**。
