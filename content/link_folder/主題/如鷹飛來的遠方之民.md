# 如鷹飛來的遠方之民

## 定義

申命記第二十八章49至52節描寫一個從遠方來的敵人：「耶和華要從遠方、地極帶一國的民，如鷹飛來攻擊你。這民的言語，你不懂得。這民的面貌凶惡，不顧恤年老的，也不恩待年少的。」

### 這一國的民是誰

四套註釋在這裡的答案不完全一樣，而且各自都給了理由。

CT 說一國的民即指巴比倫人，如鷹飛來的鷹是巴比倫人的表號（耶四十八40）；不過他在同一段的備註裡把範圍放寬——49至57節所描述的外敵侵略時的慘狀，也應驗在巴比倫人之前的亞述人之侵攻北國以色列，以及主後70年羅馬帝國太子提多率軍攻打耶路撒冷兩件事上。

GT《申命記雷氏研讀本》的判斷是：顯然是巴比倫，因為聖經把巴比倫比作鷹；並說這預言也可能在耶路撒冷被其他人、尤其是主後70年的羅馬人圍攻的事件裡應驗。GT《啟導本聖經申命記註釋》則把「如鷹飛來攻擊」讀成亞述人攻擊力量的大而且快。

KC 的判斷方向相反：他說這幾節看來更像羅馬人的壓迫，而前面幾節比較像迦勒底人這個敵人；並補上一個具體理由——羅馬人的軍旗上就有一隻鷹。GT《聖經精讀本──申命記註解》給了一個折衷：與其說仇敵指某一特定軍隊，不如說是指包括羅馬軍隊的一切當以色列悖逆時折磨他們的列邦。

### 語言不通這一點

第49節末句「這民的言語，你不懂得」，GT《啟導本聖經申命記註釋》說這說明一般以色列人不懂亞述與巴比倫的語言。BH 讀出的重點在心理上：語言不通加深了失去控制與溝通的恐懼，這在聖經的征服與被擄敘事裡是常見的主題。

### 這個敵人做什麼

第50至52節把行為寫得很清楚：不顧恤年老的，也不恩待年少的；吃盡牲畜與土產；把人困在各城裡，直到高大堅固的城牆都被攻塌。CT 說這形容以色列人屆時將放棄鄉村田野，逃到有城牆防護的幾個城市中，被敵軍圍困，終至陷落。GT 說這幾節詳細形容這些侵略者的行為——他們不尊重生命，徹底劫掠百姓。BH 指出以色列往往倚靠設防的城，這一節強調的正是人的工事終究靠不住。

#### [[05 申命記/第28章|第28章]]
- 本章重點：第49至52節。CT 說一國的民即指巴比倫人、如鷹飛來的鷹是巴比倫人的表號（耶四十八40），並備註49至57節的慘狀也應驗在亞述人侵攻北國以色列與主後70年羅馬提多攻打耶路撒冷兩件事上；GT《雷氏》說顯然是巴比倫、也可能在主後70年羅馬人圍攻時應驗；GT《啟導本》把如鷹飛來讀成亞述人攻擊力量的大而且快，並說這民的言語你不懂得說明一般以色列人不懂亞述與巴比倫的語言；KC 說這幾節看來更像羅馬人的壓迫、前面幾節較像迦勒底人，並指羅馬人的軍旗上就有一隻鷹；GT《精讀本》說與其說指某一特定軍隊不如說是指包括羅馬軍隊的一切折磨以色列的列邦；BH 說語言不通加深了失去控制與溝通的恐懼，並指人的工事終究靠不住。
- 與本章關聯：這是本章咒詛描寫得最具體的一段，也是四套來源分歧最明顯的一處——同一段經文被指向亞述、巴比倫與羅馬三個時代。第52節的圍城直接帶出第53至57節城中吃兒女的慘況。
