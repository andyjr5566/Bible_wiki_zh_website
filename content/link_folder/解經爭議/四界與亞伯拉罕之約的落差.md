# 四界與亞伯拉罕之約的落差

## 定義

神給亞伯拉罕的應許是「從埃及河直到伯拉大河」（創15:18）；民數記34 畫出來的四界卻小得多。這個落差各家怎麼處理，說法並不一致。

| 來源 | 說法 |
|---|---|
| GT《聖經精讀本》 | 這裡的領土比應許給亞伯拉罕的縮小很多，到大衛和所羅門時期才得以成就 |
| KC | 這些邊界與神向亞伯拉罕提到的不相符，祂應許亞伯拉罕的地區大得多 |
| GT《啟導本》 | 所羅門王全盛時期的版圖，的確達到了本章所描述的四界 |
| GT《舊約聖經背景註釋》 | 以色列史中沒有一個階段的國界與本段相同 |

GT《聖經精讀本》的解釋是分期的：「這說明神對亞伯拉罕的應許是將來要成就的事情,而不是在征服迦南時。在以色列征服初期,神並沒有把以色列需要之外的土地賜給他們,以此教導他們知足和順服。本文所提到的地界是征服迦南的世代剛好能加以鞏固,建立家園的地界。」

GT《啟導本聖經註釋》的說法完全相反：所羅門王全盛時期的版圖的確達到了本章所描述的四界，並把埃及小河解為歷代為埃及和以色列的邊界。

GT《舊約聖經背景註釋》既不採前者也不採後者：以色列史中雖然沒有一個階段的國界與本段相同，這裡的描述卻與主前十五至十三世紀時埃及在迦南所占領的土地大致相似，並且亦接近聖經對大衛和所羅門所控制區域的敘述。它並提醒實際領土另有一個常用的說法——撒下三10 的「從但直到別是巴」。

KC 把落差本身讀成一個原則：邊界把屬於神的與不屬於神的分開，人需要知道該征服什麼、不該征服什麼；不要把神沒有給我們作產業的東西據為己有。

## 按書卷累積

### 民數記

<!-- accumulation:民數記:34:start -->
#### [[04 民數記/第34章|第34章]]
- 本章重點：第2-12節的四界與創15:18 應許給亞伯拉罕的疆域不同。GT《聖經精讀本》說領土縮小了很多、到大衛所羅門時期才成就；GT《啟導本》說所羅門全盛時期的版圖的確達到了這四界；GT《舊約聖經背景註釋》說以色列史中沒有一個階段的國界與本段相同；KC 把落差讀成邊界本身的意義。
- 與本章關聯：這是本章最實在的一個張力：同一段經文既可以讀成應許的縮小，也可以讀成應許在後代的成就。
