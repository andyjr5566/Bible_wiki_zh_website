# 罪伏在門前

## 定義

創世記4章7節中，「罪」חַטָּאת（H2403B）是陰性單數名詞，「伏」רֹבֵץ（H7257）是陽性單數分詞；神警告該隱，罪正伏在門前、戀慕他，而他要管轄它。註釋由此把罪描寫成蹲伏門口、伺機撲來的活物。

### 與目前整理書卷的關聯

神在該隱犯罪前給他警告。罪被描寫為獅子般蹲伏的活物，等待機會吞吃人。這句話顯示神給人選擇和制伏罪的能力。

## 主題發展

### 神學意義／研讀意義

- STEP 顯示「戀慕」תְּשׁוּקָה（`H8669`）與創3:16是同一個詞；「管轄」תִּמְשָׁל（`H4910`）是第二人稱陽性單數 Qal 未完成式。這組詞形先呈現罪的趨向與神對該隱的吩咐，註釋再討論「他」所指及長子地位等延伸讀法。
- CT 把本節的「罪」描寫成一個**人格化的活物**（羅七17），蹲伏在門前隨時撲過來；CT 並列出原文字義：「罪」＝罪孽（射不中目標）、罪刑、贖罪祭，「伏」＝躺臥、蹲伏
- 「蒙悅納」原文的意思是**上升、仰起臉來**（CT），GT《丁道爾聖經註釋》同樣指出原文意為「高舉」，正與6節「變了臉色」（原文為臉面下沉）相反
- 「他必戀慕你」— BH 指出「戀慕」與創三16女人戀慕丈夫是**同一個字**，表示強烈的支配傾向
- **爭議並陳：「他」指誰？** GT 丁良才記下兩種讀法——「有注釋家以為這『他』字是指著罪惡說的，意思說：罪惡如兇猛的野獸要害該隱，但他若行得好就可以得勝。也有人以為這『他』字是指著亞伯說的，意思說：該隱若行得好就能仍有長子的名分，兄弟必戀慕他（參三16）。」KC 也提到後一種方向：該隱若聽從，就仍能取得長子的地位並享受隨之而來的祝福
- 「你卻要制伏他」— 人有**選擇的能力**，但需要靠神才能勝過（羅七24-25）；BH 引加五16-17，指制伏罪不是靠人的力量，而是靠神的恩典與能力
- 宗教勸人為善，但**不能給人能力行善**（CT，羅七18）
- 神在該隱犯罪前先警告，顯示神的恩典和忍耐；GT《聖經精讀本》指出該隱受咒詛不是因為供物沒被悅納，而是「因他不理會神的督促，始終沒有悔改」
- GT《聖經精讀本》另指這是聖經裡第一次出現的「罪」，被描寫成試圖撲向人類的貪婪猛獸——「希伯來人借用古代巴比倫的表現手法，描寫罪就象守在門口向屋內的人吼叫的野獸」
