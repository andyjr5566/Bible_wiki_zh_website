# @quartz-community/search

The search component for the Bible study site.

## Features

- **Verse Search** - Search published Bible text one verse at a time and follow a link to the chapter.
- **Refinement and Shortlist** - Add terms that must occur in the same verse or save verses from separate queries in the current tab.
- **Knowledge Search** - Search entries and appendices by text, with multiple selectable categories.
- 📱 **Mobile Responsive** - Works great on all devices
- 🎯 **Search Preview** - Optional content preview panel
- 🌐 **Multi-Language** - Supports 30+ locales
- ⌨️ **Keyboard Shortcuts** - `Ctrl/Cmd + K` to open, `Escape` to close

## Installation

```bash
npx quartz plugin add github:quartz-community/search
```

## Usage

```yaml title="quartz.config.yaml"
plugins:
  - source: github:quartz-community/search
    enabled: true
    layout:
      position: left
      priority: 20
      group: toolbar
      groupOptions:
        grow: true
```

For advanced use cases, you can override in TypeScript:

```ts title="quartz.ts (override)"
import * as ExternalPlugin from "./.quartz/plugins";

ExternalPlugin.Search({
  enablePreview: true,
  placeholder: "Search for something",
  title: "Search",
});
```

## Configuration Options

```typescript
interface SearchOptions {
  /** Enable content preview panel */
  enablePreview?: boolean;
  /** Custom placeholder text */
  placeholder?: string;
  /** Custom title for the search button */
  title?: string;
  /** Feedback-form link shown under verse results; omitted = no hint. */
  feedbackForm?: {
    url: string; // https form URL
    choiceEntry: string; // entry.NNN of the routing question
    choiceValue: string; // option prefilled for that question
    queryEntry: string; // entry.NNN that receives the reader's query
  };
}
```

### Verse-search hints (build-time data)

Two hand-maintained tables in `quartz/data/` feed `static/verseSearchHints.json` (emitted next to
`verseIndex.json`; no plugin rebuild needed to edit them):

- `verse-search-related.json`: `{ "query word": ["wording used by the 1919 text", ...] }`. Shown as
  related-word chips; words with no hit in the published verses are dropped at build time.
- `verse-search-pins.json`: `[{ "query": "...", "ref": "申命記 11:18", "cuv": "word in that verse" }]`.
  The verse appears after the direct hits with `cuv` highlighted. Entries for unpublished chapters are
  skipped silently; a missing verse or `cuv` word logs a warning and is dropped.

## Default Behavior

By default, the search component:

- Displays as a button with a search icon
- Opens a fullscreen search modal when clicked
- Shows the total and renders results one page at a time
- Enables content preview on desktop (can be disabled)
- Supports keyboard navigation (arrow keys, Enter, Escape)
- Loads the index for the active mode as needed

## How It Works

The Search component:

1. Looks up direct Scripture references with the site's slim page index.
2. Matches text and refinement conditions in `static/verseIndex.json`, generated from published chapter pages.
3. Loads the full content index for knowledge search and filters matches by the selected categories.
4. Fetches page HTML separately for knowledge result previews.

> [!info]
> Knowledge search requires the ContentIndex emitter. Verse search uses the site's VerseIndex emitter.

## Keyboard Shortcuts

- `Ctrl/Cmd + K` - Open/Close search
- `Escape` - Close search
- `Arrow Up/Down` - Navigate results
- `Enter` - Open selected result

## Data sources

The original-language study data (`quartz/data/verse-original-terms.json`, format v2, shown as the
「換個譯法，也找得到相關經文」 cards) is generated by `scripts/original-terms/` from
[MACULA Hebrew](https://github.com/Clear-Bible/macula-hebrew) (Clear Bible / Biblica, CC BY 4.0; includes the
Cherith Chinese glosses by Andi Wu, CC BY 4.0), STEP Bible data and the 1919 CUV; see `scripts/original-terms/README.md`
and `dev-notes/original-terms/`.

The cross-version matching data (`src/data/compatData.ts`) is generated by `scripts/build-verse-compat.py` from:

- Chinese Union Version 1919 (Traditional; Public Domain) — the site's own scripture text.
- CrossWire SWORD modules ChiUn / ChiUns (Public Domain).
- [seven1m/open-bibles](https://github.com/seven1m/open-bibles) CUV USFX (Public Domain).
- [Unicode Unihan](https://www.unicode.org/charts/unihan.html) variants (Unicode License v3).
- [STEP Bible data](https://github.com/STEPBible/STEPBible-Data) by Tyndale House, Cambridge (CC BY 4.0) —
  Hebrew/Greek lemmas, transliterations and glosses.
- [BibleNLP biblical-names-data](https://github.com/BibleNLP/biblical-names-data) — aligned biblical proper
  names (CUV 2010 name column, built on [Macula Greek](https://github.com/Clear-Bible/macula-greek) /
  [Hebrew](https://github.com/Clear-Bible/macula-hebrew), CC BY 4.0). Used only to find modern
  proper-name spellings (e.g. 呂便 → 流便); the site ships these name pairs only, not any CUV 2010 verse text.
  The repository declares no license.
