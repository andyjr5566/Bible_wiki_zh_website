# 致咒詛苦水儀式是否迷信之爭

## 定義

喝苦水判案，看起來很像迷信。這個質疑本章來源自己就提了出來，並給了四種回應。

| 來源 | 回應的方向 |
|---|---|
| GT 賈斯樂郝威《聖經難解經文詮釋手冊》命題7 | 從身心關係解釋：結果不是化學或生理作用，而是「屬靈」或「心理」上的作用；並以假性懷孕、心因性失明、安慰劑為例，說「科學事實證明人的心思意念可以影響身體的生理機序」，苦水「就如測謊器一樣」 |
| GT 李道生《舊約聖經問題總解》 | 從性質區分：古代異教用熱鐵、滾水、毒藥，「有害無益」；「但神所吩咐使用的水，無害於人」，是神所用的一種超自然方法 |
| GT《啟導本》 | 從儀式的普遍性回應：儀式在人類生活中一向佔重要地位，國王加冕、總統宣誓、畢業典禮、婚禮都是；喝苦水反映以色列民重視貞潔，而「讓犯罪的女人不孕是神的作為，苦水起不了作用」 |
| GT《民數記串珠聖經註釋》 | 從受眾的認知回應：真正使儀式有效的仍是全能的神，而對曾目睹神榮耀的那一代人來說，「他們絕不會以為咒詛的苦水本身有魔術的能力」 |

賈斯樂郝威還提了一個文本上的細節：這段經文並沒有說任何人喝了苦水就必定腹脹，經文用的是條件句——「或是」她行淫才會遭到這種結果。

GT《聖經精讀本》從反方向補一句警告，對象是讀者而不是經文：「咒詛的話」本身沒有任何功效，人若只相信感覺得到的結果、對神用來成就旨意的工具表示敬畏，「這是危險的宗教習慣，能誘發拜偶像」。

## 主題發展

GT《舊約聖經背景註釋》從古代近東的比較給了這場爭論一個外部參照點：多數神明裁判都牽涉水、火、毒藥等危險，被告在神明未表態前處於假定有罪的位置；「相對而言，本段不施法術，也沒有牽涉危險，只是製造供神作出回應的環境而已」，女子在此是假定為清白的。這一點使本章與周圍文化的同類做法拉開距離。

GT《民數記串珠聖經註釋》在思想問題裡把同一個問題丟回給讀者：中世紀英國曾規定被告徒手持熱銅棒、手不被燙傷即證無辜，它問這與本章的做法有沒有相近之處、能否用科學觀點解釋，並提醒讀者參看申命記十六18-20 與十九15-21——那才是以色列判案的主要方法。
