# 古代近東廟宇奉獻典禮

## 定義

以色列不是唯一會為聖所辦落成典禮的民族。GT《舊約聖經背景註釋》把利未記第九章放回它的時代背景裡看：七天的承接聖職之禮結束後，「七天的啟用奉獻典禮完成後，制度在第八日開始實施」，而整場典禮的高潮是神親自現身——「主的顯現是典禮的高潮（4～6節、23～24節）」。

**同一套作法在以色列史上再出現過一次。** 同一則註釋指出，所羅門聖殿啟用時（王上八62～64）也有類似的啟用典禮，並且用「啟用」（hanok）一詞來形容。這裡有個常見的混淆要先澄清：猶太教的修殿節（Hanukkah，約十22）雖然名字由此而來，卻與利未記這一段無關——修殿節紀念的是主前二世紀馬喀比革命（Maccabeans）在安提阿古‧伊比芬尼（Antiochus Epiphanes）污穢聖殿之後，重新啟用聖殿和祭壇的事。

**真正的差別在典禮的中心放了什麼。** 這是同一份註釋在第23節提出的對比：「古代近東大部分的廟宇奉獻典禮，都是環繞神明正式在廟中開光而舉行（通常指神像搬入廟中）。」也就是說，鄰近民族的落成典禮，高潮是把神像請進廟裡、為神像開光——神明的「到場」是由人動手完成的。利未記第九章沒有這個環節：「耶和華在此沒有開光，但其榮光卻從剛奉獻的聖幕之中顯現出來。」會幕裡沒有神像可搬，神的臨在不是被安置進去的，而是自己顯現出來的。

**顯現的方式也有具體的推斷。** 同一則註釋認為「雲柱火柱是最可能的顯現方式（見：出十三21～22註釋），在整個曠野歷程中，神的臨在都是如此彰顯。在此火從柱中冒出，燒盡所有的祭物。」這個讀法與本章其他來源對「火從哪裡來」的判斷並不一致，屬於各家並陳的一項。

- 本章重點：GT《舊約聖經背景註釋》為本章提供兩則古代近東背景。其一在v1：七天啟用奉獻典禮完成後制度於第八日開始實施，主的顯現是典禮高潮（v4-6、v23-24），並比對所羅門聖殿啟用（王上八62～64）所用的「啟用」（hanok）一詞，同時澄清修殿節（Hanukkah）雖同源卻紀念馬喀比革命的事。其二在v23：古代近東廟宇奉獻典禮多半環繞神明在廟中開光而舉行，通常指神像搬入廟中。
- 與本章關聯：本章是會幕落成程序的最後一步，也是這個對比最集中的一處。鄰近民族的典禮高潮是人把神像請進廟裡，本章的高潮則是「耶和華在此沒有開光，但其榮光卻從剛奉獻的聖幕之中顯現出來」——同樣是聖所交付使用，主動的一方完全相反。

## 主題發展

這個對比不是只在利未記出現。以色列的聖所從設計階段就與周圍民族的廟宇走了不同的路：會幕與聖殿都沒有神像，至聖所裡放的是約櫃與法版。等到落成的一刻，這個差別就變得可見——別人請神像進門，以色列等神自己降臨。所羅門聖殿啟用時的情況一樣（王上八62～64），而典禮用的詞（hanok）後來又被借去命名一個完全不同時代的節期（修殿節）。同一個詞跨越了曠野的會幕、耶路撒冷的聖殿與馬喀比時期的重新奉獻三個場景，三次都指向「把一座聖所交付使用」這件事。
