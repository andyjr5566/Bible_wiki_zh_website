# 以實瑪利

## 定義

以實瑪利（Ishmael），亞伯蘭與夏甲所生之子。名字意為「神聽見」。豫表按血氣生的（加四23），是阿拉伯人的祖先。

## 主題發展

### 「像野驢」是罵人還是稱讚？

創十六12「他為人必像野驢」是本章分歧最明顯的一句，而分歧的方向完全相反：

| 來源 | 讀法 |
|---|---|
| GT 丁良才《創世紀註釋》 | 負面：「住在曠野，自由，兇猛，不法，不安寧，難管轄」（伯十一12；二十四5；三十九5-8等） |
| CT | 負面：「離開常人居住之地，在曠野四處漂泊，無拘無束，並且對別人懷有敵意，性情兇暴，不服管轄」 |
| GT《串珠聖經註釋》 | 中性偏負：「象徵衝動、獨立和野性」 |
| BH | 中性：獨立不受馴服的沙漠動物，指向遊牧而自由的生活方式 |
| GT《創世記雷氏研讀本》 | **正面**：「這綽號是**一種稱讚**，因為這種幾乎不能馴服的野驢是一種受稱讚和珍貴的動物」 |

雷氏是唯一把它讀成褒義的。這不是細節之爭——它決定第12節整句是預告一個受咒詛的性情，還是描述一種被賞識的野性。GT《聖經精讀本──創世記註解》走第三條路，把重點放在生活形態而非褒貶：以實瑪利成為十二個族系的祖先（創二十五12-16），阿拉伯貝都因人「打消定居生活的念頭，蔑視文明生活，騎著馬，拿著長槍賓士在廣闊的自然中」，正體現這句預言，並引伯三十九5-8 的野驢描寫為對照。

### 「住在眾弟兄的東邊」

丁良才與 CT 都註明「東邊」在原文作「對面」。GT《串珠聖經註釋》據此把整句讀作關係而非方位：「原是『在眾弟兄的前面』，即和眾弟兄有一種敵對的關係。」GT《啟導本聖經創世記註釋》則兩者兼取：「『東邊』一詞除了說明地理位置，也表明一種與住在西邊的以色列人隔離和對峙的關係」。GT《創世記雷氏研讀本》明說兩種可能並存，不作裁決：「可能指以實瑪利的後裔要住在亞伯拉罕其它後裔的東邊，也可能指他們常常與亞伯拉罕其它的後裔發生衝突。」

### 「阿拉伯人的祖先」這個說法要多小心

各家措辭的強弱有別，值得照原樣保留分寸：GT《啟導本》說他「是阿拉伯人**公認的**祖先」；GT《創世記雷氏研讀本》說「**許多亞拉伯人稱**以實瑪利是他們的祖先」——後者陳述的是族群自我認同，不是血緣考證。CT 說「以實瑪利是阿拉伯人公認的祖先，有十二族從他而出（創十七20）」。這三種說法都不等於一句「以實瑪利即阿拉伯人的血統祖先」的斷言。

### 創21：被逐之後他靠什麼活下來

第20節說他「住在曠野，成了弓箭手」。GT《聖經精讀本──創世記註解》讀作成年的表記：「箭是曠野生活必備的工具」，這句話暗示以實瑪利已經長大成人（創二十五12-18）。GT《舊約背景註釋》給的解釋更實際：被逐之後在巴蘭的曠野生活，逼使他們學習求生的本領，而以實瑪利擅長弓箭，「不但能夠養活家人，或者更容許他找到僱傭兵的工作」——它並舉以賽亞書二十一17 為旁證，那裡提到以實瑪利之子基達後裔中的弓箭手。

第21節的婚姻則決定了後代的走向。精讀本指出由於娶了外邦女子為妻，外邦的世俗與傳統在其文化中迅速蔓延，以實瑪利為祖先的族群因而成為希伯來人與埃及人的混血民族。至於他住的地方，見[[巴蘭的曠野]]——各家對其確切位置的說法並不一致。

### 他被逐時究竟幾歲

來源算出來的數字不一致，而差距全來自「斷奶幾歲」這個假設。GT 丁良才《創世紀註釋》按猶太傳說以撒三歲斷奶推算：以實瑪利十三歲受割禮（創十七25），一年後撒拉生以撒（創十七21），因此斷奶時他正是十七歲；他並記下另一說——也有註釋家以為以撒到五歲才斷奶。GT《聖經精讀本──創世記註解》同樣採三歲斷奶，得出十七歲。但 GT《啟導本聖經創世記註釋》在第14節說「以實瑪利此時已經十五歲大了」，CT 則只說「此時至少十五歲了」，丁良才在第19節也用「至少有十五歲」的說法。經文沒有給以實瑪利的歲數。

各家在一件事上倒是一致：他已經不是需要人抱的孩子。這一點直接決定了第14至15節該怎麼讀（見[[夏甲]]）。

### 名字與性情的張力

KC 提出一個貫串全章的讀法：這孩子被指定的名字是「神聽見」，「他的名字裡帶著對神持續的記念」；但同一位使者接著預告「他為人必像野驢」——「**他的性情將不符合他的名字**」。CT 也注意到名字的來歷：亞伯蘭照使者指示夏甲的名字為兒子命名，「表示他在經歷中認識了神真是一位聽見人苦情的神」。
