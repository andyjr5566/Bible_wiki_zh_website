# 試探神十次

## 定義

第22節神說：「這些人雖看見我的榮耀和我在埃及與曠野所行的神蹟，仍然試探我這十次，不聽從我的話。」

**「十次」是實數還是虛數？兩種讀法都有。** GT 丁良才：「大概是多次的意思（參創三十一7，伯九3）」，但他隨即列出十件實事。BH 也說「這數字可能是象徵性的，代表完全或圓滿」。CT 則直接當實數處理：「意指多次試探神，實際上也達十次之多。」

**三份來源各列了一份清單，內容幾乎一致：**

| # | 事件 | 出處 |
| :--- | :--- | :--- |
| 1 | 在紅海 | 出14:11-12 |
| 2 | 在瑪拉 | 出15:22-24 |
| 3 | 在汛的曠野 | 出16:2 |
| 4 | 嗎哪留到次日早晨 | 出16:20 |
| 5 | 安息日出去收嗎哪 | 出16:27 |
| 6 | 在利非訂 | 出17:1-4 |
| 7 | 在西乃山下拜金牛犢 | 出32:7 |
| 8 | 在他備拉 | 民11:1-3 |
| 9 | 在基博羅哈他瓦 | 民11:4-6 |
| 10 | 在加低斯巴尼亞 | 民14 |

CT、GT 丁良才與 GT《啟導本聖經註釋》三份清單完全對得上；GT《聖經精讀本》的第七項作「在何烈」，其餘相同。

**GT《民數記串珠聖經註釋》換了一種分類法**，不逐件列舉而按性質分成三類：「１ 六次為水和食物埋怨神（出15:23; 16:3, 20; 17:2; 民11:3-4）；２ 兩次不順服領袖（利10:1; 民12:1）；３ 兩次最嚴重的罪惡是拜金牛（出32:7）和探子報惡信。（民13:32）」它把利10 的拿答亞比戶與民12 的米利暗也算進去，與另外三份清單並不相同。

**STEP 原文資料**顯示第11節「藐視」是 ye.na.'a.Tzu./ni（H5006，詞典形 na.ats，詞典義 to spurn），「信」是 ya.'a.Mi.nu（H539，詞典形 a.man，詞典義 be faithful）的 Hiphil 形。

## 按書卷累積

### 民數記

<!-- accumulation:民數記:14:start -->
#### [[04 民數記/第14章|第14章]]
- 本章重點：第22節神以「試探我這十次」總結出埃及以來的歷史。CT、GT 丁良才、GT《啟導本聖經註釋》三份清單一致列出十件事，從紅海一路數到加低斯巴尼亞；GT《民數記串珠聖經註釋》改按性質分成六次為水和食物、兩次不順服領袖、兩次最嚴重的罪惡。
- 與本章關聯：這一節把本章從一次孤立的失敗提升為一條完整的軌跡——本章正是這條線的第十次，也是最後一次。GT 丁良才在民11:5 另有一份只涵蓋民11-14 的五次清單，兩份清單在加低斯這一點上重合。
