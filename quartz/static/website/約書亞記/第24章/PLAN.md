## 一、專案定位與技術架構

### 1. 核心架構決策

1. **單頁長捲軸、一體成型**：上半部為捲動帶動（scroll-scrubbed）的七段故事（序、第一至第六幕、終），故事走完即讀完約書亞記 24 章全部 33 節；下半部為「再看一次」整理區（01–07、GT《串珠》六題思想問題、關於）。不設閱讀模式切換或讀者分級，由淺入深全靠閱讀順序與每一拍固定的四層結構（畫面 → 白話一句＋和合本經文全文 → 就地展開的『各家怎麼說』『原文』→ 知識庫完整條目外部連結）。
2. **一個常駐 WebGL 舞台、三個空間**：背景 `<canvas id="jos-canvas" aria-hidden="true">` 全程不卸載，依經文結構在三個空間轉換：
   - **示劍山谷**（3D 人的高度，`y ≈ 1.2–2.6`）：第 1 節、第 14–28 節。
   - **記憶地圖**（從示劍垂直升起展開至幼發拉底河與埃及的羊皮紙暈渲地圖）：第 2–13 節（神以第一人稱述說歷史）。
   - **石頭旁的時間**（固定於橡樹下大石頭旁，日月沿天弧繞行，絕不閃爍畫面明暗）：第 29–33 節與終幕收尾。
3. **兩個鏡頭的家**：
   - 第一幕至第四幕：約瑟子孫示意一家三代（親眼見過紅海的爺爺、曠野出生的父親、這地出生的女兒；母親可在畫面裡同行站立，但全站說話的家人只有爺爺、父親、女兒三人）在會眾裡站立的位置；對話採 3/4 側面斜拍，同時拍到約書亞與會眾的臉，說話者背後不站雜人。
   - 第五幕立石以後至終幕：移至橡樹下那塊大石頭旁；第 28 節眾人散去時鏡頭留在石頭旁目送眾人與最後離開的約書亞；第六幕全在石頭旁看世代更替（幾輪後爺爺不再出現，不演死亡）。
4. **`file://` 與公開網域雙棲的單檔架構**：
   - 使用 Vite + TypeScript + 原生 DOM + Three.js + `vite-plugin-singlefile` 輸出 `dist/index.html`（`base: './'`）。
   - **零 `fetch` 原則**：從 Obsidian 以 `file://` 直接打開 `dist/index.html` 時，瀏覽器會以 CORS 阻擋 `fetch()` 與跨域圖片送入 WebGL `texImage2D`。因此：
     - 所有 `.glb` 模型與送入 WebGL 的地形暈渲貼圖（`relief-wide`、`relief-canaan`）皆透過 Vite `?inline` 轉為內嵌 `data:` URI，於啟動時解碼成 `ArrayBuffer` 交由 `GLTFLoader.parse()`，或以 `data:image/webp;base64,...` 載入 `THREE.Texture`，執行期完全不發 `fetch`。
     - 環境音與單次音效放 `public/audio/*.mp3`（複製至 `dist/audio/`），於讀者首次手勢後以原生 `<audio src="./audio/...">` 播放，不用 Web Audio `decodeAudioData`。
     - 無 WebGL 降級插圖放 `public/fallback/<cue>.webp`（複製至 `dist/fallback/`），以原生 `<img src="./fallback/...">` 顯示。
5. **開發與預覽埠**：開發埠 `127.0.0.1:3024`，預覽埠 `127.0.0.1:4224`（已掃描 `appendix/website/` 現有 421 個檔案確認無撞埠，且無任何 `jos-` class 或 `--jos-` CSS 變數撞名）。所有指令一律在 PowerShell 執行。

## 七、風險與備案

1. **Adreno X1-45 整合顯卡與手機效能風險**
   - **對策**：DPR 上限鎖在桌機 `1.75`、手機 `1.5`；十二支派群眾一律使用單一 `THREE.InstancedMesh`（色盤以 instance color 區分支派衣色，180 人僅 1 次 draw call）；全場景同屏總三角形控制在 **6 萬～8 萬**以內（遠低於 15 萬上限）；render loop 內預先配置 `Vector3`／`Matrix4`／`Quaternion` 暫存物件，每幀零 GC 配置；`document.hidden` 時立即暫停 `requestAnimationFrame`；畫面無捲動且動態關閉時進入按需重繪（pointer 事件立即喚醒）。
2. **廣域（吾珥至埃及）＋迦南區域＋示劍山谷三尺度地形資料量**
   - **對策**：高程 PNG 瓦片由 `scripts/fetch-dem.mjs` 下載至系統 `os.tmpdir()/jos24-dem/`，絕不進 repo；廣域圖用 z7（約 48 張瓦片）、迦南區域用 z10（約 72 張瓦片）、示劍山谷 3D 網格用 z12（僅 9 張瓦片），在 Blender 烘焙成壓縮 `.webp`（合計 < 700 KB）與減面 `.glb`（< 300 KB），兼顧真實地形與單檔輕量。
3. **Blender MCP 外掛未開啟或連線逾時**
   - **對策**：所有 3D 模型與地形暈渲皆以 **Blender 5.2 背景腳本模式**為主路徑：`& "C:\Program Files\Blender Foundation\Blender 5.2\blender.exe" -b --python scripts\blender\<script>.py`。腳本內建獨立場景建立、孤兒網格清理（防 `.001` 撞名）、`use_active_scene=True` 匯出與全尺寸檢查圖渲染，完全可重現且不干擾使用者已開啟的 Blender 視窗。
4. **`file://` 本地開啟時 `fetch()` 與 WebGL 貼圖遭瀏覽器阻擋**
   - **對策**：如第一節所述，`.glb` 與 WebGL 地形貼圖一律走 Vite `?inline` 內嵌 `data:` URI 解碼；音檔走原生 `<audio>` 標籤；無 WebGL 插圖走原生 `<img>` 標籤，徹底避開 `file://` CORS 限制。
5. **本機 Windows 開啟系統級「減少動態」導致動態測試失效**
   - **對策**：本站動態狀態只讀本站頂列開關（`localStorage` 鍵 `jos-motion`，包 `try/catch`，預設一律開啟），不讀 `prefers-reduced-motion`；CDP 驗收腳本亦顯式測試本站開關之開與關。
6. **無 WebGL2 環境或瀏覽器禁止自動播音**
   - **對策**：`createScene()` 偵測不到 WebGL2 或發生 `webglcontextlost` 時回傳 `null`，舞台自動切換顯示 `public/fallback/<cue>.webp` 對應拍靜態插圖，經文與所有 2D 互動完全正常；音效僅在使用者第一次點擊／觸控／按鍵手勢後建立並解鎖 `<audio>`，音檔缺失或播放被拒時安靜略過不拋錯。
7. **CI 環境無上層 Vault 目錄**
   - **對策**：`verses.json`、`step.json`、`geo.json`、`site.json` 皆進版控；`npm run build` 跑 `tsc --noEmit && vitest run && vite build`（不強制重跑讀 vault 的 `npm run data`），並在交件前將本站資料夾單獨複製到系統暫存目錄實測 `npm ci && npm run build` 通過。
