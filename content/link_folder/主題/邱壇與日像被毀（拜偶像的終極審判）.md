# 邱壇與日像被毀（拜偶像的終極審判）

## 定義

利未記26章30節：「我又要毀壞你們的邱壇，砍下你們的日像，把你們的屍首扔在你們偶像的身上；我的心也必厭惡你們。」

**「日像」到底是什麼，各家並不一致。** CT 說是「迦南人所拜象徵太陽的偶像」；GT 李道生《舊約聖經問題總解》順著這個方向解釋，說巴比倫、亞述都拜日像，而埃及的安城是奉拜日球之地，「其希伯來名伯示麥，意即日球之室」，並指約西亞王曾革除此弊（王下廿三5、11）。但 GT《串珠聖經註釋》給的是另一個答案：「『日像』：原指拜偶像的祭壇。」BH 也是這一派：「香壇被用於敬拜外邦神明，毀掉它們代表除盡使以色列離棄耶和華的做法。」STEP 語言資料兩邊都沾得上——本節這個字是 חַמָּן（Strong H2553），簡要詞典義是 pillar（柱），而本節的 context gloss 卻作 incense altars（香壇）。詞典義域偏「柱」、本節譯義偏「香壇」，兩派註釋各自靠著這個字義域的一端。

**「屍首」與「偶像的身上」在原文是同一個字，這一點可以直接驗證。** GT 丁良才早就指出：「本節的『身』和『屍首』幾個字按原文是－樣的，顯明這些偶像是被打倒而破碎的，也暗指這些偶像原是死的。」STEP 顯示 v30 確實有兩個 פֶּגֶר（H6297，corpse）：先是「你們的屍首」，再是「你們偶像的屍首」。而「偶像」用的字是 גִּלּוּל（gi.lu.lei，H1544），STEP 詞典義作 idol。

丁良才另外交代了邱壇的來歷與下場：以色列人有時也曾藉邱壇敬拜耶和華（士六25-26、撒上七10、王上三2），但因為這些邱壇「往往是為拜偶像用的」，神吩咐只可在祂所揀選的地方獻祭；而「這些邱壇既是被毀壞了，就顯明以色列人所敬拜的偶像是沒有能力的」。GT《聖經精讀本》把這個諷刺講得最直白：把屍首扔在偶像身上，是「諷刺偶像不能給事奉它的人帶來任何益處，也不能保障生命」。KC 則注意到動手的是誰：「祂要親自毀滅他們的城邑。」

這一節與本章第1節首尾相扣：全章以「不可立雕刻的偶像或是柱像」開場，以神親手打碎偶像、把拜偶像者的屍首堆在偶像碎塊上收場。

## 按書卷累積

### 利未記

<!-- accumulation:利未記:26:start -->
#### [[03 利未記/第26章|第26章]]
- 本章重點：v30 宣告毀邱壇、砍日像、把屍首扔在偶像身上；「日像」一詞 CT 與李道生讀作太陽神像、《串珠》與 BH 讀作香壇，而 STEP 顯示該字 חַמָּן（H2553）詞典義是「柱」、本節 context gloss 是「香壇」，兩派各據義域一端；丁良才指出「屍首」與偶像的「身」原文同字，STEP 確認兩處都是 פֶּגֶר（H6297）。
- 與本章關聯：這一節與本章第1節禁立柱像首尾呼應，全章以禁偶像開場、以神親手毀偶像並使拜者與偶像同倒收場，也是「我的心也必厭惡你們」第一次出現的位置。
