# 擅敢行事與褻瀆耶和華的剪除處分

## 定義

與因誤行、無心違背神的寬大饒赦（無論是大眾或一人）構成強烈刺目的冰雪懸殊對比：第15章30-31節宣示了令人戰慄肅靜的絕對重判。若是存有任何人（本土自生亦或留宿的寄人），膽敢橫出驕邁邪志、故逞己狂「擅敢行事」（原文帶有舉起拳頭反亂之神意），這便被神直接嚴厲判定為「褻瀆了耶和華」。這種高顏抗行、蓄意輕狂、藐視耶和華威誠神口的話語並且明目打破其誠命者，絕對不得企待有任何免過代祭留藏，必須「總要從民中剪除」，其無解厚債必久負自擔、承禍亡滅。

- 與本章關聯：彰顯了對抗神恩聖治最不可觸踩的神性紅線：主意並並非任由人恣妄踐弄無度；蓄意以自我意志凌拒浩然的主權即等於絕緣救贖，墮落無盡空滅。
