## 2. F3｜存一份到我的 Google Drive＋備份提醒

### 2.1 已確認
- **觸發：每週自動＋手動。** 第一次由使用者手動按（這時才申請 `drive.file` 權限）；之後每次打開網站、登入且權限有效時檢查，**超過 7 天沒備份、而且之後有改過東西**就在背景存一份。隨時可手動按。
- **保留最近 10 份**，超過的把最舊的移到 Drive 垃圾桶（30 天內可救回）。只動本站自己建立的備份檔。
- **只存 JSON**（與現有「匯出備份」同格式，可完整還原）。
- **提醒**：〈我的筆記〉頁頂端；**未登入的人也提醒**（提醒下載備份檔或登入同步）。
- **使用者額外要求：用不會讓介面很亂的方式告訴使用者這個功能是做什麼的。**

### 2.2 使用者看到的樣子（預設）
- 「⚙ 設定與備份」新增一區「備份到 Google Drive」：
  - 還沒開啟：一個按鈕「存一份到我的 Google Drive」，下面**一行灰字**：「每週自動在你的 Google Drive 存一份筆記備份（最多 10 份）。」旁邊一個收合的「這是什麼？」（`<details>`），打開才看到 3～4 點：存在哪個資料夾、只能碰本站自己建立的檔案（看不到你 Drive 的其他東西）、怎麼還原、怎麼關掉。
  - 開啟後：一行狀態「上次備份：3 天前 · 每週自動備份 開」＋「立即備份」＋「每週自動備份」開關（這台裝置）＋「查看備份與還原」（列出 Drive 裡的備份：日期、筆數、「從這份還原」）。
  - 還原 = 現有的合併匯入（`importBackup`），不刪除、不覆蓋；完成後顯示「新增 N、更新 N、另存 N」。
- 提醒（〈我的筆記〉頁頂端，用 `shell.setNotice`）：
  - 條件：超過 30 天沒有任何備份（存到 Drive 或下載 JSON 都算），而且那之後有改過東西；有開每週自動備份且正常運作的人不會看到。
  - 文字一行：「已經 40 天沒有備份筆記了。」按鈕：登入者「存到 Google Drive」「下載備份檔」；未登入者「下載備份檔」「用 Google 同步」。另有「之後再說」（這台裝置 7 天內不再提醒）。
- 自動備份成功不跳通知（不打擾）；失敗只在設定區塊的狀態行顯示原因，連續失敗 3 次才在〈我的筆記〉頁提醒一次。

### 2.3 技術設計（預設）
- **Drive 位置**：我的雲端硬碟根目錄建立資料夾「聖經知識庫筆記備份」。資料夾與檔案都加 `appProperties`（`app=bwz-notes`、`kind=backup-folder`／`backup`、`records=<筆數>`），**用 appProperties 找，不用名稱找**（使用者改名或搬動資料夾也找得到）。檔名「聖經筆記備份 YYYY-MM-DD HHmm.json」。
- **授權**（`auth/gis.ts`，目前 scope 寫死在 :9、token client 在 :89-96、`include_granted_scopes:false`、token 存 sessionStorage `bwz-notes-token`）：
  - 申請時一次要 `drive.appdata drive.file` 兩個（不能只要 drive.file，否則新 token 沒有 appdata、又會蓋掉唯一的 token）。
  - 記住「這個帳號已開過 drive.file」（localStorage，依帳號），之後的續期都要兩個。
  - 用 `hasGrantedAllScopes` 檢查；使用者在同意畫面沒勾 drive.file → 同步照常，備份區塊顯示「沒有取得 Google Drive 權限，可以再按一次」。
  - `TokenSource`（`session/session.ts:32-46`）加上權限相關方法；`prepare()` 只能在現有的地方呼叫（11）。
- **adapter**：新增 `adapter/driveFiles.ts`（找／建資料夾、列備份、上傳、讀取、移到垃圾桶）。現有 `adapter/drive.ts` 的 `request`／節流／退避（:90-130）抽成共用的 `adapter/http.ts`，兩邊共用。**不要**把這些加進 `SyncAdapter`（同步介面保持不變）。
- **session**：`session/` 新增備份編排（確認權限 → 取 token → `exportBackup` → 上傳 → 修剪到 10 份 → 記錄時間）與 `autoBackupIfDue()`（在成功同步後呼叫）。features 不能 import adapter／auth，所以編排一定在 session。
- **上次備份時間**：每個帳號的 IndexedDB meta 新增 `lastBackupAt`、`lastBackupKind`（drive／file），透過 repo 或 session 包一層給 features 用；下載 JSON 也要記。跨裝置：有 drive.file 權限時，從備份清單最新一份的建立時間更新。
- **「之後有改過東西」**：比較所有紀錄的最新 `updatedAt` 與 `lastBackupAt`。
- **UI**：新功能模組 `features/backup/`（〈我的筆記〉view：設定區塊＋提醒）。現有 notes 的「備份與匯出」區塊保持不動。
- **使用者要做**：Google Cloud →「Google 驗證平台／OAuth 同意畫面」→「資料存取」→ 新增範圍 `https://www.googleapis.com/auth/drive.file`（非敏感範圍，不需要審查）。開工時就把步驟寫進 08 並告訴使用者。
- **隱私權政策**（`content/教學/隱私權政策.md`，由 repo 維護）要補：多了 drive.file、只碰本站建立的備份檔、存在哪、怎麼刪。

### 2.4 風險等級：第 3 級
動到授權與刪除 Drive 檔案。Codex `gpt-6-sol`（high）實作或嚴格審查，Antigravity `gemini-4-argon-high` 交叉審查，主導者裁決。

### 3.3 條目改名後找回（預設）
- **適用**：所有掛在條目上的紀錄（F4 時是條目書籤；F5 之後也包括條目筆記）。
- **純函式** `relocateNode({slug, title}, pages)`（`pages` 來自 `static/personal-notes/links.json`：`{s, t, a}`）：
  - 舊 slug 還在 → 不變。
  - 否則只在 `link_folder/` 底下找：標題等於舊標題、或別名（`a`）包含舊標題、或檔名等於舊 slug 的最後一段。**剛好一個**才算找到，零個或多個都算找不到。
- **條目頁**：這頁沒有書籤，但有「舊 slug 已不存在、且 relocate 指到這一頁」的紀錄 → 當作已加書籤，並把紀錄的 `node` 改成目前的 slug 與標題（`revise`，會同步）。只有使用者有條目紀錄時才載入 links.json。
- **〈我的筆記〉頁**：舊 slug 不存在 → 用 relocate 的新網址；找不到 → 標示「（條目可能已改名或刪除）」，並提供「移除」。
- **限制寫進教學**：搬資料夾一定找得回；改檔名會連標題一起變，要在 Obsidian 的 `aliases` 留下舊名才找得回。

## 6. F7｜筆記操作教學（獨立於網站導覽）

### 6.1 已確認
- **動畫示範＋自己試**：每個功能一段短動畫（在一個假的小經文頁上，虛擬游標示範選字、工具列跳出、便條貼上去…），看完可以在同一個示範區自己點點看；**示範區不會寫進真正的筆記**。

  1. 〈我的筆記〉頁上方按鈕（「⚙ 設定與備份」旁邊）。
  2. 網站導覽（wiki-tour）筆記那一站加一句：「筆記功能比較多，想完整了解 → 看筆記教學」，連到 `/my-notes?tutorial=1`（自動打開教學）。
  3. **章節筆記面板的小問號「?」→ 打開簡單的文字版教學，不是動畫教學**。文字版最下面一行連結「看動畫教學」（預設）。
- 兩套教學分開：網站導覽介紹整個網站，筆記教學介紹筆記相關操作。

### 6.2 動畫教學的樣子（預設）
- 全螢幕對話框「筆記教學」。上方是段落小圓點與標題，中間是示範區，下方是「上一段／重播／下一段」與一行說明文字。
- 示範區是一張「假的經文頁」（幾節創世記經文、筆記面板、〈我的筆記〉縮小版），風格沿用網站的紙張主題與便條的美術，支援深色模式。
- 動畫用 CSS 與 Web Animations：虛擬游標移動、選取範圍掃過、工具列彈出、按鈕按下的波紋、便條貼上並微微傾斜、數字跳動。每段 8～15 秒，播完自動進入「換你試試」：示範區變成可以點（只存在記憶體，關掉就消失）。
- 段落（預設 8 段）：
  1. 寫整章筆記：面板 → 新增 → 自動儲存
  2. 選經文：畫重點、書籤、寫經節筆記
  3. 便條紙：貼上、換色、收起／展開
  4. `[[條目]]` 連結 → 條目頁「我的相關筆記」
  5. 引用到筆記：註釋區選字 → ❝
  6. 條目頁：寫筆記、加書籤
  7. 〈我的筆記〉：分頁、搜尋、`#標籤`、依書卷
  8. 同步與備份：用 Google 同步、存到 Google Drive、匯出
- 鍵盤：← → 換段、Esc 關閉；`prefers-reduced-motion` 時不播動畫，改顯示每段的最後畫面＋步驟文字。手機：直式版面、示範區等比例縮小、可以觸控試用、不左右捲。
- 記住看到第幾段（這台裝置，localStorage）。

### 6.3 文字版教學（「?」）
- 小對話框，6～8 條，每條一個圖示＋一句話（寫筆記、選經文的工具列、便條、`[[條目]]`、引用、我的筆記、同步與備份）。最下面「看動畫教學」。

### 6.4 技術設計（預設）
- 新功能模組 `features/tutorial/`（〈我的筆記〉view）。外框目前沒有「在標題列加按鈕」的方法 → 在 `ui/myNotesShell.ts` 加 `addAction()`（或類似），不要讓模組直接改外框的 DOM。
- 網址 `?tutorial=1` 打開教學；打開後用 `history.replaceState` 拿掉參數。
- 文字版教學放在 notes 功能（章節面板標題旁的「?」），內容與動畫教學的說明文字共用一份資料時，放在 `ui/` 底下（features 不能互相 import）。
- wiki-tour：`plugins/wiki-tour/src/components/scripts/tour.inline.ts` 的筆記那一站。改完要跑 tourcheck。
- 不引入動畫函式庫。

## 10. 使用者實機測試清單（F3，加好 drive.file 之後）

用電腦版 Chrome（或 iPhone Safari）打開正式網站，已登入 Google 同步、至少有一則筆記。

1. 〈我的筆記〉→「⚙ 設定與備份」→「備份到 Google Drive」→ 按「存一份到我的 Google Drive」。
   預期：跳出 Google 視窗，畫面列出「Google 雲端硬碟」相關權限（只限本站建立的檔案）→ 允許 → 出現「已存到 Google Drive（N 則）」。
2. 打開 https://drive.google.com ：我的雲端硬碟有資料夾「聖經知識庫筆記備份」，裡面一個「聖經筆記備份 日期 時間.json」。
3. 回到「⚙ 設定與備份」：顯示「上次備份：今天（Google Drive）」、「每週自動備份（這台裝置）」已勾選。
4. 按「查看備份與還原」→ 看到剛才那一份 →「從這份還原」→ 確認。預期：「還原完成：新增 0 則、更新 0 則…」，筆記沒有變多或被改。
5. （可選）在另一台裝置登入同一個帳號：「⚙ 設定與備份」按「存一份到我的 Google Drive」時可能會再問一次權限；之後兩台的「上次備份」會一致。
6. （可選，會真的刪資料，建議先匯出備份）用一個測試帳號試「刪除全部筆記」：確認視窗有「同時把 Google Drive…移到垃圾桶」勾選框，預設不勾。
