# 但支派至終定居於何地

## 定義

民數記26:42-43：但的眾子只有書含一族，卻共有六萬四千四百名——是十二支派中人數第二多的。CT 指出這比民1:39 的六萬二千七百名增加了一千七百名。

**GT 收錄的艾基斯《舊約聖經難題彙編》用一整篇處理這個支派後來的去向。** 他先講原本的地業：「根據約書亞記十九章四十至四十六節，但支派的地業界乎猶大的西陲與地中海之間，包括非利士地的北部。這地區土壤肥沃，降雨量豐，故可以出產豐富的農作物以供人口如此眾多的支派。」但接著出了問題：「然而，在某些原因影響下，但支派的武力不足以趕走非利士人；雖然有勇猛的戰士，但在約書亞佔領迦南地之後幾代，便淪為非利士人的附庸。」

於是有了北遷：六百個但人北上攻取拉億，把城改名為「但」，成了十二支派地業中最北之點，也是「從但到別是巴」這句成語的由來。艾基斯並記下一個後果：北國的耶羅波安一世在但建立官方的殿，讓百姓在那裡拜金牛犢。

**GT《聖經精讀本》講的是同一段歷史，但把重點放在原因。** 它先引雅各（創49:17）與摩西（申33:22）的預言說但支派是好戰勇猛的，接著說：「但是他們連自己的產業,就是肥沃的平原都沒能守住,被人趕到了山地(士1:34)。這事以後他們中間的一部分人佔領了拉憶,把這個地方改名叫‘但’。」

**CT 只作數字紀錄**，沒有討論後來的遷徙。BH 則從另一個角度提到但支派的北遷：它說但支派的領土後來成了拜偶像的中心（士18:30-31），並把這件事讀成對忠心的警戒；同時它也引雅各的預言說但要為他的百姓伸張公義（創49:16）。

**分歧在哪。** 本章只給一個數字，這場討論的材料全在後來的書卷。艾基斯與《精讀本》都認同北遷這件事，差別在於怎麼看它：艾基斯把它讀成經濟與政治壓力下的自然結果，《精讀本》讀成沒能守住神所賜的產業，BH 則讀成後續拜偶像的伏筆。
