# 七月的三個節期

## 定義

民29 把三個節期擠在同一個月裡：初一吹角節（v1-6）、初十贖罪日（v7-11）、十五日起八天的住棚節（v12-38）。GT 丁良才說「七月中有節期的日子，比全年其餘各月之節期的日子更多」。

**為什麼集中在七月，各家給的理由互相補足：**

| 來源 | 理由 |
|---|---|
| GT《民數記串珠聖經註釋》 | 「七月是適合休息和慶祝的時間，因為莊稼已經收成了」 |
| GT《聖經精讀本》 | 「是為了振作以色列百姓屬靈的士氣,使他們盡情享受從神得到的一切祝福和恩典」 |
| GT《舊約聖經背景註釋》 | 吹角日「發生在全年新月第七次出現的七月（參較安息日的循環），可能是它這麼重要的原因之一」 |
| KingComments | 「第一組主要應用在教會身上，第二組則對以色列有特別的意義。」 |

**三個節期的次序本身是有意義的。** GT《聖經精讀本》說吹角節「同時也是預告贖罪日的悔改(十日)和住棚節的慶典(十五日)」；KingComments 也照這個次序讀：先是吹角（神重新對待以色列），再是贖罪日的降卑，最後才是住棚節的歡慶。

## 按書卷累積

### 民數記

<!-- accumulation:民數記:29:start -->
#### [[04 民數記/第29章|第29章]]
- 本章重點：v1、7、12 把吹角節、贖罪日、住棚節都排在七月，本章即依這個次序列出各節期的祭物。
- 與本章關聯：民28 列的是每日、每週、每月與春季節期，本章接著列七月的三個秋季節期，兩章合成一整年。
