# 設立律法者的分存留指什麼

## 定義

申33:21 給迦得的祝福裡有一句不好讀的話：「他為自己選擇頭一段地，因在那裡有設立律法者的分存留。他與百姓的首領同來；他施行耶和華的公義和耶和華與以色列所立的典章。」

「設立律法者的分存留」到底在說什麼，四套註釋給了四種不完全一樣的答案。

### 四家的讀法

| 來源 | 讀法 |
|---|---|
| CT | 設立律法者指有權訂立律法的首領；這一句是說迦得支派自認領袖群倫、配分得那段地 |
| GT《申命記串珠聖經註釋》 | 直接給另一個譯法——或作「因他期望得到首領的位分」 |
| GT《聖經精讀本──申命記註解》 | 指其它支派皆從約書亞分得了地，而迦得支派卻從立律法者摩西手中直接分得了產業 |
| KC | 頭一段地與統治者的份相連，指向治理與掌權 |
| BH | 統治者的份表示一份帶著尊榮與領導意味的特別分地，「保留」一詞暗示神的護理 |

### 分歧在哪裡

差別集中在「設立律法者」指誰。CT 與 GT 串珠讀成迦得自己或首領的位分；GT 精讀本讀成摩西——它的根據是分地程序上的差別，說其它支派的地是從約書亞手上分得的（書14:1-3），迦得卻是直接從摩西手上得的。KC 與 BH 則把重點放在統治者的份這個概念上，不去指名。

### 這一句以外的部分四家一致

「頭一段地」指什麼，各家沒有異議。CT 說是迦得支派自己所選擇的約但河的東面中段，是他們認為最好的地段（參民三十二1）；GT《申命記串珠聖經註釋》說頭一段地指最好的土地。

下半句「他與百姓的首領同來」的所指也一致。CT 說指迦得支派的首領來見摩西和祭司以利亞撒，並會眾的首領（參民三十二2），提出分得那段地的要求，並承諾在境內遵行神的公義和律法。GT《聖經精讀本──申命記註解》說這句話預言了他們將誠實地履行作為比其它支派先分得約但河東地的條件而與摩西所立之約，即在佔領約但河西之地的迦南征服戰中作先鋒打頭陣的應許（民32:16-27）。KC 說迦得加入了百姓的首領，履行他一同過河爭戰的承諾（書1:12-18、書4:12）；BH 說迦得參與了決策與軍事行動（書22章），顯出這支派對立約群體的委身。

## 按書卷累積

### 申命記

<!-- accumulation:申命記:33:start -->
#### [[05 申命記/第33章|第33章]]
- 本章重點：第21節「他為自己選擇頭一段地，因在那裡有設立律法者的分存留。他與百姓的首領同來；他施行耶和華的公義和耶和華與以色列所立的典章。」這半句怎麼讀四家不同：CT 說設立律法者指有權訂立律法的首領，這一句是說迦得支派自認領袖群倫、配分得那段地；GT《申命記串珠聖經註釋》直接給另一個譯法「因他期望得到首領的位分」，並說頭一段地指最好的土地（參民32:1）；GT《聖經精讀本──申命記註解》說這句話指其它支派皆從約書亞分得了地，而迦得支派卻從立律法者摩西手中直接分得了產業（書14:1-3）；KC 說頭一段地與統治者的份相連、指向治理與掌權；BH 說統治者的份表示一份帶著尊榮與領導意味的特別分地，保留一詞暗示神的護理。下半句四家一致：CT 說指迦得支派的首領來見摩西和祭司以利亞撒並會眾的首領（參民三十二2），GT《聖經精讀本》說這預言了他們將履行與摩西所立之約、在迦南征服戰中作先鋒（民32:16-27），KC 引書1:12-18 與4:12。
- 與本章關聯：這是本章各支派祝福裡唯一一處和合本行文本身就不易讀通的句子。四家的分歧不在迦得得了什麼地，而在「設立律法者」指誰——是迦得自己的領袖地位，還是分地時直接經手的摩西。本章整理把兩路並陳。
