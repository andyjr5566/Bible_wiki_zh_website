# 古實

## 定義

古實的希伯來名是 כּוּשׁ（H3568A），是基訓河環繞之地；STEP 在本章將它辨識為專有地名。CT／KC 進一步以「黑暗」解釋名字，並從四河向外流動的整體圖像，延伸討論生命供應臨到罪人與萬民。

### 與目前整理書卷的關聯

古實是基訓河環繞之地。CT／KC 另以「黑暗」意象發展聖靈工作臨到萬民的應用；經文本身沒有把古實居民等同黑暗。

### 神學意義／研讀意義

- 「黑色／黑暗」＝罪人的光景
- 聖靈的工作不分種族，臨到「黑色／黑暗」之地
