# 以東王斷然拒絕摩西行使大道經界並遣重兵驅逐

## 定義

在西元前中東古代荒漠大長征歷劫將達目標之冬夏交鋒期，摩西仰待親緣手足之友善舊盟，自加低斯遣發外交專使馳造相望之「紅土長國」以東王城，以苦楚四百載身歷無休患痛為信，乞期得以付費買水並遵踏中央修繕良嚴的「王道（The King's Highway）」經越疆土；詎知承繼以掃舊意、嗜奉血緣自利的以東主后斷言橫心全絕，非但悍然喝罵更親統巨兵大衛盛戈殺向邊線迎截；此等嚴絕逼迫使不妄開爭鋒的聖盟社群順奉上主平安與不依賴肉體之良義，轉塗別塗長途迂回。
