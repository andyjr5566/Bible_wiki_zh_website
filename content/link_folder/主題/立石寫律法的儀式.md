# 立石寫律法的儀式

## 定義

申命記第二十七章第1至8節：過了約但河、進入那地的當天，要立起幾塊大石頭，墁上石灰，把這律法的一切話寫在上面；石頭要立在以巴路山上，旁邊還要築一座壇。

### 先立石，再做別的

CT 的話中之光注意到這個次序：過河後的第一件事，不是別的，是要立起石頭。他並說明「當天」這兩個字的份量——什麼時候他們進入享用應許，什麼時候他們也進入了權柄；雖然這些石頭在以後的日子要搬到以巴路山，但是他們當天就得把石頭立起來，說明律法已經開始生效了。

KC 讀的是同一個次序：進入那地時，第一個行動就是要立起一份對律法的記念，在那地裡一切往後的行動都必須以律法為根據。

### 這是當時通行的作法

GT《啟導本聖經申命記註釋》把它放進當時的環境：立石，把話寫在石頭上，以昭永志，是古代中東的普通做法；用石灰塗在石頭上，可能指先將石灰塗在石頭上，再用油漆把字寫在上面，這也是埃及等地的普遍方法。GT《申命記串珠聖經註釋》說得一樣：在巴勒斯坦及埃及一帶常有石頭上刻字的做法，有些是刻在石頭上，有些則寫在那些人工塗上的石灰面上。BH 也指出把律法刻在石頭上，與古代近東把條約刻在石版或泥版上的作法相同。

GT《聖經精讀本──申命記註解》給的是這個儀式的用意：此儀式是象徵性行為，用肉眼可視之物宣告了神的統治權將實實在在地臨到迦南地，正如臨在曠野一樣；故此儀式的目的在於生動地曉諭以色列百姓，以色列未來歷史的興衰榮辱將取決於是否遵行了記錄在這些石頭上面的律法。

### 「律法的一切話」到底是哪些

這一點各家並沒有定論，而且有一家把三種可能都列了出來。

CT 認為範圍不大：『律法的一切話』並非指《申命記》書中的一切律法，而是指律法中關於神的總綱，更有可能僅指「十誡」。GT《申命記雷氏研讀本》的推測不同：「這律法的一切」大概指這裏的咒詛與祝福，以及其後的經文。GT《啟導本聖經申命記註釋》取的是最大的範圍：「這律法的一切話」指摩西所重申的一切法例規章。

GT《聖經精讀本──申命記註解》乾脆把三種讀法並列：關於所要記錄在石碑上的律法是摩西法典的哪一個部分，有以下三種解釋——在摩西所教導的所有律例中，純粹法律性的部分；單指27章與28章所記錄的祝福與咒詛的話語；從狹義上指本章15~26節所記錄禁止咒詛的規定。

### 後來真的做了

GT《申命記雷氏研讀本》記下執行的紀錄：約書亞執行了這些指引（書八30～35）。KC 說得更精確：第4節在約書亞記8章應驗（書8:30-34）。CT 在第26節的話中之光補上一個細節：進了迦南以後，這律法言語全部都要宣讀，沒有一句不宣讀的（書八34~35）。

KC 另外把這一章的書寫放進申命記自己的脈絡裡：這是我們第三次聽到寫下律法的事——前兩次都在申命記十章，一次是回頭指向何烈山（申10:2），一次是與摩西鑿出來的版有關（申10:4）。而這一次動筆的是百姓自己——KC 說他們藉著寫這個動作，向神的誡命表示了同意。

### 申命記

#### [[05 申命記/第27章|第27章]]
- 本章重點：第1至8節規定過約但河當天要立起大石頭、墁上石灰、把律法的一切話寫在上面，石頭立在以巴路山，旁邊築壇獻祭。STEP：va./ha.ke.mo.Ta（H6965I qum，立起）、'a.va.Nim ge.do.Lot（H68G＋H1419A，大石頭）、ve./sad.Ta（H7874）ba./Sid（H7875，墁上石灰）、ve./kha.tav.Ta（H3789 ka.tav，寫）、kol div.Rei ha./to.Rah（H3605＋H1697G＋H8451，這律法的一切話）。CT 注意到過河後第一件事就是立石，並說「當天」表示律法已經開始生效，另認為「律法的一切話」可能僅指十誡；GT《啟導本》說立石刻字是古代中東的普通做法，並認為指摩西所重申的一切法例規章；GT《串珠》說巴勒斯坦及埃及一帶常有石頭上刻字的做法；GT《雷氏》說大概指咒詛與祝福及其後的經文，並記下約書亞執行了這些指引（書8:30-35）；GT《精讀本》把三種範圍讀法並列，並說此儀式是用肉眼可視之物宣告神的統治權臨到迦南地；KC 說進地的第一個行動是立起對律法的記念、這是申命記第三次講到寫律法，而這一次動筆的是百姓自己。
- 與本章關聯：這是摩西第三篇講章的開頭，也是全章兩個主題的第一個。石頭與壇並立在同一座山上——碑上寫的是神對人的要求，壇上獻的是人對神的回應。第26節那句「不堅守遵行這律法言語的」用的動詞，正是第2節「立起」石頭的同一個字。
