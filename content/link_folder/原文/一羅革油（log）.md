# 一羅革油（log）

## 定義

利未記14章的潔淨禮，無論富人或貧窮人都要帶「油一羅革」（10、12、15、21、24節）。STEP 語言資料顯示這個字是 לֹג（H3849），簡要辭典就作 log；BH 也註明「log 是一個度量單位」。

**這一羅革到底多少，來源沒有共識。** CT 註「約合半公升」，GT《串珠》同樣說「約半公升」，KC 說大約半公升；GT《啟導本》與《聖經精讀本》都說約合 0.3 公升；GT 丁良才用的是舊制，說「一羅革約重十二兩」；BH 一處說約等於一品脫，另一處說約三分之一公升。GT《舊約聖經背景註釋》乾脆承認測不準：「羅革的分量不大，連一品脫也不足，但卻難以精確估計。聖經只在本章使用這字，它在其他語言中出現時亦同樣含糊。」

**這個字只在本章出現。** 上面那句話還帶出一個容易錯過的事實：整本聖經只有利未記14章用到「羅革」這個單位。

**它在禮儀中怎麼用。** 這一羅革油先與贖愆祭的公羊羔一同作搖祭（12、24節），然後祭司把油倒在自己左手掌，用右手指頭在耶和華面前彈七次（15-16、26-27節），再抹在求潔淨者的右耳垂、右手大拇指、右腳大拇指上，最後把剩下的抹在他頭上（17-18、28-29節）。GT 丁良才特別指出，這原是尋常的橄欖油，卻「因祭司在耶和華面前搖過而成聖」；GT《聖經精讀本》也說它與祭司承接聖職所用的膏油不一樣，是普通的油，要在耶和華面前彈七次「為了使油分別為聖」。

#### [[03 利未記/第14章|第14章]]
- 本章重點：本章五次出現「一羅革油」，作為潔淨大痲瘋者儀式中必備的油量，配合贖愆祭搖祭、抹血抹油、彈油七次、抹頭等步驟，象徵聖靈充滿的分量。
- 與本章關聯：核心度量單位，貫串潔淨禮儀的油膏抹部分，連結贖愆祭與聖靈工作。
