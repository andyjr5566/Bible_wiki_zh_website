## 3b. 舊約回聲（前後呼應）

**做法**

- **回聲拍**：
  - 放在被呼應的那一章最後，顯示「後來」標籤；
  - 進場用時間跳躍的抹除轉場，配色偏舊紙，讓讀者知道是後來的歷史；
  - 說明框裡有「呼應」小標，點了跳回被呼應的那一拍，沿用月份導覽的跳轉：抹除＋瞬間定位，**不做平滑捲動**。
- **章末「舊約其他書卷」一欄**，和「新約」並列，分兩小節：
  - 「後來的人怎麼守」；
  - 「同樣的字，不同的場合」。
  - 每筆是：出處＋和合本原句（建置時從 raw_scripture 抽）＋一句網站自己的話＋連到知識庫該章（`chapterUrl()`）。
- **契約**：
  - Beat 加 `echoes?: string[]`，填被呼應的拍 id；
  - StoryChapter 加 `ot?: { kind: 'kept' | 'word'; ref: string; note: string }[]`。
  - 建置要檢查：出處對得到 raw_scripture；kind 只能是這兩種；echoes 指到存在的拍。
- 回聲拍的註釋照樣四家並陳。該章的 raw 都齊：書5、代下30／35、王下23、拉3／6、尼8、亞14、珥1–2、賽1、摩5、詩81、得2 都有四家＋STEP。開工先用 build_index.py 補索引。

**候選**（主筆讀完經文與註釋後定案；回聲拍以 5–6 拍為上限，其餘放章末）

| 呼應的拍 | 回聲 | 形式 | 為什麼呼應 |
|---|---|---|---|
| 初熟 `not-yet`（利23:14 不可吃烘的子粒） | 書5:10-12：在吉甲守逾越節，次日吃那地的出產、無酵餅和烘的穀，嗎哪止住 | 回聲拍 | 「到了那地」終於實現；第一次吃新穀 |
| 二月逾越節 `unclean`／`second-month`（民9） | 代下30：希西家在二月守逾越節，不潔淨的人也吃了，王為他們禱告 | 回聲拍 | 民9 的補守條例在歷史上真的用上 |
| 七七節 `corners`（利23:22 留給窮人和寄居的） | 得2：路得在波阿斯的田裡拾穗，「直到收完了大麥和小麥」 | 回聲拍 | 田角的條例活在一個寄居的寡婦身上；大麥到小麥正好是初熟到七七節 |
| 吹角節（七月初一） | 尼8:1-12：七月初一以斯拉宣讀律法，百姓哭，被勸「不要悲哀哭泣」 | 回聲拍 | 七月初一的聖會 |
| 住棚節／第八日 | 尼8:13-18：照律法搭棚，自約書亞以來沒有這樣行；第八日嚴肅會 | 回聲拍 | 住棚與第八日的嚴肅會 |
| 無酵節 | 拉6:19-22：被擄歸回的人歡歡喜喜守除酵節七日 | 章末「後來的人怎麼守」 | |
| 逾越節 | 王下23:21-23、代下35：約西亞的逾越節 | 章末「後來的人怎麼守」 | |
| 住棚節 | 拉3:4、亞14:16-19 | 章末「後來的人怎麼守」 | 亞14 是先知看見的將來，說明要寫清楚 |
| 月朔 | 撒上20、王下4:23、詩81:3 | 章末 | 詩81:3 同時提月朔與吹角 |
| 吹角節、嚴肅會 | 珥1:14、2:1、2:15；賽1:13-14；摩5:21；王下10:20 | 章末「同樣的字，不同的場合」 | 禁食悔改、被神厭惡的聚會、為巴力宣告的嚴肅會：都不是這裡的節期 |

**規矩**

- 回聲拍的敘述只寫經文自己說的。關聯怎麼解讀交給註釋；「為什麼呼應」那一欄是給主筆與工程看的，不直接放上網站。
- 「同樣的字」那一節要讓讀者一眼看出它不是節期，說明句只寫經文自己交代的場合。
- 場景需要的新地點：
  - 吉甲營地（可沿用西乃帳棚）；
  - 耶路撒冷聖殿院子與人群（代下30、尼8 共用）；
  - 木臺（尼8:4）；
  - 房頂、院內的棚（尼8:16）；
  - 大麥田的拾穗人（沿用 corners 的田）。
  - 新場景一樣照「動態規格」做。
