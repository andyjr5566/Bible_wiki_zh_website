# 羅得的世俗選擇與後果

## 定義

羅得在創世記十三章選擇約但河平原，漸漸挪移帳棚直到所多瑪（[[羅得的墮落]]）。在創世記十四章中，此選擇的後果立即顯露——羅得因住在所多瑪而被四王聯軍擄走，家產全失。

## 主題發展

### 神學意義

- 羅得的經歷是「與世俗為友即與神為敵」（雅四4）的活生生範例
- 世俗選擇的後果：失去自由、失去平安、失去保障
- 羅得被救回卻不離開所多瑪，表明罪有極大的纏繞力
- 對比：亞伯蘭信靠神得自由，羅得信靠世俗受捆綁

### 地位的三級推進

KC 把創13至19章之間的位置變化排成一條線：羅得先是住在所多瑪**附近**，後來住在所多瑪**裡面**，到本章已經坐在所多瑪的**城門口**。坐在城門口意味著進入城市議會；KC 的說法是，他大概還為「宜居的所多瑪」奔走過，試圖恢復價值與規範。但他的整個見證與所多瑪的生活氣氛綁在一起，因而成了對耶和華的反見證。

第9節暴民的回話從反面確認了這條線的極限：「這個人來寄居，還想要作官哪！」——羅得再怎麼融入，在他們眼中始終是外人。KC 把這句話讀成靈性黑暗中的一線微光，雖然那光很微弱。

### 丁良才：七苦與五失

丁良才把羅得在所多瑪的收支列成兩張清單。

**所受的苦有七**：全家被擄；心中憂傷（彼後二8）；惡人欺凌；家財盡傾；妻變鹽柱；幾乎喪命；女子敗壞。

**所失去的有五**：平安、家產、親眷、良善、美名。

值得注意的是這兩張清單裡沒有一項是「失去救恩」——彼後二7-8 仍稱他為義人。清單所量度的是選擇的代價，不是他的結局。

### 啟導本：同一個家庭、同一個環境、兩種結局

GT《啟導本聖經創世記註釋》把亞伯拉罕與羅得並排，並指出對比之所以成立，正因為兩人的起點幾乎一樣：出自同一家庭（十一31）、處於同一環境，而且都被稱為義人（十五6；彼後二7-8）。分歧點是十三11 的一個抉擇。

| | 羅得 | 亞伯拉罕 |
|---|---|---|
| 當日的抉擇 | 貪圖屬世好處，選擇約但河平原（十三11） | 不為眼前所囿，住在希伯崙幔利的橡樹那裡（十三18） |
| 所住 | 熱鬧城市（19:2） | 帳棚 |
| 所望 | — | 「等候那座有根基的城」（來十一10） |
| 結局 | 逃進山洞（19:30） | 得天上的家（來十一16） |

啟導本的結語是：這兩個人代表著屬世與屬靈的兩種信徒。

### 消失的方式

KC 注意到敘事收尾的一個特徵：聖經沒有記載羅得何時何地死亡。GT《聖經精讀本──創世記註解》記下同一件事，並補上新約的處理方式——路17:28-29、32 與彼後二7-8 提到他，都只是一帶而過，為的是給後人敲響警鐘。精讀本的結論是：罪雖然可得饒恕，那行為所撒的種卻會長成荊棘。
