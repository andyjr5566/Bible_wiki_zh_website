# 奉獻壇之禮（十二支派首領奉獻）

## 定義

「用膏抹壇的日子，首領都來行奉獻壇的禮，眾首領就在壇前獻供物」（v10）。CT 說明「行奉獻壇的禮」的意思就是「將祭壇分別為聖」，GT《民數記串珠聖經註釋》稱它「相等於啟用禮」。

**每位首領獻的東西完全一樣**（v13-17）：

| 項目 | 內容 |
|---|---|
| 銀盤子 | 一個，重一百三十舍客勒，盛滿調油的細麵作素祭 |
| 銀碗 | 一個，重七十舍客勒，同樣盛滿調油的細麵 |
| 金盂 | 一個，重十舍客勒，盛滿了香 |
| 燔祭 | 公牛犢一、公綿羊一、一歲公羊羔一 |
| 贖罪祭 | 公山羊一 |
| 平安祭 | 公牛二、公綿羊五、公山羊五、一歲公羊羔五 |

CT 推測銀盤子「大概是用來供祭司承裝歸給他們享用的祭肉」，銀碗「可能是供祭司承裝奠祭的酒或素祭的細麵」；GT《民數記串珠聖經註釋》則說銀盤、銀碗、金盂「都是用來盛載素祭的材料」。

**為什麼沒有贖愆祭**，三家給的理由不一樣（見[[贖罪祭與贖愆祭的分別]]）。

**為什麼平安祭的數量最多**：GT《聖經精讀本》的解讀是「以最少的祭物獻為贖罪祭，用最多的祭物獻為平安祭，暗示著實際上為奉獻壇的禮物是作為感謝而獻上的平安祭」。CT 的觀察相同：平安祭「是用了最多的數量」，因為「平安祭是為著感恩的」。

KC 從首領對祭物的分辨讀出他們的認識：獻上燔祭、一隻贖罪祭與大量平安祭，「顯示這些首領對各種祭之間的分別有洞見」；而「贖罪的層面並不佔最大的地位」。

#### [[04 民數記/第7章|第7章]]
- 本章重點：本章第10-88節記十二支派首領一連十二天行奉獻壇之禮，各獻銀盤、銀碗、金盂與燔祭、贖罪祭、平安祭。GT《民數記串珠聖經註釋》稱它相等於啟用禮；GT《聖經精讀本》指出贖罪祭用最少、平安祭用最多，本質上是感謝的祭。

## 主題發展

GT《舊約聖經背景註釋》對 v84-88 的清單提出一個容易被略過的判斷：「經文不是說這些牲畜立刻被獻為祭。譯作『所獻的』一語的字眼，原文並不是指犧牲。牲口到聖幕時，是指定為何祭所獻……但牠們暫時只是聖所的牲口，到有需要時才用得上而已。這些運作的基本所需，可說是聖所喬遷的禮物。」

GT《啟導本》從制度面補上另一個功能：獻禮物除了表示感恩，「也是全民對新制度的效忠，同時確立了祭司的侍奉由各族供養的定例」，並指出先講各族長獻上素祭，「是對此制度的肯定」，因為素祭是祭司收入的重要來源。

GT《民數記串珠聖經註釋》把這場禮與新約接起來：「神設立祭壇使人可以藉獻祭親近，得到悅納。新約時代，耶穌基督成為祭壇上最完美的祭物……今日我們獻上的祭物是屬靈的（彼前2:5），要將身體作活祭獻給神（羅12:1）。」
