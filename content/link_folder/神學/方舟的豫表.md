# 方舟的豫表

## 定義

創世記6章以 תֵּבָה（H8392）稱方舟，以 קִנִּים（H7064，「巢／隔間」）描述內部，又用 וְכָפַרְתָּ（H3722B，動詞「遮蓋」）和 בַּכֹּפֶר（H3724B，名詞「松香／瀝青」）描述防水安排。CT、KC與BH進一步把方舟理解為基督的預表：人在神所預備的方舟裡經過審判、得保全生命；各項規格也被用來發展救贖與遮蓋的靈意。

## 主題發展

### 方舟豫表基督八方面

| 項目 | 說明 | 靈意豫表 |
|---|---|---|
| 歌斐木 | 富樹脂柏木，耐水浸蝕 | 基督堅固完美的人性 |
| 分一間一間造 | 內部隔間 | 基督是各種人的安息 |
| 抹松香 | 柏油/瀝青防水 | 基督寶血的救贖功效 |

| 透光處 | 上邊高一肘 | 基督是世界的光 |

| 松香原文 | STEP 分別標出動詞「遮蓋」（H3722B）與名詞「松香」（H3724B）；CT、KC進一步把相近詞根連於贖罪／挽回 | 基督的救贖 |

### 神學意義／研讀意義

- 在方舟裡＝在基督裡，得保全生命
- 方舟內外的分別：惟有進入方舟者得救——「除祂以外，別無拯救」（徒四12）
- 洪水豫表審判（太廿四39）和受浸的水（彼前三20-21）
- 方舟也豫表教會——在基督裡一同經過審判
