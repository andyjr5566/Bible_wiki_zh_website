# 拉結偷神像的動機

## 定義

創31:19拉結偷了父親家中的神像（特拉芬），經文沒有明說她的理由。各家的說法有幾種：為了取得繼承權（《聖經精讀本──創世記註解》、《啟導本聖經創世記註釋》、BH）；為了保平安、保家族豐饒（《串珠聖經註釋》、《創世記雷氏研讀本》）；為了宗教或占卜的目的，顯示拉結還有濃厚的異教信仰（《雷氏研讀本》、《啟導本》、KC）；華爾頓則說，有學者認為這些小像代表祖先，也有學者認為只與家族的守護神有關。

## 主題發展

### 各家的說法

| 說法 | 理由 | 來源 |
|---|---|---|
| 取得繼承權 | 努斯泥板顯示擁有家族神像與合法繼承財產的資格相關；女婿如收為岳父的養子，擁有神像就代表擁有岳父產業的繼承權 | 《聖經精讀本──創世記註解》、《啟導本聖經創世記註釋》、BH |
| 保平安、保家族豐饒 | 以為神像能幫助一家平安抵達迦南，或保家族豐饒 | 《串珠聖經註釋》、《創世記雷氏研讀本》 |
| 宗教或占卜的目的 | 神像在某種意思上是拉結的神，她要用來完成宗教或占卜的目的；她還有濃厚的異教信仰 | 《創世記雷氏研讀本》、《啟導本》、KC |
| 代表祖先或家族守護神 | 一個新近發表的研究認為小像代表祖先，其他學者相信只與家族的守護神有關 | 華爾頓《創世記背景註釋》 |

華爾頓說，拉班十萬火急地追索，證明這些神像對他家族是何等重要。經文只寫「拉結偷了他父親家中的神像」（創31:19），創31:34、35寫她怎麼藏，並沒有給理由。

### 拉結付出的代價

創31:32雅各在不知情的情況下說：「你在誰那裡搜出來，就不容誰存活。」《聖經精讀本》記猶太拉比把這句話理解為『他不能享滿自己的壽』，因為不久後拉結就因難產而死（創35:16-20）；《啟導本》說這個誓幾乎令拉結喪命（見[[雅各不知情發下咒詛]]）。

創31:35拉結說「現在我身上不便，不能在你面前起來」，坐在神像上面。經期中的女人坐過的東西不潔淨（利15:20；《啟導本》）；《精讀本》說，拉班無法想像經期的女兒敢把守護神坐在身子下面。
