# 香爐被鍛釘為包裝壇上的銅片與長遠鑑誡

## 定義

盡管執提香爐之狂士在天火劫浪間身化紅死灰泥，然則天意慈鑑：凡被牽舉陳奉到永生主天壇堂宇前的一粟料具，已自無比光榮裡蒙受分別，成了不可貶撇世俗污渠之「聖物」。是以主令大祭司幼嗣以利亞撒步進灰場撿取那二百五十個尚遺神火餘熱之銅質香爐，呼工眾將其逐次大聲敲搥錘平，細作精寬燦耀無縫的巨大熟銅片，層疊包蓋於浩大外層燔祭壇軀面。這一項壯烈深刻的禮物更換與實體重造，是將大禍流血記憶打磨成千秋青史的最洪響警石；使代代來年率牛拉犢行至於高揚會殿獻靈之以色列後輩，目光甫接這刺目壇皮，內在良明立刻長吟震撼，絕不敢借勢逾份狂窺亞倫世家專為王使之獨家血統大職。
