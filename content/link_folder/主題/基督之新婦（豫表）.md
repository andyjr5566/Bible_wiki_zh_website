# 基督之新婦（豫表）

## 定義

在豫表的讀法裡，利百加被視為教會——基督之新婦——的圖畫。這個讀法在創世記二十四章有最完整的形式：KC 在本章開頭直接說「本章給了我們一幅醒目的圖畫，是三一神為聖子得著新婦的工作」——發起在父（1-9節），僕人是聖靈的圖畫（10-61節），新婦是與主耶穌聯合的教會（62-67節）。CT 的三一豫表表列與此一致。

## 主題發展

### CT 列的八項對應

CT〈利百加豫表教會是基督的新婦〉把對應逐項標出，每一項都指得回經文：

| 教會的特徵 | 利百加的對應 |
|---|---|
| 有基督的生命 | 她與以撒同族（4節） |
| 得自世界 | 她在米所波大米（10節） |
| 貞潔的童女（林後十一2） | 她還是處女（16節） |
| 與神的性情有分（彼後一4） | 她具有美好的品格（18-19節） |
| 雖未曾見祂，卻是愛祂（彼前一8） | 她願隨老僕人而去（58節） |
| 有無數的屬靈兒女 | 作千萬人的母（60節） |
| 歷經世途艱難 | 她隨老僕人長途跋涉（61節） |
| 使基督得到滿足 | 她使以撒得了安慰（67節） |

丁良才另給了一份三欄的對照，把以撒比作主耶穌（獨生子、承受產業、如同從死復活、與父同住、迎接新婦）、僕人比作聖靈（在遠方招新婦、專誇美父富子榮、將禮物賜新婦、引新婦至迦南）、利百加比作信徒（親自定意、憑著信心、撇下所有、走往迦南、隨僕引導、新郎歡迎）。

### 這個讀法從哪裡取得根據

KC 指出兩處經文使它站得住。其一是第67節「這是聖經第二次說到愛」——第一次是父對子（創二十二2），這一次是夫對妻，因此後者被讀成基督與教會之愛的圖畫。其二是撒拉與利百加的接替：「撒拉被利百加取代了；照樣，教會取代了以色列。」KC 在第1-2節也說得很清楚：新婦必須從亞伯拉罕所出之地被領來，而以撒留在應許之地——「照樣，主耶穌留在天上，聖靈則在地上預備教會去迎見她的新郎」。

CT 從新婦的來歷讀出同一件事：亞伯拉罕要老僕人為以撒娶妻，「乃豫表父神起意要為祂的獨生愛子（基督）娶妻，就差遣聖靈在與祂愛子具有相同肉身的人（『本族』）中間尋找合適的對象」。

### 分寸

KC 自己給了一條限定，值得照抄：本章所呈現的「不是教會被提與主同在」；相會的地點是**帳棚**，而帳棚說的是寄居。因此這幅圖畫講的是父與聖靈如今就在地上作工，要教會在聖子裡尋得她的一切，並且現在就與祂有交通——不是末了那一幕。

另一條分寸來自敘事本身：這一整套對應是新約回望所建立的讀法，創世記二十四章記的是一樁婚事的談判與成行。兩個層次都值得保留，但不宜互相取代。
