# 過紅海

## 定義

過紅海是出埃及記第14章的核心歷史事件，也是整個出埃及敘事的最高潮。事件包括：神吩咐以色列人轉回安營在海邊 → 法老率全軍追趕 → 以色列人懼怕發怨言 → 摩西宣告救恩 → 雲柱火柱轉到後邊保護 → 摩西伸杖、神用大東風一夜分開海水 → 以色列人下海中走乾地、水在左右作牆垣 → 埃及軍兵追入海中 → 神混亂埃及軍兵 → 摩西再次伸杖、海水復原淹沒埃及全軍 → 以色列人敬畏信服神。CT 給本章的內容綱要標題是【神以大能拯救以色列人過紅海】；GT《串珠聖經註釋》一句話概括全章：「神帶領以色列人經過蘆葦海走在乾地上，並毀滅一切追趕他們的埃及軍隊。」

### 出埃及記

#### [[02 出埃及記/第14章|第14章]]
- 本章重點：全章核心事件。CT 的內容綱要標題是【神以大能拯救以色列人過紅海】；GT《串珠聖經註釋》概括為「神帶領以色列人經過蘆葦海走在乾地上，並毀滅一切追趕他們的埃及軍隊」。事件序列：v1-4 神預告計畫 → v5-9 法老追趕 → v10-14 百姓懼怕、摩西宣告 → v15-20 神吩咐前行、使者與雲柱保護 → v21-22 海水分開、百姓走乾地 → v23-28 埃及軍兵追入、海水復原淹沒 → v29-31 以色列人敬畏信服。
- 與本章關聯：過紅海是本章全部內容——出埃及旅程中最具決定性的事件，以色列從此徹底脫離埃及。

## 主題發展

**它在舊約救恩史上的份量。** GT《丁道爾聖經註釋》兩處把話說到頂：在 v18 說「對以色列來說，這場戰役是神集救恩、救贖、審判的大成，其重要性怎麼說都不算高估，於我們來說，也應當是這樣」；在 v30 說「這個蘆海的神蹟所以成為舊約最主要的救恩表徵（賽五十一9～11），無疑就是始於本節這種木已成舟的態勢」。

**新約怎麼用它。** CT 的〔話中之光〕說「以色列人過紅海象徵信徒受浸，兩者都是借水得救，使我們得以脫離撒但和世界的轄制」，並引「在海中雲下受浸歸入摩西（表徵基督）」（林前十1）。KC 引來十一29 指出同一件事對兩邊的結果完全相反：「他們因著信，過紅海如行乾地；埃及人試著要過去，就被吞滅了。」GT《聖經精讀本──出埃及記註解》則從身分講：保羅把渡紅海比喻成洗禮（林前十2），「這意味著過去在埃及為奴的以色列完全地葬在了紅海裡面，一個嶄新的以色列重生了」。

**埃及的史料為什麼查不到。** GT《靈修版聖經註釋》給的解釋是體例問題：「在埃及的歷史中，沒有記載出埃及這件大事。因為埃及歷代法老的慣例都是報喜不報憂。他們甚至從現有記錄之中，把奸臣與政敵的名字除去。法老一定處心積慮地不去記載他的大軍追逐逃亡的奴隸而全軍覆沒的一頁。由於埃及人沒有記載，或是有記載但尚未被發現，我們至今無法判定這件事的準確時間。」
