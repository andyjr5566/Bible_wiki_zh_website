# 挖井

## 定義

以撒重新挖出父親亞伯拉罕在世之日所挖的水井，並繼續挖新井。挖井豫表尋求屬靈供應。

## 主題發展

### 重挖與新挖是兩件事

本章的挖井分兩類。第18節是**重挖**父親的舊井，而且「仍照他父親所叫的叫那些井的名字」；第19、21、22節則是在基拉耳谷**新挖**，其中第19節挖到的是「活水井」——CT 註這是有水自地底泉湧出來的井，在巴勒斯坦相當稀罕珍貴；丁良才說得更簡：「活水井」就是泉源。GT《聖經精讀本──創世記註解》提醒難度：巴勒斯坦地帶土質由沙漠構成，「在這裡找到水源挖井極其困難」。

KC 對「仍照他父親所叫的名字」有一個很具體的應用：我們從神話語中所學的真理必須一直用同樣的名字來稱呼——「不要給它們另一種意思」。他同時說明為什麼還要自己挖：雖然我們該用前人所得的光照，但「那不表示我們可以停在那裡」，我們必須自己研究，知識才會增長（但十二4）。

### 挖井是產權行為

GT 華爾頓《創世記背景註釋》在第23-25節指出：第25節的三個舉動（築壇、支搭帳棚、挖井）都與得地為業有關，因此是第24節立約應許的正確回應——「祭壇認定神對他說話之地的神聖，支搭帳棚和挖井都是大致公認，在無主之地確立所有權的方法」。

它在第17-22節也說明爭執為何難免：井一般是由村落所挖掘、亦受村落所保護；水井有淤塞和塌陷的可能，因此需要不時視察；所牽涉的人力，加上水是人口、作物、牲口的必需品，「村落之間，以及村落和同樣堅持有用水權的牧民之間發生爭執，是很可能的事」。

### 起名就是宣告歸屬

華爾頓在第20節另有一段：「標明水井或其他自然資源所有權的方法之一，是給它起名。名稱一經通用，所有權就不難確立。因此起名能夠避免將來發生爭執，並且即使爭執一旦發生，亦可以提供解決的途徑。」他並補上一句：起名也是部落傳說的一部分，可以一代一代地傳講下去。

這解釋了本章為何連續四次記下井的名字（埃色、西提拿、利河伯、示巴），而 GT《聖經精讀本──創世記註解》也說給每口井起名「充分說明水井在人們生活中的重要性」。

### 忍讓換來的井

丁良才對第19-22節的評語最短：「挖三口井的事顯明以撒能讓人」（羅十二19-21）。CT 說得更完整：以撒一面是平和沉靜的人，不願和霸佔他井的人相爭；另一面是堅忍持久的人，靜靜地繼續挖，直到挖到一口仇敵不能佔有的井——「就是這一種堅忍持久的信心，使他能充分享受神的祝福」。
