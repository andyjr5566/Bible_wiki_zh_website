# 審判已過

## 定義

創8:1-5依次使用「消退」שָׁכַךְ（H7918）、被關閉（H5534）、被止住（H3607）、退回 שׁוּב（H7725G）與減少 חָסֵר（H2637）等動詞，描寫洪水逐步退去、山頂顯露。CT再由和合本「閉塞了、止住了、過了、現出來了」的敘事節奏，理解為審判轉向恢復、新局面開始。

## 主題發展

### 創八2-5的四個「了」

1. 「淵源和天上的窗戶都**閉塞了**」
2. 「天下的大雨也**止住了**」
3. 「**過了**一百五十天」
4. 「山頂都**現出來了**」

### 屬靈意義

- 審判已過，信主耶穌者已得蒙赦罪（徒十43）
- 苦難並非立時消除，管教後來必結出平安的果子（來十二11）
- 山頂現出→得救盼望有了確實證據
