## 本章整理

### 神的試驗（1-2節）

「這些事以後」——指生以撒、趕出以實瑪利、與亞比米勒立約之後。神「試驗」（נִסָּה，H5254G）亞伯拉罕（[[神試驗亞伯拉罕]]）。全知的神並不需要藉著試驗才能得知亞伯拉罕的存心，而是藉此使受試驗者顯出實際光景，信心經過試驗就比金子更寶貴（彼前1:7）。

神在第2節發出三重漸進式命令：
1. 「你的兒子」（בִּנְךָ，H1121A）——極切身的要求；
2. 「你獨生的兒子」（יְחִידְךָ，H3173）——等了二十五年、世上無法替代的立約之子；
3. 「你所愛的以撒」（אָהַבְתָּ，H157G；יִצְחָק，H3327）——最心愛的獨生子。

這是聖經全書第一次出現「愛」（אָהַב，H157G）字，用來描述父親對兒子的深愛，指向父神與愛子的關係（太3:17；約3:16）。

GT《啟導本聖經創世記註釋》把這次試驗放進亞伯拉罕一生的抉擇序列：他共有四次重要抉擇，每次都捨棄一樣原本看重的事物——離開本地本族（創12:1）、與姪兒羅得分手（創13章）、在以撒與以實瑪利間抉擇（創21:14），最後是奉獻以撒。丁良才《創世紀註釋》指出神試驗的三重目的：表明信心的實在、表明敬畏主過於愛兒子，並使他因受試煉而得著稱讚、尊貴和榮耀（彼前1:7）。GT《聖經精讀本──創世記註解》進一步區分：撒但的試探（temptation）旨在使人跌倒墮落，神的試驗（test）旨在驗證並煉淨信仰。

> [!quote] KC
> 你更信我所賜給你的，還是更信我自己？——這是亞伯拉罕與我們都要學的功課。

KC 指出本段歷史可從三層理解：字面意義（父親經歷嚴厲信心試驗）、救贖圖畫（父神獻上愛子；[[亞伯拉罕豫表父神]]），以及預言應許（獻祭帶來的萬國祝福）。KC 同時將本章放進創世記的獻祭序列中：這是創世記第四次獻祭（前三次為皮衣、亞伯、挪亞），回答了救贖應許的真正根基何在。

神吩咐亞伯拉罕往「摩利亞地」（אֶרֶץ הַמֹּרִיָּה，H776G、H4179；[[摩利亞地]]）去，在神指示的山上將以撒獻為「燔祭」（לְעֹלָה，H5930A；[[燔祭]]）。代下3:1 記所羅門在摩利亞山上建造聖殿；傳統亦常將各各他與摩利亞山相連。GT《舊約背景註釋》指出本段關於摩利亞位置唯一的線索是「距離別是巴三日路程」，經文未提方向，除代下3:1外未再提及該名；它並提出地形反證：耶路撒冷附近的樹林排除了攜帶木柴的必要，第3節亞伯拉罕特意自備木柴，暗示目的地可能是缺柴之處。李道生《舊約聖經問題總解》亦坦承年代久遠難以確指，列出基利心山或錫安山等候選，並記下摩利亞後來為耶布斯人亞勞拿禾場、大衛築壇止住瘟疫的傳統（撒下24:18-25；代下3:1）。路程本身則有一致估算（啟導本、雷氏研讀本、精讀本皆記約八十公里／五十英里），正解釋了為何需要備驢（[[驢]]）與劈柴。

關於當時近東的人祭風俗（[[古代近東獻兒女為祭]]），GT《舊約背景註釋》指出古代近東（如腓尼基與北非迦太基文獻）常有以兒童為祭以求豐饒多產的儀式，神的要求對亞伯拉罕來說在文化上並不陌生；丁良才舉出考古學家在基色城邱壇附近挖出盛裝嬰孩朽骨的粗大陶罐（獻給亞斯他錄），房屋基址下亦有同樣奠基祭品。然而，本章的結局（12節天使攔阻並以公羊代替）鮮明確立了以牲畜代替人為祭物的模式，將以色列與周遭異教文化徹底劃分開來。

針對律法禁止人祭的疑難，GT 賈斯樂郝威《聖經難解經文詮釋手冊》在〈命題41〉給了四條理由：神從未打算真正殺死以撒（12節為證）；律法所禁是獻給摩洛等外邦神；亞伯拉罕深信神能使以撒復活（來11:17-19）；生命主權本在神手中。GT 艾基斯《舊約聖經難題彙編》指出重心在於父親是否甘心交出兒子，並順帶處理士師記十一章耶弗他之女的平行難題，指兩處皆用「燔祭」一詞，後者意為終身奉獻歸神。

### 亞伯拉罕的順服（3-8節）

亞伯拉罕「清早起來」（[[清早起來]]），備上驢，帶兩個僕人和以撒，劈好燔祭的柴，立刻啟程。CT 指出他展現了不遲延的順服：不與神理論、不為己辯護、不為兒求情、不與妻商量、清早即行。

到了「第三日」（[[第三日]]），亞伯拉罕舉目遠遠看見那地方。來11:17-19 記下他心中的思量：他相信「神能叫人從死裡復活」（[[神能叫人從死裡復活（來十一17-19）]]）。KC 特別指出：希伯來書十一章列舉舊約信徒時多記其憑信所做之事，唯獨對亞伯拉罕特別記下他在心裡所深信的道理；KC 觀察到在當時尚無死人復活先例的歷史背景下，亞伯拉罕單憑對神信實本性的認識而相信神能使死人復活。

亞伯拉罕對僕人說「我們……就回到你們這裡來」（5節）——憑信說話，而非誆言。以撒問：「燔祭的羊羔在哪裡呢？」（7節）亞伯拉罕答：「神必自己預備作燔祭的羊羔（יִרְאֶה，H7200；הַשֶּׂה，H7716；8節）。」這句話成為了穿越救贖歷史的預言（約1:29）。經文在第6節與第8節兩次重複「於是二人同行」，映照出父子同心順服的景象（約8:29）。

GT《聖經精讀本》為「第三日」補上曆法對應：從接受指示算起，抵達之日為第四日，與出埃及記12:3 逾越節前四天預備待宰羔羊的規定一致。精讀本提醒讀者不要把順服讀成毫無內心掙扎的平靜；那一夜他很可能整夜不眠，面對生命尊嚴（創9:4-6）、應許繼承人與多國之父等多重張力，但他選擇在信心裡順服神的權柄。

### 築壇與神的介入（9-14節）

到了指示之處，亞伯拉罕築壇、擺柴，捆綁以撒放在壇的柴上，伸手拿刀（הַמַּאֲכֶלֶת，H3979）要殺他的兒子。以撒此時已有足夠體力背柴爬山，年齡足以反抗，但他順從父親的安排，任憑捆綁，正如基督甘心順服、不開口抗拒（賽53:7）。

千鈞一髮之際，「[[耶和華的使者]]」（מַלְאַךְ יְהוָה，H4397H、H3068G）從天上呼叫他：「你不可在這童子身上下手！一點不可害他！現在我知道你是敬畏神的了（יְרֵא אֱלֹהִים，H3373、H430G；[[敬畏神]]）；因為你沒有將你的兒子，就是你獨生的兒子，留下不給我（12節）。」

雅各書2:21-24 引述此段指出信心與行為並行、因著行為信心才得成全（[[因行為稱義（雅二21-24）]]）。KC 指出經文記載亞伯拉罕「獻上了以撒」，他的行動審慎而堅定，使內心的信心藉著實際行動顯明出來。

亞伯拉罕舉目觀看，看見一隻「公羊」（אַיִל，H352A；[[公羊]]），兩角扣在稠密小樹中，便取來獻為燔祭，「代替他的兒子」（תַּחַת בְּנוֹ，H8478、H1121A；[[公羊代贖]]）。GT《舊約背景註釋》指出，替代性獻祭的概念在古代近東並不如想像中普及（常規獻祭多為禮物或交通關係），以色列亦以買贖長子和逾越節為主要例外；本章公羊「代替」以撒格外醒目，生動預表了基督作為代贖羔羊（約1:29）。部分屬靈註釋亦將角被小樹扣住進一步引申為基督甘心受限於人性、順服受死。

關於第12節「現在我知道」，GT 賈斯樂郝威在〈命題43〉分辨了兩種知道：神以認知（by cognition）知道一切，與神以實證（by demonstration）知道事實，亞伯拉罕以行動證明了神早已知道的事（如數學課堂演算證明已知答案）。在〈命題42〉中他解釋「獨生的兒子」：創25章眾子為庶出，以實瑪利非約中應許後嗣，「獨生」指心愛、特別的兒子（創21:12；約1:18、3:16）。

亞伯拉罕給那地方起名叫「耶和華以勒」（יְהוָה יִרְאֶה，H3068G、H7200；[[耶和華以勒]]，意即「耶和華必預備」或「耶和華必看顧」）。直到今日人還說：「在耶和華的山上必有預備（יֵרָאֶה，H7200）。」丁良才指出這成為以色列人患難中彼此勉勵的俗諺，近代內地會亦以此為標幟；CT 與註釋家常由此延伸屬靈應用，指人唯有在實際奉獻順服的經歷中，才能深刻體會神預備的真實。

### 神指著自己起誓賜福（15-19節）

耶和華的使者第二次從天上呼叫亞伯拉罕：「你既行了這事，不留下你的兒子，就是你獨生的兒子，我便指著自己起誓（בִּי נִשְׁבַּעְתִּי，H9907、H7650；[[指著自己起誓]]）。」

希伯來書6:13-17 闡明：人起誓都是指著比自己大的起誓；神沒有比祂更大的可以指著起誓，就指著自己的永恆生命起誓，證明祂的應許決不更改。

祝福內容包括：
1. 必賜大福；
2. 子孫如天上的星、海邊的沙（屬天與屬地的子孫；雷氏研讀本指出肉眼可數之星約三千顆，海沙則無法數算，兩者為數量級遞進）；
3. 子孫必得著仇敵的城門（שַׁעַר אֹיְבָיו，H8179G、H341）——字面意指在軍事爭戰中佔領仇敵城池（丁良才），新約神學進一步理解為基督與屬靈後裔勝過黑暗權勢（太16:18）；
4. 地上萬國都必因你的後裔得福（בְזַרְעֲךָ，H2233A）——「後裔」原文單數，指基督（加3:16）。

丁良才歸納亞伯拉罕一生七重「捨與得」的對稱整理：

| 他所捨棄的 | 神所應許的 |
|---|---|
| 自己的祖國（創12:1） | 成為一個大國（創12:2） |
| 自己的親戚（創12:1） | 有極大的名聲（創12:2） |
| 自己的父家（創12:1） | 萬族都因他得福（創12:3） |
| 自己的地土（創12:1） | 將迦南地賜他為業（創13:15） |
| 王的賞賜（創14:23） | 神自己作他的賞賜（創15:1） |
| 以實瑪利（創21:14） | 賜以撒為他的後裔（創21:12） |
| 捨兒子的心（本章3節） | 使他的子孫繁多（本章17節） |

### 以撒與基督的豫表對照

本章細節構成了舊約關於基督受難的重要預表素材（[[以撒豫表基督]]、[[亞伯拉罕豫表父神]]）：

| 以撒 | 基督 |
|---|---|
| 父親獨生且所愛的兒子（創22:2） | 父神所愛的獨生子（約3:16；太3:17） |
| 親自背負燔祭的柴（創22:6） | 背著自己的十字架走向刑場（約19:17） |
| 任憑捆綁、不掙扎（創22:9） | 甘心捨命（約10:18；賽53:7） |
| 被放在壇上、至死順服（創22:9-10） | 存心順服以至於死（腓2:8） |
| 歷經三日彷彿從死裡得回（創22:4；來11:19） | 第三日真實復活（路24:46；林前15:4） |

### 拿鶴家譜與神的預備（20-24節）

亞伯拉罕回到別是巴（[[別是巴]]）居住。此後，有人告訴亞伯拉罕關於兄弟[[拿鶴]]的近況：妻子[[密迦]]為拿鶴生了八個兒子（包括長子烏斯、布斯、基母利、基薛、哈瑣、必達、益拉、[[彼土利]]），妾流瑪生了四個兒子。丁良才指出：拿鶴有八個嫡子與四個庶子，與以實瑪利十二族長、雅各十二兒子形成巧妙對稱。

CT 註記名單原文字義：密迦「王后」、拿鶴「鼾睡」、烏斯「穩固」、布斯「輕視」、亞蘭「高地」、基母利「神的會眾」、基薛「星卜者」、哈瑣「異象」、必達「火焰」、益拉「哭泣」、彼土利「神的住處」、利百加「以美迷人」、流瑪「高大」、提八「屠殺者」、迦含「燃燒」、他轄「紅／獾」、瑪迦「壓迫」。

家譜中特別點出「彼土利生[[利百加]]（23節）」——為第24章以撒娶利百加預作伏筆。本章主題既是「神預備」，這段家譜正說明神也預備了以撒的妻子。KC 指出：利百加在此處出現，是因為以撒的婚姻建立在死而復活的根基之上；正如教會作為羔羊的新婦，是建立在基督死而復活的根基上。

丁良才指出，神在此指著自己起誓，以色列人一切好處皆藉此誓而來（創24:7、50:24；出13:5；路1:73；徒7:17）；本章也是聖經記載神直接向亞伯拉罕顯現說話的最後一次。GT《舊約背景註釋》補充了別是巴的考古現況：是巴遺址掘出王國至波斯時代文物，但未見族長時代文物，經文亦未稱其為有城牆之城邑，現代城市底下另有初期定居證據。
