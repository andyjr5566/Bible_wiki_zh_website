# 墳地

## 定義

神應許將迦南全地賜給亞伯拉罕的後裔（創13:14-15；15:18），但亞伯拉罕在迦南地所取得的**第一塊永久性產業，是一塊墳地**——用來埋葬妻子撒拉（創23:20；CT）。

GT《聖經精讀本──創世記註解》問，神應許的『迦南』到底在哪裡，並答說是他死時領受的天上迦南、新天新地的天國；CT 則把這塊墳地連到天上更美的家鄉（來11:8-16）。

### 創世記

#### [[01 創世記/第23章|第23章]]
- 本章重點：
  - 神應許迦南全地，亞伯拉罕此時所得的唯一永久產業是墳地（CT）
  - 亞伯拉罕按足價購置，在神的時間未到以前不用不義的方法獲得（CT）
  - 埋葬是種下，撒種是為著收成（KC）
  - 六位族長皆葬麥比拉洞——舊約信徒存信心而死，等候與新約信徒同得更美復活（來十一39-40）
- 與本章關聯：本章墳地的歸屬一步步轉變：赫人說可以在他們最好的墳地埋葬亞伯拉罕的死人（創23:6），亞伯拉罕要求按足價買來作自己的墳地（創23:9），最後田與洞定準歸他作墳地（創23:20）。

## 主題發展

### 神學或研讀意義

- **天上更美的家鄉**：神所應許的產業非地上物質產業，乃是天上更美的家鄉（來十一8-16）
- **埋葬 = 種下**：種子埋入土裏等候收割——死亡不是終結（KC）
- **身體就是人**：經文寫的是『他妻子撒拉』（創23:19），沒有用『遺體』這樣的詞（KC）
- **神的買贖**：神用獨生子的血買贖世界（KC）
- **埋葬 vs 焚燒**：埋葬=復活盼望；焚燒=審判（KC）
- **六位族長同葬**：亞伯拉罕、撒拉、以撒、利百加、雅各、利亞皆葬麥比拉洞——舊約信徒存信心而死，等候與新約信徒同得更美復活（來十一39-40）
