# R14 燈臺與陳設餅播放器

R14 把燈臺照料與陳設餅納入 R13 的逐步播放器。兩個程序都由 `src/data/rituals.json` 定義，面板沿用同一組進度、上一個、下一個、暫停、重播與退出控制。

## 燈臺照料

燈臺程序有三步：預備清橄欖油、祭司整理燈盞、顯示七盞燈常常點著。燈火 cue 只在第三步啟用；離開、暫停、完成或退出時由播放器清除。第一步不虛構採油者或採油場景，第二步使用供職祭司與日常聖衣。

## 陳設餅

陳設餅程序有四步：預備十二個餅、祭司在金桌上排列成兩行／摞、每安息日更換、換下的餅歸亞倫和子孫在聖處食用。製作人、烘焙器具與唯一排列形狀仍保留為未決資料，面板用文字與物件高亮表達，不播放未有來源支持的寫實烘焙或進食動畫。

## 驗收邊界

- `lampstand-care` 與 `shewbread-service` 都可由 `AppKernel.startRitual` 啟動。
- 燈火只由 `lamp-light` 步驟觸發 `menorah-flames`，不會因進入學習模式整場常亮。
- 每一步保留角色、服飾、器物、位置、經文、claim、提示與 unresolved 欄位，方便回查來源。
- Blender 場景本輪沒有寫入；沿用 R07–R12 已驗證的器物資產。
