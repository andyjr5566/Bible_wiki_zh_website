# 聖所的器皿是什麼

## 定義

民31:6 說非尼哈「手裡拿著聖所的器皿和吹大聲的號筒」。這句話的兩個名詞是並列還是同一件東西，四套來源給了四種不同的答案。

| 來源 | 判斷 |
|---|---|
| CT | 「『聖所的器皿』指可以隨身攜帶的小型器具，可能是祭司點火之用的香爐(參十六37~38)，象徵禱告」 |
| GT 丁良才 | 「有注釋家以為本句當作聖所的器皿，就是吹大聲的號筒（十1-10）。」 |
| GT《舊約聖經背景註釋》 | 「本節所指的器皿是什麼並不清楚，但可能包括約櫃、祭司胸牌，和烏陵土明」 |
| KingComments | 器皿就是號筒；並明確排除烏陵土明的說法，理由是非尼哈當時還不是大祭司 |

**STEP 只能界定字面。** v6 的原文是 u./khe.Lei ha./Ko.desh（H3627 器皿的構造式加 H6944G 聖）接 va./cha.tzo.tze.Rot ha./te.ru.'Ah（H2689 號筒加 H8643 大聲），兩組之間只有一個連接詞。這個連接詞既可以是「和」，也可以是解釋性的「就是」；句法本身不替兩種讀法作結。

**功能上各家倒是一致。** GT 串珠說「『聖所的器皿』和『號筒』：象徵神與百姓同在，為他們爭戰」；KingComments 說非尼哈知道得勝必須從耶和華而來，所以帶著號筒，好叫耶和華聽見（民10:9）；GT《舊約聖經背景註釋》則把它放進古代近東的通例：「古代近東幾乎所有的軍隊，都有祭司、占卜者」、先知，與手提的聖物同行。

## 按書卷累積

### 民數記

<!-- accumulation:民數記:31:start -->
#### [[04 民數記/第31章|第31章]]
- 本章重點：v6「聖所的器皿和吹大聲的號筒」所指為何：CT 猜香爐，GT 丁良才與 KingComments 讀成同位語（器皿就是號筒），GT《背景註釋》猜可能含約櫃、胸牌與烏陵土明，KingComments 則排除烏陵土明。
- 與本章關聯：原文兩組名詞之間只有一個連接詞，既可讀成並列也可讀成解釋，因此四種判斷都停在推測層面。
