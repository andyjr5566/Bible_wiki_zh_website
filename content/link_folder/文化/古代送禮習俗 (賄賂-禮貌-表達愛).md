# 古代送禮習俗 (賄賂-禮貌-表達愛)

## 定義

古代近東送禮具多重功能，創33章雅各送禮給以掃集中體現：①賄賂/求和——軟化怒氣、換取安全（箴21:14「暗中送禮、挽回怒氣」）；②相愛表達——父子/兄弟/朋友間情感流通；③禮貌問候——重要會面前按對方職業送禮（以掃牧人、故送牛羊）。雅各禮物分五群遞送（創32:13-21）、見面時堅持以掃收下（33:10-11），希伯來文 *minchah* 兼具「禮物、供物、貢物、福分」意，雅各視為歸還當年詭取的長子福分（創27:35同字）。收禮在古代法律即確立和好、放棄報復權（書9:14-15基遍人詐降立約）。

## 主題發展

### 送禮可以有三種意思

GT《靈修版聖經註釋》在第11節下把當時送禮的可能動機列成三項：（1）賄賂，希望用禮物贏得對方的歡心和支持；（2）相愛的表現；（3）在重要的會面前，作為禮貌上的問候。

它並指出這些禮物常常跟對方的職業有關——以掃是個牧人，所以雅各將牛羊牲畜送給以掃；而以掃在起初不願接受雅各的禮物，是因為「他不想、也不需收受賄賂，他已經原諒了雅各，況且他自己也豐衣足食」。

這三分法在本章特別有用，因為第9至11節那場推讓，正是兩兄弟對這份禮屬於哪一種意思的角力。

### 「禮物」在原文是「祝福」

這是本章最值得記住的一處原文觀察，三家都指出來了。CT 註第11節：「『禮物』：原文與『福分』（創二七35）同字，雅各藉此表示他是從神所給的『福分』裏，把他從前用詭計從哥哥奪去的『福分』還給他。」

GT《啟導本聖經創世記註釋》說得一樣完整：希伯來文「禮物」和「祝福」同一字；雅各承認他當年強求的祝福乃來自神，現在要把從哥哥那裡取來的祝福，藉著神已給他的祝福，歸還給哥哥。GT《創世記雷氏研讀本》只作字面說明：「『我帶來給你的禮物』原文是『我帶來給你的祝福』。」

要注意第10節那份禮的用字不同——CT 註第10節的「禮物」原文字義是「供物，貢物，贈品」，第11節才是「福分，祝福」。同一場對話裡雅各換了字，而換的那一次正是他非要以掃收下不可的那一次。

### 收下等於和好

CT 指出收受禮物的法律意涵：「收受禮物，乃是表明從此願意受約束，放棄向送禮的人採取敵對或報復，因此被視為和好的憑據（參書九14-15）。」GT 丁良才《創世紀註釋》引的是同一處經文：「收禮物就是和好的憑據。【比方】書九14-15。」

這解釋了第11節末尾那句「雅各再三地求他，他才收下了」為什麼重要——不是客套的推讓，是雅各要一個具約束力的憑據。BH 的說法方向一致：在古代近東，拒收禮物往往等同於拒絕那段關係。

### 兩句對照的話

KC 把第9節與第11節排在一起讀：以掃說他「已經夠了」，雅各說靠神的恩典他「一切都有了」——雖然那是他辛苦掙來的。KC 指出雅各在此說的是信心的話，活出了摩西後來對以色列所說的：「你要記念耶和華你的神，因為得貨財的力量是他給你的」（申八18）。

同一場推讓裡兩種「夠」：一種是不缺，一種是有神就有一切。

- 禮物雙重屬性：外交手段 + 屬靈供物
- 收禮 = 和好確立、棄報復權（古代近東法律慣例）
- *minchah* 語義演變：貢物 → 供物 → 福分 → 基督獻祭預表
