# 河東城邑的位置考據

## 定義

民數記32 列了兩份城邑名單：第3節是兩支派開口要的九座，第34-38節是他們實際建造的十二座。GT《舊約背景註釋》為這兩份名單各寫了一段考據，多數城邑都能定到具體的遺址。

| 城邑 | GT《舊約背景註釋》給的位置 |
|---|---|
| 亞大錄 | 底本西北八哩、死海東面八哩之處的阿塔魯斯廢墟 |
| 底本 | ＝迪班，摩押的首都，亞嫩河北面約四哩、死海以東十二哩處 |
| 寧拉 | 今日之寧林遺址附近，與雅謝一同位於外約但的北區 |
| 希實本 | ＝黑什班，馬達巴平原的西北角，尼波山東北三哩 |
| 以利亞利 | ＝阿珥，在希實本東北 |
| 示班 | 地點不明 |
| 尼波 | 位置未確定，但曾在米沙石碑中提及 |
| 比穩 | ＝馬因，希實本西南十哩 |
| 亞羅珥 | 亞嫩河畔，迪班以南三哩 |
| 約比哈 | ＝朱貝哈特，拉巴西北五哩 |
| 伯哈蘭 | 寧林遺址以南 |
| 基列亭 | ＝庫雷亞特廢墟，迪班西北六哩之外 |

**兩件與碑文有關的事。** 關於亞大錄，GT《舊約背景註釋》說：「米沙石碑（約主前830年）的碑文也提到這城是以色列人所建，以及迦得支派在此定居。」關於比穩，同一份資料說：「摩押王米沙（主前九世紀）在其凱旋紀念碑上，宣稱此城是他自己所建。」也就是說，同樣的城在以色列的名單裡和摩押王的碑文裡都出現過。

**這一區的地形。** GT《舊約背景註釋》寫道：「本區氣候乾燥，因此必須倚靠灌溉才能耕作，但卻為遊牧民族提供足夠的牧草。」GT《啟導本聖經註釋》則點出這片地的弱點：「外約但屬高原地帶，雨水豐足，土地肥沃，宜於放牧，但缺少軍事屏障。」

**考據仍在進行。** GT《舊約背景註釋》在名單末尾說明：「近二十年來考古學家加強了對本區的注意，但不少遺址至今仍未挖掘。」

BH 對名單中的個別城邑另有補充，多半是名字的字義與後續出現的位置：亞大錄意為「冠冕」；寧拉又名伯寧拉，名字意為「純淨」或「清澈」，可能與水質有關；以利亞利意為「神已升起」；約比哈意為「高聳」，士師記八11 記基甸追趕米甸人時經過此地；基列亭意為「雙城」。

## 按書卷累積

### 民數記

<!-- accumulation:民數記:32:start -->
#### [[04 民數記/第32章|第32章]]
- 本章重點：第3節與第34-38節兩份城邑名單：GT《舊約背景註釋》逐一考據十二處位置，多數可定到具體遺址，示班與尼波仍不確定。米沙石碑同時提到亞大錄是以色列人所建、比穩是摩押王米沙所建。BH 另補各城名字的字義。
- 與本章關聯：這份考據把本章末尾看似流水帳的名單還原成一片真實的高原：土地肥沃宜於放牧、卻缺少軍事屏障，正是兩支派看中它、也是後來最先被擄的地理原因。
