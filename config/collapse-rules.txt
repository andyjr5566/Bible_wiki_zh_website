# 
# 📝 使用說明：
# 1. 每一行代表一個你希望在網頁上「預設收合」的標題名稱。
# 2. 單層收合：直接寫標題名稱（例如：本章知識節點）。
# 3. 按書卷分組：如果該段落底下是「各卷書（H3 標題）＋各章（H4）＋清單」的結構，
#    請在該行後方加上：-> books（例如：按書卷累積 -> books）。
#    效果：標題旁的徽章顯示「N 卷書」，內容以單層呈現（書名是小標題、清單滿版），不再每卷書各自收合。
#    （舊的 -> subheadings 仍可用：各卷書 H3 會各自再收合一層，目前沒有段落使用。）
# 4. 井字號（#）開頭的行為註解，不會生效。
# 5. 修改此檔案後，重新發布或同步即可全站生效！
