# 拿細耳人滿期還俗條例

## 定義

許願的日子滿了，不是自己宣布結束就好，要走完一整套公開的程序（v13-21）。

| 步驟 | 內容 | 節次 |
|---|---|---|
| 一 | 由人領他到會幕門口 | v13 |
| 二 | 獻一歲公羊羔作燔祭、一歲母羊羔作贖罪祭、公綿羊作平安祭，都要沒有殘疾 | v14 |
| 三 | 獻一筐無酵調油細麵餅與抹油的無酵薄餅，並同獻的素祭和奠祭 | v15 |
| 四 | 祭司先獻贖罪祭和燔祭，再獻平安祭與素祭奠祭 | v16-17 |
| 五 | 在會幕門口剃離俗的頭，把頭髮放在平安祭下的火上 | v18 |
| 六 | 祭司取已煮的公羊前腿與一個無酵餅、一個無酵薄餅放在他手上，作搖祭搖一搖 | v19-20 |
| 七 | 之後拿細耳人可以喝酒 | v20 |

**獻祭的次序有意思**：GT《聖經精讀本》指出祭司「在獻上燔祭之前首先獻上了贖罪祭，這是因為對於人來講最重要的是應首先解決罪的問題」。KC 注意到同一件事，並拿它跟前一段對比：用鳥獻祭時贖罪祭在先（v10-11），這裡卻是燔祭列在第一。

**為什麼還俗還要獻贖罪祭**：這是最容易被問的問題。GT 丁良才的答案是「人最好最聖的事都被罪惡玷污，除非流血獻祭，就不得蒙悅納」；GT《聖經精讀本》的答案是「因為所有的人在神面前都是罪人（羅3:10）」。

**祭司多拿的那一份**：CT 指出第19節那條已煮的前腿是「平安祭牲的左腿，因右腿已經指定歸給祭司享用（利7:32），那已煮的左腿原來屬於獻祭的人」，所以祭司在這裡可以額外享用一條腿。GT《民數記串珠聖經註釋》給了同一件事一個解釋：祭司所得除了慣常的胸和腿，還加上額外的前腿及兩個餅，「表明拿細耳人的事奉是超額的」。

**把頭髮燒在平安祭火上**：KC 認為這是全本聖經獨一無二的安排——「除了拿細耳人的這頭髮以外，我們在任何地方都沒有讀到人身上的任何東西與祭物相連。這證明神極其看重人向祂獻身所作的事。」GT《聖經精讀本》的解釋方向不同：這個動作象徵離俗日子裡分別為聖的生活「都是因神的恩典」。

## 按書卷累積

### 民數記

<!-- accumulation:民數記:6:start -->
#### [[04 民數記/第6章|第6章]]
- 本章重點：本章第13-21節規範滿期還俗的七個步驟：領到會幕門口、獻燔祭贖罪祭平安祭與素祭奠祭、剃頭燒髮於平安祭火上、搖祭歸祭司，之後方可喝酒。GT 串珠指出祭司額外得前腿與兩個餅，「表明拿細耳人的事奉是超額的」。
- 與本章關聯：完備拿細耳人許願結束時的公開禮儀；KC 指出把人身上的頭髮燒在祭物火上是全本聖經僅見的安排，GT《聖經精讀本》則強調義務雖結束、奉獻並未結束。

## 主題發展

還俗不等於奉獻結束。GT《聖經精讀本》逐一解釋四種祭物的作用，並在燔祭那裡點出重點：「說明雖然拿細耳人的義務結束了，但向神的奉獻並沒有結束。」至於平安祭，它是「為了繼續與神交通」而獻，因為「與神的交通應持續一生」。

第21節留了一道彈性的門：除了規定必須獻的，還可以「照許願的人能力追加奉獻」（CT）。GT 丁良才說得簡潔：「離俗的人，若有力量，就可隨意多獻。」GT《聖經精讀本》從神的角度讀這條彈性：這是「因考慮經濟情況所說的話，表明神的慈悲和愛」，並強調「比起人獻上的祭物，神更喜悅的是人的心」。

GT《民數記串珠聖經註釋》注意到本段沒有列出便宜的替代品，指定要用三隻羊，認為這「表示以聖潔事奉神是需要付代價的」。

STEP 原文資料顯示第20節的兩種祭在原文是兩個不同的字：「搖祭」是 te.nu.Fah（H8573，詞典形 te.nu.phah，詞典義 wave offering），「所舉的腿」的「舉」是 ha./te.ru.Mah（H8641，詞典形 te.ru.mah，詞典義 contribution）；而動詞「搖一搖」是 ve./he.Nif（H5130B，詞典形 nuph，詞典義 to wave）。
