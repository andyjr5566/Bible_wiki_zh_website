# 拉結偷神像的動機

## 定義
創31:19 拉結偷父親家神像（特拉芬），學者見解分歧：1) 保佑家族豐饒/平安抵達迦南（啟導本/串珠）；2) 爭產業繼承權——努斯泥板顯示擁有神像=合法繼承人（GT/啟導本/KC/BH）；3) 宗教/占卜目的——拉結仍有濃厚異教信仰（雷氏研讀本）；4) 華爾頓指神像可能代表祖先或家族守護神，拉班十萬火急追索證明其重要性。動機可能混合以上因素。

## 主題發展

### 五種動機

| 主張 | 理由 | 來源 |
|---|---|---|
| 為了繼承權 | 努斯泥板顯示家神像的持有與家產繼承有法律關聯 | GT 華爾頓《創世記背景註釋》、GT《創世記雷氏研讀本》、BH |
| 為了報復父親 | 拉班把她們當外人賣了、又吞了她們的價值（15節） | GT《聖經精讀本──創世記註解》 |
| 為了保平安、當護身符 | 迷信心理未除，以為神像能保佑路上平安 | CT、GT《串珠聖經註釋》 |
| 為了阻止父親占卜追趕 | 家神像也用於問卜，取走就斷了拉班的一項工具 | GT《舊約背景註釋》系列的占卜用途說 |
| 為了使父家脫離偶像 | 動機是正面的——把偶像帶走 | 少數解經家（CT 記為並存說法之一） |

### 繼承權說要小心

這是最常被引用的一說，但 GT 華爾頓《創世記背景註釋》自己加了一個限制：努斯的材料顯示家神像通常隨產業一併轉移，可作為所有權的憑證，但那些文獻的情境與本章並不完全對應——拉班有親生兒子（第1節），所以「女兒的丈夫憑神像取得產業」這條路在拉班家未必走得通。KC 因此完全不走這條路，只留下一句對整件事的判語：「把一個可以被偷走的東西稱為神，是何等的愚妄。」

CT 的處理最保守：它列出各家的推測，然後說經文沒有明說。這是可以核對的——第19節只寫「拉結偷了他父親家中的神像」，第34、35節寫她怎麼藏，敘事者始終沒有給理由。

### 拉結付出的代價

第32節雅各在不知情的情況下說「你在誰那裏搜出神像來，不容那人存活」。CT 與 GT 多家都把這句話接到創三十五19 拉結難產而死——雖然經文沒有明說因果，這個先後次序歷來被讀成一個沉重的呼應（見[[雅各不知情發下咒詛]]）。

第35節拉結說「現在我身上不便，不能在你面前起來」，坐在神像上面。GT《聖經精讀本──創世記註解》指出這在當時具有雙重效果：按潔淨觀念，經期中的女子所坐之物為不潔（比較利十五20），拉班因此不會去翻。一個被人坐在底下、又被視為沾染不潔的「神」，敘事的諷刺已經到頂。
拉結偷神像動機雖複雜（產權/保佑/宗教殘餘），但本章四次「神像／偶像」緊張預備創35章雅各全家潔淨行動（35:2「除掉你們中間的外邦神」），指向「聖殿不可與偶像有分」（林後6:16）。
