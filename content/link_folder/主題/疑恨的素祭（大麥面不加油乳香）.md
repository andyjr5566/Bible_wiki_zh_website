# 疑恨的素祭（大麥面不加油乳香）

## 定義

民數記五章15節：丈夫要為妻子帶「大麥麵伊法十分之一作供物，不可澆上油，也不可加上乳香；因為這是疑恨的素祭，是思念的素祭，使人思念罪孽」。這份素祭處處與尋常的素祭相反：

| 項目 | 尋常素祭 | 疑恨的素祭 |
|---|---|---|
| 材料 | 細麵（利2:1） | 大麥麵 |
| 油 | 澆上 | 不可澆上 |
| 乳香 | 加上 | 不可加上 |
| 用意 | 喜樂與感恩 | 思念罪孽 |

為什麼用大麥，GT 丁良才說得最直接：「大麥面的價值最賤（王下七1、16、18），這無非是表明那婦人的卑下。」CT 說法相同：大麥麵價值比細麵便宜，「表示不齒其行為」。GT《民數記串珠聖經註釋》把不加油與乳香的理由說清楚：通常加油和乳香代表喜樂和感恩，此處不加，是要「表明獻者的不潔和悲哀贖罪的心態」。GT《聖經精讀本》另給一個技術性的理由：這素祭不與燔祭或平安祭一同獻上，只單獻素祭，所以不能澆上除罪之不潔的油，也不能加上象徵禱告的乳香。

STEP 原文資料在名稱上有一個容易讀過去的細節：「疑恨的素祭」的「疑恨」在這裡是複數形，STEP 的 context gloss 逐字作「jealousi<es>」；而「思念的素祭」的「思念」是 זִכָּרוֹן（zikh.ron，H2146，詞典義 memorial），與「素祭」מִנְחָה（min.chah，H4503G，詞典義 offering）搭在一起。

## 主題發展

GT《舊約聖經背景註釋》指出這份祭與一般素祭不同的兩點：獻的是大麥「如窮人的祭」而非小麥，而且和其他可能與犯罪有關的素祭一樣不可加油和乳香——因為「油和乳香通常和慶典有關，而此非喜慶之事」。

KC 從預表的角度讀這份最低等的素祭：它顯出主耶穌在地上最深的降卑，而祂在其中對神完全忠心；因為這祭是「使人思念罪孽」的記念，所以不能加油與乳香——神在不義上得不著喜悅（乳香），聖靈（油）與不義也完全無分。

BH 補上一層：這份祭是丈夫帶來的，因此它同時是他關切的表達與群體對公義的承擔；「記念」一詞表示這件事被帶到神面前存記，等候神的判斷。
