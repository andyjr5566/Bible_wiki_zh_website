# 你們不能事奉耶和華

## 定義

百姓剛說「我們必事奉耶和華，因為他是我們的神」（書24:18），約書亞卻說：「你們不能事奉耶和華；因為他是聖潔的神，是忌邪的神，必不赦免你們的過犯罪惡。」（書24:19）百姓立定了志向，約書亞卻說他們做不到，還說神必不赦免，這兩點都引起討論。

**原文。** STEP 顯示「不能」是 lo' tu.khe.Lu（H3201，簡要詞典義 ya.khol: be able），「事奉」是 la./'a.Vod（H5647H）；「聖潔的神」是 'E.lo.Him ke.do.Shim（H430G 加 H6918G，形容詞是複數形），「忌邪的神」是 'el- ka.No'（H410G 加 H7072）；「必不赦免」是 lo'- yi.Sa'（H5375I，簡要詞典義 na.sa: to lift: forgive）。GT《約書亞記研經資料》說 SH 7072 這個字聖經只出現兩次，另一次在鴻1:2。

**「不能」的幾種讀法。**

| 來源 | 讀法 |
|---|---|
| CT〔文意註解〕 | 信仰的告白、經歷上認識神是一回事，能做到討神喜悅的事奉又是另一回事，必須對付罪惡 |
| CT〔話中之光〕 | 可能是指人意志薄弱，無法靠自己的力量事奉；約書亞在這句話中提出了因信稱義的原則 |
| GT《研經資料》 | 明顯的激將法；神賜下律法的主要目的，不是告訴罪人「能」，而是告訴罪人「不能」 |
| GT《聖經精讀本》 | 約書亞不因百姓一時的強烈決志而滿意，為了堅固他們順服到底而強烈警告 |
| GT《約書亞記綜合解讀》 | 神只接受人專心歸向祂，心裡還藏著偶像的人不能事奉耶和華 |
| KC | 約書亞知道他們心裡的光景，人自己沒有力量，這和在西乃山時一樣 |
| BH | 百姓的保證不能靠熱情或全國的決心，約書亞揭露了分裂之心的不足 |

**「必不赦免」。** GT《研經資料》說這句話引起很多爭議，應該是約書亞的一種表達方式，強調背叛神會有嚴重的後果。KC 說約書亞並不是說神不是赦免人的神，他要說明神不能用半心事奉，離棄祂去事奉別神是嚴重的罪。BH 說神不會忽略那藏在空洞應許底下、刻意而持續的悖逆。

**百姓的回答。** 百姓說「不然，我們定要事奉耶和華」（書24:21）。GT《丁道爾》說這是直接而堅定的「不」，是信仰的第一步，不過這種信心究竟有多少能耐，還需要經過考驗；GT《研經資料》說一般人在百姓選擇神的時候就會高興地停止，約書亞卻進一步逼百姓面對自己的軟弱。

## 按書卷累積

### 約書亞記

<!-- accumulation:約書亞記:24:start -->
#### [[06 約書亞記/第24章|第24章]]
- 本章重點：第19節約書亞在百姓宣告必事奉耶和華之後說「你們不能事奉耶和華」，理由是神是聖潔的、忌邪的，必不赦免他們的過犯罪惡；第21節百姓回答「不然，我們定要事奉耶和華」。STEP 顯示「不能」是 tu.khe.Lu（H3201），「必不赦免」是 lo' yi.Sa'（H5375I）。CT 讀成要對付罪惡，也讀出因信稱義的原則；GT《研經資料》說是激將法；GT《聖經精讀本》說是為堅固百姓的警告；KC 說約書亞並不是說神不赦免人；BH 說約書亞揭露分裂之心的不足。
- 與本章關聯：本章的立約在百姓三次說「必事奉」中完成，這句話夾在中間，各家對它的意思看法不一。
