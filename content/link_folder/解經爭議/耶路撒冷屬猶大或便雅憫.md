# 耶路撒冷屬猶大或便雅憫

## 定義

書15:63 說「至於住耶路撒冷的耶布斯人，猶大人不能把他們趕出去」，士1:21 卻說便雅憫人沒有趕出耶路撒冷的耶布斯人，書18:28 又把耶布斯列在便雅憫的城中。耶路撒冷到底分給誰？士1:8 又說猶大人攻取了耶路撒冷，這和「不能把他們趕出去」怎麼配合？

**分界線的位置。** GT《綜合解讀》說猶大的邊界從耶路撒冷城的南邊繞過去（書15:8），耶路撒冷城屬於便雅憫支派；GT《串珠》也說耶路撒冷並不在猶大境內。GT《約書亞記研經資料》說耶路撒冷處於猶大與便雅憫的交界，雖然劃分給便雅憫（書18:16、28），卻很容易成為一個三不管地帶，不管是猶大或便雅憫都拿它沒辦法。BH 也說耶路撒冷位在猶大與便雅憫的邊界附近。

**上城與下城。** 幾家用上城、下城來解釋士1:8 與本節的張力，但說法不一致：

| 來源 | 說法 |
|---|---|
| GT《雷氏研讀本》 | 猶大人確實佔據了下城（士1:8、21），但上城到了大衛王的時候才被佔領 |
| GT《啟導本》 | 約書亞只攻取到下城（北部），未能攻下上城（南部），要到大衛時代才取得 |
| GT《綜合解讀》 | 猶大人暫時攻取了西南部的下城（士1:8），便雅憫人卻未能攻下東北部的上城（士1:21） |
| GT《約書亞記研經資料》 | 士1:8 的攻取可能只達到很短暫的控制，直到士師記後期此城還無法奪下（士19:10-12） |
| GT《聖經精讀本》 | 耶布斯人後被猶大支派與西緬支派部分佔領（士1:8），到大衛時期才被完全征服 |

GT《啟導本》說下城在北、上城在南，GT《綜合解讀》則說下城在西南、上城在東北，兩家對上下城的方位說法相反。各家一致的是：耶路撒冷要到大衛時才完全攻取（撒下5:6-7）。GT《研經資料》與《綜合解讀》還提醒，即使到了大衛的時代，城裡仍有耶布斯人（撒下24:16、代上21:15）。

**為什麼不能趕出。** CT 的話中之光說，猶大人能趕出亞衲族的三個族長，卻不能趕出耶布斯人，「問題不在耶布斯人比亞衲族更強，問題乃在猶大人信心與順服的情況有了改變」。KC 也說，猶大作為一個支派缺少把仇敵趕盡的力量（信心）。

## 按書卷累積

### 約書亞記

<!-- accumulation:約書亞記:15:start -->
#### [[06 約書亞記/第15章|第15章]]
- 本章重點：第63節「住耶路撒冷的耶布斯人，猶大人不能把他們趕出去」。GT《綜合解讀》說城屬便雅憫，猶大的邊界從城南繞過；GT《研經資料》說它是兩支派交界的三不管地帶；GT《雷氏研讀本》《啟導本》《綜合解讀》用上城、下城解釋士1:8，但對方位說法相反。
- 與本章關聯：本章是這個問題的起點之一：猶大的北界貼著耶路撒冷南邊走（第8節），章末又說猶大人不能趕出城裡的耶布斯人（第63節）。

<!-- accumulation:約書亞記:18:start -->
#### [[06 約書亞記/第18章|第18章]]
- 本章重點：第16、28節便雅憫的南界貼近耶布斯的南邊，耶布斯列在便雅憫的城邑。GT 所引華爾頓與《研經資料》都說這條邊界經過欣嫩子谷，證明耶路撒冷在便雅憫屬地之內；BH 說耶路撒冷位於便雅憫與猶大的交界上；KC 說耶路撒冷在便雅憫與猶大之間。
- 與本章關聯：第15章給了問題的一半（猶大的北界與猶大人趕不出耶布斯人），本章給了另一半：城被列在便雅憫。
<!-- accumulation:約書亞記:18:end -->
## 主題發展

這個問題由兩章的經文一起構成。書15:8 猶大的北界「貼近耶布斯的南界」，從欣嫩子谷繞過城的南邊；書15:63 卻又說猶大人不能趕出住耶路撒冷的耶布斯人。到了書18:16，便雅憫的南界同樣經過欣嫩谷、「貼近耶布斯的南邊」，書18:28 再把「耶布斯（耶布斯就是耶路撒冷）」列在便雅憫的城邑裡。

兩章合起來看，界線和實際的佔有是兩回事。照書18 的界線，城落在便雅憫這一邊；照書15:63，住在城裡的耶布斯人猶大人趕不出去；士1:21 又說便雅憫人也沒有趕出他們。地界畫好了，城卻一直在耶布斯人手裡，要到撒下5:6-9 大衛攻取，才真正歸以色列。
