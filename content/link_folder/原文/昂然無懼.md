# 昂然無懼

## 定義

出埃及記第14章 v8「因為以色列人是昂然無懼地出埃及」。原文為 בְּיָ֥ד רָמָֽה（*be-yad ramah*，H3027G 搭配 H7311A），STEP 直譯為「帶著高舉的手」（with a raised hand），context gloss 作「exalted / raised」。CT 解釋這是「法老對以色列人離開埃及時，那種得勝者高昂的姿態（參民三十三3），心有不甘」。GT 丁良才《出埃及記註釋》說得更直接：「以色列人出埃及的狀態，不是像逃命的奴僕，乃是像神自由的百姓。」BH 用的字是「昂首闊步地出去」，並說這份膽量來自他們對神保護的信靠。

## 按書卷累積

### 出埃及記
<!-- accumulation:出埃及記:14:start -->
#### [[02 出埃及記/第14章|第14章]]
- 本章重點：v8「以色列人是昂然無懼地出埃及」。CT 給的原文字義是「昂然」升起、升高、攀登，「無懼地」手，並解釋為「得勝者高昂的姿態」（參民三十三3）；GT 丁良才說這是「不是像逃命的奴僕，乃是像神自由的百姓」；BH 說這份膽量來自對神保護的信靠。
- 與本章關聯：CT 進一步把這種「高舉著手」、如得勝者般離開的姿態，理解為法老心有不甘、追趕以色列人的因素之一。
