# 按日獻供物（十二天奉獻禮）

## 定義

「眾首領為行奉獻壇的禮，要每天一個首領來獻供物」（v11）。本章因此成為摩西五經中最長的一章——同樣的清單原樣重複了十二次。

**為什麼要分十二天，有一個很實際的理由。** GT《民數記串珠聖經註釋》算給讀者看：每支派的人口數以萬計，「不能全部齊集在帳幕前，況且利未人的營地將他們與帳幕隔開，所以必須由首領代表獻供物」；而每支派獻的祭牲「總共便有十七隻」，「花一天的時間去處理是相當合理的」。

**為什麼經文要一字不省地重抄十二遍**，各家的答案彼此呼應：

| 來源 | 理由 |
|---|---|
| CT | 「照一般人的作法……盡可記載『同上』……但聖經的記載，與人的想法不同。」神「不單是紀念人所作的奉獻，並且是很具體的紀念，祂絕不會漏掉人對祂的敬愛」 |
| GT 丁良才 | 「十二首領所獻的禮物雖是一樣，神還讓他們每天一個首領來獻，也一一地記錄在聖書上。這就顯明神重視他們各人和各人的禮物（來6:10）」 |
| GT《啟導本》 | 「正好說明，每一族在敬拜神、支持會幕和供養祭司的事上，都有同等的責任」 |
| KC | 「重複對神來說不是一件累人的事」，並舉詩篇一百三十六篇二十六節都重複同一句為例；在讚美中我們常用同樣的話，但神從不說「這我已經聽過了」 |
| BH | 各支派所獻完全相同，象徵支派之間的合一與平等 |

CT 另從人性的角度補一句：「人的天性都喜歡把自己顯露，因此都不願意與別人相同」，而奉獻「不是要與人作比較，更不是要與人爭強鬬勝，而是向神表明敬愛祂的心」。GT 丁良才對獻的次序也有一句觀察：各首領所獻都一樣，「表示有一樣的熱忱、感恩和樂捐的心，也免得有嫉妒，或自誇的心」。

#### [[04 民數記/第7章|第7章]]
- 本章重點：本章第11節命令每天一個首領獻供物，第12-83節逐字重複十二次。GT 串珠給了實際理由（人口數以萬計無法齊集、每支派十七隻祭牲一天處理合理），CT、丁良才、啟導本、KC 與 BH 則各自解釋為何經文不肯省筆。
- 與本章關聯：展現神對個人與群體奉獻的具體數點；KC 以詩篇一百三十六篇的重複作類比，指出「重複對神來說不是一件累人的事」。

## 主題發展

十二天裡會不會遇上安息日，本章來源討論過。GT 丁良才在第11節說「就是在安息日，他們大概也沒有停止」，在第48節又補一句「這未必是安息日，但在獻禮物的日子中，必有一個安息日」；GT《聖經精讀本》的判斷相同：「不能斷定這日是相當於安息日的日子。但是在獻上禮物的十二天中，肯定包括安息日。」它並給了三個理由說明為何不算違背安息日：榮耀神的聖潔之事不違背安息日、歸榮耀與神是超越人意志的基本義務、為神榮耀所作的事應在維持秩序中進行。

獻的次序也不是隨意排的。CT 指出「猶大支派領先奉獻，因為是按照軍隊起營和紮營的順序」，並列出四隊的組成；KC 的說法一致——「這與民數記第2章描述支派安營的次序相同」。

「十二」這個數字各家也都給了解讀。CT：「在聖經中，十二是代表神揀選的數字，所以十二天的獻上，就是在被揀選的見證中獻上」；GT《聖經精讀本》：「『十二』這個數字意味著完全，說明以色列百姓在神面前獻上了完全的感謝的禮物」；BH：十二在聖經數字象徵中常代表完整或神的子民。
