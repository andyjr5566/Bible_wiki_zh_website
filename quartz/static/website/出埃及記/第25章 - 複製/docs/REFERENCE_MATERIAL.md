# 參考資料使用紀錄

本專案收到的 `docs/addition_info/` 檔案是**設計與空間閱讀參考**，不是已納入網站的圖片或 3D 資產。所有網站內的模型、文字與儀式說明仍須分別以經文和 `src/data/*.json` 驗證，並標示 `textual`、`reconstructed` 或 `interpretive`。

## 授權邊界

三份提供檔案內顯示 FreeBibleimages / Rev. Yves Langevin 的 CC BY-NC 4.0 歸屬資訊。它們沒有被複製、轉檔、嵌入或隨網站發布；因此目前不屬於 `docs/ASSETS.md` 的「使用中資產」。如果日後要把任何一張圖放入網站，必須先建立獨立資產紀錄、保存原始來源 URL、依 CC BY-NC 4.0 提供完整署名，並確認網站用途不違反非商業條款。

## 已採納的可核對設計原則

1. 導覽與地圖維持由入口進入外院、先經燔祭壇與洗濯盆、再進聖所、面向幔子與至聖所／約櫃的順序；程式中的器具位置仍以 `tabernacle.json` 為唯一 runtime 資料。
2. 入口簾採用《出埃及記》27:16 與 26:36–37 所列的藍、紫、朱紅色線與細麻意象；圖樣與材質表現一律為 `reconstructed`，不主張是唯一歷史外觀。
3. 會幕外層以《出埃及記》26:1–14 的覆蓋物次序提供可讀的分層提示；「海狗皮／獾皮」等翻譯或具體材質辨識有詮釋差異，介面不得當成無爭議的文字事實。
4. 祭司、大祭司、以弗得與胸牌的視覺將以《出埃及記》28、39 作資料基線。參考圖只幫助理解資訊架構，不能代替經文、考據或已確認的模型授權。

本次更新採納參考圖的「會幕位於營地中央」視覺構圖：runtime 以低成本 instanced tents／embers 建立遠景營地，標記為 `reconstructed`，只作空間氛圍，不主張圖中的營位數量、人員位置或活動是經文記載。

## 刻意未採納為既定事實的內容

- 參考資料中的象徵性色彩解讀與敘事性說法，除非另有明確資料來源，不能在網站寫成經文直接記載。
- 參考資料對約櫃內容物的圖像化整理，不能取代不同經文段落與時序的辨析。目前網站僅依本專案範圍呈現「法版」的剖面研究標記，並附具體經文連結。
- 參考圖中的部落營位、人員位置、夜景和動作屬後續研究／重建素材；在未建立可追溯資料與可信度標籤前，不作為 runtime 的歷史主張。
