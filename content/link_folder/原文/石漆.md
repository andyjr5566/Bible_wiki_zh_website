# 石漆

## 定義

石漆（tar／bitumen），即瀝青，死海地區盛產的天然礦物。BH 說明這些天然瀝青礦床在當地十分常見，古代用作防水與建築材料，是有價值的資源。西訂谷中有許多石漆坑（創十四10）。GT《串珠聖經註釋》形容石漆「乃是一種黏性物質，有如修補馬路的柏油；故此，任何人掉在坑裡就會被黏住，不能再逃跑」；GT《創世記雷氏研讀本》則直接把「漆坑」解作「產瀝青的礦井」。

第10節「有掉在坑裏的」該怎麼讀，來源分歧，不必壓平：

- **落坑遇難說**：CT 與 GT《串珠聖經註釋》按和合本讀作五王的人逃跑時陷入坑中被黏住；CT 進一步指出五王選在西訂谷擺陣本是想借地形之險取勝，「結果卻自己『掉在坑裏』」。BH 同樣把落坑讀成致命的後果。
- **自行下坑避難說**：GT《舊約背景註釋》指出原文譯作「坑」的字眼與舊約其他形容水井的字相同，一般指掘出來的地點，因此西訂谷有很多開採瀝青的礦坑，是五王的避難之處——「他們是『自己吊下去』，不是『掉進坑裡去』」。

兩說的分別不只在字義：若按前者，兩王當場覆沒；若按後者，這是一次有計畫的躲藏。經文本身留下的線索支持後者至少可行——第17節所多瑪王仍活著出來迎接亞伯蘭。

## 主題發展

石漆在創世記中出現三次，三次都與人的建造或求生有關：巴別塔以石漆當灰泥（創十一3），摩西的蒲草箱抹上石漆防水（出二3，GT 丁良才在本節並引此二處），西訂谷的石漆坑則成了敗軍的去處。這條線索顯示石漆本身是中性的資源——它可以砌塔，可以救命，也可以困住逃亡者；決定結果的是使用它的人與處境，而不是材料。

本章的爭議點提醒一件方法上的事：和合本的「掉在坑裏」是一個已經作了選擇的翻譯。GT《舊約背景註釋》從原文用字（與「井」同字）反推出人工礦坑與主動下坑的讀法，而 CT、串珠、BH 三方沿用落坑遇難的讀法。引用時應說明分歧所在，不要只取其一當作經文本身的意思。
