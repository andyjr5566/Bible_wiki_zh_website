# 娶被擄女子為妻的條例

## 定義

申命記第二十一章第10至14節處理一件古代戰爭裡很常見、律法卻不放任的事：以色列人戰勝之後看上了被擄的女子，想娶她為妻。條例沒有禁止，但在中間插進一個月的等待，並在結尾加上一條不可反悔式的保障。

### 適用對象：迦南以外的俘虜

這一點四套來源都有交代，理由來自前一章。CT 的備註寫得最直接：神命不可留迦南人的活口（參申二十16），所以這些俘虜當係迦南人以外的敵人。GT《啟導本》說「敵人」指迦南四境外的國民，戰敗之後其婦女可以留下，不在消滅之列。GT《雷氏研讀本》說這種在第七章3、4節之條例以外的做法，只應用於從迦南以外擄來的俘虜。GT《聖經精讀本》講得最短：但是絕對禁止娶迦南女子（7:3）。KC 說法相同。

### 一個月的程序

第12至13節列出四個動作：剃頭髮、修指甲、脫去被擄時所穿的衣服、住在家裡哀哭父母一個整月。

STEP 顯示這些動作各有其字：「剃」是 ve./gi.le.Chah（H1548，ga.lach: to shave），「指甲」是 tzi.pa.re.Nei./ha（H6856，tsip.po.ren: fingernail），「被擄時所穿的衣服」是 sim.Lat shiv.Ya/h（H8071 sim.lah 加 H7628A she.vi），「一個整月」是 Ye.rach ya.Mim（H3391 加 H3117G），字面是一個月的日子。

這些動作的意思，各家給的解釋不完全一樣：

| 來源 | 對剃頭髮修指甲的解釋 |
| --- | --- |
| CT | 有兩種可能性：為她父母哀哭的表示，或潔淨自己使與未來的丈夫相稱 |
| GT《串珠》 | 表示該女子已從外邦社會中移居於以色列家，也表示哀傷 |
| GT《聖經精讀本》 | 潔淨儀式包含徹底清理過去的生活習慣，進入以色列共同體開始新生活 |
| GT《雷氏研讀本》 | 第12、13節的儀式表示她從舊有的生活轉變過來，或許也為離開父母或父母被殺而哀悼 |
| KC | 凡在她從前的身分裡使她有吸引力、標誌著她的，都必須除去 |

哀哭父母的原因同樣有兩說。CT 列出兩種可能：父母死於戰亂中，或女子歸化猶太籍與父母從此訣別。GT《串珠》說這可能暗示女子的父母已在戰亂中死亡，也可能是被迫離開父家的一種哭訴。GT《啟導本》寫的是父已被殺、母也為奴。

至於為什麼要等，BH 給的理由最實際：一個月讓她有時間哀悼與適應，也確保娶她的決定不是倉促作成的。KC 的說法接近，並稱這段哀悼期本身就是神恩慈的安排。

### 結尾那條保障

第14節：後來若不喜悅她，就要由她隨意出去，決不可為錢賣她，也不可當婢女待她。

STEP 顯示「由她隨意出去」是 ve./shi.lach.Ta/h le./naf.Sha/h（H7971H sha.lach: to send: let go 加 H5315L ne.phesh），字面是照她自己打發她走；「決不可為錢賣」是 u./ma.Khor lo'- tim.ke.Re./nah（H4376 ma.khar，不定詞絕對式加未完成式的強調結構）；「當婢女待」是 tit.'a.Mer（H6014B，a.mar，簡要詞典義 to tyranise）；「玷污」是 'i.ni.Ta/h（H6031B，a.nah: to afflict，本節譯義 you have humiliated her）。CT 的原文字義也記下：「意」魂，自我；「玷污」苦待，錯待，並說「玷污了她」的原意是使她降卑了。GT《串珠》另給一個限定：「你玷污了她」即你曾佔有了她，這不是指用暴力的強奸。

各家對這一條的評價一致。BH 說這條規定在當時是罕見的，體現一種看重個人自由的道德標準，也強調不可把她當作商品或奴僕，維護她的尊嚴與人性。CT 說一旦成為夫妻，便不可待她如婢女、隨意轉賣；他在本章的話中之光另指出，感情上的變化不能改變她的地位使她再作奴僕——她一次得了自由，就永久享用自由。KC 說藉著娶她，這人成了她的丈夫而不再是她的主人，她也因此進入以色列女兒的權利。GT《雷氏研讀本》則把「由她隨意出去」接到申二十四章1至4節，說這就是容許他們離婚。

### 一個諧音

CT 在本章的話中之光留下一個原文觀察：「妻子 אִשָּׁה」與「被擄的人 שִׁבְיָה」原文是諧音，由「被擄的人shibyah」變成「妻子 ishshah」，因著聯合而脫離了奴僕的地位，同樣成為神的百姓。STEP 顯示第11節「女子」是 'E.shet（H802G，ish.shah: woman），而「被擄的人中」是 ba./shiv.Yah（H7633，shiv.yah: captive）；第13節「被擄時所穿的衣服」用的是同一字根的 shiv.Ya/h（H7628A）。

- 本章重點：第10至14節：戰勝後若戀慕被擄的美貌女子要娶為妻，須先領回家，剃頭髮、修指甲、脫去被擄時所穿的衣服，哀哭父母一個整月，然後才可同房；後來若不喜悅她，要由她隨意出去，不可為錢賣她，也不可當婢女待她。CT 備註這些俘虜當係迦南人以外的敵人（參申二十16），列出剃頭髮修指甲與哀哭父母各有兩種可能性，並說「玷污了她」的原意是使她降卑了；GT《啟導本》說「敵人」指迦南四境外的國民、給了女俘一定的人身權利；GT《雷氏研讀本》說只應用於從迦南以外擄來的俘虜，並把「由她隨意出去」接到申二十四章1至4節；GT《串珠》說成婚之先女子必須行潔淨禮，並註「你玷污了她」即你曾佔有了她、不是指用暴力的強奸；GT《聖經精讀本》說潔淨儀式含有徹底清理過去生活習慣進入以色列共同體的意思，並說絕對禁止娶迦南女子（7:3）；KC 說藉著娶她這人成了她的丈夫而不再是她的主人，並稱一個月的哀悼期是神恩慈的安排；BH 說一個月讓她哀悼與適應、確保決定不是倉促作成，並說不可賣她不可待她如奴的規定在當時罕見。STEP 顯示「戀慕」是 ve./cha.shak.Ta（H2836A cha.shaq），「美貌」是 ye.fat- To.'ar（H3303 加 H8389），「剃」是 ve./gi.le.Chah（H1548），「指甲」是 tzi.pa.re.Nei./ha（H6856），「一個整月」是 Ye.rach ya.Mim（H3391 加 H3117G），「由她隨意出去」是 ve./shi.lach.Ta/h le./naf.Sha/h（H7971H 加 H5315L），「當婢女待」是 tit.'a.Mer（H6014B），「玷污」是 'i.ni.Ta/h（H6031B a.nah）。
- 與本章關聯：這一段緊接在第20章的戰爭條例之後，適用範圍也直接由那一章決定：可以娶的只有迦南地以外被擄的女子。它與本章其他四段一樣，處理的都是勝利者或掌權者手上握著別人命運的時刻——律法在每一處都插進一道限制。
