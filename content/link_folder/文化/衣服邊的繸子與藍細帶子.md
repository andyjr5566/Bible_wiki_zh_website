# 衣服邊的繸子與藍細帶子

## 定義

民數記第15章結尾在血涼而警凜的營外罰刑後，開啟了一道極富日常撫持溫存且光徹閃燦的長世佩束象徵：神溫和叫告摩西傳諭千邦選孫，必定要在各衣袍外角垂編精工柔順的「繸子」（鬚狀摺邊），且更於此邊際正眼處牽挑穿扣「一根藍細帶子」。那沉穩高聳、象徵雲端天朝光瀚無雙的深湛天蔥底色（藍）嵌連與潔素相伴，讓這凡世軀殼披肩衣飾變成了活潑走動的神契呼籲神鐘。每一刻俯首或步履垂目，那迎風的淺藍牽扣宛加從穹蒼降臨的慈心挽索，提醒行走其中的世客不要被世俗沙塵掩卻靈明，時常銘抱屬於天家的神潔使命。

#### [[04 民數記/第15章|第15章]]
- 本章重點：傳達終年隨世的服飾銘訓規度：叫全以色列生生孫孫都要在其穿用的外套下際挑造整縷之繸，且特意以令人心向往藍空的蔚天細絹條橫綴牽繫。
- 與本章關聯：將深奧遙垂的誡命與天道恩慈揉進平日觸手及眼可遇的生活常衣之中，塑造出不忘初志、持定自天而落無微照顧的大能護顧護儀。
