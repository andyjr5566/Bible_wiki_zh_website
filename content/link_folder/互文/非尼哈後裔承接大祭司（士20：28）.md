# 非尼哈後裔承接大祭司（士20：28）

## 定義

民數記25:13 的應許——「這約要給他和他的後裔，作為永遠當祭司職任的約」——在後面的歷史書裡被追蹤了下去。

**四套來源都指向同一組經文。**

| 來源 | 所引經文與說法 |
|---|---|
| CT | 「這個約後來除了一度短暫由以利父子接任外，後來轉回到非尼哈的後裔，一直到主耶穌降生（參撒上一9；王上二27；代上六4~8，24~38），祂才是真正永遠的大祭司（參來七20，24）」 |
| GT 丁良才《民數記註釋》 | 「非尼哈後來果然繼續他父親以利亞撒做了大祭司（士二十28）」 |
| KC | 神以永遠的祭司職分獎賞非尼哈與他的後裔（Jdg 20:28；1Chr 6:4-15） |
| GT《啟導本聖經註釋》 | 「此約應許非尼哈的後裔永遠擔任大祭司的職務（代上六3～15）」 |

**丁良才把中斷也算了進去。** 他在第13節寫道：「本節的應許，後來應驗了。除了以利家做了幾十年的大祭司以外，這大祭司的職分，就歸了非尼哈的後裔，直到耶穌降生（撒上一9，王上二27，代上六4-8，24~38）。」CT 的說法一致，都把以利家那一段當作插曲而不是推翻。

**家譜上的證據。** GT《舊約聖經背景註釋》指出一個很具體的痕跡：「非尼哈這時的虔誠行為，是亞倫家中惟有屬他的一族得到在聖殿事奉之專利的根據（代上六3～14的家譜單獨記述他的家系，他弟兄的則絕口不提）。」KC 另提到一處：在列出守門的人時，非尼哈被以極大的尊敬記念（代上9:19-20）——他說非尼哈行事像一個真正的守門人，確保惡從神面前被除去。

**這條線往哪裡去。** CT 把它一路接到新約：非尼哈的後裔承接大祭司職分直到主耶穌降生，而祂才是那位真正永遠的大祭司（參來七20、24）。
