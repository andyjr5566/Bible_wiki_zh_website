# 拿細耳人長髮與保羅禁令的張力

## 定義

神吩咐拿細耳人不可剃頭，保羅卻說男人留長髮是羞辱。這兩句話怎麼並存，本章來源有專門處理。

**第一個爭議：長髮本身**

GT 賈斯樂郝威《聖經難解經文詮釋手冊》把它立成命題8：「在此拿細耳人（Nazarite）許願是否與保羅的教訓禁誡人留長髮有衝突？」難題陳述得很直接：「保羅認為男人若有長頭髮是違反本性（against nature）(林前十一14)。但是拿細耳人所許的願是不可剃頭發。」

他的解答走「例外」這條路：一般規矩是男人不可穿著像婦女一樣，也不可像女人一樣留長頭髮；例外的情形包括邪行、健康安全因素，以及「神聖的義務(sanctity)」，而「拿細耳人的許願就是由於為了神聖的義務」。他並補上一句判斷：「沒有一個出於邪惡意念企圖混淆性別的人能夠作出這種自我犧牲的許願。」

其他來源沒有走例外論，而是各自給長髮一個正面的意思，彼此並不一致：

| 來源 | 長髮代表什麼 |
|---|---|
| CT | 甘心以辱為榮。「男人若有長頭髮，便是他的羞辱」（林前11:14），但拿細耳人為了主接受這個羞辱 |
| GT 丁良才（說法一） | 力量的奉獻。以色列人以為茂盛的頭髮顯明完全的體力（撒下14:25-26），留長髮「是表明他們把一切的精神力量全獻於主」 |
| GT 丁良才（說法二） | 「也有人以為是表明他們情願為主受羞辱的意思（林前十一14），不隨世界的潮流和看法」 |
| KC | 交出權柄的位置。男人代表神在地上的權柄，長髮是倚靠與順服的記號；在人眼中這不是尊榮的位置，在神眼中卻是 |
| BH | 古代近東文化中頭髮象徵力量、活力與身分，未剪的頭髮是誓願的可見提醒 |

**第二個爭議：保羅該不該許這個願**

使徒行傳十八18記保羅在堅革哩剪了頭髮，因為他許過願。這件事各家評價相反：

| 來源 | 立場 |
|---|---|
| CT | 肯定。「保羅在他生命當中的一個階段，也似曾經許過拿細耳人的願」，並說他「生活聖潔公義無可指摘，是聖徒榜樣」 |
| GT 丁良才、李道生 | 肯定。都把徒18:18、21:23-24 列為暫時離俗之願的實例 |
| GT《啟導本》 | 肯定但保留。史家約瑟夫說主後第一世紀流行此舉，使徒行傳提到的願「很可能是拿細耳人的願」 |
| KC | 否定。保羅參與此事「不合乎他的呼召與職事」；基督徒「不在律法之下，乃在恩典之下」（羅6:14），不該把自己置於律法之下，許願不屬於他的地位 |

四份來源在第二個爭議上是三比一。

## 按書卷累積

### 民數記

<!-- accumulation:民數記:6:start -->
#### [[04 民數記/第6章|第6章]]
- 本章重點：本章第5節「不可用剃頭刀剃頭」與林前11:14「男人若有長頭髮，便是他的羞辱」形成張力。GT 賈斯樂郝威命題8以「神聖的義務」為特殊例外化解；CT、GT 丁良才、KC、BH 則各給長髮一個正面解釋（受辱、獻上力量、交出權柄、身分記號）。延伸爭議是保羅在堅革哩許願（徒18:18）該不該做，CT／GT／BH 肯定、KC 明確否定。
- 與本章關聯：把本章第5節的禁令放進新舊約之間的張力裡，呈現四套來源在同一段經文上的分歧與並陳。

## 主題發展

兩個爭議的分歧點其實是同一個：拿細耳人的條例在新約時代還算不算數。主張算數的一方（CT、GT 各家、BH）把它讀成可以延續的奉獻形式，所以保羅許願沒有問題，長髮也可以當作特殊例外；KC 則從基督徒的地位出發，認為這一整套已經完成在基督身上——祂是地上真正的拿細耳人，「不是照字面，而是照真義」。

值得注意的是 KC 對主耶穌的描述本身就在化解字面主義：「祂確實喝酒，我們沒有讀到祂留長髮，祂也摸過死人。」照這個讀法，奉獻是內在的事，外在特徵只是可見的記號。
