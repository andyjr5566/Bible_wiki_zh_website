# 希伯崙

## 定義

原文意為「同盟、聯合、交通、友誼」。位於耶路撒冷以南約32公里，原名基列亞巴。亞伯蘭與羅得分離後搬到希伯崙幔利的橡樹居住並築壇。

## 主題發展

### 位置：來源給的方位與距離並不一致

| 來源 | 方位與距離 |
|---|---|
| CT（創23） | 位於耶路撒冷之西南 |
| GT 丁良才《創世紀註釋》（創23） | 耶路撒冷以南五十餘里，比地中海高出三百零四丈 |
| GT《串珠聖經註釋》（創13） | 耶路撒冷以南三十二公里（二十英里） |
| GT《創世記雷氏研讀本》（創13） | 耶路撒冷以南二十二英里（三十五公里） |
| GT《啟導本聖經創世記註釋》（創13） | 耶路撒冷以南三十餘公里 |
| GT《舊約背景註釋》（創13） | 耶路撒冷西南約十九哩，別是巴東北二十三哩 |

方位有正南與西南兩說，距離從十九哩到二十二哩不等。

### 它為什麼重要

GT《舊約背景註釋》給的是地理與經濟的理由：希伯崙城位於猶大山地（海拔約三千三百呎），是通往東面之拉吉和北面耶路撒冷兩條古道會集之處，「地位重要，自古一直有人居住」；當地的泉水和井水，足以種植橄欖、葡萄，以及應付創世記二十三章所形容的那種半農牧經濟的需要。它並指出築壇之舉把本城變為後世的宗教中心，而族長後來在此埋葬「更加強了它在政治上的重要性」（可見於大衛的史事：撒下二1-7、十五7-12）。

背景註釋另記一項年代線索：聖經說希伯崙「比埃及的鎖安城早七年」被建造（民十三22），據考證是主前十七世紀。GT 丁良才則註明這城最古（民十三22）。

### 三個名字

希伯崙、基列亞巴、幔利三名在族長敘事裡指同一片地方。CT 註希伯崙的字義是「同盟，友誼」，並說它「後和幔利混為一城」；[[基列亞巴]]是它的古稱（書十四15），到約書亞的時候又復稱原名（書十四15；十五13、54）。GT《啟導本聖經創世記註釋》把三名並列，並指幔利是當時一個著名人物（創十四13），聖經常用「幔利的橡樹」來指這個地方。

### 族長的祖墳

亞伯拉罕在此買地葬妻（創二十三1-20），此地遂成家族祖墳：亞伯拉罕（創二十五9）、以撒與利百加、雅各與利亞（創四十九29-32）皆葬於此。啟導本並指以撒、雅各大部分時間都住在希伯崙（創三十七至四十五章），而「帳棚」與「祭壇」是他們生活的重要標記。
