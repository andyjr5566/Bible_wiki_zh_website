# 迦南四境的地名考據

## 定義

民數記34 的四界上有十幾個地名，多數今天只能考證到「大概在哪裡」。GT《舊約聖經背景註釋》為它們寫了一整段。

| 地名 | GT《舊約聖經背景註釋》給的判斷 |
|---|---|
| 哈馬口 | 最可能是奧朗底河源頭之一旁邊的萊布韋 |
| 西達達 | 很可能是今日的瑟達德，位於萊布韋東北三十五哩 |
| 西斐崙、哈薩以難 | 通常被考證為西達達東南面的兩個綠洲 |
| 哈薩亞達、押們 | 學者經常考證為加低斯一帶的另外兩個水泉 |
| 亞克拉濱坡 | 位置不明，通常被考證為沿馬拉乾河朝東北前往死海南端的窄道 |
| 第11節的地名 | 皆不可考 |

**北界的走向。** 同一份資料把北界描述成一條線：從大海直入利巴嫩山區的何珥山（位置不明的山峰，大概在利巴嫩山脈內）與哈馬口，「這是哈馬地的南界，因此也是迦南地──包括大馬色一帶和巴珊（大約相等於今日的戈蘭高地）──的北界」。

**東界與南界的走向。** 它接著說：向南延伸的邊界穿越加利利海直到雅穆克河谷，然後西入約但河谷，南達位於尋的曠野的加低斯巴尼亞，最後往西在阿里什乾河轉入地中海。

**兩條最清楚的線。** GT 同一段的判斷是：「最明顯的界線是東界和西界──約但河和地中海。」

**中文註釋補的位置。** CT 註哈馬口位於今敘利亞、為古以色列地的北境，西達達在敘利亞首都大馬士革東北方，西斐崙僅知在今敘利亞境內，哈薩以難是邊界的東北角（結47:17；48:1）。GT 丁良才註亞克拉濱坡就是蠍子坡的意思，在死海南、相離約二十四裡路。BH 補的多是字義：亞克拉濱意為「蠍子的上坡」，哈薩以難可譯作「泉水之村」。

## 按書卷累積

### 民數記

<!-- accumulation:民數記:34:start -->
#### [[04 民數記/第34章|第34章]]
- 本章重點：GT《舊約聖經背景註釋》為四界地名逐一定位：哈馬口＝萊布韋、西達達＝瑟達德、西斐崙與哈薩以難是兩個綠洲、哈薩亞達與押們是加低斯一帶的水泉、亞克拉濱坡位置不明；第11節所列地名皆不可考。它並指出最明顯的界線是東界和西界——約但河和地中海。
- 與本章關聯：這份考據把一段地名清單還原成一條可以在地圖上走的線，也標出哪些地方今天已經查不到。
