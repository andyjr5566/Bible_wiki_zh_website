# 血郎的含義

## 定義

「血郎」是西坡拉在出埃及記4:25-26兩次對摩西說的稱呼：割下兒子的陽皮之後，她說「你真是我的血郎了」；耶和華放了摩西之後，她又說「你因割禮就是血郎了」。這稱呼在聖經裡只出現在這兩節，沒有平行經文可以參照，又緊貼著「耶和華想要殺他」的危急場面與割禮的動作，因而成為出埃及記中最集中的短語解經難題。GT《丁道爾聖經註釋》說得最直白：「這話原來的背景和確實意義已不可考。」GT《串珠聖經註釋》同樣認為「原來意義已失，只能推測它是與割禮有關」。

## 按書卷累積

### 出埃及記
<!-- accumulation:出埃及記:4:start -->
#### [[02 出埃及記/第4章|第4章]]
- 本章重點：v25西坡拉割下陽皮後說「你真是我的血郎了」；v26耶和華放過摩西後，她又說「你因割禮就是血郎了」——第二次把「血郎」與割禮直接綁在一起。各家的推測分歧很大：CT 讀作歡喜的宣告（丈夫藉血脫離了被神擊殺的危機），KC 讀出不情願的語氣（她雖然不願意，仍作了這流血的舉動來救丈夫，就這樣把他當作新郎「換」了回來），GT《中文聖經註釋》從婚俗解釋（埃及人和亞拉伯人都有在結婚前行割禮的習俗，男人在割禮期間被稱為血郎），GT《舊約背景註釋》則引近年研究從岳家與庇護的角度解釋。
- 與本章關聯：GT 李道生《舊約聖經問題總解》指出「郎」字的原文與創19:12、14的「女婿」同字，中文有親戚的意思；呂振中譯本作「出血新郎」，英文聖經作 A Bloody Husband（血的丈夫）。GT 倪柝聲《聖經問答》把第26節看作第25節的自註：「因割禮而染血，故為血郎。」GT《啟導本聖經腳註》記下一種意譯：「你是我用割禮的血換來的丈夫。」CT 則把它連到逾越節——她承認流血的救贖，正如塗血在門楣和門框上拯救了全家的人一樣（12:21-23）。

## 主題發展

### 各家的推測

| 來源 | 對「血郎」的解釋 |
|---|---|
| CT | 「血郎」原文是「血的新郎」——她欣然歡樂地宣告，丈夫藉血脫離了被神擊殺的危機；並承認流血的救贖，正如逾越節塗血救全家（12:21-23） |
| KC | 她「雖然不願意」，仍作了這流血的舉動來救丈夫，藉這儀式把丈夫當作新郎「換」了回來；KC 也直說她這話究竟何意「並不很清楚」 |
| GT《中文聖經註釋》 | 埃及人與亞拉伯人（米甸是亞拉伯地區的一部分）都有在結婚前行割禮的習俗，男人在割禮期間被稱為「血郎」——快要結婚的新郎；西坡拉用這話表明摩西也（藉代替）行了割禮 |
| GT《舊約背景註釋》 | 引一份近年研究：割禮在很多文化中「是由男子的岳家執行，並且能夠將家庭的保護延伸，包括該男子及其子女」；若米甸也有此習俗，此舉就是把摩西在米甸所受的庇護延伸過來 |
| GT 李道生 | 「郎」與創19:12、14「女婿」同字；呂振中作「出血新郎」，英文作 A Bloody Husband |
| GT 倪柝聲 | 「因割禮而染血，故為血郎」 |
| GT《丁道爾》 | 背景與確實意義已不可考；後世用這話稱呼施割禮者，「可能不過是後期的發展」 |
| BH | 「『血的新郎』一語反映立約關係的代價——那往往牽涉犧牲與流血」；血「表明潔淨與分別為聖」，而西坡拉是米甸人，這句話也顯出「文化習俗與神的命令之間的張力」 |

### 爭議的重心不在字義

GT《丁道爾聖經註釋》引戴維斯的話，把這段的重點拉回來：「本段的要點是割禮的必要性，而非『何時』或『向何人』施行。」這正是各家雖然對「血郎」眾說紛紜、卻在另一件事上完全一致的地方——事件的起因是摩西沒有給兒子行割禮，事件的了結是割禮補行之後「耶和華才放了他」。

BH 另注意到這個動作的方向：「有學者認為『腳』是生殖器的委婉說法」，因此把陽皮觸在摩西身上「可能代表西坡拉的代求，藉著滿足立約的要求，使神的忿怒離開摩西」。GT《舊約背景註釋》另指出一條把這段接到後文的線索：從以色列人的角度看，第25節的塗血在逾越節的儀式中再次出現（12:7、44-48），保護人不被滅命的天使所殺。
