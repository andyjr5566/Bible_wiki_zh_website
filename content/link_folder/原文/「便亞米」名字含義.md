# 「便亞米」名字含義

## 定義

「便亞米」是羅得小女兒所生之子的名字，也是亞捫人的祖名。希伯來語通常解作「我族人之子」或「我親屬之子」；部分註釋依出生情境譯作「我父之子」。

## 主題發展

創19:38把便亞米稱為「現今亞捫人的始祖」；「亞捫」這個族名與便亞米名字中的 *ammi*（我的族人／親屬）形成關聯。

不同中文註釋有「我民之子」、「我父之子」甚至其他譯法。較穩妥的做法是保留語詞本身的親族含義，再說明敘事如何把它放在父女所生後裔的背景中。

### 四家的譯法排開來

| 來源 | 所給譯法 |
|---|---|
| CT | 「我父之子」、「我民之子」（並列兩義） |
| GT《啟導本聖經創世記註釋》 | 「我父之子」 |
| GT《創世記雷氏研讀本》 | 「我民之子」，並解作孩子的父親和母親都是同一家人 |
| GT 李道生《舊約聖經問題總解》 | 「我民之子」 |
| GT《串珠聖經註釋》 | 「我血流的兒子」 |
| BH | "son of my people" |

多數落在 *ammi*（我的族人／親屬）這條線上。雷氏的注解說明了為什麼這個一般性的詞在本處會刺耳：如果父母本來就是同一家人，「我民之子」這句話就不再只是族屬宣告。串珠的「我血流的兒子」是明顯的外圍讀法，本條目記下但不採為主要義。

### 與「摩押」的分工

串珠把兩個名字放在一起下結論：「二名都表明這兩個兒是出自父親羅得。」GT《聖經精讀本──創世記註解》說得更直接——摩押（「由於父親」）和亞捫（「我父親的兒子」）這兩個名字表示近親相奸，「等於把父親的恥辱永留後世」。詩83:8 稱兩族為「羅得子孫」，正沿用同一條線。

需要與族名區分開：李道生記「亞捫」一名本身的意思是「先天的」，CT 給的是「含糊的，先天的，忠誠的」——那是族名的字義，與便亞米這個人名的構詞不是同一件事。
