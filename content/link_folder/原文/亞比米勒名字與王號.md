# 亞比米勒名字與王號

## 定義

「亞比米勒」（Abimelech）通常分析為「我父是王」或「王是父」。創世記在亞伯拉罕時代與以撒時代都記載基拉耳王亞比米勒，因此一些註釋把它視為非利士王的王號，類似「法老」；也可能是不同君王共用的個人名。

## 按書卷累積

### 創世記

<!-- accumulation:創世記:20:start -->
#### [[01 創世記/第20章|第20章]]
- 本章重點：亞比米勒（אֲבִימֶלֶךְ，H40G）是基拉耳王，因誤信撒拉未婚而把她取去，後受神警告、歸還撒拉並求得亞伯拉罕代禱。
- 原文構詞：由 אָב（*av*，H1，父）與 מֶלֶךְ（*melekh*，H4428G，王）組成，字面意為「我父是王／王的父親」。
- 與本章關聯：名字意義本身不決定他是王號；王號說主要來自同名君王在創20、26章重複出現。
- 來源：CT, GT, BH, STEP Bible

## 主題發展

士師記9章另有基甸之子亞比米勒，顯示這個形式確實也能作個人名字。創20章與26章的君王是否同一人、世襲王號或不同同名者，單憑名字不能定論。

### 各家給的字義

| 來源 | 所給字義 |
|---|---|
| CT | 「王的父親」 |
| GT《啟導本聖經創世記註釋》 | 「王（神）是我的父」 |
| GT《串珠聖經註釋》 | 「我的父是王」 |
| GT 李道生《舊約聖經問題總解》 | 「王的父親」 |
| BH | "my father is king" |

分歧在於哪一半作主詞。中文來源分成「王是我父」與「王的父親」兩路，BH 取前者。構詞上兩種切分都可行，本條目並列而不裁決。

### 王號說的證據與限度

丁良才、GT《啟導本》與《串珠聖經註釋》都把它視為基拉耳王的尊號，並以**法老**、**凱撒**為類比——同一個稱謂由歷代君王沿用，不指某一個人。支持這個讀法的是創20 與創26:1 的王同名，而兩者相隔一代以上；創21:22 與26:26 中亞比米勒身邊都有一位名叫非各的軍長，也常被引為同一王號傳承的旁證。

限度在於：士9 的基甸之子亞比米勒是明確的個人名字，撒上21 標題所稱的亞比米勒（即迦特王亞吉）又顯示這個稱謂可跨族群使用。因此「亞比米勒必定是王號」與「創20 和創26 必定是同一人」都超出資料所能支持的範圍。

### 與「法老」類比的一項差異

值得留意的是，聖經在稱呼埃及王時幾乎只用「法老」而不給個人名，但在基拉耳這一線，經文除了亞比米勒之外還記下臣屬的名字（非各）。這使「亞比米勒」比「法老」更接近一個可能兼具王號與人名雙重身分的稱謂。
