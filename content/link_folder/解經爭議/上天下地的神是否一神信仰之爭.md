# 上天下地的神是否一神信仰之爭

## 定義

書2:11 喇合對探子說：「耶和華─你們的神本是上天下地的神。」STEP 顯示原文是 'E.lo.Him ba./sha.Ma.yim mi./Ma.'al ve./'al- ha./'A.retz mi./Ta.chat（H430G 加 H8064 加 H4605 加 H5921A 加 H776G 加 H8478G），字面是在上面的諸天、在下面的地上都是神。

這句話該讀成一個迦南女子的一神信仰告白，還是讀成她對一位強大神明的求助，四套來源分成兩邊。

| 來源 | 立場 |
|---|---|
| CT | 靈意註解直接寫「罪人相信獨一的真神」 |
| GT《聖經精讀本──約書亞記註解》 | 喇合的神觀大大超越了迦南人，她承認以色列的神是廣大無邊的最高之神 |
| KC | 她相信耶和華本身，不只把祂當作某一族的神，而是天地的神 |
| BH | 她指名以色列的立約之神，承認祂在迦南諸假神之上；這個告白標誌著決定性地從她那座城的偶像轉向永生神 |
| GT《舊約背景註釋》（華爾頓） | 她的話遠非一神信仰的表示 |

### 兩邊各自的理由

GT《聖經精讀本》先分出一條線：不僅是希伯來人，連迦南人都擁有對神的知識；然而多數迦南人認為耶和華只是諸神之一、只是希伯來民族的神，因此他們的神觀與希伯來人的獨一神觀相距甚遠。它接著說喇合的神觀大大超越了這一點。KC 指出她這句話與摩西在申4:39 要以色列人存記在心的話極其相似。BH 也把它接到申4:39。

華爾頓的說明最詳細，方向卻相反。他說在古代近東的宗教思想中，這是將耶和華歸入宇宙性神明一類，以祂為具有大能的國家守護神；迦南人所聽聞的報告顯示祂能夠影響天氣、河海、疾病和動物世界。他接著列出她沒有做的事：她沒有宣稱放棄舊神，或表達摒棄的意願，也沒有向耶和華表示效忠，只是向祂求助；她對於律法的要求似乎一無所知。他的結論是，她的話顯示她並沒有擺脫多神觀點的桎梏，她只是有認識權能的慧眼而已。GT《約書亞記研經資料》轉述了同一段，並把語氣調成「可能並非對一神信仰的表白，似乎只是向祂求助」。

### 沒有爭議的部分

四套來源對兩件事沒有分歧。第一，她確實指名耶和華，並且用了「上天下地」這個涵蓋全部空間的說法。第二，新約兩處把她列為信心的例子（來11:31、雅2:25），這一點連華爾頓的背景說明也沒有推翻——他處理的是這句話在當時宗教語言中的位置，不是她最終的歸屬。

### 約書亞記

#### [[06 約書亞記/第2章|第2章]]
- 本章重點：第11節「耶和華─你們的神本是上天下地的神」，STEP 為 'E.lo.Him ba./sha.Ma.yim mi./Ma.'al ve./'al- ha./'A.retz mi./Ta.chat（H430G、H8064、H4605、H776G、H8478G）。CT 靈意註解寫「罪人相信獨一的真神」；GT《聖經精讀本》說喇合的神觀大大超越了迦南人，她承認以色列的神是廣大無邊的最高之神；KC 說她相信耶和華不只是某一族的神，而是天地的神，並把這話接到申4:39；BH 說她承認祂在迦南諸假神之上，是決定性地從偶像轉向永生神。GT《舊約背景註釋》的華爾頓則說這是把耶和華歸入宇宙性神明一類，她沒有宣稱放棄舊神、沒有表示效忠，只是向祂求助，並沒有擺脫多神觀點的桎梏；GT《研經資料》轉述同一段並調成「可能並非對一神信仰的表白」。
- 與本章關聯：這句話是本章唯一一次由迦南人口中說出的神學宣告，也是探子回去報告的根據。分歧的位置很集中：同一句話，四家讀成信仰的轉向，一份背景註釋讀成古代近東常見的對強大神明的敬畏。
