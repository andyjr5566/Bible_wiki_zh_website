# 申命記34章的作者

## 定義

申命記最後一章記的是摩西的死與葬，還有他死後才寫得出來的一句話——「只是到今日沒有人知道他的墳墓」（申34:6）。這一章顯然不可能出自摩西自己，四套註釋都處理了這個問題，而且各自給了不同分量的回答。

### 四家的說法

| 來源 | 說法 |
|---|---|
| CT | 由申34:1至3 的敘述可知，本章是在摩西死後、約書亞率領以色列人進占迦南地全境並分配各支派的產業之後，才補寫的跋文 |
| GT《聖經精讀本──申命記註解》 | 兩種可能並列：摩西以預示性的洞察力記錄自己死後的事，或由約書亞、以利亞撒在他去世後附加 |
| GT《雷氏研讀本》 | 這一章不可能出自摩西手筆，但這絕不能否定本書其餘部分是摩西所寫的 |
| KC | 這最後一章不是摩西寫的，約書亞應該就是被神使用來寫這段的人 |

### CT 的內證

CT 的理由是文本本身給的。他注意到申34:2 提到的地名——拿弗他利、以法蓮、瑪拿西、猶大——都是約書亞分地以後各支派的名字；摩西說話的當下，這些支派還沒有各自的地。由此他推斷這一章是分地之後補寫的跋文。

### GT 精讀本的兩條路

GT《聖經精讀本──申命記註解》把問題攤開來說：關於記錄摩西的死亡及其後事的本章作者，眾人議論紛紜。它給的第一條路是摩西自己——因摩西是特殊的先知（申34:10、民12:6~8），故有可能以預示性的洞察力記錄了自己死後的事。第二條路是希伯來文學的慣例：在偉大故人的最後一部作品中附加他的死亡記事，故有可能在摩西去世後由繼承人約書亞或大祭司以利亞撒附加記錄。

它自己不選邊，只加了一句收束：不論本章是由誰記錄的，必定是因神的感動，記錄得毫無差錯。

### 一段完整的護教回應

GT 另外收了艾基斯《舊約聖經難題彙編》一整段回應，處理的正是這個質疑：申命記既然記載摩西被葬在人們不知曉的墳墓裡，聖經的首五卷書又怎會是摩西的作品。

艾基斯的答法是舉一個現代出版的實例：羅蘭德富的遺著在正文前由甘仁補寫了一段前言，開頭就說作者沒能看見這本書出版；他指出其他卓越學者的最後一部作品，結尾部份通常也都有一段沒有指明作者的訃文。他的結論是，沒有有責任感的讀者會因著這樣一段短短的訃文，就否認原作者的著作地位。

KC 從另一頭補一句實際的觀察：百姓中大概沒有誰像約書亞那樣清楚摩西是何等不凡的人物，因為約書亞近距離跟了他很久很久。

### 四家的共識與分歧

共識是：這一章的內容不影響全卷其餘部分的作者歸屬。分歧只在誰動的筆——約書亞、以利亞撒，還是摩西自己憑先知的洞察。沒有一家宣稱有定論。

## 按書卷累積

### 申命記

#### [[05 申命記/第34章|第34章]]
- 本章重點：本章記摩西的死與葬，還有「只是到今日沒有人知道他的墳墓」這句他死後才寫得出來的話，因此作者是誰成為必須交代的問題。CT 在第1節的備註說：由1~3節的敘述可知，本章是在摩西死後、約書亞率領以色列人進占迦南地全境並分配各支派的產業之後，才補寫的跋文。GT《聖經精讀本──申命記註解》把兩種可能並列：一是因摩西是特殊的先知（10節、民12:6~8），故有可能以預示性的洞察力記錄了自己死後的事；二是希伯來文學的慣例是在偉大故人的最後一部作品中附加他的死亡記事，故有可能由繼承人約書亞或大祭司以利亞撒附加記錄；它並說不論本章是由誰記錄的，必定是因神的感動、記錄得毫無差錯。GT《雷氏研讀本》說本章有關摩西之死的記載不可能出自摩西手筆，然而這絕不能否定本書其餘部分是摩西所寫的。GT 另收艾基斯《舊約聖經難題彙編》一整段回應，用羅蘭德富遺著由甘仁補寫前言的實例作類比，說沒有有責任感的讀者會因著一段短短訃文便否認原作者的著作地位。KC 說這最後一章不是摩西寫的，約書亞應該就是被神使用來寫這段的人。
- 與本章關聯：這是全卷申命記唯一一處四套註釋都得先交代作者問題才能往下註的地方。CT 的理由取自文本本身——第2節的支派地名要到約書亞分地之後才成立；其餘三家則從文體慣例與默示原則來處理。
