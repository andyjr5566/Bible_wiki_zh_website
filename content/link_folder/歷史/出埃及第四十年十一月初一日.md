# 出埃及第四十年十一月初一日

## 定義

申命記1:3 給了一個精確到日的時間戳。GT《啟導本》指出：「這是本書唯一記載的日期。」

**這一天離什麼有多遠。**

| 事件 | 時間 |
|---|---|
| 摩西講這番話 | 出埃及第四十年十一月初一日 |
| 摩西過世 | 約一個月後（CT） |
| 為摩西舉哀 | 三十天（GT《啟導本》，申三十四8） |
| 百姓進迦南 | 約兩個月後（GT《啟導本》，比較書四19） |

換句話說，整卷申命記的內容壓縮在摩西生命最後一個多月裡。

**四十年怎麼分配。** GT《雷氏研讀本》拆得最清楚：「其中兩年停留在西乃山和前往加低斯巴尼亞，其餘三十八年飄流在曠野（二14）。」GT《啟導本》的算法相同：四十年從出埃及之日算起，包含在西奈山下的日子、去加低斯的旅程，和之後的三十八年。

**「十一月」是哪個月。** GT《雷氏研讀本》與《啟導本》都說相當於今天的一月至二月間。BH 指出希伯來曆這個月稱為 Shevat。

**紀年方式。** GT《啟導本》點出這裡用的是以出埃及為元年的紀年法：「像今天用基督降生來開始紀元一樣，以色列人用出埃及的那一年作為紀元之始，現在已是第四十年。」

**這一節的另一半。** 「摩西照耶和華藉著他所吩咐以色列人的話都曉諭他們」——CT 說這就是重申神所頒佈律法命令的要點，也就是本書的內容，故稱《申命記》。BH 強調這句話把訊息的來源指向神而非摩西本人。

## 按書卷累積

### 申命記

<!-- accumulation:申命記:1:start -->
#### [[05 申命記/第1章|第1章]]
- 本章重點：第3節「出埃及第四十年十一月初一日」。GT《啟導本》：這是本書唯一記載的日期，兩個月後百姓進迦南，其間用了30天為摩西舉哀；CT：就是摩西死前大約一個月。GT《雷氏研讀本》把四十年拆成「兩年停留在西乃山和前往加低斯巴尼亞，其餘三十八年飄流在曠野」。BH 指出希伯來曆這個月稱為 Shevat。
- 與本章關聯：這個日期把整卷申命記定位成臨終前一個多月的講話。第1-2節先給地點與距離，第3節給時間，第4節給剛發生的戰事，第5節才開始講律法——開場五節是一組完整的時空定位。
