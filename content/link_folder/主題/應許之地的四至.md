# 應許之地的四至

## 定義

申命記1:7 神叫以色列人起行時，一口氣點出要去的整片範圍：「亞拉巴、山地、高原、南地，沿海一帶迦南人的地，並利巴嫩山又到伯拉大河。」

**這是一份分區清單。** CT 逐項給了對應：

| 經文用詞 | CT 的說明 |
|---|---|
| 亞拉巴 | 約但河流域從加利利海到死海南端以迄阿卡巴灣的河谷 |
| 山地 | 約但河西，迦南地加利利以南的中部地區，綿延不斷的高山山脈 |
| 高原 | 迦南地中部「山地」以南、西面與非利士地鄰接的丘陵地帶 |
| 南地 | 迦南地境內的南部，別是巴以南一片貧瘠乾地 |
| 沿海一帶迦南人的地 | 迦南地的北部地區 |
| 利巴嫩山 | 迦南地的最北部，與利巴嫩接壤 |
| 伯拉大河 | 即今幼發拉底河，是神所應許之地的北方界線 |

GT《啟導本》指出這段是輪廓，詳細描寫載於民數記34:2-12。

**和給列祖的應許對得上。** GT《啟導本》：「本節所描寫的迦南應許地範圍與神當年應許亞伯拉罕、以撒和雅各的符合（創十五18；二十六2～4；三十五11～12）。大衛和所羅門王時代，已見到這塊擴展的版圖。」BH 也把伯拉大河接回亞伯拉罕之約。

**原文的兩個地理專名。** STEP 原文資料顯示，「高原」是 u./va./she.fe.Lah（H8219），「南地」是 u./va./Ne.gev（H5045G）；「沿海一帶」是 u./ve./Chof hai./Yam（H2348 choph「coast」＋H3220G yam「sea」），指的是海岸，不是紅海。「伯拉大河」是 ne.har- pe.Rat（H5104H na.har「river」＋H6578）。

**KC 的觀察。** KC 指出神把這地呈現在他們面前時是連同它的遼闊一起給的，仇敵此刻仍住在那裡，但神已經把地給了祂的百姓；並說「地」這個字在申命記出現約 160 次。

## 主題發展

**兩章用兩種方式畫同一片地。** 申1:7 神叫以色列人起行時點的是地形——亞拉巴、山地、高原、南地、沿海一帶迦南人的地，並利巴嫩山又到伯拉大河，那是一份分區清單，說的是裡面有什麼。申11:24 換成方向：四個地標各守一面，說的是邊在哪裡。前者讓人知道要走進什麼樣的地方，後者讓人知道走到哪裡為止。

**兩處共用的那一端最遠，也最晚兌現。** 伯拉大河在申1:7 是清單的終點，在申11:24 是東界。GT《啟導本聖經申命記註釋》說「到所羅門時代，這廣大土地才為以色列人所取得」，BH 也說東界要到大衛與所羅門在位時才部分實現（王上4:21）。同一條河在兩章都被說出來，中間隔著好幾百年才走到。

**四至的功能也跟著換了。** 申1 的清單接在起行的命令後面，是行程的目標；申11 的四界接在「凡你們腳掌所踏之地都必歸你們」後面，是應許的範圍。一個要人動身，一個告訴人動身之後能走多遠。
