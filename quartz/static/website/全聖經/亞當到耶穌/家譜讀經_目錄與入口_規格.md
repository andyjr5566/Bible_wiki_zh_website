# 規格：「從亞當到耶穌」的目錄與入口

第三階段完成後，使用者發現名冊、城牆、從大衛到所羅門這些畫面「沒有入口」：只能從讀經時的小下拉選單或直接打網址進去。2026-10-16 與使用者逐項定案如下。

## 定案

1. **目錄分頁**：和「家譜樹」「大衛立的職位」等並排的一個分頁，放在**最左邊**；打開網站的首頁照舊是家譜樹。
   - 列出讀經路線的全部段落，照現有分組（創世記、出埃及記到撒母耳記、歷代志上的族譜、大衛立的職位、列王、歸回、新約）。
   - 每一段：標題、經文範圍、畫面圖示（家譜樹／職位圖／名冊／城牆，段內會換畫面的照主要畫面）、**一句介紹**（Opus 照經文寫，白話、不加評論，寫在 `讀經路線.yaml` 的 `intro`）。
   - 點一段 → 從那一段的第一節開始帶你讀（和讀經時選段落一樣）。
   - 讀經時經文欄上方的段落下拉選單照舊保留。
2. **「歸回的名單」分頁**：六份名單各一張卡（拉 2、拉 8、拉 10、尼 3、尼 7、尼 10）：標題、經文範圍、一句介紹、名冊或城牆的縮圖；點卡片就從那一段開始帶你讀。
3. **導覽最後加兩站**：
   - 倒數第二站「一起讀經」：介紹帶你讀經能做什麼（播放、暫停、變速、朗讀、讀到誰亮誰、畫面跟著換成職位圖／名冊／城牆、偷看家譜樹、回到朗讀處）。
   - 最後一站「目錄」：打開目錄分頁，請讀者挑一段開始讀。
   - 原本最後一站的「想一節一節讀歷代志上的家譜嗎？」邀請移除（範圍早已不只歷代志上）。

## 規則

- 讀者看得到的字照共同規則：不寫檔名、欄位名、內部用語；「」只放逐字經文；強調用『』；女性主詞用「他」。
- 介紹句建置時檢查：每一段都要有、不可含「」、長度 60 字以內。
- 手機 390px 可用、亮暗色都要好看、不准 `scrollIntoView`。
- 完工：建置、閘門、vitest 全過；截圖（目錄、歸回的名單、導覽最後兩站；桌機亮、暗、手機）；改完重建 dist；一個 commit，不 push、不部署。
