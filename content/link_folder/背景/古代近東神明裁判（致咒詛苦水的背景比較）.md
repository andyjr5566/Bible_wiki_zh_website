# 古代近東神明裁判（致咒詛苦水的背景比較）

## 定義

GT《舊約聖經背景註釋》為民數記五章23-24節寫了一則專門的背景，說明「神明裁判」在古代近東是什麼，以及本章與它們差在哪裡。

它先給定義：神明裁判是「透過某種通常會對被告構成危險的機制，把他放在神的手中。神明若是插手保護被告得免受害，就是宣告被告清白的判決」。接著指出古代近東大部分神明裁判「都牽涉到水、火、毒藥等危險」，而暴露在這些危險中的被告，「實質上在神明未曾施行作為表明其清白之前，是在假定為有罪的處境底下」。

然後是關鍵的對比：「相對而言，本段不施法術，也沒有牽涉危險，只是製造供神作出回應的環境而已。如此女子在此是假定為清白，直至（受神操縱的）環境證明實際情況相反為止。」

| 項目 | 古代近東多數神明裁判 | 民數記第五章 |
|---|---|---|
| 機制 | 水、火、毒藥等危險 | 聖水加塵土，本身無害 |
| 舉證起點 | 假定有罪，待神證明清白 | 假定清白，待環境證明相反 |
| 是否施法術 | 是 | 否 |

同一份註釋另舉兩則平行文獻：漢摩拉比法律包括類似案例，女子在河中接受神明裁判以斷定清白；馬里（美索不達米亞西北部）文獻則提到一宗案例，要求神明喝飲混和了城門泥土的水，「此舉對神明構成約束，要他們履行保護該城的誓言」——與本章「聖水加聖所地上塵土」的配方形式相近。

## 主題發展

同一條對比在華人註釋裡也有人用不同的材料講過。GT 李道生《舊約聖經問題總解》列了三種古代異教的試驗法：命犯人手拿一斤多重的熱鐵、或腳踏燒紅的犁頭、或把手放入滾水熱油、或使人喝紅而有毒的水；他的結論是那些「乃出於人的種種惡毒苦刑之法，非人身體所能忍受得了，有害無益」，而「神所吩咐使用的水，無害於人」。GT 丁良才在第27節也列了幾乎相同的三種方法，並下一句判語：「熱鐵、滾水、毒藥，都是害人之物。但神所吩咐的水，本不害人。」

把幾家並排來看，這場儀式與周圍文化最大的差別不在有沒有儀式，而在兩件事上：水本身不具傷害力，以及舉證的起點站在被告這一邊。
