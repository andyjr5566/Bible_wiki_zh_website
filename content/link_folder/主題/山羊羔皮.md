# 山羊羔皮

## 定義

利百加用山羊羔皮包裹雅各的手和頸項光滑處，以模仿以掃渾身有毛的外觀，是雅各騙取以撒祝福的偽裝工具。

- 利百加用山羊羔皮包在雅各的手上和頸項光滑處（創二十七16）
- 亞蘭國山羊羔的毛很長而且細（GT）
- 以撒有百年牧羊經驗，卻分不出羊皮和人的手（CT）
- 山羊羔皮豫表基督的救贖——人得著屬靈福氣不是靠自己的價值，而是靠基督（CT 靈意註解）
- 日後雅各自己被拉班用同樣方式欺騙（創三十一31-34）

## 主題發展

### 這個道具為什麼行得通

GT 丁良才《創世紀註釋》提供了一項容易被當成誇張的細節：亞蘭國山羊羔的毛「很長而且細」，後來羅馬國的禿子多用這種羊皮當作假髮。換句話說，用山羊羔皮冒充人的體毛在當時並非異想天開。GT《聖經精讀本──創世記註解》也指出雅各的擔心是必然的——他與以掃的皮膚差別明顯，就算能瞞過父親昏花的視覺，也騙不過觸覺；羊皮正是為此而備。

### 同樣的道具日後回到雅各身上

KC 指出一個對稱：這場欺騙用的是兩隻山羊羔和牠們的皮，而日後雅各自己也將被同樣的方式欺騙——他的兒子們用公山羊的血染了約瑟的彩衣來騙他（創三七31-34）。用山羊行騙的人，後來被人用山羊所騙。

### 靈意讀法與它的界線

CT 從這裡發展出一組豫表：雅各獲得父親的祝福，「不是靠自己的皮膚，而是靠他母親為他包上的山羊羔皮」，因此豫表人得著屬靈的福氣不是依靠自己的價值，而是靠基督的救贖；同章第9節用現成的山羊羔代替需要花費時間勞力才能獵得的野味，也被讀成「不在乎自己的掙扎努力，乃在乎神的恩典」。BH 也把獸皮遮蓋與後來的獻祭制度相連。

這是新約回望所建立的讀法。就本章敘事本身而言，羊皮是一件欺騙的道具——經文接下來記的是家庭破裂與二十年的逃亡。

- 山羊羔皮代表虛假的遮蓋（與基督真正的義袍對比）
- 雅各日後被拉班欺騙（創三十一），經歷同樣的痛苦
