# 假意悔改與冒死擅自作戰

## 定義

「假意悔改與冒死擅自作戰」指民數記第十四章39至45節中記錄，當以色列人於加低斯聽獲神審判必須在曠野磨亡漂蕩四十載之嚴詞告諭後，全民眾雖然瞬間深受打擊「甚悲哀」，並於明日清晨大聲高唱認責之言說「我們在這裡，我們有罪了；情願上耶和華所應許的地方去」（40節），最終卻釀成大逆與全軍受痛挫於山崗的震撼歷史事變。
靈修學與正統聖經評鑑深指：這場看似願意走上起初主令道阻的晨動出巡，本質上絕非出自折服上帝管教、心醉痛惜真理與尊聖君令之真實降順；而是出自一種懼怕沙漠苦果、妄想運用私我的狂悍武勇來衝潰聖裁鐵案的表裝「偽真反叛」（Counterfeit Obedience / Presumptuous Rebellion）。因真正的順服當緊依神選定的時刻及方式——神既命他們「明天你們要轉回，從紅海的路往曠野去」（25節），再去硬爭「我們進出應許之野」就落得成了更沉厚強烈的傲氣不馴與越牆抗罰。摩西嚴告彼等說：「你們為何違背耶和華的命令呢？這事不能順利了。不要上去；因為耶和華不在你們中間」（41-42節）。然而百姓依然任情宣武「擅敢上山頂去」，卒在毫無約櫃護主及天先知督導的情況裡，深陷仇家無期衝撲的屠宰厄境中，留任下「自我意志裝飾為奉神意氣」定致傾倒滅頂之千古史錄。
