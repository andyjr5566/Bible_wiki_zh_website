# 罪的後果（創世記3章）

## 定義

創世記 3 章記載了犯罪後的六大後果：失去權柄、失去快樂、失去良善、失去聖潔、失去平安、失去生命。

## 按書卷累積

### 創世記

<!-- accumulation:創世記:3:start -->
#### [[01 創世記/第3章|第3章]]
- 本章重點：犯罪後立刻出現羞恥、害怕、躲避神、推諉責任，並帶來生產苦楚、婚姻張力、土地咒詛、勞苦與死亡。
- 與本章關聯：本章將罪的後果擴展到人與神、自己、配偶、土地和生命樹通路的全部關係。

## 主題發展

### 神學意義／研讀意義

- 犯罪的六大後果：
  1. **失去權柄**（一28）
  2. **失去快樂**（16-20，24節）
  3. **失去良善**（傳七29；創四章；六5-8）
  4. **失去聖潔**（7節；傳七29；西三10；弗四24）
  5. **失去平安**（8-15節）
  6. **失去生命**（19節；羅五12；六23；雅一15）
- 人犯罪使**萬物也受了連累**（羅八19-23），因亞當是舊造的元首
- 「赤身露體」不再是純潔的象徵，而成為羞恥的記號
- 躲避神＝罪使人與神隔絕
- 推諉責任＝罪人的通病

罪的後果是創世記 3 章的核心信息之一。人因犯罪而失去與神的同在，也失去對萬物的權柄。
