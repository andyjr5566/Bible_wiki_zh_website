# R16 贖罪日完整教學路徑

R16 把贖罪日從單一入口說明拆成十四個可暫停、回退與重讀的 step。程序固定由 `atonement-entry` 觸發，角色與服裝依每一步資料切換，讀者使用研究觀察視角，不取得自由穿越幔子的遊戲權限。

## 路徑分段

1. 大祭司預備細麻布聖服，接著處理兩隻公山羊抽籤與為自己和本家獻公牛。
2. 大祭司帶香爐、火炭與香進入幔內，依序顯示公牛血與公山羊血的文字標記。
3. `atonement-empty-room` 只留下「會幕裡不可有人」的研究狀態，其他角色不顯示。
4. 程序回到燔祭壇潔淨、活羊交接與曠野路線，再由所派之人負責營外段落。
5. 大祭司在 `atonement-change-clothes` 切換至 `post-atonement-garments`，完成自己的燔祭與百姓燔祭，最後以營外焚燒與洗身進營收束。

香煙只在贖罪日帶香步驟啟用，血點使用文字與克制標記；沒有新增血量、煙雲形狀、距離、工具或寫實動作。所有位置、角色、服裝、經文與 unresolved 都保留在同一份 step snapshot，回退時不依賴向前播放的副作用。
