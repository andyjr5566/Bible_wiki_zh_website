# R02 角色與區域權限矩陣

本矩陣是程序資料的約束，不是允許讀者扮演古人自由漫遊的遊戲規則。教學相機可以使用 `study-observer` 觀看幔內，畫面必須明示這是研究視角。角色模型的臉孔、身高與衣服外觀不能由本表推導。

## 角色轉換與排他規則

1. 每個 step 的 `actorRole` 是單一主要職責；需要交接時拆成兩步，並在 `nextStepIds` 明示。
2. `most-holy-place` 的贖罪日 step 進入排他狀態，隱藏其他角色；退出後才恢復外院／聖所的教學觀察。
3. `offering-person` 在利1牛／羊分支按手與宰殺，不因此取得 priest 的灑血、放火或聖所權限；鳥分支由祭司處理利1:15–17 的動作。
4. `levite` 的搬運必先由祭司遮蓋並交付（民4），不以目前可見模型的碰撞或路徑推翻來源權限。
5. `study-observer` 的 unrestricted camera 只作用於瀏覽器視角；UI 必須顯示「研究視角」，不能用「可進入」描述角色禮儀權限。
