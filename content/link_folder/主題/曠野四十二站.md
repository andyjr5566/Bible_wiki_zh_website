# 曠野四十二站

## 定義

民數記33:1-49 是一份清單：以色列人從埃及蘭塞出發，一站一站走到摩押平原，全部列出來。這份清單本身就是民數記全書的骨架。

**分段的兩種方式。** CT 的內容綱要分成四段：從出埃及到西乃山共十二站（1-15節）、從西乃山到加低斯共二十一站（16-36節）、從加低斯到約但河東岸共九站（37-49節）、過約但河前的吩咐（50-56節）。

GT《民數記串珠聖經註釋》的分法完全不同——它把四十二站排成六程、每程七站，並指出「四十二為七的倍數」。它列出的對應有三組：

| 串珠指出的對應 | 內容 |
|---|---|
| 第四、五、六程的第六站 | 亞倫和摩西死的地方 |
| 第一程與第五程的第五站 | 神供水的地方（瑪拉與加低斯） |
| 第一站、第七站、第十二站 | 出埃及、過紅海、西乃山頒律法 |

串珠的結論是：「這些都不似巧合，而是在數字上有象徵的意義。」它並指出第一程與第二程各站發生的事完全類同——第一站與第八站都是神蹟奇事，第四站與第十一站都是爭戰得勝，第六站與第十三站都是供應水和食物。

**原文的公式是兩個動詞。** GT 串珠說：「『從 ...... 起行，安營在 ...... 』是此段的公式語，但每一次其實都有神的雲柱、火柱在帳幕上作指示（9:15-23）。」STEP 顯示這個公式在原文是固定的兩個動詞：na.sa（H5265，簡要詞典義 to set out）與 cha.nah（H2583，簡要詞典義 to camp），四十多次一字不改。

**CT 為每一站都給了名字字義與靈意。** 例如第一站蘭塞是「太陽之子」，CT 讀成脫離黑暗的權勢；第十三站基博羅哈他瓦是「貪慾之人的墳墓」，CT 讀成肉體的貪婪被神懲治。這種逐站解讀只有 CT 做，其他三套註釋都沒有。

**這份清單不完備。** GT《舊約聖經背景註釋》說：「但此表也略去了一些重要的地點（瑪撒、米利巴），表示它也非完備。」GT 串珠也列了他備拉、瑪他拿、拿哈列、巴末幾處沒有記進來的地方。

## 按書卷累積

### 民數記

<!-- accumulation:民數記:33:start -->
#### [[04 民數記/第33章|第33章]]
- 本章重點：第1-49節的四十二站行程表。CT 分成十二站、二十一站、九站三段；GT 串珠排成六程各七站，並指出三組數字上的對應。STEP 顯示每一站的公式在原文都是同兩個動詞 na.sa（H5265，to set out）與 cha.nah（H2583，to camp）。
- 與本章關聯：它是民數記全書的骨架：出埃及記12 章到民數記32 章之間發生的事，在這裡被壓縮成一串地名。同時它也是不完備的——幾處重要地點沒有列進來。
