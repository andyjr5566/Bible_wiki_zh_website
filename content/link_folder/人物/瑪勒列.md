# 瑪勒列

## 定義

創世記5章12-17節用 מַהֲלַלְאֵל（*Mahalalel*，H4111G）稱該南的兒子瑪勒列；他是雅列的父親，共活八百九十五歲。註釋進一步把名字解作「神的稱讚」（CT）、「神的讚美」（GT《丁道爾聖經註釋》），或「讚美神／蒙神賜福」（BH）。

### 與目前整理書卷的關聯

瑪勒列是塞特系第五代先祖。名字意思是「神的稱讚」，在屬靈歷程的解讀中代表：蒙神喜悅、蒙神稱讚。
