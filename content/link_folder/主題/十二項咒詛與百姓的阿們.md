# 十二項咒詛與百姓的阿們

## 定義

申命記第二十七章第14至26節：利未人向以色列眾人高聲宣告十二項咒詛，每宣告一項，百姓就回答一次阿們。

### 十二項是哪些

| 節 | 所咒詛的行為 |
| --- | --- |
| 15 | 製造並在暗中設立偶像 |
| 16 | 輕慢父母 |
| 17 | 挪移鄰舍地界 |
| 18 | 使瞎子走差路 |
| 19 | 向寄居的和孤兒寡婦屈枉正直 |
| 20 | 與繼母行淫 |
| 21 | 與獸淫合 |
| 22 | 與同父或同母的姊妹行淫 |
| 23 | 與岳母行淫 |
| 24 | 暗中殺人 |
| 25 | 受賄賂害死無辜之人 |
| 26 | 不堅守遵行這律法言語 |

CT 把這份清單的結構點出來：15~26節列出了十二條咒詛作為代表，原文每句都以「咒詛」開頭。STEP 證實了這一點——每一項的第一個字都是 'a.Rur（H779，簡要詞典義 a.rar: to curse，Qal 被動分詞），每一項的最後一個字都是 'a.Men（H543）。

### 前十一項有一個共同點

CT 指出：前十一項（15~25節）通常都是「暗中」進行的罪惡，第十二項（26節）泛指所有的罪惡。這提醒百姓，隱藏的罪雖然不容易被人發現，但耶和華是鑒察人心、試驗人肺腑的。STEP 顯示第15節與第24節都明寫了 ba./Sa.ter（H5643A，簡要詞典義 se.ter: secrecy）——在暗中。

GT《申命記雷氏研讀本》一句話說同一件事：神看見人「在暗中」所做的事。KC 的說法一致：即使不順從是暗中發生的（第15、24節），咒詛還是會擊中它的目標；沒有一樣罪會逃過公義的刑罰。

GT《申命記串珠聖經註釋》注意到這份清單的性質：咒詛一共有十二種，都是對個人的良心而發的；以色列民聚在一起，公開地裁定這些惡行的罪。GT《聖經精讀本──申命記註解》則把它讀成十誡的反面：可以說，這十二種咒詛只是悖論性地表現了十誡的精神，即愛神與愛人（太22:36~40）。

### 最後一項與前面十一項不同

第26節不指名任何一種行為：不堅守遵行這律法言語的，必受咒詛。CT 說它意指凡違背本章所列舉的律法的。GT《啟導本聖經申命記註釋》說本節應為以前所列應受咒詛的事的總結，凡不遵守本書所記一切教訓的人都在咒詛之下，並提醒「只是口裡說遵守律法是不夠的，必須在生活中實行出來」。

KC 說得更嚴：最後提到的這項咒詛（第26節）關乎律法的任何一項違犯，而不只是上面所提那些較為可怕的罪；凡不持守律法所說的一切的人都在咒詛之下（加3:10），沒有任何脫身條款。GT《申命記雷氏研讀本》指出保羅正是引述這一節（加三10），說明沒有人可以靠遵守律法而得到永生。

### 「阿們」是什麼意思

CT 給的解釋最短：『阿們』意思是「是的、誠心所願、實實在在」；百姓如此回應，表示要負起自己行為的責任。GT《申命記雷氏研讀本》從字源說：阿們直譯作堅定或保證，因而表示「願它堅定」。

GT《聖經精讀本──申命記註解》講得最完整：這個詞原是指「支持」或「信任」某一物件，後來發展到意指「實實在在是如此」，或者是「惟願如此成就」；它不僅支持、確認或承認某一宣告、讚美及禱文，還包含著要將那內容如實地適用在其生活中的決志。它並記下這個詞後來的去向——在新約時代，耶穌基督常用「阿們」來強調某一事實，使徒保羅主要用來作祝福與頌讚的結語，約翰啟示錄甚至用這句話來指耶穌基督（啟3:14）。

BH 對這聲回應的重點放在群體：全體百姓一起說阿們，表示同意並接受，反映的是整個群體共同承擔守約的責任。

CT 在末尾對這聲回應下了一個評語：招惹咒詛的內容是這樣具體，惹動咒詛的機會又是這樣大，但當利未人每一次宣告律法的時候，眾百姓都回應說阿們；這個回應實在是嚴肅，但又實在是非常的美，既承認了神所不能喜悅的事，也承認了神是義的。

- 本章重點：第14至26節列出十二項咒詛，每一項百姓都回應阿們。STEP：每一項都以 'a.Rur（H779 a.rar，Qal 被動分詞）開頭、以 'a.Men（H543）作結；第15節與第24節都明寫 ba./Sa.ter（H5643A se.ter: secrecy，在暗中）。CT 指出原文每句都以「咒詛」開頭、前十一項通常都是暗中進行的罪惡而第十二項泛指所有罪惡，並說阿們意思是「是的、誠心所願、實實在在」、表示要負起自己行為的責任；GT《雷氏》說神看見人在暗中所做的事、阿們直譯作堅定或保證，並指保羅引述第26節（加3:10）；GT《串珠》說十二種咒詛都是對個人的良心而發的，以色列民公開地裁定這些惡行的罪；GT《精讀本》說這十二種咒詛悖論性地表現了十誡的精神，並詳述阿們的字源與新約用法；GT《啟導本》說第26節是總結、只是口裡說遵守律法是不夠的；KC 說即使不順從是暗中發生的咒詛還是會擊中目標、第26節關乎律法的任何一項違犯且沒有脫身條款；BH 說全體回應阿們反映群體共同承擔守約的責任。
- 與本章關聯：這是全章篇幅最長的一段，也是整場儀式唯一有文字記下來的部分——祝福的內容一句都沒有寫。十二項裡有十一項針對具體行為，最後一項把整部律法收進來；而每一項的結尾都需要百姓自己開口，那聲阿們把宣告變成了自我承擔。
