# 遠方城的招降條例

## 定義

申命記第二十章第10至15節規定了以色列攻城的固定順序，而第15節把適用範圍講得很清楚：「離你甚遠的各城，不是這些國民的城，你都要這樣待他。」這套規則管的是迦南地以外的城，不是迦南七族的城。CT 在第10節底下直接加了備註：10~15節僅適用於迦南地以外的敵城(參15節)。KC 說的是同一件事——和平的提議只適用於地界以外的城。

### 第一步：先說和睦的話

「你臨近一座城、要攻打的時候，先要對城裡的民宣告和睦的話」。CT 說這裡的「你」指第9節的軍長，而宣告和睦的話「指講明招降的和平條款」。STEP 顯示這個詞是 le./sha.Lom（H7965G，sha.lom: peace），第11節城方的回應也是同一個字 sha.Lom。

BH 把這一步讀成神性情的表達：這道命令顯出神是和平的神（羅15:33），也給對方一個在審判之前悔改降服的機會。

### 第二步：開城的結果是服勞役

第11節：「他們若以和睦的話回答你，給你開了城，城裡所有的人都要給你效勞，服事你」。CT 說「所有的人」指成年男人，「效勞，服事」指服勞役。STEP 顯示「效勞」是 la./Mas（H4522，mas: taskworker），「服事」是 va./'a.va.Du./kha（H5647G，a.vad: to serve）。

各家對這個結果的評價不同，值得並列：

| 來源 | 對開城服勞役的說法 |
| --- | --- |
| GT《聖經精讀本》 | 開了城表明他們無意爭戰且嚮往和平；據猶太學者的解釋，這些城的居民即使不受割禮，也要放棄拜偶像，在宗主權性契約之下獻貢於以色列 |
| GT《雷氏研讀本》 | 這句話是挪亞咒詛迦南的應驗（參看創世記九章25節的腳註） |
| CT | 神希望所有的人都知道神是賜平安的神；效勞服事的意思是聽從以色列人的話、棄掉偶像歸向神 |
| KC | 聽從和平的提議會帶出一種立約關係，本來屬於世界範圍的因此被帶進神子民的範圍裡並為之效力 |
| BH | 強迫勞役是古代近東對降服者的常見處置，也讓人想起以色列自己在埃及的遭遇（出1:11） |

### 第三步：拒絕的後果

第12至14節寫的是另一條路：「若不肯與你和好，反要與你打仗，你就要圍困那城。」STEP 顯示「和好」是動詞 tash.Lim（H7999B，sha.lam，本節譯義是 it will make peace），與第10、11節的名詞 sha.lom 同一組字；「圍困」是 ve./tzar.Ta（H6696A，tsur: to confine）。

城破之後要「用刀殺盡這城的男丁」。STEP 顯示「男丁」是 kol- ze.khu.Ra/h（H2138，za.khur: male），「用刀」直譯是 le./fi- Cha.rev（H6310H peh 加 H2719 che.rev），逐字是刀的口。GT《聖經精讀本》解釋這個處置的社會意義：「男丁」指可以參戰的成人，「在古代社會,男子就是一個家庭、城邑及國家的代表,因此,這樣的懲罰意味著完全滅絕一個族類」。

婦女、孩子、牲畜與城內財物則可以取為掠物。STEP 顯示「掠物」是 she.la.La/h／she.Lal（H7998，sha.lal: spoil），動詞是 ta.Voz（H962，ba.zaz: to plunder）。CT 讀出這句話的歸屬：一切戰利品是神給參軍者的賞賜——經文自己說「耶和華─你神把你仇敵的財物賜給你」。

### 這套程序的整體形狀

GT《聖經精讀本》把它整理成三段：先提出和親以便和平佔領那城，對方接受就在上繳朝貢的條件下休戰得享和平，對方拒絕才與之爭戰並除盡城中所有男丁。GT《啟導本》講法相同，並強調界線：「但此例只限對待不屬迦南地居民的城；若在神賜為業的四境之內，則一人也不可留」。GT《串珠》則從態度上說：「選民對待遠方敵人，須儘量以和為本（參書11:19; 撒下10:19）」。

KC 從屬靈的角度讀這一段：傳講神全備的旨意時常會遇到抵擋，抵擋必須被除去，別人才能被贏得；他並指出希伯來文裡「爭戰」與「事奉」是同一個字，所以傳講神的話既是利未人的事奉，也是爭戰。CT 則把和睦的話讀成福音的圖像：我們在未信主之前都是神的仇敵（羅五10），神也藉著福音向我們宣告和睦的話。

### 申命記

<!-- accumulation:申命記:20:start -->
#### [[05 申命記/第20章|第20章]]
- 本章重點：第10至15節的攻城程序：先宣告和睦的話（v10），對方開城則全城服勞役（v11），拒絕則圍困、城破後殺盡男丁、婦孺牲畜財物取為掠物（v12-14），而第15節限定這套規則只適用於「離你甚遠的各城」。CT 說「你」指第9節的軍長、宣告和睦的話指講明招降的和平條款、「所有的人」指成年男人、10~15節僅適用於迦南地以外的敵城；GT《聖經精讀本》分成提出和親、上繳朝貢休戰、拒絕則爭戰三段，並說「男丁」指可以參戰的成人；GT《啟導本》說此例只限對待不屬迦南地居民的城；GT《串珠》說對遠方敵人須儘量以和為本（參書11:19; 撒下10:19）；GT《雷氏研讀本》把「都要給你效勞，服事你」讀為挪亞咒詛迦南的應驗；KC 說聽從和平提議會帶出立約關係；BH 說強迫勞役是古代近東常見處置，並讓人想起以色列在埃及的遭遇（出1:11）。STEP 顯示 v10、v11「和睦」是 sha.Lom（H7965G），v12「和好」是 tash.Lim（H7999B sha.lam），「圍困」是 ve./tzar.Ta（H6696A tsur），v11「效勞」是 la./Mas（H4522 mas），「服事」是 va./'a.va.Du./kha（H5647G a.vad），v13「男丁」是 ze.khu.Ra/h（H2138 za.khur），v14「掠物」是 she.la.La/h（H7998 sha.lal）。
- 與本章關聯：這一段與第16至18節構成本章刻意設計的對照：同樣是攻城，遠方的城先得到一次和平的機會，迦南七族的城則沒有。第15節的「離你甚遠的各城，不是這些國民的城」正是把兩套規則切開的那句話，而第16節「但這些國民的城」立刻轉向另一套。
