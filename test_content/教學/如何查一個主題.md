# 🔍 如何查一個主題

> 用「**神的榮耀**」當範例，示範 4 種查主題的方法。

## 方法 1：全文搜尋（最直接）

**熱鍵**：`Ctrl/⌘ + K`

1. 按 `Ctrl/⌘ + K` 開啟搜尋
2. 輸入「神的榮耀」
3. 結果會列出所有包含這詞的頁面，按相關度排序
4. 點任一結果跳轉

**適合**：明確知道要找什麼詞的時候。

**範例結果**：
- `link_folder/主題/神的榮耀.md`（主題條目）
- `content/02 出埃及記/第33章.md`（經文中出現「神的榮耀」）
- `content/02 出埃及記/第40章.md`（會幕充滿榮耀）

## 方法 2：標籤搜尋（看分類）

**熱鍵**：`Ctrl/⌘ + Shift + K`

1. 按 `Ctrl/⌘ + Shift + K`
2. 輸入 `#主題` 或 `#神學`
3. 列出所有該分類的條目

**適合**：想看某個分類下有哪些條目。

**範例**：
- `#主題` → 所有主題條目
- `#人物` → 所有人物條目（亞伯拉罕、摩西、大衛…）
- `#地點` → 所有地點條目（西乃山、耶路撒冷、迦南地…）
- `#原文` → 希伯來文/希臘文詞條
- `#互文` → 跨書卷引用關係

## 方法 3：語意搜尋（找概念）

**熱鍵**：`Ctrl/⌘ + K`（同一個搜尋框）

語意搜尋會理解你的**意思**，不只比對字面。

**範例**：
- 輸入「神彰顯自己的榮耀」→ 找到「神的榮耀」「神的同在」「會幕」等概念相近的條目
- 輸入「神與人同住」→ 找到「會幕」「聖殿」「道成肉身」等

**底層技術**：本站用 NVIDIA `nemotron-3-embed-1b` 模型做 embedding，存到 Pinecone 向量資料庫。

**適合**：不知道確切用詞，只知道概念時。

## 方法 4：反向連結（看誰提到）

**位置**：每個頁面右側「Backlinks」面板

1. 先用方法 1-3 找到一個相關條目（例如「神的榮耀」）
2. 捲到頁面底部，看右側「Backlinks」
3. 列出所有**連到這個條目**的頁面

**範例**：
- 「神的榮耀」條目的 Backlinks 會列出：
  - `02 出埃及記/第33章`（摩西求見神的榮耀）
  - `02 出埃及記/第40章`（會幕充滿榮耀）
  - `03 利未記/第9章`（亞倫祝福後榮耀顯現）

**適合**：想看一個概念在哪些經文脈絡中出現。

## 組合技：4 種方法串起來

深度查一個主題的推薦路徑：

```
1. 全文搜尋「神的榮耀」→ 找到主題條目
2. 點進去看「按書卷累積」→ 看跨書卷脈絡
3. 點 Backlinks → 看哪些章節提到
4. 進到具體章節 → 看經文 + 註釋
5. 從章節的 wiki-link → 跳到相關人物/地點/原文
```

## 搜尋技巧

| 技巧 | 說明 |
|---|---|
| **多關鍵字** | 空格分隔，AND 邏輯 |
| **`#` 前綴** | 篩標籤 |
| **中文/英文混用** | 支援，例如搜「covenant 聖約」 |
| **詞形變化** | 語意搜尋會處理，不需完全一致 |
