# 比珥活水泉谷與眾首領用圭用杖挖井引頌讚凱歌

## 定義

在古以色列人在南東荒涼行程裡破毒揚帆而往後前征的歷程中，有一幕全然毫無投訴哭苦、轉為長詠甘美恩悅之輝煌篇幅，那即是安營到達象徵「賜活井泉」之勝處——「比珥（Beer）」；在此古乾林野地，不再依傍人民絕望咒叫與摩西失措狠打大磐，而是造天王君自動喜言向摩西下頒慈誠口諭：「把萬家族眾聚起，我必將活蜜寒水盡予他們一口豪飲」！會民滿懷天樂不用兵荒爭執，應時張放千喉長唱喜樂天章：「井啊！快快為民湧發歡流！爾們應依是恩井歌賀」；更見那代表不惑信靈的一代十二高長首領以及七十位至崇貴長者，以自己領家統御之高貴皇階「權圭」並仗行足下所拄「手杖」，在野地合力誠心勤力挖掘掏剔；如此手心同一除去雜泥堵塞、盡讓井喉深水滾滾長躍之情，向千世宣告聖徒若願卸了肉身障壁並施發稱恩歡唱，必召奔活水甘泉不休直冒。
