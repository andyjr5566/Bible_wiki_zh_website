# 🔗 如何跨書卷找相關條目

> 用「**逾越節**」當範例，示範如何從一個概念追到所有相關經文。

## 什麼是「跨書卷」？

聖經 66 卷書不是獨立文件，而是互相引用、互相解釋的網絡。本站的 `link_folder/互文/` 資料夾專門收錄跨書卷的引用關係（例如新約引用舊約）。

## 方法 1：從主題條目追

1. 搜尋「逾越節」→ 找到 `link_folder/主題/逾越節.md`
2. 該條目有「按書卷累積」H2，列出所有提到逾越節的章節
3. 點任一章節跳轉

**範例路徑**：
```
逾越節（主題）
  → 出埃及記 第12章（設立逾越節）
  → 利未記 第23章（節期規定）
  → 民數記 第9章（第二次守逾越節）
  → 申命記 第16章（重申節期）
  → 馬太福音 第26章（最後的逾越節）
```

## 方法 2：從經文 wiki-link 追

1. 開啟 `02 出埃及記/第12章.md`
2. 經文中所有藍色連結都是 wiki-link
3. 點「[[逾越節]]」→ 跳到主題條目
4. 從主題條目再跳到其他章節

**優點**：在閱讀經文時自然發現相關條目，不打斷閱讀。

## 方法 3：從互文資料夾查

**位置**：`link_folder/互文/`

這個資料夾專門收錄「A 經文被 B 經文引用」的關係。

**範例**：
- `link_folder/互文/出埃及記12章被引用.md` 列出所有引用出埃及記 12 章的新約經文
- 包含馬太、馬可、路加、約翰的相關段落

**適合**：研究「舊約預表 → 新約應驗」的神學主題。

## 方法 4：從人物/地點追

很多主題會牽涉到特定人物或地點。

**範例：逾越節相關**
- 人物：[[摩西]]（設立逾越節）、[[耶穌]]（最後的逾越節）
- 地點：[[埃及]]（出埃及的地）、[[耶路撒冷]]（後來守節的地方）
- 原文：[[פֶּסַח]]（希伯來文「逾越」）

從主題條目底部「相關條目」可以看到這些連結。

## 方法 5：用 local graph 看（進階）

**位置**：每個頁面右側（啟用後）

啟用 local graph 後，每個頁面會顯示一個小型圖譜，視覺化當前頁的所有連結關係。

**優點**：一眼看出這個條目連到哪些頁面、被哪些頁面連到。

**注意**：目前只啟用 local graph（不啟用 global graph），因為全站節點數太大，global graph 會有效能問題。

## 實戰範例：追蹤「會幕」

```
1. 搜尋「會幕」→ 找到 link_folder/主題/會幕.md
2. 看「按書卷累積」→ 出埃及記 25-40 章、利未記、民數記
3. 點 Backlinks → 看哪些章節提到會幕
4. 從會幕條目跳到：
   - 人物：摩西、亞倫
   - 地點：西乃山、西乃曠野
   - 原文：מִשְׁכָּן（mishkan，希伯來文「居所」）
   - 互文：希伯來書 8-9 章（新約對會幕的詮釋）
5. 從希伯來書 8 章 → 跳到「新約的會幕 = 天上的真帳幕」概念
```

## 跨書卷查詢的 4 個層次

| 層次 | 工具 | 範例 |
|---|---|---|
| **字面** | 全文搜尋 | 找所有出現「逾越節」的頁面 |
| **概念** | 語意搜尋 | 找「神的救贖」「羔羊之血」相關 |
| **引用** | 互文資料夾 | 找出埃及記 12 章被新約引用處 |
| **網絡** | local graph | 視覺化整個會幕主題的連結 |
