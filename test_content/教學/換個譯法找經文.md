# 🔤 換個譯法，也找得到相關經文

> 在「經文搜尋」輸入一個詞，結果下方有時會多出一區「**② 換個譯法，也找得到相關經文**」。這一頁說明它在做什麼、怎麼看，以及它能幫你發現什麼。

## 先看一個例子

打開搜尋（`Ctrl/⌘ + K`），在「經文搜尋」輸入 **赦免**：

- **① 直接符合「赦免」**：經文裡真的有「赦免」兩個字的經節。
- **② 換個譯法，也找得到相關經文**：例如創世記 18:24——

  > 不為城裡這五十個義人**饒恕**其中的人嗎？

這節經文沒有「赦免」兩個字，為什麼會出現？因為在希伯來文原文裡，這裡的「饒恕」和出埃及記 34:7「**赦免**罪孽、過犯」用的是**同一個字**，而且是同一個意思。和合本的譯者在不同地方選了不同的中文。

只用中文查，你會錯過這些經文；這一區就是把它們找回來。

## 為什麼需要它

把聖經從希伯來文、希臘文翻成中文時，常常會遇到兩種情況：

1. **同一個原文字，在不同經文翻成不同的中文。** 例如上面的「赦免」和「饒恕」；又如「心」這個字，和合本有時譯作「心」，有時譯作「心意」「心裡」，甚至「胸」（出埃及記 28:29「帶在胸前」）。
2. **同一個中文詞，背後可能是不同的原文字。** 例如「赦免」光在創世記到約書亞記，就來自三個不同的希伯來文字。

翻譯讓我們讀得懂，但也可能把經文之間原本的連結藏起來。這個功能做的事，就是**透過原文，把這些連結重新接上**。

## 它是怎麼找的

1. 本站整理了每一節經文裡，**原文的每個字對應到和合本的哪幾個中文字**，也標出那個字在這裡是**哪一種用法**。
2. 你輸入一個詞，網站先找出：和合本在哪些地方用這個詞翻了哪個原文字、哪一種用法。
3. 再把**同一個原文字、同一種用法**、但和合本換了說法的經文列出來。

所以列出來的經文，不是「字面像」，而是**原文是同一個字、而且用法相同**。

> 同一個原文字常有好幾種用法。例如有一個希伯來文字，在不同經文裡可以是「舉起」「抬」「擔當」「娶」，也可以是「赦免、饒恕」。你查「赦免」時，網站只會帶出它當「赦免、饒恕」用的那些經文，不會把「抬東西」的經文也混進來。

## 畫面怎麼看

每一個原文字（和它的一種用法）是一張卡片：

| 位置 | 意思 |
| :--- | :--- |
| 希伯來文和讀音 | 這張卡片說的是哪一個原文字 |
| 「這裡的用法：赦免、饒恕」 | 這個字在這些經文裡的用法；只有一種用法時直接寫譯法 |
| 橫條和譯法按鈕 | 和合本把這個用法翻成哪些中文、各幾處，由多到少排。虛線框的是你查的詞（那些經文已經在 ① 列過了） |
| 「你找到的一處」 | 一節含有你查的詞的經文 |
| 「另一種譯法」 | 同一個原文字、同一個用法，但和合本換了說法的一節經文。點上面的譯法按鈕，就換成那種譯法 |
| 讀前後文 | 跳到章節頁的那一節，看上下文 |
| 列出「…」N 節 | 列出這種譯法的全部經文 |
| 換一節 | 換一節同樣譯法的經文來看 |
| 這個字的其他用法 | 看同一個原文字在別的經文裡還有哪些用法 |

卡片依「你查的詞出現的次數」排序，最相關的排在最前面。

## 它可以帶給你什麼

- **看見被翻譯藏起來的連結**：查「心意」，會發現民數記 16:28「憑我自己**心意**」和創世記 6:6「耶和華……**心**中憂傷」，原文是同一個字。
- **認識一個字怎麼用**：查「剛硬」，會看到法老「心裡剛硬」那些經文用的字，在別處也譯作「剛強」「壯膽」——同一個字，有時是好事，有時是壞事，要看上下文。
- **查經、備課、帶小組**：用兩節並排的經文，就能帶大家一起比較同一個字在不同情境中的用法。

## 使用時請注意

- **目前涵蓋創世記～約書亞記。** 其他書卷整理好後會陸續加入。
- **對應是整理出來的資料，可能有誤。** 絕大多數是正確的，但仍可能有少數錯誤，請配合上下文閱讀；發現錯誤歡迎從搜尋結果最下方的問卷回報。
- **同一個原文字，不代表每一處的意思完全一樣。** 它告訴你「這些經文可以放在一起比較」，意思仍要看各自的上下文。
- **有些地方和合本沒有逐字翻出某個字**，意思融入整句。卡片上會寫「另有 N 處，這個詞沒有可單獨對應的中文字」。
- **什麼時候不會出現這一區？**
  - 只輸入一個字（例如「心」）——一個字背後的原文字太多，列出來反而看不清楚。
  - 太常見的字，例如「一切」「說」「給」，出現幾百、幾千次，不展開。
  - 和合本只用你查的詞翻過那個原文字一次——只有一次可能是資料的偶發錯誤，所以不採用。
  - 在「進階條件」裡加了「再查關鍵字」或勾選「嚴格字面比對」時。
