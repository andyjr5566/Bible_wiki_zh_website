# 刀劍

## 定義

刀劍在創世記第27章中出現於以撒給以掃的祝福：「你必倚靠刀劍度日」（創二十七40），預言以掃後裔（以東人）將生活在荒蕪之地，以武力維生。

- 以撒給以掃的祝福：「你必倚靠刀劍度日」（創二十七40）
- 預言以東人常有搶掠的行動（CT，參俄10、13-14）
- 以掃後裔住在西珥山，土地貧瘠，戰爭和擄奪是他們唯一的出路（BH）
- 刀劍象徵戰爭和生存武力（BH）

## 主題發展

### 創27：一句應驗了的預言

第40節「你必倚靠刀劍度日」是以撒對以掃的宣告。CT 指出這預言以東人常有搶掠的行動（俄10、13-14）；GT《聖經精讀本──創世記註解》說得更完整：這預示以掃和他的後裔殘酷、好戰的性格——「在荒涼的土地上，戰爭和擄奪才是他們唯一的出路」（耶四九7-22）。BH 也記以東人以尚武著稱，與以色列屢次交戰。

「刀劍」在這裡因此不是勇武的稱讚，而是生計的方式：他們住的地方不足以養活他們（39節），只能靠奪取。

### 軛與掙開軛

同一節下半是「又必事奉你的兄弟；到你強盛的時候，必從你頸項上掙開他的軛」。兩段歷史被各家一致引用：服事應驗在大衛時代——CT 記大衛在以東全地設立防營，以東人就都歸服大衛（撒下八14）；掙開軛應驗在猶大王約蘭年間，以東人背叛猶大、自己立王（王下八20、22；BH 另舉代下二一8-10）。

GT《舊約背景註釋》據此提醒不要把第39-40節整段讀成咒詛：這話「預期以掃一系繼續存在，並且至終得自由」。這與 GT《聖經精讀本》判它為變相咒詛的說法直接相衝，見[[以掃所得的是福還是禍]]。

- 以掃住在貧瘠之地，需靠刀劍生存
- 以東與以色列的長期衝突（王下八20-22）
- 刀劍也象徵神的審判和公義
