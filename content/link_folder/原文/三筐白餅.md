# 三筐白餅

## 定義

創世記40:16膳長夢中「我頭上頂著三筐白餅」，BH 指出「白餅」是當時可能被視為精緻或上等的餅，反映膳長為法老製膳的職分。約瑟解「三個筐子就是三天」（18節），筐數對應天數。膳長職掌膳食，夢中頭頂三筐白餅、極上筐為法老烤食物、被鳥吃，象徵職責失效、審判臨到。

- 本章重點：膳長夢見頭頂三筐白餅（16-17節），埃及人習慣頭頂搬運（CT、GT、BH）。極上筐法老食物被鳥吃，膳長未趕鳥，象徵不忠職守。三筐→三天→斬首掛木頭，預表應驗精確。
- 與本章關聯：與酒政「三根枝子」對比，同為三、同為職責意象、異結局（生/死）。

## 主題發展

CT 由膳長的餅讀出兩層意思：製餅所需的碾磨、烤焙代表苦難，受苦原與人有益（詩119:71），但成果有可能被飛鳥吃去；並以此連到主的比喻——許多人聽見神的話，因存心有問題就被惡者奪了去，以致不能結實（太13:4、19）。
