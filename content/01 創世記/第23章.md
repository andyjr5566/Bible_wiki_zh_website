1. [[撒拉]]享壽一百二十七歲，這是撒拉一生的歲數。
2. [[撒拉]]死在迦南地的[[基列亞巴]]，就是[[希伯崙]]。[[亞伯拉罕]]為他哀慟哭號。
3. 後來[[亞伯拉罕]]從死人面前起來，對[[赫人]]說：
4. 我在你們中間是外人，是[[寄居者身份|寄居的]]。求你們在這裡給我一塊地，我好埋葬我的[[死人]]，使他不在我眼前。
5. [[赫人]]回答[[亞伯拉罕]]說：
6. 我主請聽。你在我們中間是一位尊大的王子，只管在我們最好的[[墳地]]裡埋葬你的[[死人]]；我們沒有一人不容你在他的墳地裡埋葬你的死人。
7. [[亞伯拉罕]]就起來，向那地的[[赫人]]下拜，
8. 對他們說：你們若有意叫我埋葬我的[[死人]]，使他不在我眼前，就請聽我的話，為我求瑣轄的兒子[[以弗崙]]，
9. 把田頭上那[[麥比拉洞]]給我；他可以按著足價賣給我，作我在你們中間的[[墳地]]。
10. 當時[[以弗崙]]正坐在[[赫人]]中間。於是，赫人以弗崙在城門出入的赫人面前對[[亞伯拉罕]]說：
11. 不然，我主請聽。我送給你這塊田，連田間的洞也送給你，在我同族的人面前都給你，可以埋葬你的死人。
12. [[亞伯拉罕]]就在那地的人民面前下拜，
13. 在他們面前對[[以弗崙]]說：你若應允，請聽我的話。我要把田價給你，求你收下，我就在那裡埋葬我的[[死人]]。
14. [[以弗崙]]回答[[亞伯拉罕]]說：
15. 我主請聽。值[[四百舍客勒]]銀子的一塊田，在你我中間還算什麼呢？只管埋葬你的死人吧！
16. [[亞伯拉罕]]聽從了[[以弗崙]]，照著他在[[赫人]]面前所說的話，把買賣通用的[[銀子]]平了[[四百舍客勒]]給以弗崙。
17. 於是，麥比拉、幔利前、[[以弗崙]]的那塊田和其中的洞，並田間四圍的[[樹木]]，
18. 都定準歸與[[亞伯拉罕]]，乃是他在[[赫人]]面前並城門出入的人面前買妥的。
19. 此後，[[亞伯拉罕]]把他妻子[[撒拉]]埋葬在迦南地幔利前的麥比拉田間的洞裡。（幔利就是[[希伯崙]]）。
20. 從此，那塊田和田間的洞就藉著[[赫人]]定準歸與[[亞伯拉罕]]作[[墳地]]。

## 本章整理

### 一、撒拉之死與哀慟（1-2節）

撒拉享壽一百二十七歲（1節；מֵאָה שָׁנָה וְעֶשְׂרִים שָׁנָה וְשֶׁבַע שָׁנִים，H3967、H8141、H6242、H7651）——她是聖經中唯一記載享壽年歲的女性，表明她一生的年日都蒙神記念；此時以撒三十七歲，距離亞伯拉罕離開吾珥大約六十二年（GT）。從亞伯拉罕受割禮（創17章）到撒拉去世，其間大約三十八年，令人聯想到以色列人在曠野漂流三十八年（申2:14；CT 靈意）。要注意本章另外提到一個三十八年，指的是另一件事：GT《聖經精讀本──創世記註解》指出撒拉「比亞伯拉罕早去世38年」——一個算的是割禮到她去世，一個算的是她去世到亞伯拉罕去世。

新約聖經對撒拉的評價非常尊貴。精讀本指出她是立約後裔的母親，也是所有信靠神之人的屬靈母親（賽51:2），一生跟隨丈夫過著寄居的生活（來11:13），聖經也記錄了她尊貴的品德（彼前3:6）。KC 補充了一項常被忽略的特點：來11:11 也提到她個人的信心，「她不像羅得那樣單單依附亞伯拉罕的信心」——她走完了整段朝聖旅程，六十二年裡都是異鄉人與寄居者，兩人一同抵達屬靈的目標，在彼此的忠誠與信實上也是如此（彼前3:5-6）。

撒拉死在迦南地的[[基列亞巴]]（בְּקִרְיַת אַרְבַּע，H7153），也就是[[希伯崙]]（חֶבְרוֹן，H2275A）。兩個地名的字義有明顯分別——「同盟、友誼」是希伯崙的字義，不是基列亞巴的：

| 名稱 | 來源 | 字義解讀 |
|---|---|---|
| 基列亞巴 | CT | 四方城，偉人之城 |
| 基列亞巴 | GT《舊約背景註釋》 | 「四之村」；可能指四個村落聯合而成的城鎮，或幾條大道在此交會 |
| 基列亞巴 | BH | 名字來自亞巴，「亞衲族中最偉大的人」 |
| 希伯崙 | CT | 同盟，友誼 |

三種說法共通的特點是「四」與「偉人」這兩個元素，差別只在於哪一個是主要由來。

亞伯拉罕為她「哀慟哭號」——「哀慟」（לִסְפֹּד，H5594，動詞 סָפַד 的不定詞）指內心的深切哀痛，「哭號」（וְלִבְכֹּתָהּ，H1058，動詞 בָּכָה 的不定詞帶第三人稱陰性字尾）指大聲哀哭（CT）；這是聖經中第一次記錄亞伯拉罕流淚（KC）。GT《聖經精讀本──創世記註解》指出這同時是一種古代喪葬儀式：送葬者面對遺體，坐在地上痛哭（撒下3:31；21:10；[[古代近東安葬習俗]]）。但精讀本隨即說明儀式不等於虛套——亞伯拉罕回想與撒拉相伴的漫長歲月，所流的是真心哀悼的眼淚，絕非一般喪禮上的應酬應景，並將其連結到主耶穌為拉撒路哀哭（約11:35）；聖經強調復活的盼望，是要讓人克制過度的悲傷，而不是要人取消真摯的情感（帖前4:13）。CT 在第3節另外註記古時中東人的習俗：哀悼者先俯伏在逝者面前，隨後站起身來準備辦理後事——第3節「從死人面前起來」記載的正是這個動作。撒拉是存著信心離開人世的（來11:11、13）；信徒為親人哀傷是人之常情，但不像沒有指望的人那樣陷入絕望的憂傷（帖前4:13-14）——真情流露的眼淚與堅定的信心完全可以並存。

GT《舊約背景註釋》為兩個地名的關聯留下探討空間：地名常會因為新住民進入或發生重要歷史事件而改變（例如耶布斯改名耶路撒冷、路斯改名伯特利），而希伯崙與基列亞巴（「四之村」）之間的確切關係尚無定論——可能指四個村落聯合而成的城鎮，也可能指幾條主要交通幹道在此交會。GT 丁良才《創世紀註釋》注意到敘事上的一處留白：前一章記載亞伯拉罕住在別是巴，「我們不知道撒拉怎樣會死在希伯崙」——經文沒有交代這段地理遷移的過程。GT《聖經精讀本──創世記註解》則點出經文刻意強調的一點：撒拉不是死在非利士地，而是死在應許的迦南地。

希伯崙具體在哪裡，各家註釋記載的方位與距離略有差異：

| 來源 | 方位與距離 |
|---|---|
| CT | 位於耶路撒冷之西南 |
| GT 丁良才《創世紀註釋》 | 耶路撒冷以南五十餘里，比地中海高出三百零四丈 |
| GT《串珠聖經註釋》 | 耶路撒冷以南三十二公里（二十英里） |
| GT《創世記雷氏研讀本》 | 耶路撒冷以南二十二英里（三十五公里） |
| GT《舊約背景註釋》 | 耶路撒冷西南約十九哩，別是巴東北二十三哩，海拔約三千三百呎 |

方位有正南與西南兩說，距離從十九哩到二十二哩不等。丁良才另外註記這座城極為古老（民13:22）；背景註釋補充它在地理戰略上的重要性：它是通往東面拉吉與北面耶路撒冷兩條古道的重要交會處，當地的泉水與井水足以支持橄欖、葡萄的種植，並能滿足創世記23章所描述的那種半農半牧經濟型態的需要。

### 二、求購墳地與寄居者身份（3-9節）

亞伯拉罕從死人面前「起來」——哀哭有時，但信心使人不致被憂傷完全吞噬（KC）。他對[[赫人]]承認自己是「外人」（גֵּר，H1616），是「[[寄居者身份|寄居的]]」（תוֹשָׁב，H8453A；4節）——按當前實際處境坦承身分，而不是憑著屬靈應許專橫自居；雖然神早已應許將迦南全地賜給他和他的後裔，但他此時在法律上連一塊安葬妻子的墳地（אֲחֻזַּת，H272；קֶבֶר，H6913）都沒有（來11:13；彼前2:11）。

赫人敬重地稱他為「[[尊大的王子]]」（6節；נְשִׂיא אֱלֹהִים，H5387A、H430G；CT 註原文字義是「神的王子、有神威的王子」，呂振中譯本作「有神威的族長」）——他在外邦人中間蒙神眷顧、大受敬重，與當年留在所多瑪遭人藐視的羅得形成鮮明對比（創19:9；KC）。但他們表面看似慷慨客氣的「只管在我們最好的墳地（מִבְחַר קְבָרֵינוּ，H4005、H6913）裡埋葬你的死人」，實為近東的外交辭令，用意在於避免外人購置具有永久法律產權的土地（CT）。

本章記載的「赫人」究竟是誰，是創世記歷史研究中最常被討論的課題之一，三份來源提供了相互補充的考證。GT《舊約背景註釋》先把歷史事實陳明：迦南當地的赫人名字屬於閃族語系（本章中的以弗崙、瑣轄都是），而小亞細亞安那托利亞的赫人帝國居民則擁有印歐語系的名字，因此「在敘利亞與迦南居住的赫人，可能和歷史上著名的小亞細亞赫人帝國有關，但也可能是同名或已被迦南同化的貿易僑民」；亞述與巴比倫的歷史文獻也經常把巴勒斯坦一帶稱為「哈提地」（Land of Hatti），證實了這片土地與赫人名稱的深厚關聯。

GT 賈斯樂郝威《聖經難解經文詮釋手冊》在〈命題44〉正面解答「赫人為何在主前2050年已在希伯崙出現」：他指出在有爭議的歷史史跡之前，安那托利亞原本有一個非印歐語系的民族被印歐語系的入侵者征服，而在閃族文字（例如希伯來文）中只記錄子音，Hatti 與 Hitti 的書寫完全相同；因此赫人帝國雖然要到主前十四世紀後半葉才達到全盛，但仍有充分的歷史證據顯示，赫人民族在亞伯拉罕的時代就曾在巴勒斯坦南部出現。GT 艾基斯《舊約聖經難題彙編》將這項論證補充得更為詳盡：加帕多家的庫爾泰培（古代卡尼什）出土了亞述商人於主前1950至1850年間留下的商業楔形泥版；在說 Nesili 語的印歐移民到來之前，當地早已存在非印歐背景的赫人定居，入侵者在主前2300至2000年間征服他們之後沿用了他們的族名。艾基斯引用赫人歷史學者加爾尼的主張——原本的赫人不只居住在小亞細亞，還在遠至巴勒斯坦南部的地方建立了殖民據點——以及科維爾1936年根據墨西里斯二世文件所作的推論。他最後補充說明：以弗崙與瑣轄看來都是閃族迦南名字，正好顯示希伯崙當地的赫人住民已經深度融入了迦南文化。

各方考證的共同結論並非單純宣稱「已經完全證實」，而是表明「不能單憑晚期文獻斷言早期定居不可能」。這與第21章非利士人出現的爭議屬於同一類歷史考證課題，處理方式也相同：文獻的最早出土記錄，不等於該民族實際存在的最早時間起點。

亞伯拉罕兩次俯伏下拜（7、12節）——展現古代近東社交禮儀上的謙遜與客氣，並非宗教敬拜（BH）。他不拐彎抹角，直接指名向[[瑣轄]]（צֹחַר，H6714）的兒子[[以弗崙]]（עֶפְרוֹן，H6085）購買田頭上的[[麥比拉洞]]（מְעָרַת הַמַּכְפֵּלָה，H4631、H4375）。CT 註記名詞原文字義：「瑣轄」意為「白的」、「以弗崙」意為「強壯」；「麥比拉」字根帶有「成雙、倍數、重疊」的意思，亦有學者解讀為「羊圈」——「羊圈」是除了通行的「雙倍」之外另一個少被引用的字義選項。亞伯拉罕堅持「按著足價」（9節；בְּכֶסֶף מָלֵא，H3701、H4392）購買——不欠人情壓力、避免日後產權糾葛；展現信徒在世事交往上行事端正、不佔便宜的公義原則。

### 三、以弗崙的談判與開價（10-16節）

以弗崙在城門出入的赫人面前回應說「我送給你這塊田，連田間的洞也送給你」（11節；נָתַתִּי，H5414）——這是古代中東買賣中以退為進的談判商業習慣（CT）：依照赫人法規，若僅出售部分土地，原土地主人仍必須負擔整塊田的稅賦與各項義務（GT），因此以弗崙希望亞伯拉罕連田帶洞整筆買下。

GT《聖經精讀本──創世記註解》對這項古代法律背景有詳細說明：依照赫族法典（The Hittite Code），凡擁有整塊土地的人都要擔負國家的稅收與軍事義務，但只購買土地一小部分的人則不需要負擔這種全筆義務——責任依然落在擁有大部分土地的人身上。亞伯拉罕起初只想購買田頭的洞，以弗崙便藉機要求他買下整塊田，從而將整筆土地的稅金與軍事責任一併轉移出去。GT《創世記雷氏研讀本》從稅務角度指出同一件事：以弗崙若單單割讓洞穴，自己仍必須負責繳納整塊土地的稅金。

GT《舊約背景註釋》補充了一層更根本的古代產權結構：可耕農地在古代近東是極為寶貴的家族產業，原則上不可出售給家族以外的外人，只有在家族內部缺乏買方、或在商業考量十分必要時，才會賣給無血緣的外人；為了符合法律程序，買方有時會被視為乾兒子，村中長老也必須出面代表買方向業主提出請求。這正好解釋了亞伯拉罕為何先向全體赫人公開請求、再由眾人代向以弗崙轉達（8節）——這不是客套，而是當時嚴謹的產權轉讓程序。背景註釋並指出亞伯拉罕拒絕接受餽贈的法律考量：如果單純接受贈與，以弗崙死後他的法定繼承人就有法律依據可以追討回這塊土地。

以弗崙開價「[[四百舍客勒]]銀子」（15節；אַרְבַּע מֵאֹת，H702、H3967；שֶׁקֶל，H8255；כֶּסֶף，H3701G），與聖經中其他購地交易對照：

| 交易 | 價格 |
|---|---|
| 麥比拉田與洞（本章） | 400舍客勒銀子 |
| 大衛買禾場和牛（撒下24:24） | 50舍客勒銀子 |
| 耶利米購地（耶32:9） | 17舍客勒銀子 |
| 奴隸身價（創37:28） | 約20舍客勒 |
| 僱工年資（背景資料） | 約10舍客勒 |

這筆估價顯然極高，但亞伯拉罕毫不猶豫、完全沒有討價還價（16節）：付清足價能確保永久且合法的產權，避免給以弗崙的後人留下任何爭議口實（舊約背景註釋）；在承受神的應許之日來到之前，他不肯佔外邦人絲毫便宜（CT）。他交付的是「買賣通用的[[銀子]]」（עֹבֵר לַסֹּחֵר，H5674A、H5503）——按照商用標準砝碼公開過磅，公平交易、誠實無欺（GT/BH）。GT《聖經精讀本──創世記註解》為「一定要付清田價」補充了一個經文未直接明說但極合理的考量：在眾人面前公開付清價銀，是為了徹底保護墳墓的安全，防止日後以弗崙家族可能反悔變卦；在眾人見證下交付價銀，就完全確立了土地的所有權（撒下24:24）。精讀本並分析了當時的公證程序：當時雖然已有早期文字，但聖經反覆強調「在城門眾人面前公布約定內容」，表明這是一種公開且具有法律約束力的口頭簽約與公證手續。

四百舍客勒在當時到底昂貴到什麼程度，GT《舊約背景註釋》做了很具體的換算：大約等於七又四分之一磅銀子；相較之下，暗利買下撒瑪利亞全城城址用了六千舍客勒銀子，大衛買下建造聖殿的地基用六百舍客勒金子，禾場本身只賣五十舍客勒，耶利米購買家族田產更只花了十七舍客勒。背景註釋指出亞伯拉罕所付的價錢非常昂貴，每年收入僅約十舍客勒的普通僱工與工匠，窮其一生也難以籌措這筆巨款。GT《串珠聖經註釋》另外引用漢摩拉比法典對照當時工價：一個普通工人的日薪大約是一舍客勒銀子。GT《舊約背景註釋》也說明「買賣通用的銀子」不是一句客套話——大約同一時期古亞述貿易信件的用語顯示，這句話指的是陸上商貿通行的標準秤銀規格。

背景註釋對整場談判的評語同樣值得留意：討價還價是古代近東商業談判的標準常態，「但當買方陷入不得不買的緊迫處境時，賣方往往會充分運用談判所賦予的優勢」。亞伯拉罕當時正處於為亡妻尋求安葬之所的緊迫時刻——撒拉的遺體還停放在那裡等待安葬。

### 四、交易定準與安葬麥比拉洞（17-20節）

麥比拉的田、洞，以及四圍的一切[[樹木]]（עֵץ，H6086H）都正式「定準」（17-18節；וַיָּקָם שְׂדֵה עֶפְרוֹן，H6965I、H7704G、H6085G，動詞 קוּם 意為「確立、合法生效」）歸給亞伯拉罕——四面界線清楚劃定，在赫人以及[[城門口交易|城門出入的人]]面前公開買妥，確立了具有完全法律保障的合法產權。此後，亞伯拉罕把妻子撒拉安葬在麥比拉田間的洞裡——經文強調他埋葬的是「我的死人」、「他妻子撒拉」，而不是抽象的遺留物；在聖經觀點中，身體代表著那個真實存在的人（KC；約19:40-42）。

這塊田位於[[幔利]]（מַמְרֵא，H4471G）前——本章把幔利、希伯崙與麥比拉三個地名同時並列（17、19節），CT 註希伯崙「後來和幔利混為一城」。希伯崙後來成為以色列三代族長家族的重要祖墳：亞伯拉罕（創25:9）、以撒、利百加、利亞（創49:29-31）與雅各（創50:13）皆安葬於此。古代近東通常以天然或人工開鑿的洞穴為墓室，供家族數代共用（[[古代近東安葬習俗]]）。關於麥比拉洞的現狀，丁良才記「這洞如今還在，後人在這洞上築了一座清真寺」；GT《創世記雷氏研讀本》指出有兩個山洞被辨識為麥比拉洞原址，位置一個在另一個之上，現在都位於希伯崙一座大清真寺之下。

GT《舊約背景註釋》把古代的安葬習俗分為兩大類：遊牧族群有「二次安葬」的習俗——在人過世較長時間後，將骸骨遷往傳統的家族祖墳安葬；定居鄉村文化則使用多室塚穴，屍體與隨葬物品置於石台，化為骸骨後再移至骨盒或墓室後方，好騰出空間安葬下一位家族成員。這正是「麥比拉」（雙重／成雙）之名可能的由來之一——GT《聖經精讀本──創世記註解》提出三種可能解釋：有兩個入口的洞、可同時安葬兩人的大洞，或洞中有洞的雙層洞穴。

丁良才在第4節下探討了一個新舊約地名記載的協調難題：本章記載亞伯拉罕在希伯崙向赫人以弗崙買地，創33:19 記載雅各在示劍向哈抹子孫買地，而徒7:16 卻提及亞伯拉罕在示劍買地。丁良才提出三點理解：第一，徒7:16 所指的可能是創世記未詳載的示劍早期購地，即神初次向亞伯拉罕顯現與築壇之處（創12:6-7）；第二，本章所買的是幔利（希伯崙）的麥比拉田與洞，撒拉、亞伯拉罕、以撒、利百加、利亞、雅各都安葬在此；第三，一百二十年後雅各在示劍用一百塊銀子向哈抹子孫買地築壇（創33:18-20），可能因早年土地被佔而重新買回，後來約瑟與眾兄弟最後正是安葬在示劍（書24:32；徒7:16）。這屬於註釋家的協調考證方案，展示了不同聖經記載之間的歷史互補性。

關鍵事實：神應許將迦南全地賜給亞伯拉罕為業，但亞伯拉罕在離世前所擁有的唯一一塊永久產權，竟然是一塊[[墳地]]——這塊墳地成為應許之地的初熟果子。神所應許的終極產業遠超越今世屬地的範疇（來11:8-16）；購地安葬具體展現了他對神的信實應許與復活盼望的堅定信心：先有死與安葬，才有將來的復活與承受產業。

### 五、信徒與世人交往的五大原則（CT）

1. 表明自己只是寄居的（4節）——坦承身分，不堅持世俗特權
2. 對人謙恭有禮（7節）——兩次下拜，尊重社會秩序
3. 不佔別人的便宜（8-9節）——堅持按足價付錢，不欠人情
4. 處事洞察明達（10-16節）——洞悉商業辭令與背後法律責任
5. 手續辦理清晰完備（17-18節）——公開公證，立約有憑有據

### 六、埋葬與復活的神學（KC）

> [!quote] KC
> 埋葬就是撒種，撒種是為著收成——「埋葬」在救贖歷史中始終與「復活」相連，而不是與「死亡」相連（林前十五3-4）。

| 要義 | 說明 |
|---|---|
| **埋葬＝種下** | 身體埋入土中如同種子，死亡並非終局，乃等候復活收成 |
| **復活次序** | 林前15:20-21——在基督裡的人都要復活 |
| **身體就是人** | 經文記「埋葬他妻子撒拉」，福音書記「把耶穌安放」（約19:40-42），肯定身體的尊嚴 |
| **神知道祂子民在哪裡** | 以色列如今看似枯骨（結37章），但神清楚知道屬祂之人的所在 |
| **全額買贖** | 亞伯拉罕付足價銀；神也藉基督的寶血付上了完全的救贖代價 |
| **埋葬與焚燒** | 埋葬承載復活盼望；舊約中焚燒多與審判相關（書7:25；利21:9） |

### 七、預表與神學結構

| 項目 | 預表／意義 |
|---|---|
| **撒拉之死** | KC 視為救贖歷史圖畫：先有撒拉（象徵以色列）被擱置，隨後以撒（基督）得著外邦新婦利百加（教會） |
| **亞伯拉罕購地** | [[復活盼望]]的具體實踐——埋葬是「種下」，等候復活收成 |
| **墳地為唯一產業** | 承受應許之地的初熟果子，神必成就全地應許 |
| **全額付款** | 展現公義與誠實，象徵神買贖世界付出完全代價 |
| **歷代族長同葬希伯崙** | 歷代存著信心離世的聖徒，同等候神所預備更美之事的完全實現（來11:39-40） |
