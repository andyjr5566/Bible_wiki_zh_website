# 配偶幫助者

## 定義
創世記2章18、20節的「幫助者」是 עֵזֶר（*ezer*，H5828）；כְּנֶגְדּוֹ（*kenegdo*）以 נֶגֶד（*neged*，H5048，「在前面、相對」）為核心，並帶有「與他相對」的意思。合起來可理解為「與他相配的幫助者」。KC、CT 與 BibleHub 再從聖經也以「幫助」稱神、男女同按神形像受造，以及整段婚姻敘事，進一步說明女人與男人相配、同等並共同承擔使命。

## 主題發展
KC 注意到神自己也被稱為人的幫助，並把 suitable 解作「在他對面者」。BibleHub 從 *ezer kenegdo* 與整段脈絡說明互補而平等的夥伴；CT 則用「相仿、相對、相配、回應者」解釋配偶。這些來源由原文詞組進一步閱讀整段婚姻關係。

這個詞組是婚姻神學的重要基礎：神為亞當預備的不只是工作上的協助，更是能與他相對、相愛並立約同行的人；人治理受造界的使命，也在與同類的關係中一同完成。
