# 創世記 第8章

1. [[神的記念|神記念]][[挪亞]]和挪亞方舟裡的一切走獸牲畜。神叫[[風與靈同字|風吹地]]，水勢漸落。
2. 淵源和天上的窗戶都[[審判已過|閉塞了]]，天上的大雨也[[審判已過|止住了]]。
3. 水從地上漸退。過了[[四十天降雨與一百五十天水勢|一百五十天]]，水就漸消。
4. 七月十七日，方舟停在[[亞拉臘山]]上。
5. 水又漸消，到十月初一日，[[審判已過|山頂都現出來了]]。
6. [[信心與忍耐|過了四十天]]，[[挪亞]]開了方舟的窗戶，
7. 放出一隻[[烏鴉與鴿子的象徵|烏鴉]]去；那烏鴉飛來飛去，直到地上的水都乾了。
8. 他又放出一隻[[烏鴉與鴿子的象徵|鴿子]]去，要看看水從地上退了沒有。
9. 但遍地上都是水，鴿子找不著落腳之地，就回到方舟[[挪亞]]那裡，挪亞伸手把鴿子接進方舟來。
10. 他又等了七天，再把鴿子從方舟放出去。
11. 到了晚上，鴿子回到他那裡，嘴裡叼著一個新擰下來的[[橄欖葉子]]，[[挪亞]]就知道地上的水退了。
12. 他又等了七天，放出鴿子去，鴿子就不再回來了。
13. 到[[挪亞]]六百零一歲，正月初一日，地上的水都[[乾的兩個希伯來字|乾了]]。挪亞撤去方舟的蓋觀看，便見地面上乾了。
14. 到了二月二十七日，地就都[[乾的兩個希伯來字|乾了]]。
15. [[神的記念|神]]對[[挪亞]]說：
16. 你和你的妻子、兒子、兒婦都可以出方舟。
17. 在你那裡凡有血肉的活物，就是飛鳥、牲畜，和一切爬在地上的昆蟲，都要帶出來，叫他在地上[[新造與新生活|多多滋生，大大興旺]]。
18. 於是[[挪亞]]和他的妻子、兒子、兒婦都出來了。
19. 一切走獸、昆蟲、飛鳥，和地上所有的動物，各從其類，也都出了方舟。
20. [[挪亞]]為耶和華[[祭壇敬拜|築了一座壇]]，拿各類潔淨的牲畜、飛鳥獻在壇上為[[燔祭]]。
21. 耶和華聞那[[馨香之氣]]，就心裡說：我不再因人的緣故[[神的恩典之約|咒詛地]]（[[人的全面敗壞|人從小時心裡懷著惡念]]），也不再按著我才行的[[挪亞之約|滅各種的活物了]]。
22. [[洪水後自然秩序的保存|地還存留的時候，稼穡、寒暑、冬夏、晝夜就永不停息了]]。

## 本章整理

### 神記念，水勢漸退（1-5節）

「[[神的記念|神記念挪亞]]」不是說全知的神一度忘了方舟。GT《串珠聖經註釋》說「『紀念』：包含著『關注』、『顧念』的意思，而且常和『施恩』連在一起」；《創世記雷氏研讀本》說「『記念』不但是記起，而且想到要給予愛心的關懷」；《聖經精讀本》講得最直接——這個詞「不是指忘記了一段時間，突然又想起來，而是指時常掛在內心深處的狀態（尼5:19；詩25:7）」；丁良才則說這是借用的話，「表明神的信實，並沒有忘記挪亞（賽四十九15；路十二6～7）」，並以但以理在獅子洞、彼得在監牢、保羅和西拉在監牢為比方。GT 賈斯樂郝威《聖經難解經文詮釋手冊》｛命題24｝正面回答[[神是否暫時忘記了挪亞|這個難題]]：「神從來就不曾忘掉挪亞，因為神在一開始就警告挪亞，並且要拯救他和他的家人。當我們想起某一個人的生日時，我們常常以同樣的方式來表達，就好像我們從未忘掉那個人的存在。」神不只記念挪亞，也顧念方舟裡的走獸牲畜。洪水的水源閉塞、大雨止住、水勢逐步下降，顯明[[審判已過|審判轉向恢復]]。

神沒有使水瞬間消失，而是讓水逐漸退去。KC以此勸勉信徒：神可使試煉停止，試煉留下的後果卻可能需要時間消退。這是牧養應用；經文直接描述的是受神掌管的漸進退水過程。

「神叫風吹地」中的希伯來文 *ruach* 也可指「靈」。在本句語境中，它直接描述使水退去的[[風與靈同字|風]]；CT、GT與BibleHub則把它與創1:2神的靈運行在水面上相照，視為再創造。CT更以神的記念、方舟及風分別連於父、子、靈的救恩工作，稱為[[三一神同工]]。這是基督教神學式的豫表閱讀，不是說希伯來文一句話明列三個位格。

方舟於七月十七日停在「[[亞拉臘山|亞拉臘眾山]]」。GT 各家一致把重點放在「山脈而非山峰」：《丁道爾聖經註釋》說「亞拉臘山本身有一萬七千英尺高；但這記錄只說停在亞拉臘山（或山丘）上，即，在以這名字稱呼之地的某個地方」，並指有人認為該地為米所波大米北邊靠近凡湖的烏拉圖；《創世記雷氏研讀本》同樣說「這裏可能指『亞拉臘山』，即連綿的山脈，而不是特指某個山峰」；《啟導本》說「聖經沒有準確記明方舟停泊的位置，只說在阿拉臘山上」；《舊約背景註釋》補上一個對照——《吉加墨斯史詩》「則清楚指明洪水事件主角的方舟擱淺在哪個山頭上：庫德斯坦南部的尼西爾山」，創世記反而沒有這樣指名。至於[[亞拉臘山與方舟遺跡爭議|方舟遺跡]]，GT 李道生轉述了第一次世界大戰俄國探險隊與後來數位宗教人士見到冰中船體的說法，但這些敘述欠缺可核查的原始紀錄、材料鑑定與可靠定年；BibleHub 同樣指出尋找精確遺址尚無決定性證據。

### 洪水消退時間軸（1-14節）

| 時點 | 事件 | 資料性質 |
|---|---|---|
| 挪亞600歲，2月17日 | 洪水爆發（7:11） | 經文明載 |
| 7月17日 | 方舟停在亞拉臘山區（8:4） | 經文明載 |
| 10月1日 | 山頂顯露（8:5） | 經文明載 |
| 再過40天 | 挪亞開窗，放出烏鴉（8:6-7） | 經文明載間隔 |
| 其後三次放鴿 | 第二、三次前各等7天（8:8-12） | 首次與烏鴉相隔7天是來源推算 |
| 挪亞601歲，1月1日 | 地面沒有積水，挪亞撤去方舟蓋（8:13） | 經文明載 |
| 2月27日 | 地全然乾透，神命挪亞出方舟（8:14-16） | 經文明載 |

GT第7章拾穗時間表以三十日月份推算若干日期，並給出371日總數；GT第8章所收另一研讀本則說挪亞一家在方舟共377天，包含洪水前七天的等候。兩者的差別來自「只算洪水起訖」或「連進舟後七天也算」以及首尾日算法，不能把任一總數當成單節經文明言。可確定的是：洪水從六百歲二月十七日開始，到六百零一歲二月二十七日地全乾，來源稱為一年又十天；挪亞在洪水前已進舟等候七天。

第13、14節的「乾了」使用[[乾的兩個希伯來字|兩個不同希伯來字]]。GT指出，13節著重地面不再有積水，14節則描述土地乾透。挪亞在正月初一已親眼看見地面乾了，仍等到二月二十七日神說話才出方舟；CT與GT以這五十多天說明[[信心與忍耐]]及不憑眼見擅自行動。

### 烏鴉、鴿子與橄欖葉（6-12節）

| 鳥與次序 | 敘事中的作用 | 來源的靈意閱讀 |
|---|---|---|
| 烏鴉 | 飛來飛去直到地面乾；食腐、能在較差環境停留 | CT、GT、KC以不潔淨的烏鴉象徵舊造或肉體 |
| 第一次鴿子 | 找不到落腳地，返回方舟 | 以基督為安息，不以受審判之物為落腳處 |
| 第二次鴿子 | 叼回新擰的橄欖葉，顯示植物恢復 | 橄欖與油連於聖靈，嫩葉象徵新生命 |
| 第三次鴿子 | 不再返回，顯示外界已可棲息 | CT解作聖靈在潔淨生命中安家 |

鳥的行為首先是挪亞觀察水與土地狀態的方法。經文沒有直接稱烏鴉為舊人、鴿子為聖靈；[[烏鴉與鴿子的象徵|這些象徵]]是來源按利11:15、太3:16等經文所作的應用。GT所引丁道爾註釋還特別說，[[橄欖葉子|橄欖葉]]在本段首先是「新造的應許」，不是經文明說的政治和平標誌；後世口銜橄欖枝的和平圖像確實由此發展。

GT背景資料將本章與[[古代近東洪水故事中的放鳥情節|古代近東洪水故事]]比較：

| 來源 | 放鳥次序 |
|---|---|
| 創世記8章 | 烏鴉一次，鴿子三次 |
| 吉加墨斯史詩 | 鴿子、燕子、烏鴉 |
| 阿特拉哈西斯傳統 | 也有以鳥探察外界的情節 |

這一點 GT《舊約背景註釋》講得最完整：「古代的領航員有用鳥來尋找陸地的習慣，但挪亞已經登陸，無需導航。他使用雀鳥不是要斷定方向。此外，雀鳥的飛行路線有時也作觀兆之用。但創世記和吉加墨斯都沒有觀察放出雀鳥的航線。」背景註釋另分別說明兩種鳥的習性：烏鴉「對航海者的功用是牠的航線……食腐肉是烏鴉的習性，因此必然有足夠的食物」；斑鳩和鴿子「續航能力有限，領航員利用牠們來斷定登陸地點。牠們自行回來，就證明附近沒有可供著陸之處」。這與敘事完全吻合——《創世記雷氏研讀本》即說烏鴉「棲息在泥濘的地面也毫無不安，所以顯然不會返回方舟」，而鴿子「不會在不潔淨的地方著陸，所以牠返回方舟去」。GT 丁良才由此發出勸勉：「鴿子的本性只好落在又乾燥又潔淨的地方……為聖徒的切不要學烏鴉，以不潔之物充饑而知足，應該像鴿子等候新天新地。」GT《聖經精讀本》則從另一面看：「溫柔脆弱的鴿子能夠做到強壯的烏鴉沒能完成的事情，象徵著神揀選那些軟弱之人傳播福音的事工（林前1:27-29）。」

### 出方舟與新造生活（15-19節）

挪亞因神的命令進方舟（7:1），也等神命令才出方舟（8:15-16）。人與各類活物離舟後，神再次吩咐活物多多滋生、大大興旺，與創1章的創造使命呼應，開啟[[新造與新生活]]。

| 創世記1章 | 創世記8章 |
|---|---|
| 神的靈運行在水面上（1:2） | 神叫風 *ruach* 吹地（8:1） |
| 水聚在一處、旱地顯露（1:9） | 水退、山頂與地面顯露（8:5、13） |
| 活物各從其類（1:20-25） | 動物各從其類出方舟（8:19） |
| 活物滋生眾多（1:22） | 活物多多滋生、大大興旺（8:17） |

CT與KC把出方舟到更新之地解作與基督同死同復活、行在生命新樣中（羅6:4）；彼前3:20-21則明文以挪亞一家藉水得救連於[[洪水與洗禮的豫表|洗禮與基督復活]]。

### 築壇、燔祭與馨香（20-21節）

挪亞出方舟後首先為耶和華[[祭壇敬拜|築壇]]。GT《聖經精讀本》指出「在這裡聖經第1次使用『壇』這個用語」，並給出字源：這詞「派生於希伯來語『殺死牲畜』的詞，指『獻祭物的地方』」，而英文 altar 源於拉丁文 altus（高的），「這是因為壇通常築立在山坡或岩石等高處（出20:24）」；精讀本並推測為何到此才出現壇——「或許是因為以往向神直接臨在的聖地（伊甸園）獻祭，所以不必特意設壇」。GT《舊約背景註釋》另提醒一個常見的誤讀：「很多學者相信祭壇被視為神明的飯桌，因為普遍的觀念以為祭物是其糧食。然而這個象喻在舊約卻得不到肯定。」挪亞取各類潔淨牲畜和飛鳥獻為[[燔祭]]，顯示第7章保存較多潔淨活物也為洪水後獻祭留下餘量。

CT、GT與KC把祭理解為感恩、敬拜與全然奉獻，並以全然焚燒的燔祭豫表基督在十字架上的完全獻上；KC再把牲畜與飛鳥分別應用為基督在地為人及從天而來。GT所引《舊約背景註釋》較謹慎：經文沒有明說這祭的用意，也沒有稱它為感謝祭或贖罪祭；燔祭在後來制度中用途廣泛，也可與懇求相關。因此，感恩與基督豫表應保留為來源解讀，不宜改寫成20節明說的祭名功能。

「耶和華聞那[[馨香之氣]]」是擬人化語言，表示神悅納祭物——GT《創世記雷氏研讀本》說原文直譯是「滿意的味道」，丁良才說「這是借用的話，顯明神喜悅挪亞有謝恩的心」。GT《舊約背景註釋》把這語彙放進古代脈絡：整部五經都用「馨香之氣」形容獻祭，「這是古代視祭物為神明食物之觀念的後遺用語」，但它「的生動性遠比《吉加墨斯史詩》為低」——那史詩描述飢餓的神明「像蒼蠅一樣」擁到祭物那裡。GT《丁道爾聖經註釋》對同一件事的評語值得整句記下：「馨香之氣的說法十分大膽，因為巴比倫洪水故事中粗糙地記著，諸神停止洪水的原因，是缺少了人的貢物，他們餓壞了。但是舊約不怕給人如此的印象（參詩五十8～15），使用了這樣生動的話語，而新約也樂於採用（弗五2）。」也就是說，舊約沿用了這套語彙，卻不描寫耶和華依賴人的食物，反把焦點放在神悅納挪亞的敬拜。CT與KC按弗5:2進一步把蒙悅納的根基連於基督的獻上。

### 人心仍惡，神仍施憐憫（21-22節）

第6章因人心終日所想盡都是惡而宣告審判；第8章同樣承認「人從小時心裡懷著惡念」，卻宣告不再照洪水所行的滅絕。KC指出，洪水審判沒有改變人的內心；上下文的轉折在於祭物蒙悅納，以及神主動選擇以憐憫保存世界。這不是神忽然發現先前判斷錯誤，也不是祂從此[[神是否改變心意|不再審判罪]]。

> [!quote] KC
> 第一次的話說在洪水之前，第二次說在洪水之後。審判並沒有改變人的心；如今神乃是基於燔祭的馨香看待這地。惡是人與生俱來的，這使人更全然倚靠神的恩典。

第8章先有神在心裡的應許，第9章才正式向挪亞一家及一切活物宣告約並賜下虹的記號。GT把這世界保存應許列為「[[無條件之約]]」，意思是經文沒有把季節繼續運作繫於人類先達成某種道德條件。

「稼穡、寒暑、冬夏、晝夜永不停息」保證的是自然節律不完全中止，不是每地每季都有豐收。GT 賈斯樂郝威《聖經難解經文詮釋手冊》｛命題26｝專門處理「既然稼穡不止息，為何仍有饑荒（創二六1；四一54）」：「這節經文只應許季節（seasons）不停止而不是收成（crops）……而且這個應允並沒有保證將不會有暫時的中斷。它只是陳述一年的季節固定週期永久的迴圈不停直到末日。」丁良才也把射程收在同一處：「從此以後，所有的水災饑荒只連累了一帶地方的人，並沒有害了全世界。」至於[[神是否改變心意]]，賈斯樂郝威｛命題25｝的回答是：神所應許的是「不再用像這次的方法」——第二次要藉「火」而非「水」（彼後三10）；GT《聖經精讀本》同樣說「這不是說，不再審判罪，只是說除滅全人類的大洪水審判只局限在挪亞時代的洪水災難」。CT、GT與BibleHub按「地還存留的時候」連於彼後3:10-13的新天新地盼望。創8:21直接應許的是不再「按著我才行的」滅各種活物；創9:11、15會更明確說不再有洪水毀壞全地。

### 復活與三一神的靈訓

CT將本章整理為在基督裡死而復活：

1. 洪水消退，表示審判已過。
2. 方舟停在亞拉臘山，豫表與基督一同復活。
3. 山頂顯露，豫表與基督一同坐在天上。
4. 出方舟到更新之地，豫表行在生命新樣中。

CT又把七月十七日與[[基督復活預表|基督復活]]相連：後來出埃及的宗教曆把原七月視為正月，逾越節在十四日，十七日遂成為第三日。這是一項傳統日期豫表；經文沒有說挪亞時代已按出埃及後的宗教曆計日，也不能據此證明方舟停靠與耶穌復活是同一現代曆日。

CT對新造生命的另一組教訓是：烏鴉表舊造性情，鴿子與橄欖新葉表聖靈和新生命，挪亞等候神的話才出舟，出舟後築壇把自己獻給神。這些教訓忠實保留來源的豫表框架，同時與敘事層面的歷史、曆法及鳥類背景分開。
