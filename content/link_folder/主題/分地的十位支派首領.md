# 分地的十位支派首領

## 定義

民數記34:16-29 是一份人事名單：分地的事由祭司以利亞撒、嫩的兒子約書亞，加上十個支派各出一位首領來辦。

**為什麼是十個而不是十二個。** GT《啟導本聖經註釋》交代得最清楚：「他只提到九個半支派的首領，因為流便、迦得和瑪拿西半個支派已經安置在外約但。」

**為什麼要這麼多人。** GT《民數記串珠聖經註釋》給的理由是公允：「分地一事由十二位領袖一起負責，並不由大祭司或約書亞單獨主持，以示公允。神親自擬出人選，藉摩西向百姓頒佈，因為分地是重要的責任。」GT 丁良才說的是同一件事的效果：「是要叫他們同以利亞撒和約書亞分地。這樣，大眾可以放心，所分的地，是至公無私的。」

**名單的次序不是隨意的。** GT 丁良才：「摩西在此所用的支派次序（19-28），就是後來從南到北得地的次序。」GT《啟導本聖經註釋》說得更具體：「記述的次序似依分配土地的順序，從猶大和西緬開始，二支派分配在南部；終於亞設和拿弗他利，所得土地在北部。」

| 支派 | 首領 | 父名 |
|---|---|---|
| 猶大 | 迦勒 | 耶孚尼 |
| 西緬 | 示母利 | 亞米忽 |
| 便雅憫 | 以利達 | 基斯倫 |
| 但 | 布基 | 約利 |
| 瑪拿西 | 漢聶 | 以弗 |
| 以法蓮 | 基母利 | 拾弗但 |
| 西布倫 | 以利撒番 | 帕納 |
| 以薩迦 | 帕鐵 | 阿散 |
| 亞設 | 亞希忽 | 示羅米 |
| 拿弗他利 | 比大黑 | 亞米忽 |

**這些人是誰，查不到。** CT 註：「19~28節所列名的各支派首領，僅迦勒一人在別處聖經提到之外，其餘眾人僅在此處見到，少數皆為同名不同人，因此究竟是怎麼樣的人，無事蹟可考。」GT 丁良才也說：「除了迦勒以外，聖書上沒有提到這些人的名字。」

**這是換過一批人的名單。** CT 註上一次記載名字的各支派首領是在民七章，但都已死在曠野中。KingComments 的說法相同：這些人除了約書亞和迦勒之外都屬第二代，民1 提到的支派領袖已經不在了；他並補上一句——神總是為祂的百姓預備一切所需要的。

**「幫助」這兩個字原文沒有。** CT 註第18節：「『幫助』原文無此字，故含有『會同』的意思。」

## 按書卷累積

### 民數記

<!-- accumulation:民數記:34:start -->
#### [[04 民數記/第34章|第34章]]
- 本章重點：第16-29節：以利亞撒、約書亞加十個支派首領。GT《啟導本》註只有九個半支派，因為兩個半支派已安置在外約但；GT 串珠註分地不由大祭司或約書亞單獨主持以示公允；丁良才與《啟導本》都指出名單次序就是後來從南到北得地的次序。CT 註除迦勒外其餘眾人僅在此處見到、無事蹟可考。
- 與本章關聯：這份名單標誌著世代交替：CT 註上一次記名字的支派首領在民7 章，都已死在曠野；KC 說這些人除約書亞與迦勒外都屬第二代。
