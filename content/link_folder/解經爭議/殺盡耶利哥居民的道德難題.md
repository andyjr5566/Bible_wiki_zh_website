# 殺盡耶利哥居民的道德難題

## 定義

書6:21：「又將城中所有的，不拘男女老少，牛羊和驢，都用刀殺盡。」四套來源都知道現代讀者會在這裡卡住，也都花了篇幅回應。

### 先確認命令的來源

CT 說表面上看，這一舉措似乎野蠻又殘忍，但務要記住以色列人是嚴格地執行了神的命令（申20:16-17），任何對神命令的指責，都是對神裁判公正性的指責。GT《艾基斯舊約聖經難題彙編》把這一步說得更清楚：矛頭其實不應指向約書亞或以色列人，「我們的批評意見乃落在神身上，約書亞和以色列人只是遵他的旨意行」。

### 各家給的理由

| 論點 | 出處 |
|---|---|
| 迦南人惡貫滿盈，寬容的時期已經結束，神曾賜給他們充足的悔改機會 | CT |
| 從創15:16「亞摩利人的罪孽還沒有滿盈」到約書亞進迦南已經過了六百七十五年，他們並沒有改變可憎的惡俗 | GT《綜合解讀》 |
| 神也用同一個標準對付以色列自己，整整一代人倒斃曠野 | GT《綜合解讀》 |
| 任憑罪人永遠活在罪中並不是真正的慈愛 | GT《綜合解讀》 |
| 人今生的生命都是短暫的，重要的是在短暫的今生做出正確的選擇 | GT《綜合解讀》 |
| 若他們得保性命而居於以色列人中間，就一定會對以色列整個民族做成更大的危害 | GT《艾基斯》 |
| 以色列軍兵是代神對充滿罪惡的耶利哥城施行審判 | GT《聖經精讀本》 |
| 神所有規定的目的都是要保持百姓的信仰和宗教不被污染 | GT《靈修版聖經注釋》 |

KC 加的是機會的一面：神並沒有不公義，耶利哥的每一個人都和喇合一樣有機會相信，只是他們沒有憑信心站到喇合那一邊；神已經等候了四百年（創15:13），所以祂施行審判時並不是沒有憐憫。BH 說審判的範圍顯出迦南根深蒂固的悖逆與拜偶像有多嚴重，而神已經等了好幾代。

### 各家都補的那一句

幾份來源在講完之後都主動把界線劃出來，不讓這段經文變成今天的行為規範。CT 說新約時代的信徒並非靠著肉體為神打仗，卻是持著屬靈的兵器（林後10:4-5），若要憑藉刀劍來保護信仰及地土，我們便沒有機會作基督的大使。GT《綜合解讀》說神並沒有命令新約的信徒發動聖戰，我們不必忙著替天行道、用公義去審判別人，而應當先用公義來省察自己。GT《艾基斯》說我們必不可定他們的罪，而應謹記他們只是順服信靠神。

### 經文自己留下的線索

GT《丁道爾聖經注釋》在第24節提出一個文本上的觀察：第19、24節重複列出要納入聖所的財物，這個表十分正式、彷彿是驗收單，看哪些東西是屬於聖所的，而不是他們從耶利哥實際所得之物的清單；它接著問，第21節要殺的人是否也屬這種性質——經文是否其實並未告訴讀者耶利哥有哪些人，只是提到那裡的王、軍人和喇合的家。

## 按書卷累積

### 約書亞記

<!-- accumulation:約書亞記:6:start -->
#### [[06 約書亞記/第6章|第6章]]
- 本章重點：第21節「又將城中所有的，不拘男女老少，牛羊和驢，都用刀殺盡」。CT 說表面上看似乎野蠻又殘忍，但以色列人是嚴格執行神的命令（申20:16-17），任何對神命令的指責都是對神裁判公正性的指責，並說迦南人已經惡貫滿盈、寬容的時期已經結束；GT《艾基斯舊約聖經難題彙編》說矛頭其實落在神身上而非約書亞，並以大洪水與所多瑪為更大的例子，說只有徹底的手術才可將毒性腫瘤病者的生命挽回，又說若他們得保性命而居於以色列人中間就一定會對以色列做成更大危害；GT《綜合解讀》列出四點：迦南人惡貫滿盈時候已到（從創15:16 到進迦南已過六百七十五年）、神也用同一標準對付以色列自己、任憑罪人活在罪中不是真正的慈愛、人今生的生命都是短暫的；GT《聖經精讀本》說以色列軍兵是代神對充滿罪惡的耶利哥城施行審判；GT《靈修版聖經注釋》說神所有規定的目的都是要保持百姓的信仰和宗教不被污染。KC 說神並沒有不公義，耶利哥每一個人都和喇合一樣有機會相信，神已經等候了四百年（創15:13）。幾份來源都補上界線：CT 說新約信徒持的是屬靈兵器（林後10:4-5），GT《綜合解讀》說神並沒有命令新約信徒發動聖戰。GT《丁道爾聖經注釋》在第24節另提一個文本觀察：第19、24節的財物清單像驗收單而非實得清單，並問第21節要殺的人是否也屬這種性質。
- 與本章關聯：這一節是本章最短、也是最多註釋要處理的一節。經文只有一句話，四套來源合起來為它寫了全章篇幅最長的一段。
