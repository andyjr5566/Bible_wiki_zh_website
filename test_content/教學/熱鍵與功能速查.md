# ⌨️ 熱鍵與功能速查

> 隨時按 `?` 開啟熱鍵面板（仿 GitHub 風格）。

## 全域熱鍵

| 熱鍵 | 功能 | 備註 |
|---|---|---|
| `Ctrl/⌘ + K` | 開啟**全文搜尋** | 顯示前 30 字摘要並高亮關鍵字 |
| `Ctrl/⌘ + Shift + K` | 開啟**標籤搜尋** | 只搜尋 frontmatter tags |
| `?` | 開啟**熱鍵面板** | 顯示全站熱鍵總覽 |
| `Esc` | 關閉任何開啟的面板 | 搜尋、overlay、popover |

## 搜尋語法

### 全文搜尋（`Ctrl/⌘ + K`）

- 直接輸入關鍵字 → 全文比對
- 支援**語意搜尋**（本站獨有）：輸入概念詞（如「神的榮耀降臨」）會找到語意相近的條目，不只字面比對
- 結果用 `↑↓` 瀏覽、`Tab/Shift+Tab` 切換類別、`Enter` 跳轉

### 標籤搜尋（`Ctrl/⌘ + Shift + K`）

- 輸入 `#標籤名` → 只顯示有該標籤的頁面
- 例如 `#人物` 列出所有人物條目
- 支援多標籤：`#人物 #摩西`

### 搜尋排除清單

以下檔案不會出現在搜尋結果中（技術性頁面）：
`index`、`readme`、`install-computer`、`install-mobile`、`license`、`changelog`、`contributing`、`code-of-conduct`

## UI 元件速查

### 左側欄

| 元件 | 功能 |
|---|---|
| **探索（Explorer）** | 樹狀檔案總管，點資料夾直接進入索引頁 |
| **🔍 搜尋** | 開啟搜尋面板 |
| **🌓 主題** | 明/暗切換 |
| **📖 閱讀模式** | 隱藏側邊欄，專注閱讀 |

### 文章區

| 元件 | 功能 |
|---|---|
| **麵包屑** | 顯示當前頁路徑（首頁不顯示） |
| **文章標題** | frontmatter title 或 H1 |
| **frontmatter 區** | 顯示 description、tags、aliases |
| **右側目錄（TOC）** | 自動從 H2/H3 生成 |
| **反向連結（Backlinks）** | 列出所有連到當前頁的頁面 |

### 互動行為

| 動作 | 效果 |
|---|---|
| **hover wiki-link** | 浮現小預覽（不用跳頁） |
| **點 wiki-link** | 跳轉到目標頁（SPA，不重新整理） |
| **點資料夾** | 進入該資料夾的索引頁（folder-page 元件） |

## 行動版差異

- 沒有熱鍵（行動裝置無鍵盤）
- 左側欄收合為漢堡選單
- 右側目錄改為頁面頂部展開
- 觸控 hover 改為長按預覽

## 進階功能（已停用但可開啟）

以下功能在 `quartz.config.yaml` 中目前停用，未來可能啟用：

- **圖譜（Graph）** — 視覺化知識網絡（目前只啟用 local graph）
- **標籤列表（Tag List）** — 側邊欄顯示所有標籤雲
- **近期更新（Recent Notes）** — 顯示最近修改的頁面
- **留言（Comments via giscus）** — GitHub Discussions 留言
