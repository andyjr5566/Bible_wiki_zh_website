# 虹

## 定義

神與挪亞立約的記號（創九13-17）。虹原文即「弓」，形狀如弓，方向朝向天而非朝向地——神立約的目的是安慰，非恫嚇。

## 主題發展

### 虹的意義

- 保證神不再以洪水毀滅全地
- 每逢雲彩蓋地出現彩虹，神便「記念」祂的約（九14-16）
- **虹＝弓**（原文），形狀如弓，方向朝向天而非朝向地——神立約的目的是安慰，非恫嚇
- 虹是日光的反映，象徵神的信實，以祂的公義為後盾（瑪四2）

### 主要給神看

- 當雲彩蓋地時，地上暗無天日，人看不見彩虹
- 但神在天上看見，受約束不毀滅一切活物
- 彩虹在苦難中象徵平安、喜樂、祥和（約十六20-22、33）

### 豫表意義

彩虹在啟示錄四2-3再次出現，保證**祝福隨審判而來**。虹豫表基督——惟有藉著祂才有祝福的可能。

### 彩虹是本章才出現的新現象嗎？

五份來源在這一點上四比一分歧：

| 來源 | 立場 |
|---|---|
| GT 丁良才《創世紀註釋》 | 「先前未必無虹，當時神才把虹當作立約的證據」 |
| GT《啟導本聖經創世記註釋》 | 「『虹』不是現在才出現。神只是指定天上的虹為立約的記號」 |
| GT《聖經精讀本──創世記註解》 | 認為主張以前從未出現過彩虹「這是無理的解釋」，並以神與亞伯拉罕立約時指著天上已有的星星起誓（十五5）作類比 |
| CT | 「這裏不是說虹在雲中出現是洪水之後才有的現象，而是說此時神才以虹當作立約的記號」 |
| GT《創世記雷氏研讀本》 | 唯一的反方：「極可能是一種新的自然現象，而這現象的產生是由於洪水後大氣層和雲霧狀況的改變」 |

《舊約背景註釋》從記號的性質給出判準，可解釋為何多數來源不需要虹是新的：「以虹為立約的記號，並不表示它是前所未見的第一道天虹。記號的作用得視乎它所代表的意義。」它並舉割禮為平行例——割禮被指定為與亞伯拉罕立約的記號，「卻是古已有之的習俗，不是亞伯拉罕一家的新創」。

### 古代近東背景

GT《舊約背景註釋》列出兩項外證，都與洪水或弓的意象相關：

- **《吉加墨斯史詩》**：女神伊施他爾指著項鍊的天青石起誓，宣稱永遠不會忘記洪水的日子。背景註釋另註明天青石（lapis lazuli）是「一種深藍色含有金色黃鐵礦成分的準寶石」。
- **主前十一世紀的亞述浮雕**：雲中伸出兩隻手來，「一手賜福，另一隻手卻握著弓」。背景註釋指這個意象很有趣，因為譯作天虹的字眼同時亦可解作弓這件武器。

第二項與 CT 的讀法在同一個字上交會，卻走向不同重點：CT 注意弓的**方向**（朝天而非朝地，故是安慰不是恫嚇），背景註釋注意弓的**並置**（賜福的手與持弓的手同時從雲中伸出）。
