# 基督之新婦（豫表）

## 定義

『基督之新婦（豫表）』是指註釋把聖經中新郎與新婦、婚姻與配偶的故事，讀成基督與教會聯合的豫表。這個讀法由新約回望所建立：保羅在弗5:31-32 引用創2:24「二人成為一體」，指明夫妻聯合的奧祕是指著基督和教會說的，使舊約的婚姻敘事成為解釋基督與教會關係的原初圖像。

註釋最常用來說明這個讀法的，是創2 亞當與夏娃、創24 以撒娶利百加這兩段。

## 主題發展

### 從創2 到創24

在創2，CT、KC 與 BH 都將亞當沉睡、肋骨造女人、以及女人被帶到男人面前（創2:21-22），整理為基督受死、藉復活生命建造教會、教會歸給基督的豫表。亞當與夏娃的一體（創2:24），預示了基督與教會在生命上的聯合。

到了創世記第24章，這幅圖畫在以撒娶妻的歷史中展開。KC 說創24 是三一神為聖子得著新婦的工作，發起在父（創24:1-9），僕人是聖靈的圖畫（創24:10-61），新婦是與主耶穌聯合的教會（創24:62-67）。CT 再把利百加的身分與作為逐項對到教會，見下表。

### CT 列的八項對應

CT〈利百加豫表教會是基督的新婦〉把對應逐項標出，每一項都指得回經文：

| 教會的特徵 | 利百加的對應 |
|---|---|
| 有基督的生命 | 她與以撒同族（創24:4） |
| 得自世界 | 她在米所波大米（創24:10） |
| 貞潔的童女（林後十一2） | 她還是處女（創24:16） |
| 與神的性情有分（彼後一4） | 她具有美好的品格（創24:18-19） |
| 雖未曾見祂，卻是愛祂（彼前一8） | 她願隨老僕人而去（創24:58） |
| 有無數的屬靈兒女 | 作千萬人的母（創24:60） |
| 歷經世途艱難 | 她隨老僕人長途跋涉（創24:61） |
| 使基督得到滿足 | 她使以撒得了安慰（創24:67） |

丁良才另給了一份三欄的對照，把以撒比作主耶穌（獨生子、承受產業、如同從死復活、與父同住、迎接新婦）、僕人比作聖靈（在遠方招新婦、專誇美父富子榮、將禮物賜新婦、引新婦至迦南）、利百加比作信徒（親自定意、憑著信心、撇下所有、走往迦南、隨僕引導、新郎歡迎）。

### 這個讀法從哪裡取得根據

KC 指出兩處經文使它站得住。其一是創24:67 說以撒娶了利百加並愛她；KC 說這是聖經第二次說到愛，第一次是父對子（創22:2），這一次是夫對妻，因此後者被讀成基督與教會之愛的圖畫。其二是撒拉與利百加的接替：KC 說撒拉被利百加取代了，照樣，教會取代了以色列。KC 在創24:1-2 也說得很清楚：新婦必須從亞伯拉罕所出之地被領來，而以撒留在應許之地；照樣，主耶穌留在天上，聖靈則在地上預備教會去迎見她的新郎。

CT 從新婦的來歷讀出同一件事：亞伯拉罕要老僕人為以撒娶妻，「乃豫表父神起意要為祂的獨生愛子（基督）娶妻，就差遣聖靈在與祂愛子具有相同肉身的人（『本族』）中間尋找合適的對象」。

### 分寸

KC 自己給了一條限定：創24 所呈現的不是教會被提與主同在；相會的地點是**帳棚**，而帳棚說的是寄居。因此這幅圖畫講的是父與聖靈如今就在地上作工，要教會在聖子裡尋得她的一切，並且現在就與祂有交通——不是末了那一幕。

另一條分寸來自敘事本身：這一整套對應是新約回望所建立的讀法，創世記二十四章記的是一樁婚事的談判與成行。兩個層次都值得保留，但不宜互相取代。
