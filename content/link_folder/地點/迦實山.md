# 迦實山

## 定義

約書亞葬地的方位標記。書24:30「以色列人將他葬在他地業的境內，就是在以法蓮山地的亭拿西拉，在迦實山的北邊」；士2:9 記同一件事，作「以法蓮山地的亭拿希烈，在迦實山的北邊」。

STEP 顯示書24:30 是 har- Ga.'ash（H2022G 加 H1608，簡要詞典義 ga.ash: Gaash）。CT 給的字義是「震動」，說確實地點不詳，大概在亭拿西拉境內的南邊。GT 所引華爾頓與《約書亞記研經資料》說它的位置雖然不明，卻應該在以法蓮山地亭拿西拉（蒂布納廢墟）以南，在示劍西南二十哩左右，研經資料作32公里左右。BH 說迦實山標出約書亞墳墓的位置，確實地點今天已不確定，並連到撒下23:30、代上11:32 的「迦實溪」。

- 本章重點：第30節約書亞葬在以法蓮山地的亭拿西拉，在迦實山的北邊。STEP 為 Ga.'ash（H1608）。CT 給字義「震動」，說確實地點不詳，大概在亭拿西拉境內的南邊；GT 華爾頓與《研經資料》說應在亭拿西拉（蒂布納廢墟）以南，示劍西南約二十哩；BH 說確實地點今天已不確定，連到撒下23:30、代上11:32 的迦實溪。
