# 收生婆的回話是否說謊

## 定義

出埃及記1:19 記收生婆對法老說：「因為希伯來婦人與埃及婦人不同；希伯來婦人本是健壯的（原文是活潑的），收生婆還沒有到，她們已經生產了。」第20至21節緊接著說「神厚待收生婆」「神便叫她們成立家室」。這段回話是不是謊言，若是，神為什麼還賜福，是本章各家分歧最大的一點。

分歧的起點是經文自己沒有評價這句話。CT 說得最節制：「注意聖經並沒有表明這話是說謊或是事實，也沒有稱許她們的靈巧。」

## 按書卷累積

### 出埃及記

<!-- accumulation:出埃及記:1:start -->
#### [[02 出埃及記/第1章|第1章]]
- 本章重點：第19節收生婆對法老的回話，以及第20至21節神隨即賜福，構成本章最常被追問的難題：這話是不是謊言，若是，神為何厚待她們。
- 與本章關聯：CT 與 GT 丁良才都把賜福的理由釘在「敬畏神」而非話術上；《靈修版》歸於救了無辜嬰孩；賈斯樂郝威與艾基斯以義務衝突與兩害相權為她們辯護；《中文聖經註釋》從原文母音指出「活潑的」可讀為「多產的」，使這話有字面成立的可能；KC 則認為這種推測本身不必要。

## 主題發展

### 這句話本身是真是假

GT 丁良才《出埃及記註釋》把它拆開判：「這話頭一句是真的，下兩句是過實的，收生婆無非要洗自己的手，好保全性命。」GT 艾基斯《舊約聖經難題彙編》則主張這話在字面上可以成立：收生婆採取的是一種「延遲抵達」的策略，「當他們接到將臨盤的希伯來婦女的召喚時，卻遲遲才出發前往接生」，因此「若站在收生婆遲遲才抵達產婦家的這觀點看來，這說話可能是正確的，他們只是沒有說出延遲抵達是預先已安排計劃好了」。

GT《中文聖經註釋》從原文提出第三種讀法：和合本小字作「原文作活潑的」，但「希伯來文原來是無母音的……在原文『活潑的』這字 ha{yo^th 的 y 字母上，只要加上一個點號，就成了 ha{yyo^th，意義就完全變了——成為『多產的』」，而「初胎容易難產，多產以後就很順產，所以收生婆還未趕到，孩子已經生下」。CT 也記這個字「按原文含有兩種意思：(1)身體健壯滿有活力，故易順產；(2)富有歷練的多產婦，故生產容易」，並補上社會層面的解釋：希伯來婦人多屬勞動階層，埃及婦人則多屬嬌生慣養的富貴階層。

### 神為什麼賜福

| 來源 | 賜福的理由 | 對「說謊」的處理 |
|---|---|---|
| CT | 「因為她們敬畏神，不肯聽從法老的吩咐，去奪取嬰孩的性命，而不是因為她們說謊話欺騙法老」 | 「本章聖經並未指稱收生婆說謊」 |
| GT 丁良才 | 「是因為她們敬畏訑，不聽從法老的吩咐，不是因為用偽言欺哄了法老」 | 明說下兩句「是過實的」 |
| GT《靈修版聖經註釋》 | 「神賜福是因為她們救了許多無辜嬰孩的生命」 | 「神不是因人撒謊而賜福……並不意味撒謊必定是應付法老最好的方法」 |
| KC | 「經文清楚地說：神厚待收生婆」 | 「有人推測這些婦人是否可以使用『危難時的謊言』。這種推測是不必要的。」 |
| GT 賈斯樂郝威《聖經難解經文詮釋手冊》 | 「就是因為她們『敬畏神』，使她們必須作出保護男嬰的行動」 | 承認她們違抗並欺騙，但主張「她們如此行在道德上是有正當的理由」 |
| GT 艾基斯《舊約聖經難題彙編》 | 「乃是她們自願地不顧個人安危，以拯救那些無辜的嬰孩的性命」 | 「神沒有為這兩個勇敢的婦人掩蓋一部份事實而祝福她們」 |
| BH | 神因她們敬畏神、行事公義而賜福 | 未判定真假，只說她們的回答是一種公民抗命 |

### 兩害相權的立論，與拒絕這場思辨的立論

GT 賈斯樂郝威把它處理成義務衝突：收生婆「只有兩條路可走：不是遵行神最高的旨意，就是屈服於法老的命令」，而「神要我們遵守政府的權柄，但祂也命令我們不可殺人（出20:13）。保護無辜的生命比服從政府的義務更重要」。GT 艾基斯用的是同一個結構、更明確的用語：「兩惡相衡，她們正確地選了較低程度的惡，以避免犯那更大的惡。」

KC 則不接受這個提問方式。他舉喇合為例——她藏起探子並向追捕者說謊，「但神把她的行動判定為信心的行為」（來11:31；雅2:25）——並下一句警告：「一般來說，對於我們並不了解的處境中信徒的某些行為，下判斷是很容易的。因此在這樣的情況下，我們作出定罪的宣告要非常小心。否則我們可能是在與神為敵。」

GT《新舊約輔讀》把焦點整個移開：「雖然聖經沒有告訴我們19節的話之真確性，但卻告訴我們，神賞賜她們所做的。她們之所以如此做是因為她們敬畏神。」GT《串珠聖經註釋》則把它留成一道問題：「收生婆向法老說謊，為什麼仍蒙神祝福？這是否表示信徒在某些情況下可以隱瞞真相？」
