# 肥尾巴
## 定義

巴勒斯坦一帶所產的綿羊尾巴特別肥大，脂肪最多。利未記 3:9 規定獻綿羊為平安祭時，「其中的脂油和整肥尾巴都要在靠近脊骨處取下」。原文是 אַלְיָה（H451），STEP 的詞典義即「fat tail」；「靠近脊骨」用的是 עָצֶה（H6096，脊椎）。CT 的〔原文字義〕另註明「整」＝完全的、健全的——整條尾巴，不是切一段。

**它到底有多重？五份材料給的數字差距很大，一併列出比取單一數字誠實：**

| 來源 | 說法 |
|------|------|
| CT | 假如所獻的羊羔體積龐大，肥尾巴可重七公斤或以上 |
| GT 丁良才 | 猶太國的綿羊是寬尾巴的，和中國的綿羊一樣，這肥尾巴在時重十幾斤 |
| GT《啟導本》 | 羊尾藏脂甚厚，有的尾巴重達 30 公斤 |
| GT《舊約聖經背景註釋》 | 本區綿羊的尾部長達四至五呎，重達五十磅 |
| GT《利未記雷氏研讀本》 | 巴勒斯坦地主要品種之東方綿羊的肥尾巴，可重達四十八至七十三磅（22～33公斤） |
| BH | 這在古代近東是牲畜身上珍貴的部位，常重達數磅 |

差距來自品種與個體大小，各家並非彼此否定。共通的一點是：這是羊身上最肥、也最被看重的部位。KC 說它是「特別的美味」。

肥尾巴屬脂油的範疇，因此歸耶和華焚燒（利3:9、16）。

## 按書卷累積

### 利未記

<!-- accumulation:利未記:3:start -->
#### [[03 利未記/第3章|第3章]]
- 本章重點：利3:9 規定獻綿羊為平安祭時，「其中的脂油和整肥尾巴都要在靠近脊骨處取下」。CT 說明這是巴勒斯坦一帶綿羊的特徵——尾巴特別肥大、脂肪最多，所以獻為供物（參出29:22）。
- 與本章關聯：本章把綿羊與山羊分成兩段條例（v6-11 與 v12-16），差別只有一項。CT 講得很明白：「燔祭的羊不分綿羊、山羊（參一10），而平安祭將綿羊和山羊分別記述，是因為綿羊有肥尾巴，山羊則無。」丁良才的說法相同：兩段的分別「只在燒整肥尾巴上」。也就是說，這兩段條例之所以要寫兩遍，全是為了這條尾巴。KC 另從預表讀它：肥尾巴是特別的美味，指向主耶穌工作中信徒特別領受、特別要告訴神的那一面。
<!-- accumulation:利未記:3:end -->

<!-- accumulation:利未記:7:start -->
#### [[03 利未記/第7章|第7章]]
- 本章重點：v3「又要將肥尾巴和蓋臟的脂油」——本節屬贖愆祭條例（1-10節），肥尾巴列在贖愆祭要焚燒的部位之中。
- 與本章關聯：利3:9 的肥尾巴只出現在綿羊平安祭，本章則顯示贖愆祭同樣要獻上肥尾巴。兩章合看，肥尾巴不是平安祭專有的部位，而是凡用綿羊為祭牲時都隨脂油一同上壇的部分。

#### [[03 利未記/第8章|第8章]]
- 本章重點：利8:25「取脂油和肥尾巴」，肥尾巴與臟上一切脂油、肝網、腰子、右腿一同構成承接聖職祭中歸神焚壇的上好部分。
- 與本章關聯：利3、7章確立肥尾巴屬平安祭牲上好部分、須焚於壇上，本章承接聖職祭（平安祭之特殊形式）同樣列入肥尾巴，確認此條例的一貫適用。

## 主題發展

肥尾巴出現在利未記的四個地方，範圍逐步擴大：平安祭的綿羊（利3:9）、贖愆祭（利7:3）、承接聖職祭（利8:25）、祭司就職後百姓的平安祭（利9:19）。牛與山羊沒有這個部位，所以牛（利3:1-5）與山羊（利3:12-16）的條例裡都不列它。它與其他脂油一樣被歸入「耶和華的食物」（利3:11、16）——CT 指出，凡把全部或一部分供物燒在壇上的都稱為火祭，肥尾巴就在這一部分裡面。
