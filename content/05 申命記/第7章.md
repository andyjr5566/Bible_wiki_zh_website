1. 耶和華─你神領你進入要[[征服迦南應許|得為業之地]]，從你面前趕出許多國民，就是[[赫人]]、[[革迦撒人]]、[[亞摩利人]]、[[迦南人]]、[[比利洗人]]、[[希未人]]、[[耶布斯人]]，共[[迦南七族（迦南地原住民）|七國的民]]，都比你強大。
2. 耶和華─你神將他們交給你擊殺，那時你要把他們[[滅絕（herem）|滅絕淨盡]]，不可與他們[[立約禁令|立約]]，也不可憐恤他們。
3. 不可與他們[[申命記7_3-4 禁止與迦南人通婚|結親]]。不可將你的女兒嫁他們的兒子，也不可叫你的兒子娶他們的女兒；
4. 因為他必使你兒子轉離不跟從主，去事奉別神，以致耶和華的怒氣向你們發作，就速速地將你們[[滅絕（herem）|滅絕]]。
5. 你們卻要這樣待他們：拆毀他們的[[古代近東祭壇|祭壇]]，打碎他們的[[柱像]]，砍下他們的[[亞舍拉（木偶）|木偶]]，用火焚燒他們[[不可為自己雕刻偶像|雕刻的偶像]]。
6. 因為你歸耶和華─你神為[[聖潔的國民|聖潔的民]]；耶和華─你神從地上的萬民中[[神的揀選|揀選]]你，特作[[屬我的子民|自己的子民]]。
7. 耶和華[[專愛（cha.Shak）|專愛]]你們，[[神的揀選|揀選]]你們，並非因你們的人數多於別民，原來你們的人數在萬民中是最少的。
8. 只因耶和華愛你們，又因要守他向你們列祖所起的誓，就用[[大能的手]][[出埃及|領你們出來]]，從為奴之家[[救贖]]你們脫離埃及王法老的手。
9. 所以，你要知道耶和華─你的神，他是神，是[[神的信實|信實的神]]；向愛他、守他誡命的人守約，[[發慈愛直到千代|施慈愛]]，直到千代；
10. 向恨他的人當面報應他們，將他們[[滅絕（herem）|滅絕]]。凡恨他的人必報應他們，決不遲延。
11. 所以，你要謹守遵行我今日所吩咐你的誡命、律例、典章。
12. 你們果然聽從這些典章，謹守遵行，耶和華─你神就必照他向你列祖所起的誓守約，[[發慈愛直到千代|施慈愛]]。
13. 他必愛你，[[祝福與咒詛|賜福]]與你，使你人數增多，也必在他向你列祖起誓應許給你的地上賜福與你身所生的，地所產的，並你的五穀、新酒，和油，以及牛犢、羊羔。
14. 你必[[祝福與咒詛|蒙福]]勝過萬民；你們的男女沒有不能生養的，牲畜也沒有不能生育的。
15. 耶和華必使[[聽命順從蒙醫治|一切的病症]]離開你；你所知道[[聽命順從蒙醫治|埃及各樣的惡疾]]，他不加在你身上，只加在一切恨你的人身上。
16. 耶和華─你神所要交給你的一切人民，你要將他們除滅；你眼不可顧惜他們。你也不可事奉他們的神，因這必成為你的[[網羅]]。
17. 你若心裡說，這些國的民比我更多，我怎能趕出他們呢？
18. 你不要懼怕他們，要牢牢記念耶和華─你神向法老和埃及全地所行的事，
19. 就是你親眼所看見的大試驗、神蹟、奇事，和[[大能的手]]，並伸出來的膀臂，都是耶和華─你神[[出埃及|領你出來]]所用的。耶和華─你神必照樣待你所懼怕的一切人民。
20. 並且耶和華─你神必打發[[黃蜂]]飛到他們中間，直到那剩下而藏躲的人從你面前滅亡。
21. 你不要因他們驚恐，因為耶和華─你神在你們中間是大而可畏的神。
22. 耶和華─你神必將這些國的民從你面前[[逐漸趕出|漸漸趕出]]；你不可把他們速速滅盡，恐怕野地的獸多起來害你。
23. 耶和華─你神必將他們交給你，大大的擾亂他們，直到他們[[滅絕（herem）|滅絕]]了；
24. 又要將他們的君王交在你手中，你就使他們的名從天下消滅。必無一人能在你面前站立得住，直到你將他們[[滅絕（herem）|滅絕]]了。
25. 他們[[不可為自己雕刻偶像|雕刻的神像]]，你們要用火焚燒；其上的金銀，你不可貪圖，也不可收取，免得你因此陷入[[網羅]]；這原是耶和華─你神所憎惡的。
26. 可憎的物，你不可帶進家去；不然，你就成了當毀滅的，與那物一樣。你要十分厭惡，十分憎嫌，因為這是[[滅絕（herem）|當毀滅的物]]。

## 本章整理

### 七族、審判與信仰界線（v1-5）

本章從一個力量懸殊的場面開始。以色列將進入應許之地，面前的[[迦南七族（迦南地原住民）|七國之民]]比他們強大；經文卻把主動者寫成耶和華，是祂領百姓進去，也是祂把列國交在他們手中。這使[[征服迦南應許]]與人的軍力分開：以色列沒有憑民族優勢取得土地，反而是在明知自己較弱的情況下領受命令。

第2節的「滅絕淨盡」需要放回這個特定場景理解。STEP 語言資料顯示，הַחֲרֵ֤ם 與 תַּחֲרִים֙ 屬 H2763A，本節的 context gloss 分別是確實要完全毀滅和你要完全毀滅；詞元 חָרַם（cha.ram）的 lexicon 義域是 to devote/destroy。這些資料說明[[滅絕（herem）|滅絕淨盡]]的語言強度，歷史對象與適用範圍則由全段界定。CT 對同節用語的說明是：「『立約』即容許和平共存；『憐恤』意指不忍殺滅。」GT、KC 與 BH 又把創世記所說[[亞摩利人罪孽滿盈]]的背景帶進來，將戰事理解為對迦南罪惡的審判，而非以色列本身比較良善。

第3至5節把命令的信仰焦點說得更具體。[[立約禁令]]之後緊接著[[申命記7_3-4 禁止與迦南人通婚|禁止與迦南人通婚]]，理由就在第4節：婚姻會使下一代轉離耶和華，去事奉別神。GT《啟導本》的原句是：「禁婚只限嫁娶迦南人，純屬宗教原因。」族裔優越並非本段提出的理由。隨後要拆毀[[古代近東祭壇|祭壇]]、打碎[[柱像]]、砍下[[亞舍拉（木偶）|木偶]]、焚燒[[不可為自己雕刻偶像|雕刻的偶像]]，也顯示問題集中在迦南宗教對以色列約忠誠的侵蝕。

[[迦南滅絕命令的歷史範圍]]因此必須保留經文給出的四重限定：進入迦南的時刻、明列的七族、已到審判的罪惡，以及使以色列轉向偶像的危險。KC 把以色列描述為執行這次特定審判的一方，並在談到今日教會時提醒信徒要向未信者施恩行善；BH 也明確把命令放在迦南征服的特殊位置，沒有把它當作歷代通行的行為規則。這段經文不能成為今日對其他民族或未信者施暴的常規授權。

### 聖潔、專愛與守約信實（v6-11）

嚴厲命令的下一句把焦點轉到以色列作為[[聖潔的國民|聖潔的民]]，沒有稱讚他們強盛。聖潔在這裡有分別歸神的意思；[[神的揀選]]使他們成為[[屬我的子民|神自己的子民]]，也要求他們在敬拜上專一。第7節立刻堵住一種可能的驕傲：神揀選他們並非因人數眾多，他們原是萬民中最少的。第8節把原因放在神的愛與祂向列祖所起的誓，並以[[出埃及]]和[[救贖]]證明祂已在歷史中履行所說的話。

本段的原文亮點是[[專愛（cha.Shak）|專愛]]。STEP 確認第7節字形為 חָשַׁ֧ק，transliteration 是 cha.Shak，Strong 編號是 H2836A，morphology 為 HVqp3ms，context gloss 是 he loved。Lexicon 把 חָשַׁק（cha.shaq）的可能義域列為 to desire。這些是詞形與義域資料；第7至8節的上下文進一步確定本節所說的是耶和華把愛放在以色列身上。CT 說「『專愛』指一種強烈傾心的愛」；GT《啟導本》也逐字指出：「祂愛以色列人不是因為人數多，或是有甚麼美德（九4～6）。這兩樣以色列人都沒有。」KC 與 BH 都從整段強調，這份愛的起點在神自己與祂的應許，不在以色列可供誇耀的條件。

第9至11節把愛帶進約的關係。耶和華是[[神的信實|信實的神]]，向愛祂、守祂誡命的人守約，[[發慈愛直到千代|施慈愛直到千代]]；祂也向恨祂的人施行審判。這兩面都出自祂對約的信實。第11節的謹守遵行是蒙愛之民應有的回應，經文沒有把人的順服寫成神最初揀選他們的原因。先有神主動的愛、向列祖所起的誓與出埃及的救贖，然後才有百姓在約中愛神、聽命的生活。

### 土地中的福分與健康應許（v12-16）

第12節由「聽從」開頭，接著展開一幅應許地生活的全景：人口增多，兒女生養，土地出產五穀、新酒和油，牛羊繁殖，疾病遠離。這些福分都發生在神向列祖起誓所賜的地上，因此[[祝福與咒詛]]在此帶有清楚的土地與盟約背景。GT《串珠》寫道：「五穀，新酒和油」：巴勒斯坦主要農產品，象徵富足和豐收。GT《啟導本》更指出，人與牲畜的生育、土地的出產來自耶和華的賜福，並非巴力或亞舍拉所賜。

第15節把健康列入這組約中應許，形成[[聽命順從蒙醫治]]的重要材料。它首先應按本段讀作神對以色列在應許地中的保護。若據此認定凡患病的人都因不順服，便超出了經文在這裡設定的對象，也忽略了 KC 對今日讀者的明確提醒：患病本身不能作為不順服的證明。四套來源都處理「埃及各樣的惡疾」，對它所指的內容留下不同說法：

| 來源 | 對「埃及各樣的惡疾」的理解 |
|---|---|
| CT | 「『惡疾』指痛苦且難治的病症。」 |
| GT《雷氏研讀本》 | 「包括眼炎、痢疾、天花和象皮病。」 |
| GT《串珠聖經註釋》 | 「埃及各樣的惡疾」：可指十災或埃及人常患的疾病。 |
| KC | 提醒今日信徒，疾病本身並不能證明人不順服；它把埃及病症作屬靈應用時，談的是人離開神後舊有態度重新顯露。 |
| BH | 較偏向把這句連到出埃及時臨到埃及的災害，視為神過去審判與保護以色列的記憶。 |

這幾種理解可以並列保留。CT 著重病症的嚴重，GT 同時保存具體地方疾病與十災兩案，BH 偏向出埃及災害，KC 則補上今日應用的界線。第16節再次提到偶像會成為網羅，說明約中福分與敬拜忠誠仍連在一起；健康應許沒有脫離本章對土地、偶像和盟約的整體討論。

### 記念勝過恐懼，征服按步展開（v17-24）

第17節把外在戰場轉進人的心裡：這些國的民比我更多，我怎能趕出他們？摩西沒有否認敵人強大，而是吩咐百姓牢牢記念法老、埃及、大試驗、神蹟奇事，以及神的[[大能的手]]和伸出來的膀臂。CT 對第18節的說明是：「袪除恐懼心理的要素是信靠神，不看自己也不看敵人，已過的經歷可以加深對神的信心。」過去的拯救成為面對新威脅的依據；百姓所倚靠的，是那位已經領他們出來、如今仍在他們中間的大而可畏之神。

第20節的[[黃蜂]]沒有得到四家一致的單一解釋，這個分歧本身值得保留：

| 來源 | 黃蜂的理解 |
|---|---|
| CT | 「『黃蜂』一種巨大且具攻擊性的毒蜂，表徵神所使用的各種天然災害。」 |
| GT《雷氏研讀本》 | “黃蜂”。實在指黃蜂這種昆蟲，或指埃及的軍隊。 |
| GT《串珠聖經註釋》 | 「黃蜂」：為隱喻寫法，描述一種從神而來，叫敵人感到驚惶紛亂的強大力量。 |
| BH | 偏向把黃蜂理解為神使敵人陷入恐懼或驚慌的形象，同時承認神也能使用自然界作工具。 |

真實昆蟲、埃及軍隊、天然災害與神所引起的恐慌，都是來源中實際存在的解釋。經文共同指向的核心較清楚：連躲藏的殘敵也不能避開神的介入。材料不足以把「黃蜂」裁成其中唯一一案。

第22節又修正人對得勝速度的想像。神應許把列國[[逐漸趕出|漸漸趕出]]，理由非常實際：若土地太快空下來，野獸會增多並危害百姓。CT 說：「『漸漸趕出』意指按照自己佔有並掌控的能力，逐步趕走敵人，以免土地荒廢，惡獸出沒。」KC 將過程概括為趕出一段、居住一段，再往前趕出；BH 同樣強調土地需要有人管理和安置。神的能力沒有因過程漸進而減少，祂的安排同時照顧勝利、居住能力與土地秩序。

### 偶像的金銀與當毀滅之物（v25-26）

最後兩節回到偶像，並把危險推進家門。雕刻的神像要焚燒，即使上面有金銀，也不可貪圖或收取，因為金銀會使人陷入[[網羅]]。本章前面已說不可事奉迦南人的神；這裡進一步處理看似可以留下的財物。偶像的價值外觀不能解除它與受禁敬拜的關聯。GT《雷氏研讀本》以一個極短的歷史提醒收束：「亞干違反這個勸告（書七1）。」KC 也把亞干列為警戒，說明把禁物留下並非無害的小事。

STEP 在第26節辨識出兩次 חֵ֖רֶם／חֵ֥רֶם，transliteration 為 Che.rem，Strong 編號是 H2764A，morphology 為 HNcmsa，context gloss 是 an object for destruction；lexicon 將 חֵ֫רֶם（che.rem）的可能義域列為 devoted thing。第2節使用 H2763A 的動詞命令，第26節則以 H2764A 名詞指向當毀滅之物。這項語言差別幫助讀者看見，命令既涉及行動，也涉及不可私取的對象。

CT 對第26節的原文是：『可憎的物』和『當毀滅的』乃是同義詞，又稱「當滅的物」(書六8；七1，11)；『與那物一樣』即指凡私自收取那物的人，便成了當滅的人。因此本章的終點落在一個嚴肅的關聯上：人若把受禁之物帶進自己的生活，也會把自己置於那物所屬的審判範圍。從第1節的七族到第26節的家中物件，整章持續追問以色列如何在神所賜的土地上，保持對這位專愛、守約之神的忠誠。
