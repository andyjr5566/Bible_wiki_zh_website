# 基拉耳

## 定義

基拉耳（Gerar），非利士人的古城。原文意為「停止地、寄居地、反芻、反復思想、被拖曳而去」。位於加低斯和書珥中間，迦薩以南約16公里。亞伯拉罕和以撒都曾寄居此地。

## 主題發展

### 位置：來源之間差了四倍

各家給的距離不一致，值得原樣並陳：

| 來源 | 所給位置 |
|---|---|
| GT《啟導本聖經創世記註釋》 | 迦薩南16公里 |
| GT《創世記雷氏研讀本》 | 迦薩以南約十英里（16公里） |
| GT《串珠聖經註釋》 | 「離開非利士人的迦薩只有四公里（三英里）」 |
| 丁良才 | 非利士人的古城，在迦撒以南 |

前兩者一致，串珠差了四倍。經文本身沒有給距離。

### 背景註釋：確實地點無法肯定

GT《舊約背景註釋》〈創二十1 基拉耳〉的態度最保留：基拉耳的**確實地點無法肯定**，只知是在尼革西部（創十19），**甚至可能是地區而非城邑的名字**。它也指出一項地理事實——基拉耳並不在加低斯和書珥之間的直線範圍內，但對遊牧為業者如亞伯拉罕一家，這說不上是很遠的距離。

至於考古對應，背景註釋說大部分考古學家基於主前一五五○年至一二○○年間這地區極受埃及影響的理由，指出**別是巴西北十五哩的哈羅珥遺址（Tel Haror，阿拉伯語稱阿布胡雷勒遺址 Tell Abu Hureireh）**可能就是基拉耳。這是候選對應而非確立的辨識。

### 一個譯讀選項

丁良才提出本節或可作「住在加低斯和書珥中間，寄居在基拉耳」（和合譯本初版），即先住前者、後寄居後者，而不是說基拉耳位於兩地之間。若採這個讀法，背景註釋所指出的直線範圍問題就不存在。

### 原文字義與靈意的分界

CT 給的原文字義是「停止地，寄居地，反芻，反復思想，被拖曳而去」。它並在此基礎上發展出一套靈意：基拉耳位於埃及與迦南之間，因此預表「良知的世界」，人憑良知與肉體的掙扎不能進入神的國。這是特定的靈意解讀，與地理資料屬於不同層次，兩者不宜混為一談。

在正典裡基拉耳出現兩次同型事件：亞伯拉罕在此稱妻為妹（創20），以撒也在此稱妻為妹（創26:1-11），兩次都遇上名為亞比米勒的王（見[[亞比米勒名字與王號]]）。
