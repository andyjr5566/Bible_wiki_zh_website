# 乳母底波拉

## 定義

利百加的乳母。創世記二十四59 記家人打發利百加時，她的乳母同行；經文在此沒有記名，GT 丁良才《創世紀註釋》、GT《啟導本聖經創世記註釋》與 GT《串珠聖經註釋》都據創三十五8 認定她就是底波拉——「就是從小把她撫養成人的奶媽底波拉」。她後來在伯特利雅各的家裡去世，葬在伯特利下邊的橡樹底下（創三十五8）。

## 主題發展

### 乳母為什麼會同行

GT《舊約背景註釋》〈創二十四59 同行的乳母〉說明了這個安排的三重意義：預備要與富人結婚的女子「應當有成群奴僕隨行」；乳母自小撫育她，「因此地位特別高」；而她會同行成為新家的一份子，「並且在途中擔任護送之職」。

換句話說，她的隨行不是感情上的陪伴而已，而是身分、照顧與護送三件事一次到位。第61節另提到「利百加和她的使女們」——GT《串珠聖經註釋》註明那是陪伴她的使女，與乳母是不同的一群人。

### 她的名字要到十一章之後才出現

本章只稱她「乳母」，直到創三十五8 才記下名字與死訊：「利百加的奶母底波拉死了，就葬在伯特利下邊橡樹底下；那棵樹名叫亞倫巴古。」GT《啟導本聖經創世記註釋》把兩處接起來——她一直跟隨利百加，並照顧她的孩子，後來在雅各的家裡去世。

一個從哈蘭跟到迦南、又活到下一代成家的人，經文只給了兩節：一節記她出發，一節記她安葬。
