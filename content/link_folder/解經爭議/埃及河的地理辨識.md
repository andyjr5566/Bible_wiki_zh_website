# 埃及河的地理辨識

## 定義

創世記15:18以「埃及河」作應許地南界。主要看法是指西奈東北的埃及小河、今日阿里什乾河；另一看法指尼羅河或其東部支流。

- 本章重點：土地範圍從埃及河延伸到伯拉大河幼發拉底河。

## 主題發展

### 五份來源，四種立場

這是本章來源分歧最徹底的一處，值得逐一列出而不必調和：

| 來源 | 立場 |
|---|---|
| GT《串珠聖經註釋》 | 直接註「埃及河：即尼羅河」 |
| GT 丁良才《創世紀註釋》 | 「這埃及河大概是尼羅河」；若是如此，本句便是概略的話，意即從埃及國到亞述國（參耶二18）——但他同時記下另一說：也有人以為是在迦南和埃及國界上流入地中海的那條小河（民三十四5，書十五4、47，王上八65，賽二十七12） |
| GT《啟導本聖經創世記註釋》 | 明確否定尼羅河：「不是尼羅河，而是迦南地迦薩南部的一條小河，很可能是今天西奈半島東北的艾拉瑞西河（Wadi el-Arish）」，並指這是歷代以來以色列與埃及之間的國界 |
| GT《舊約背景註釋》 | 以色列西南疆土通常以「埃及小河」（乾河，即僅在雨季有水的河床）為界，據考證是西奈東北部的阿里什乾河（民三十四5），「不太可能是尼羅河」；另一可能是尼羅河三角洲最東面注入西爾博尼斯湖的支流 |
| GT《創世記雷氏研讀本》 | 傾向尼羅河，並提出唯一的語言學論據：「這裏使用的河字是指『大河』。要形容一條不是長年有水的溪流，所用的字是不同的，而該字的意思是『小河』」 |

### 爭點在哪裡

阿里什乾河說的支撐是疆界經文的一致性——民34:5、書十五4、47 等處劃迦南南界時用的正是「埃及小河」，而阿里什乾河確實長期是以色列與埃及之間的界線。尼羅河說的支撐則是本節的用字：雷氏指出創十五18 用的字是「大河」而非「小河」，若作者要指一條季節性乾河，本可以用另一個字。

兩邊各自站得住，而且爭的其實是兩件事：**用字**支持尼羅河，**疆界慣例**支持阿里什乾河。丁良才的處理最持平——他先說「大概是尼羅河」，隨即補上另一說，並指出若採尼羅河，這句話就是概略之詞，意思是「從埃及國到亞述國」，而不是精確的水文界線。

值得注意的是，同一節的北界毫無爭議：「伯拉大河」四份來源一致指幼發拉底河。南界之所以成問題，正因為「埃及河」這個詞本身在舊約裡不是固定術語。章內宜保留諸說並標明主流辨識，不要用一個譯名把爭議收掉。
