# 吃兒女的肉（極端饑荒的咒詛）

## 定義

利未記26章29節只有一句話：「並且你們要吃兒子的肉，也要吃女兒的肉。」它排在第五層警告的開頭，是整章語氣最重的一節。

GT《舊約聖經背景註釋》說明這種描述為什麼會被寫進條約式的咒詛裡：「只有在極端絕望和瀕臨饑饉的情況下，才會導致古代近東的人採取食人的下策。本段和申命記二十八53～57的咒詛部分，以及主前七世紀的亞述條約包括這一點，以求顯示神對悖逆之人的懲罰，是何等的可怕。」也就是說，這一句在當時的文體裡有它固定的位置，用來標示咒詛的極限。

GT 丁良才列出歷史上的應驗：王下六28-29（撒瑪利亞被圍）、耶十九8-9、哀二20、哀四10，並指出「羅馬人毀滅耶路撒冷城的時候就有這樣殘忍的事」。GT《聖經精讀本》把它接回前一節的饑荒描述，指申二十八53-57 早已警告「甚至人們會因饑荒吃自己所生的孩子」，而「這種悲慘境況，在以色列歷史中時常發生」。

KC 讀出的重點是人倫的崩壞：饑餓「越來越啃噬人心，逼得人淪落到吃人的可怕地步」，「自私自利大到一個地步，所有天然的親情都消失了」——並補上一句對照：兒女不只被獻給偶像，「在這裡他們純粹是為了活命而被犧牲」。BH 從文化禁忌的角度定性：在古代近東，這類行為「被視為可憎，並且經常被看作神的審判」，而經文提到的是「兒子與女兒」，強調的是家族傳承的斷絕，因為在古以色列「兒女被視為祝福與家系的延續」。

CT 對這一節的註解只有一句：「吃兒女的肉表示飢荒非常嚴重。」在〔靈訓要義〕中，他把它列在第四層禍之下，並給了一個屬靈的對照：「弟兄姊妹相咬相吞。」

- 本章重點：v29 宣告極端饑荒下食子女的慘況；GT《舊約聖經背景註釋》指此為古代近東條約咒詛的固定極限描述（另見申28:53-57 與主前七世紀的亞述條約），丁良才列出王下6:28-29、哀2:20、哀4:10 與羅馬毀城時的應驗。
