# 使用者要求的體驗回復

日期：2026-09-10。修改前 HEAD：`99a8b0d5`。真正分支建立前版本：`a0c47e3f`（以 Git reflog 確認）；`c0aefae8` 已是分支建立後的修改。

本次依使用者要求撤回造成體驗退步的部分，取代繼續擴張 R00–R24 功能的工作方向。這不是 R24 全規格通過宣告。

| 項目 | 處理 |
| --- | --- |
| 器物側倒、零件散開 | 撤回器物模式自動切換 structural/detail 的行為；恢復完整會幕內六器物及分支前各自的取景座標。移除細節模型與未對齊部件的操作入口。 |
| 開場運鏡 | 恢復分支前八幕相機路徑；五站手動導覽仍獨立保留。明確啟動自動導覽時播放相機動畫，暫停、繼續、重播、退出可用。 |
| 鏡頭被中斷 | 同模式的其他 UI 狀態更新不重設相機；模型遲到的載入完成回報不覆蓋正在播放的鏡頭；退出恢復原模式取景。 |
| 中央大字卡 | 修正 3D 尺寸標籤隨鏡頭接近而放大的問題，預設關閉標尺、按需開啟；移除中央互動提示；底部僅顯示正式經文的一節節錄，全文由使用者展開。 |
| 操作過於繁雜 | 回到總覽、五站導覽、器物與經文三個主入口；六器物選擇置頂；來源與尺寸細節收合。撤下新增程序播放、角色卡、五祭比較的入口。 |
| 可保留修正 | 正式經文抽取、來源與授權資料、載入取消與釋放、較節制的光影及粒子、鍵盤與手機基本支援。 |
| 標尺效能 | 同一器物與單位不再每幀重建幾何與文字貼圖；切换單位才重建。 |
