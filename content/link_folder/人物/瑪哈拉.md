# 瑪哈拉

## 定義

以實瑪利的女兒、尼拜約的妹子。以掃看出父親不喜悅迦南女子後，在原有二妻之外又娶她為妻。創世記三十六章3節稱她為巴實抹。

瑪哈拉的婚姻顯出以掃試圖用親近亞伯拉罕血統的方式挽回父親歡心；但他沒有離開原有婚姻，也沒有真正明白應許之約的承接不只在血統或外在模仿。

## 主題發展

### 她是誰

CT 註「瑪哈拉」的原文字義為「豎琴，溫和」；BH 也作「弦樂器」「里拉琴」。她是以實瑪利的女兒、尼拜約的妹子，也就是亞伯拉罕的孫女——以掃在原有二妻之外所娶的第三個妻子（創二八9）。

GT 丁良才《創世紀註釋》記下一個名字上的線索：「她的妹子瑪哈拉又名巴實抹（創三六3）」——與以掃另一個赫人妻子巴實抹同名，這正是創三六章要用別名「亞大」區分的原因（見[[以掃有幾個妻子]]）。

### 這樁婚事的性質

各家對以掃此舉的評價一致。GT 丁良才說他娶本族的女兒為妻「似乎有一點悔改的心；但他的意思不過是要討父母的歡喜，並沒有向神悔改」。GT《聖經精讀本──創世記註解》列出兩項錯誤：以實瑪利家族雖是亞伯拉罕的血統，卻是從神的祝福中分離出來、在立約之外的民族；而他原有的妻子既沒死亡又沒離婚，他卻因要得祝福的野心，輕忽神定下的一夫一妻制。

KC 的說法最短：這首先是「額外的一個妻子」，而那從來不是神的心意；其次，這是從一個被亞伯拉罕打發走的家族（創二一9-14）娶妻——以實瑪利代表肉體的作為，以掃把自己與之連結。GT《創世記雷氏研讀本》另注意到一個事實：以掃入贅以實瑪利家的時候，並沒有拋棄他的外邦妻子。

CT 把這件事的邏輯講得最清楚：以掃既知父親的心意是要雅各娶母親哥哥的女兒，「所以為了討他父親的歡心，就去娶父親哥哥的女兒」；若按出生順序，以實瑪利和以掃都是長子，「所以這個婚姻乃是兩個長子的聯盟」——但這絕不能使他們有資格承受長子的名分。

本條目目前以人物身分與家族關係為主，後續可按創世記三十六章補充其別名及後裔資料。
