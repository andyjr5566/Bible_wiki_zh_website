# 創世記 第23章

1. [[撒拉]]享壽一百二十七歲，這是撒拉一生的歲數。
2. [[撒拉]]死在迦南地的[[基列亞巴]]，就是[[希伯崙]]。[[亞伯拉罕]]為他哀慟哭號。
3. 後來[[亞伯拉罕]]從死人面前起來，對[[赫人]]說：
4. 我在你們中間是外人，是[[寄居者身份|寄居的]]。求你們在這裡給我一塊地，我好埋葬我的[[死人]]，使他不在我眼前。
5. [[赫人]]回答[[亞伯拉罕]]說：
6. 我主請聽。你在我們中間是一位尊大的王子，只管在我們最好的[[墳地]]裡埋葬你的[[死人]]；我們沒有一人不容你在他的墳地裡埋葬你的死人。
7. [[亞伯拉罕]]就起來，向那地的[[赫人]]下拜，
8. 對他們說：你們若有意叫我埋葬我的[[死人]]，使他不在我眼前，就請聽我的話，為我求瑣轄的兒子[[以弗崙]]，
9. 把田頭上那[[麥比拉洞]]給我；他可以按著足價賣給我，作我在你們中間的[[墳地]]。
10. 當時[[以弗崙]]正坐在[[赫人]]中間。於是，赫人以弗崙在城門出入的赫人面前對[[亞伯拉罕]]說：
11. 不然，我主請聽。我送給你這塊田，連田間的洞也送給你，在我同族的人面前都給你，可以埋葬你的死人。
12. [[亞伯拉罕]]就在那地的人民面前下拜，
13. 在他們面前對[[以弗崙]]說：你若應允，請聽我的話。我要把田價給你，求你收下，我就在那裡埋葬我的[[死人]]。
14. [[以弗崙]]回答[[亞伯拉罕]]說：
15. 我主請聽。值[[四百舍客勒]]銀子的一塊田，在你我中間還算什麼呢？只管埋葬你的死人吧！
16. [[亞伯拉罕]]聽從了[[以弗崙]]，照著他在[[赫人]]面前所說的話，把買賣通用的[[銀子]]平了[[四百舍客勒]]給以弗崙。
17. 於是，麥比拉、幔利前、[[以弗崙]]的那塊田和其中的洞，並田間四圍的[[樹木]]，
18. 都定準歸與[[亞伯拉罕]]，乃是他在[[赫人]]面前並城門出入的人面前買妥的。
19. 此後，[[亞伯拉罕]]把他妻子[[撒拉]]埋葬在迦南地幔利前的麥比拉田間的洞裡。（幔利就是[[希伯崙]]）。
20. 從此，那塊田和田間的洞就藉著[[赫人]]定準歸與[[亞伯拉罕]]作[[墳地]]。

## 本章整理

### 撒拉之死（1-2節）

撒拉享壽一百二十七歲——聖經中唯一記載壽數的女人，表示她一生的年日蒙神記念；此時以撒三十七歲，距亞伯拉罕離開吾珥六十二年（GT）。自亞伯拉罕受割禮（創17）至撒拉死，其間約三十八年，令人聯想以色列人在曠野繞行三十八年（申2:14；CT 靈意）。要注意本章另有一個三十八年，指的是另一件事：GT《聖經精讀本──創世記註解》說撒拉「比亞伯拉罕早去世38年」——一個算的是割禮到她死，一個算的是她死到亞伯拉罕死。

新約對她的評語，兩家都補上了。精讀本說她是立約後裔的母親，也是所有信神之人的母親（賽五十一2），一生跟隨丈夫過寄居的生活（來十一13），聖經並記錄了她神聖的品德（彼前三6）。KC 補上一項容易被忽略的分別：來十一11 也提到**她自己的**信心，「她不像羅得那樣倚靠亞伯拉罕的信心」——她走完了整段旅程，六十二年都是外人與寄居的，兩人一同抵達目標，在彼此的信實上也是如此（彼前三5-6）。


她死在迦南地的[[基列亞巴]]，就是[[希伯崙]]。兩個地名的字義要分開——「同盟、友誼」是希伯崙的字義，不是基列亞巴的：

| 名稱 | 來源 | 字義 |
|---|---|---|
| 基列亞巴 | CT | 四方城，偉人之城 |
| 基列亞巴 | GT《舊約背景註釋》 | 「四之村」；可能指四個村落聯合而成的城鎮，或幾條大道在此交會 |
| 基列亞巴 | BH | 名字來自亞巴，「亞衲族中最偉大的人」 |
| 希伯崙 | CT | 同盟，友誼 |

三說共通的是「四」與「偉人」這兩個成分，分歧只在哪一個是主。

亞伯拉罕為她「哀慟哭號」——「哀慟」指裏面的情緒，「哭號」原文是大聲哀號（CT）；這是聖經中亞伯拉罕第一次流淚的記錄（KC）。GT《聖經精讀本──創世記註解》指出這同時是一種儀式：送葬的人們面對屍體，坐在地上哀哭（撒下三31；二十一10）（[[古代近東安葬習俗]]）。但它隨即說明儀式不等於形式——亞伯拉罕回憶與撒拉的過去時光所流的是真心哀悼的眼淚，「決不是一般葬禮儀式上的悲傷眼淚」，並把它接到主耶穌為拉撒路哭泣（約十一35）；聖經強調復活的盼望，是要讓人克制過度的悲傷，不是取消悲傷（帖前四13）。CT 在第3節另註古時中東人的習俗：哀號者是俯伏在死者面前的，然後就起身準備辦理後事——第3節「從死人面前起來」記的正是這個動作。撒拉存著信心而死（來11:11、13）；信徒為親人哀傷是正常的，但不像沒有指望的人過度憂傷（帖前4:13-14）——自然的眼淚與信心兼容。
GT《舊約背景註釋》為兩個地名的關係留了一個問號：地名會因新人種進入或值得紀念的事件而改變（如耶布斯與耶路撒冷、路斯與伯特利），而希伯崙與基列亞巴（「四之村」）之間的關係「並不清楚」——它可能指四個村落聯合而成的城鎮，也可能指幾條大道在此交會。GT 丁良才《創世紀註釋》另注意到敘事上的一個空白：前一章記亞伯拉罕還在別是巴，「我們不知道撒拉怎樣會死在希伯崙」——經文沒有交代這段移動。GT《聖經精讀本──創世記註解》則點出經文刻意強調的一件事：撒拉不是死在非利士地，而是死在迦南地。


希伯崙在哪裡，各家給的方位與距離並不一致：

| 來源 | 方位與距離 |
|---|---|
| CT | 位於耶路撒冷之西南 |
| GT 丁良才《創世紀註釋》 | 耶路撒冷以南五十餘里，比地中海高出三百零四丈 |
| GT《串珠聖經註釋》 | 耶路撒冷以南三十二公里（二十英里） |
| GT《創世記雷氏研讀本》 | 耶路撒冷以南二十二英里（三十五公里） |
| GT《舊約背景註釋》 | 耶路撒冷西南約十九哩，別是巴東北二十三哩，海拔約三千三百呎 |

方位有正南與西南兩說，距離從十九哩到二十二哩不等。丁良才另註這城最古（民十三22）；背景註釋補上它為何重要——它是通往東面拉吉和北面耶路撒冷兩條古道的會集之處，當地的泉水和井水足以種植橄欖、葡萄，並應付創世記二十三章所形容的那種半農牧經濟的需要。

### 求購墳地與寄居者身份（3-9節）

亞伯拉罕從死人面前「起來」——哀哭有時，但信心使人不被憂傷吞噬（KC）。他對[[赫人]]承認自己是「外人，是[[寄居者身份|寄居的]]」（4節）——憑現實承認地位，非憑應許自居；雖然神應許迦南全地歸他，此時卻連一塊葬身之地都沒有（來11:13；彼前2:11）。

赫人稱他為「[[尊大的王子]]」（CT 註原文字義是「神的王子，有神威的王子」，呂振中譯作「有神威的族長」）——他在外邦人中蒙神眷顧、受人敬重，與被藐視的羅得成對比（創19:9；KC）。但他們表面慷慨的「只管用我們最好的墳地」實為外交辭令，意在避免外人購置永久性土地（CT）。
本章的「赫人」究竟是誰，是創世記裡最常被提出的年代難題之一，而三份來源給了互相補充的處理。GT《舊約背景註釋》先把事實擺清楚：迦南赫人的名字屬閃族語系（本章的以弗崙、瑣轄都是），而安那托利亞的赫人卻有印歐語系的名字，因此「在敘利亞和迦南居住的赫人，可能和歷史上有名的赫人有關，但也可能無關」；它並指出亞述與巴比倫的記錄經常稱巴勒斯坦為「哈提地」，證實了這地與這些人之間的關係。

GT 賈斯樂郝威《聖經難解經文詮釋手冊》在〈命題44〉正面回答「赫人為何在主前2050年已在希伯崙」：他指出在有爭議的史跡之前，安那托利亞本有一個非印歐語系的民族被印歐語系的入侵者征服，而在閃族文字（如希伯來文）中只寫子音，Hatti 與 Hitti 書寫相同；因此赫人帝國雖到主前十四世紀後半葉才臻全盛，仍有足夠證據顯示他們在亞伯拉罕的時代曾在希伯崙出現。GT 艾基斯《舊約聖經難題彙編》把同一論證做得更細：加帕多家的庫爾泰培（古代的卡尼什）出土了亞述商人主前1950至1850年間留下的楔形文字商業泥版；而在說 Nesili 語的印歐移民到來之前，當地已有非印歐背景的赫人種族定居，入侵者在主前2300至2000年間征服他們後採用了他們的族名。艾基斯並引研究赫人的學者加爾尼的主張——原本的赫人不只居留在小亞細亞，還在遠至巴勒斯坦南部的地方建立起殖民地——以及科維爾1936年根據墨西里斯二世文件所作的推論。他最後補上一句方法上的話：以弗崙與瑣轄看來都是閃族迦南名字，正顯示這些希伯崙的赫人「如何容易被當地的文化所同化」。

三說的共同結論不是「已經證實」，而是「不能據現有文獻斷言不可能」。這與第21章非利士人的爭議是同一型的難題，處理方式也應相同：文獻的最早出現不等於存在的最早時間。


亞伯拉罕兩次下拜（7、12節）——古代近東禮儀上的謙恭，不是敬拜（BH）。他不繞遠路，直接指名向[[瑣轄]]的兒子[[以弗崙]]購買田頭上的[[麥比拉洞]]。CT 為這幾個名字都註了原文字義：「瑣轄」白的、「以弗崙」強壯、「麥比拉」羊圈，倍數，成雙——最後一個字義有三種讀法，而「羊圈」是通行的「雙倍」之外另一個少被引用的選項。他堅持「按著足價」，並堅持「按著足價」——不要人情壓力，避免日後糾葛；恩典不叫我們可以不顧公義。

### 以弗崙的談判（10-16節）

以弗崙在城門出入的赫人面前說「我送給你這塊田，連田間的洞也送給你」（11節）——中東以退為進的買賣手段（CT）：按赫人法規，僅出售部分土地，原主仍須負擔整塊田的稅賦與義務（GT），故他要亞伯拉罕連田帶洞整塊買下。
GT《聖經精讀本──創世記註解》把這條法規講得更明確：依赫族法律（The Hittite Code），凡擁有土地的人都要擔負國家的軍事義務，但只擁有土地一小部分的人沒有這種義務——責任落在擁有大部分土地的人身上。亞伯拉罕本只想買一個洞，以弗崙便以此為由要他買下整塊田，等於把稅金與軍事責任一併轉出去。GT《創世記雷氏研讀本》給的是同一件事的另一面說法：以弗崙若只賣洞，就仍要負責繳付整塊地的稅項。

GT《舊約背景註釋》再補一層更根本的產權背景：可作農田的土地是極貴重的財產，原本不可賣給親族以外的人，只有在族中缺乏買方、或從生意角度十分可行時，才出售給沒有關係的外人；為避免法律問題，買方可以被認為養子，村中長老也可以代表買方向業主提出請求。這正解釋了亞伯拉罕為何先向全體赫人開口、再請他們代為向以弗崙求（8節）——那不是客套，而是程序。背景註釋並點出亞伯拉罕拒收餽贈的法律理由：若接受贈與，以弗崙死後他的繼承人就有追回土地的權利。


以弗崙開價[[四百舍客勒]]銀子（15節），與其他聖經交易對照：

| 交易 | 價格 |
|---|---|
| 麥比拉田與洞（本章） | 400舍客勒銀子 |
| 大衛買禾場和牛（撒下24:24） | 50舍客勒銀子 |
| 耶利米購地（耶32:9） | 17舍客勒銀子 |
| 奴隸身價（創37:28） | 約20舍客勒 |
| 僱工年資（背景資料） | 約10舍客勒 |

估價顯然過高，但亞伯拉罕沒有討價還價（16節）：全額付款可確保永久產權，避免給以弗崙的後人留下追討口實（舊約背景註釋）；在承受應許之日來到以前，他不肯佔別人便宜（CT）。他用「買賣通用的[[銀子]]」——商用標準砝碼，公正無欺（GT/BH）。GT《聖經精讀本──創世記註解》為「一定要付田價」補了一個本章沒有明說的理由：這是為了保護屍體的安全，以防日後以弗崙可能變卦；在眾人面前付價，就明確了土地的所有權（撒下二十四24）。它並指出當時的公證方式：雖然那時已有最初的文字，聖經幾次強調的卻是「在眾人面前公布約定內容」，因此這可能是口頭簽約的形式，或是在書面買賣約定書之外並行的公證程序。
四百舍客勒到底貴到什麼程度，GT《舊約背景註釋》換算得很具體：約等於七又四分之一磅銀子；相較之下暗利買下撒瑪利亞城址用了六千舍客勒，大衛買聖殿地皮用六百舍客勒金子，禾場本身只賣五十舍客勒，耶利米購置產業更只花十七舍客勒。它的結論很不客氣：亞伯拉罕所付的價錢「與其說是得到什麼折扣，不如說是昂貴到荒謬的程度」；而每年只有十舍客勒的僱工和匠人，窮其一生也無法賺得這麼多金錢。GT《串珠聖經註釋》另引漢摩拉比法典佐證當時工價：一個工人的日薪為一舍客勒銀子。GT《舊約背景註釋》也說明「買賣通用的銀子」不是虛詞——大約同時之古亞述貿易信件的用語顯示，這句話指的是陸上貿易標準的秤銀方法。

背景註釋對整場談判的評語同樣值得記下：討價還價是近東的標準生意手段，富於娛樂性與競爭性，「但當買方陷於不得不買的處境，或是極想交易時，賣方可以用盡談判所提供的優勢」。亞伯拉罕正是在這個處境裡——妻子的遺體還停在那裡。


### 交易完成與埋葬（17-20節）

麥比拉田、洞、四圍的[[樹木]]都「定準」歸亞伯拉罕（17-18節）——界線清楚劃定，在赫人及[[城門口交易|城門出入的人]]面前買妥，有公開的法律保障。此後亞伯拉罕把「他妻子撒拉」葬在麥比拉田間的洞裡——他埋葬的是「我的死人」、「他妻子撒拉」，不是「遺體殘留」；身體就是那個人（KC；約19:40-42）。

這塊田在[[幔利]]前——本章把幔利、希伯崙與麥比拉三個地名一次並列（17、19節），CT 註希伯崙「後和幔利混為一城」。希伯崙後來成為族長家族的祖墳：亞伯拉罕（創25:9）、以撒、利百加、利亞（創49:29-31）、雅各（創50:13）皆葬於此。古代近東以洞穴墳為常見，多代共用（[[古代近東安葬習俗]]）；至於今日的現況，來源只說到這一步——GT 丁良才《創世紀註釋》說「這洞如今還在。回回教人在這洞上築了一座清真寺」，GT《創世記雷氏研讀本》說有兩個山洞被辨識為麥比拉洞原址，位置一個在另一個之上，「現在都在希伯崙一座大清真寺之下」。
GT《舊約背景註釋》把當時的安葬習俗分成兩類：遊牧民族有「第二次安葬」的習慣——在死後很久，將骸骨搬運到傳統的墳地安葬；鄉村文化則使用塚室，即天然或開鑿出的山洞或地下多室墓穴，大多數墓室使用好幾代，屍體與陪葬物（食物、陶瓷、武器、工具）安放在預備好的平台上，化成骸骨後再搬到另一墓室、放進骨罐或掃到墳墓後面，好騰出空間安葬下一位。這正是「麥比拉」（雙重）之名可能的由來之一——GT《聖經精讀本──創世記註解》列出三種解釋：有兩個入口的洞、可同時埋葬兩人的大洞，或洞中有洞的雙層洞穴。GT《創世記雷氏研讀本》另記今日的現況：有兩個山洞被辨識為麥比拉洞原址，位置一個在另一個之上。

丁良才在第4節下處理了一個真正的難題：本章記亞伯拉罕在希伯崙向赫人以弗崙買地，創三十三19 記雅各在示劍向哈抹子孫買地，而徒七16 卻說亞伯拉罕用銀子從哈抹的子孫買了一塊墳地。他的調和分三步：其一，徒七16 所指的可能是創世記未記載的另一次購地，地點在示劍——那正是神初次向亞伯拉罕顯現、他初次築壇之處（創十二6-7）；其二，本章所買的是幔利（希伯崙）的麥比拉田與洞，撒拉、亞伯拉罕、以撒、利百加、利亞、雅各都葬在此；其三，一百二十年後雅各在示劍用一百塊銀子向哈抹子孫買地築壇（創三十三18-20），丁良才推想哈抹的子孫可能一度佔了亞伯拉罕早年所購的墳地，雅各不願相爭而把地買回，後來亞摩利人又霸佔，雅各才用弓刀奪回（創四十八22）；約瑟與眾兄弟最後正是葬在示劍那塊地（書二十四32；徒七16）。這是調和方案而非經文明說，引用時應標明性質；但它至少說明兩處記載未必互相排斥。


關鍵事實：神應許賜迦南全地為業，但亞伯拉罕此時所得唯一的永久性產業，竟是一塊[[墳地]]——應許地的初熟果子。神所應許的產業不止於地上（來11:8-16）；購地安葬正是他對神應許不動搖的信心：先有死與安葬，才有將來的復活與得地。

### 信徒與世人交往的五要（CT）

1. 表明自己只是寄居的（4節）——不堅持權利
2. 對人謙恭有禮（7節）——兩次下拜
3. 不佔別人的便宜（8-9節）——堅持按足價付錢
4. 要有智慧（10-16節）——聽得出話中的話
5. 一切手續辦得清清楚楚（17-18節）——有憑有據

### 埋葬與復活的神學（KC）

> [!quote] KC
> 埋葬就是撒種，撒種是為著收成——「埋葬」與「復活」相連，而不是與「死亡」相連（林前十五3-4）。

| 要義 | 說明 |
|------|------|
| 埋葬＝種下 | 種子埋入土裏等候收割，死亡不是終結 |
| 復活次序 | 林前15:20-21——在基督裏的人都要復活 |
| 身體就是人 | 「我的妻子撒拉」而非「遺留物」；約翰福音記「把耶穌安放」而非「遺體」 |
| 神知道祂子民在哪裏 | 以色列如今看似枯骨（結37），但神知道他們的位置 |
| 全額買贖 | 亞伯拉罕付足價；神也用獨生子的血付足了買贖世界的代價 |
| 埋葬與焚燒 | 埋葬連於復活盼望；焚燒在舊約多連於審判（書7:25；利21:9） |
