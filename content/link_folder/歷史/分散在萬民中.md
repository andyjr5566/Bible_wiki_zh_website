# 分散在萬民中

## 定義

申命記4:27 是摩西在第一篇講章結尾說出的一句預言：「耶和華必使你們分散在萬民中；在他所領你們到的萬國裡，你們剩下的人數稀少。」

**CT 讀出兩層意思。** 〔原文字義〕：「分散」散開，打碎；「稀少」男人。文意註解：「意指被擄散住在萬民當中」，而「剩下的人數稀少」意指「失去神的賜福，不再繁茂、強盛（參出一7），終至滅亡」。

**GT 把應驗年代寫了出來。** GT《聖經精讀本》：「以色列人因在迦南地犯了敬拜偶像的罪，結果，北以色列於 B.C.722 被亞述所毀，南猶大則於 B.C.586 被巴比倫所滅並擄去，至此，此預言完全得到了成就。自那之後，約過了二千五百年之後以色列百姓才又重建『以色列』這一國度，然而，至今為止，其後裔依然散居世界各地。」

GT《雷氏研讀本》另指出這是本書第一次出現這個預言：「摩西在此首次預言，以色列人若證實為不順服神，便要從應許地被除去。」

**BH 補上一個神學上的轉折。** 「The scattering serves as both a punishment and a means to preserve a remnant that will eventually return to God.」（分散既是刑罰，也是保存餘民的手段，那餘民終將歸回神。）

**GT《啟導本》把這段的對比列得最整齊。** 「不但得不到美地，反會被滅絕；不是進入迦南，而是分散萬國；不是人丁繁盛，而是人數稀少。」——三組全部是應許的反面。

## 按書卷累積

### 申命記

<!-- accumulation:申命記:4:start -->
#### [[05 申命記/第4章|第4章]]
- 本章重點：第27節「耶和華必使你們分散在萬民中⋯你們剩下的人數稀少」。CT〔原文字義〕「分散」散開，打碎；「稀少」男人，並解為被擄散住在萬民當中、不再繁茂強盛。GT《聖經精讀本》：北以色列於 B.C.722 被亞述所毀，南猶大則於 B.C.586 被巴比倫所滅並擄去，至此此預言完全得到了成就。GT《雷氏研讀本》：摩西在此首次預言以色列若不順服便要從應許地被除去。GT《啟導本》：不是進入迦南，而是分散萬國；不是人丁繁盛，而是人數稀少。BH：分散既是刑罰，也是保存餘民的手段。
- 與本章關聯：本節接在「速速滅盡」「盡行除滅」之後，是那段判詞的第三步；第28節再往下推到在異地事奉木石之神。但第29-31節緊接著給出路，所以這句預言在本章不是終局。
