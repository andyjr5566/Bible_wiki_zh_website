# 亞伯拉罕買麥比拉洞 (創23)

## 定義

創世記23章記載亞伯拉罕為妻子撒拉買麥比拉洞作墳地，向赫人以弗崙以四百舍客勒銀子購得。這是聖經記載第一筆迦南地合法產業交易，建立「買地立約」的先例。雅各在創33:19買示劍地（一百客西達銀子）、創34底拿事件後約瑟歸葬此地（書24:32），承襲此傳統。

## 主題發展

### 華爾頓為什麼把兩處並列

GT 華爾頓《創世記背景註釋》在創卅三19 下把本章的買地直接接到創世記二十三章：「本節的土地交易與創世記第二十三章一樣，都是包括了實數（一百塊銀子），表示這是有契約的轉讓，不是付錢租用這地。」

兩處的共同點有三：都詳記價錢（麥比拉洞四百舍客勒，示劍地一百客西達）、都是與當地居民的正式交涉、都在族長尚未擁有全地時取得一小塊。

### 第三個共同點才是重點

華爾頓補上一句：「和創世記第二十三章一樣，這地至終也是用作墳地（見書二十四32）。」

麥比拉洞葬了撒拉、亞伯拉罕、以撒、利百加、利亞，最後是雅各（創四九29-32、五十13）。示劍那塊地葬了約瑟（書二四32）。

族長在應許之地實際持有的產業只有這兩塊，兩塊都是墳地。應許的是全地，手上的是兩座墓——這個落差是族長敘事一直沒有消解的張力，來十一13 稱他們「都是存著信心死的，並沒有得著所應許的」。

### 一個要留意的差別

麥比拉洞是亞伯拉罕主動要求購買的（創二三4「我在你們中間是外人，是寄居的，求你們在這裏給我一塊地，我好埋葬我的死人」）——他買地是為了埋葬撒拉，目的明確。

雅各買示劍地不是為了埋葬，是為了居住：第18節他「在城東支搭帳棚」，第19節買下「支帳棚的那塊地」。GT 丁良才《創世紀註釋》的判斷是：「雅各買地就顯明他預備在那裡居住。」

同樣的交易形式，動機不同；而正是這個居住的動機，成了各家對雅各此刻屬靈狀態評價分歧的焦點（見[[疏割居住是否屬靈倒退]]）。

### 徒七16 把兩件事併在一起說

使徒行傳七16 說列祖葬在「亞伯拉罕在示劍用銀子從哈抹子孫買來的墳墓裡」——把示劍的買主寫成亞伯拉罕，等於把兩樁交易合成一樁。

GT 倪柝聲《聖經問答》正是用這個角度來解：亞伯拉罕買地（創廿三）和雅各買地中間約隔八十年，雅各「重新再買其祖所已買的」。GT 丁良才則主張兩個哈抹不是同一人（見[[買示劍地的買主是亞伯拉罕還是雅各]]）。

兩種解法都建立在同一個前提上：這兩樁交易在功能上是同一類東西。

- 信心的行動：神應許全地、族長買部分作定金/保證
- 產權轉移法律程序：公開、立契、付銀、證人
