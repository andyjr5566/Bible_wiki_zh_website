# 宰殺燒牛的血彈會幕前方七次作贖罪見證

## 定義

在以色列神聖祀典裡，當純紅母牛被引率往孤涼寂遙的會營境外進行宰滅當時，上帝特意委由亞伦的大兒子繼承祭司以利亞撒出征執行祭職，要用鮮淨指尖蘸取溫厚滿生命活威的大血，回面遙看天主聖顏臨在的見證帳房前方，揚臂連續揮彈七次紅雨；這儀程不僅奠下無上完全的贖罪恩義，更證實一切潔除生活沾惹死靈污黑的力量皆直接溯源於神前羔羊全死長流之得勝功德。
