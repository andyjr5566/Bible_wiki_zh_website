# ⚙️ 專案設定與參數目錄 (Config)

本目錄集中存放聖經研讀知識庫網站的各項客製化設定與參數檔案，供你隨時自主調整，無需翻找或修改深層程式碼：

| 設定檔案 | 說明 |
| :--- | :--- |
| **`collapse-rules.txt`** | **段落收合規則設定**：決定文章中哪些標題（如「本章知識節點」、「按書卷累積」）在網頁上要預設收合、哪些是「按書卷分組」的段落（徽章顯示卷數、單層呈現）。 |
| **`interactive-sites.json`** | **互動網站的補充資料**：標題、說明、涵蓋哪幾章，建置時會自動從網站本身推出來，這裡只補推不出來的：類型標籤（`type`，例如場景導覽、查詢工具）、直達某一章的網址樣板（`deepLink`、`deepLabel`，用 `{short}` `{chapter}` `{book}` 代入書卷簡稱、章號、書卷全名）、額外涵蓋的章（`extraChapters`）、封面截圖的裁切範圍（`cover.crop`，只有拍封面的工具會讀）。新網站不用在這裡登記，放進筆記庫同步後就會自動出現，只是沒填的話少一個類型標籤。 |
