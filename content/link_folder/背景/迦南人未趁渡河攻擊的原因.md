# 迦南人未趁渡河攻擊的原因

## 定義

以色列人在書4:13 過河之後，到耶利哥的平原「等候上陣」。從軍事角度看，這是一支剛渡完河、還沒站穩腳跟的隊伍，對岸的迦南人卻沒有趁機出手。四套註釋都注意到這件事，給的理由略有不同。

### 三個可能的原因

GT《丁道爾聖經注釋》用問答的方式列出三點。第一，迦南人或許不確定以色列人會不會過河、或什麼時候會過河——以色列人似乎已在摩押地的什亭安頓下來，過河的行動十分突然，在岸邊停留的時間也很短暫。第二，過河的地點出人意外，在亞當城以南，那裡並不容易涉水而過，如果迦南人要等著攻擊，或許會選擇北邊一帶。第三，在晚銅時期（主前1550至1200年），迦南只有幾個地方人口比較集中，靠近耶利哥平原一帶若有一些民族移入，對這些地方並不會造成威脅；而耶利哥並不是一個主要的聚居之地，那城鎮的居民對以色列人的過河也束手無策。

GT《約書亞記研經資料》把理由收在一句話裡：迦南地的居民沒有出面伏擊以色列人，可能是因為以色列人的過河方式太過離奇，他們沒有想到以色列人這樣神速地通過湍急的河水。它另外從書4:10「百姓急速過去了」推回來，說以色列人自己也是迅速過河，以免遭遇敵人攻擊。

CT 給的是同一組因素的簡短版：以色列人過河的時間、地點和方式都出人意外，迦南人沒有來得及阻擊他們。

### 城的規模

GT《研經資料》另外提供一個數字：當時的耶利哥城估計有1500到2000居民。BH 則把耶利哥形容成扼守以色列進入迦南中部的堅固城，是接下來第一場大仗的目標。

### 兩種急速

書4:10 說百姓急速過去了。GT《約書亞記綜合解讀》給了兩種可能：可能是為了避免迦南人的阻擊，也可能是因為看到神跡，興奮而急切地順服神的命令、進入應許之地。KC 讀到的是後者——在一切預備的安穩之後，過河發生得很快，因為有一股進入應許之地的渴望。

- 本章重點：第13節「到耶利哥的平原，等候上陣」。GT《丁道爾聖經注釋》以問答列出三個可能原因：迦南人或許不確定以色列人會不會過河或何時過河，因為以色列人似乎已在摩押地的什亭安頓下來、過河行動十分突然；過河地點在亞當城以南、出人意外且不容易涉水而過；晚銅時期（主前1550至1200年）迦南只有幾個地方人口比較集中，耶利哥並不是一個主要的聚居之地。GT《研經資料》說迦南地的居民沒有出面伏擊，可能是因為以色列人的過河方式太過離奇、沒想到他們這樣神速通過湍急的河水，並由第10節推知以色列人也是迅速過河以免遭遇攻擊；它另說當時的耶利哥城估計有1500到2000居民。CT 說以色列人過河的時間、地點和方式都出人意外，迦南人沒有來得及阻擊他們。第10節「百姓急速過去了」，GT《綜合解讀》給兩種可能——避免迦南人阻擊，或因看到神跡而興奮急切地順服；KC 說在一切預備的安穩之後過河發生得很快，因為有一股進入應許之地的渴望。BH 說耶利哥的堅固城扼守以色列進入迦南中部的通道，是接下來第一場大仗的目標。
- 與本章關聯：這一節是本章唯一從軍事角度看事情的地方。前面二十節都在講紀念，第13節忽然把讀者帶到耶利哥平原上一支等著開打的軍隊面前——而敵人在整個渡河過程中都沒有出現。
