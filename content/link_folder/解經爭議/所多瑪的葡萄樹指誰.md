# 所多瑪的葡萄樹指誰

## 定義

申32:32-33用一串很兇的比喻收住這段審判：「他們的葡萄樹是所多瑪的葡萄樹，蛾摩拉田園所生的；他們的葡萄是毒葡萄，全掛都是苦的。他們的酒是大蛇的毒氣，是虺蛇殘害的惡毒。」

問題出在「他們」。緊接在前面的申32:30-31講的是以色列的仇敵，申32:34以後又轉回神為自己百姓伸冤，因此這兩節的主詞可以順著兩個方向讀，四套註釋也真的分成兩路。

### 讀成外邦仇敵

CT 說這意指外邦敵人是邪惡的種類，因為深深植根在惡中，所能發出的也是惡毒；申32:33同樣說外邦敵人的享樂乃是有害的毒素。

GT 這一邊有兩份材料同向：《申命記雷氏研讀本》說這裏指出外邦人是出自邪惡的種類，《啟導本聖經申命記註釋》說這裡描寫了敵人的情況，因為深深植根在惡中，所能發出的也是惡毒。

### 讀成以色列自己

GT《聖經精讀本──申命記註解》走的是另一路。它說「他們的葡萄樹」統稱以色列（何西阿書10章1節、約珥書1章7節），並提醒詩篇作者與先知以賽亞曾說神從埃及挪出一顆上好的葡萄樹栽在迦南地（詩篇80篇8節、以賽亞書5章2節）；照這個讀法，所多瑪的葡萄樹意指以色列放棄神之選民的聖潔生活，成為隨從所多瑪與蛾摩拉之淫亂的墮落百姓，毒葡萄則象徵拜偶像等所有罪孽。它並引以賽亞書5章2節那句歎息——指望結好葡萄，反倒結了野葡萄。

BH 也是這樣讀的：這是把以色列人的道德敗壞與所多瑪的惡名並列，說他們採納的作法與價值已經和所多瑪一樣，正好與葡萄樹通常用來代表神選民的意象相反。

### KC 兩種都列

KC 先說申32:32似乎是指以色列那些惡貫滿盈的仇敵，他們罪孽的量已經滿了（創世記15章16節），神因此把他們交在以色列刀下；仇敵的磐石就是他們的神，裡面沒有能力。

接著他說這幾節也可以指以色列自己（詩篇80篇8節）：他們本是被栽的佳美葡萄樹、全然忠信的種子，卻因罪變成外邦葡萄樹的敗壞枝子（耶利米書2章21節），甚至接過並超過了所多瑪與蛾摩拉的罪孽（耶利米書23章14節、以西結書16章48節）；神稱他們為自己的葡萄園、他所喜悅的樹，期待好果子，園子卻結出臭果（以賽亞書5章1至7節）。

### 原文能與不能決定的

STEP 顯示申32:32的用字：mi./Ge.fen se.Dom（H1612 ge.phen: vine 加 H5467 se.dom）、gaf.Na/m（他們的葡萄樹）、u./mi./shad.Mot a.mo.Rah（H7709 she.de.mah: field 加 H6017）、i.ne.vei Ro.osh（H6025 e.nav: grape 加 H7219 ro.osh: poison）、ash.ke.Lot me.ro.Rot（H811 esh.kol: cluster 加 H4846 me.ro.rah: gall）。這些字確認了比喻的內容，但代名詞本身沒有指明對象，所以這一節的歸屬要靠上下文判斷，各家因此分歧。

### 申命記

#### [[05 申命記/第32章|第32章]]
- 本章重點：第32至33節「他們的葡萄樹是所多瑪的葡萄樹，蛾摩拉田園所生的；他們的葡萄是毒葡萄，全掛都是苦的。他們的酒是大蛇的毒氣，是虺蛇殘害的惡毒。」這兩節的「他們」指誰，四家分成兩路。CT 說意指外邦敵人是邪惡的種類，因為深深植根在惡中，所能發出的也是惡毒；GT《申命記雷氏研讀本》說這裏指出外邦人是出自邪惡的種類，《啟導本聖經申命記註釋》說這裡描寫了敵人的情況。但 GT《聖經精讀本──申命記註解》說「他們的葡萄樹」統稱以色列（何10:1、珥1:7），並引詩80:8、賽5:2，說所多瑪的葡萄樹意指以色列放棄選民的聖潔生活；BH 同樣讀成以色列，說這是把以色列的道德敗壞與所多瑪的惡名並列。KC 兩種都列：先說似乎指以色列那些惡貫滿盈的仇敵（創15:16），再說也可以指以色列自己（詩80:8、耶2:21、耶23:14、結16:48、賽5:1-7）。STEP 顯示第32節用字為 mi./Ge.fen se.Dom（H1612 加 H5467）、u./mi./shad.Mot a.mo.Rah（H7709 加 H6017）、i.ne.vei Ro.osh（H6025 加 H7219）、ash.ke.Lot me.ro.Rot（H811 加 H4846）。
- 與本章關聯：這段緊接在第30至31節「他們的磐石不如我們的磐石」之後，第34節又轉回神的府庫與伸冤，主詞因此可以兩讀。本章整理保留兩種讀法並陳，不替四家裁決。
