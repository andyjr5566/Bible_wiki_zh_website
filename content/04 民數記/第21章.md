1. 住南地的迦南人亞拉得王，聽說以色列人從亞他林路來，就和以色列人爭戰，擄了他們幾個人。
2. 以色列人向耶和華發願說：你若將這民交付我手，我就把他們的城邑盡行毀滅。
3. 耶和華應允了以色列人，把迦南人交付他們，他們就把迦南人和迦南人的城邑盡行毀滅。那地方的名便叫[[迦南大敗直到何珥瑪|何珥瑪]]（何珥瑪就是毀滅的意思）。
4. 他們從[[何珥山]]起行，往紅海那條路走，要繞過[[以東|以東地]]。百姓因這路難行，心中甚是煩躁，
5. 就怨讟神和[[摩西]]說：你們為什麼把我們從埃及領出來、使我們死在曠野呢？這裡沒有糧，沒有水，我們的心厭惡這淡薄的食物。
6. 於是耶和華使[[火蛇（saraph）|火蛇]]進入百姓中間，蛇就咬他們。以色列人中死了許多。
7. 百姓到[[摩西]]那裡，說：我們怨讟耶和華和你，有罪了。求你禱告耶和華，叫這些蛇離開我們。於是摩西為百姓禱告。
8. 耶和華對[[摩西]]說：你製造一條[[火蛇（saraph）|火蛇]]，掛在杆子上；凡被咬的，一望這蛇，就必得活。
9. [[摩西]]便製造一條[[銅蛇（nehushtan）|銅蛇]]，掛在杆子上；凡被蛇咬的，一望這銅蛇就活了。
10. 以色列人起行，安營在阿伯。
11. 又從阿伯起行，安營在以耶亞巴琳，與[[摩押]]相對的曠野，向日出之地。
12. 從那裡起行，安營在撒烈谷。
13. 從那裡起行，安營在亞嫩河那邊。這亞嫩河是在曠野，從亞摩利的境界流出來的；原來亞嫩河是[[摩押]]的邊界，在摩押和[[亞摩利人]]搭界的地方。
14. 所以[[耶和華的戰記]]上說：蘇法的哇哈伯與亞嫩河的谷，
15. 並向亞珥城眾谷的下坡，是靠近[[摩押]]的境界。
16. 以色列人從那裡起行，到了比珥（比珥就是井的意思）。從前耶和華吩咐[[摩西]]說：招聚百姓，我好給他們水喝，說的就是這井。
17. 當時，以色列人唱歌說：井啊，湧上水來！你們要向這井歌唱。
18. 這井是首領和民中的尊貴人用圭用杖所挖所掘的。以色列人從曠野往瑪他拿去，
19. 從瑪他拿到拿哈列，從拿哈列到巴末，
20. 從巴末到[[摩押]]地的谷，又到那下望曠野之毘斯迦的山頂。
21. 以色列人差遣使者去見[[亞摩利人]]的王西宏，說：
22. 求你容我們從你的地經過；我們不偏入田間和葡萄園，也不喝井裡的水，只走[[大道（原文作王道）]]，直到過了你的境界。
23. 西宏不容以色列人從他的境界經過，就招聚他的眾民出到曠野，要攻擊以色列人，到了雅雜與以色列人爭戰。
24. 以色列人用刀殺了他，得了他的地，從亞嫩河到雅博河，直到[[亞捫人]]的境界，因為亞捫人的境界多有堅壘。
25. 以色列人奪取這一切的城邑，也住[[亞摩利人]]的城邑，就是希實本與希實本的一切鄉村。
26. 這希實本是亞摩利王西宏的京城；西宏曾與[[摩押]]的先王爭戰，從他手中奪取了全地，直到亞嫩河。
27. 所以那些作詩歌的說：你們來到希實本；願西宏的城被修造，被建立。
28. 因為有火從希實本發出，有火焰出於西宏的城，燒盡[[摩押]]的亞珥和亞嫩河邱壇的祭司（祭司原文作主）。
29. [[摩押]]啊，你有禍了！[[基抹（摩押的神）|基抹]]的民哪，你們滅亡了！基抹的男子逃奔，女子被擄，交付亞摩利的王西宏。
30. 我們射了他們；希實本直到底本盡皆毀滅。我們使地變成荒場，直到挪法；這挪法直延到米底巴。
31. 這樣，以色列人就住在[[亞摩利人]]之地。
32. [[摩西]]打發人去窺探雅謝，以色列人就佔了雅謝的鎮市，趕出那裡的[[亞摩利人]]。
33. 以色列人轉回，向[[巴珊]]去。巴珊王噩和他的眾民都出來，在以得來與他們交戰。
34. 耶和華對[[摩西]]說：不要怕他！因我已將他和他的眾民，並他的地，都交在你手中；你要待他像從前待住希實本的亞摩利王西宏一般。
35. 於是他們殺了他和他的眾子，並他的眾民，沒有留下一個，就得了他的地。

## 本章整理

### 在同一個地名上反敗為勝（v1-3）

本章一開場就打了一仗，而且是被人先動手的。住南地的迦南人亞拉得王「就和以色列人爭戰，擄了他們幾個人」。CT 推測神容許這件事是有教育目的的：迦南人可能出其不意擄走幾個掉隊的人，「神容讓迦南人稍微得逞，以教訓以色列人不敢輕敵」。

新一代的反應與三十八年前完全不同。他們沒有哭號也沒有硬衝，而是 [[戰勝亞拉得王|向耶和華發願]]：「你若將這民交付我手，我就把他們的城邑盡行毀滅。」神應允了，那地方就名叫何珥瑪。CT 的〔話中之光〕點出這個地名的重量：「何珥瑪是以色列人從前失敗的地方(參民十四45)，如今就在那地反敗為勝，而且是大大的得勝。米利巴記錄了百姓的虧欠，何珥瑪記錄了百姓的信心恢復。」這正是 [[迦南大敗直到何珥瑪|民14:45 那場慘敗]]的翻案——GT《民數記串珠聖經註釋》說得更直接：這是「一雪三十八年前的恥辱（14:45）」。

不過這個願好不好，來源並不一致。KC 認為百姓是在交換條件，而耶和華沒有為這種形式的不信責備他們，反倒給了大勝；GT《聖經精讀本──民數記註解》的判斷嚴厲得多，說他們的要求並不是出於對耶和華的信仰，「只是因單純的民族優越感」；CT 的讀法最正面，說禱告表徵信靠神。

> [!note] STEP語言資料：第2節的兩個詞
> 「發願」在原文是同源受詞結構：動詞 נָדַר（H5087，簡要義域 to vow）加名詞 נֶדֶר（H5088，簡要義域 vow），正好對上 CT 的〔原文字義〕所註「發願(原文雙字)」發誓(首字)；誓言(次字)。「盡行毀滅」是 חָרַם（H2763A，簡要義域 to devote/destroy）——CT 說它與「永獻」同一字根，BH 則把它音譯作 herem，說明意思是把某物完全毀滅、藉此獻給神。

### 吃膩了天上的糧（v4-9）

打完勝仗，百姓卻在繞路時垮了。[[以東]]拒絕借道之後（民20:21），他們得往南繞回紅海那條路，[[何珥山]]起行的這一段路很不好走。GT 丁良才《民數記註釋》寫出實際的地形：「亞拉伯地是有沙土碎石的平原，而且水草很缺乏，故此百姓因這路難行，心中甚是煩燥，況且他們越走，離迦南越遠。」

他們的抱怨這次抱到了 [[嗎哪]]頭上——[[厭惡淡薄的食物與火蛇之災|「我們的心厭惡這淡薄的食物」]]。KC 抓住這句話的荒謬：他們說沒有糧沒有水，其實他們有，他們是吃膩了。GT 丁良才《民數記註釋》把它拉到今天：「就是厭惡那從天上降下來的嗎哪，到如今也有許多人照樣以神的道理為淡薄的食物。」（見 [[百姓厭棄嗎哪（約6：31-35）]]）

於是 [[火蛇（saraph）|火蛇]]進入百姓中間。要留意的是蛇不是新來的——GT 丁良才《民數記註釋》說明關鍵：「以色列人所過的曠野，本來有蛇不少（申八15）；但神常保護他們，直到祂發惡的時候。」換句話說，改變的不是曠野，是神收起了保護的手。

百姓認罪之後，神給的解法卻不是他們求的。

| | 百姓求的 | 神給的 |
| :--- | :--- | :--- |
| 對象 | 叫這些蛇離開我們（v7） | 造一條火蛇掛在杆子上（v8） |
| 方式 | 把問題挪走 | 把問題做成記號舉起來 |
| 條件 | 無 | 一望這蛇，就必得活 |

KC 把這個落差說得最清楚：神不是拿走蛇，而是加上一樣東西——摩西必須用那個正在害人的東西來造，正如主耶穌必須進入我們的處境。[[舉銅蛇望而得活|這條銅蛇]]因此成了全章最重的一段（見 [[銅蛇（nehushtan）]]）。CT 把材料的象徵拆開：「杆子是預表十字架。銅在聖經中是審判的意思，預表耶穌在十字架上替我們受了審判，所有的火蛇都有毒，只有銅蛇是沒有毒的，那就是預表耶穌是沒有罪的」。但他也提醒重點不在那條蛇：「並不是銅蛇能醫治百姓，乃是他們對神醫治的信心發生功效。他們的信仰，藉順從神的吩咐表明出來。」GT 丁良才《民數記註釋》把仰望拆成三層：「銅蛇是以色列人受罰的記號。他們遵著神的命令，仰望銅蛇，就表明三層意思：1他們承認己罪，2他們盼望得救，3他們信服神的救法。」而這條蛇後來的下場也被記下來（見 [[銅蛇被毀滅預表除去偶像（王下18：4）]]）。

> [!note] STEP語言資料：神說的與摩西做的不是同一個詞
> 第8節神吩咐造的只是 שָׂרָף（sa.Raf，H8314A，簡要義域 serpent）——只說撒拉弗，沒有說材質；第9節摩西做的是 נְחַשׁ נְחֹשֶׁת（ne.Chash ne.Cho.shet，H5175 蛇＋H5178A 銅）。這兩個字的字形極為接近，正是 GT 李道生《舊約聖經問題總解》所引呂振中譯本注所說「希伯來文[銅]字與[蛇]字很相似」。另外「杆子」是 נֵס（Nes，H5251H，簡要義域 ensign），帶有旗號、標竿的意思；而「望」在兩節也不同——第8節是 רָאָה（H7200G，to see），第9節是 נָבַט（H5027，to look），KC 正是指出這裡的仰望帶有專注凝視的意思。第5節「淡薄的」則是 קְלֹקֵל（H7052，簡要義域 worthless），正是 GT《啟導本聖經註釋》所說「原文qeloqel有“不屑”、“討厭”之意」的那個字。

### 一路向北，中間唱了一首歌（v10-20）

第10節起是一段行程表。這一段常被跳過，但它記下了 [[曠野飄流四十年|四十年判詞應驗的那一刻]]——GT 丁良才《民數記註釋》在撒烈谷註了一句：「當時十四35節的話全然應驗了。」

```mermaid
flowchart LR
    A["v10 阿伯"] --> B["v11 以耶亞巴琳（與摩押相對）"]
    B --> C["v12 撒烈谷"]
    C --> D["v13 亞嫩河（摩押與亞摩利的邊界）"]
    D --> E["v16 比珥（就是井的意思）"]
    E --> F["v18 瑪他拿"]
    F --> G["v19 拿哈列、巴末"]
    G --> H["v20 摩押地的谷、毗斯迦山頂"]
```

第14節在這段地理描述中間引了一本書：[[耶和華的戰記]]。CT 判斷它「大概是一本詩歌書，記載以色列人得勝的凱歌(參17~18節)」；GT《啟導本聖經註釋》定位為「以色列人的歷史戰歌集，與《約書亞記》十13和《撒下》一18所記的《雅煞珥書》同類」。這本書已經佚失，GT《舊約聖經背景註釋》因此說：「可惜這兩本書都已佚失，但聖經提到它們，顯出經文的記載至少有一部分，是基於文化傳統之記憶的。」

到了比珥，百姓做了一件曠野裡少見的事——他們唱歌。[[井之歌（比珥掘井）|「井啊，湧上水來！你們要向這井歌唱」]]。KC 指出這是出埃及之後在曠野裡第二次唱歌，中間唯一的另一次還是為金牛犢唱的（出32:18）。CT 的〔話中之光〕把這一節讀成一條原則：「讚美使我們得到泉源，怨言使我們招審判。甚至禱告亦不能使井湧上水來，因為沒有一件東西比讚美更能叫神喜悅。讚美是信心最準確的憑據。」同一批人，隔了十幾節就從抱怨沒水變成向井歌唱。

至於「用圭用杖」，GT 丁良才《民數記註釋》說得最短：「意思說用圭或杖的，是有權勢」。STEP語言資料可以支持這個讀法：第18節的「圭」是 חָקַק（H2710，簡要義域 to decree）的分詞，本節譯義是統治者的杖；「挖」與「掘」在原文也確實是兩個不同的動詞（H2658 與 H3738B）。

### 東岸的兩場硬仗（v21-35）

以色列人向 [[亞摩利人]]的王西宏提出的請求，與民20 向以東提的幾乎一字不差：只走 [[大道（原文作王道）|大道]]、不偏入田間和葡萄園、不喝井裡的水。西宏的回應也一樣是拒絕，但結果完全不同。GT 丁良才《民數記註釋》指出差別在於神的命令：「神沒有禁止以色列人擾害亞摩利人，像禁止他們騷擾以東和摩押人一樣（參申二9、19），乃是命以色列人與他們爭戰（申二24）」，而以色列人仍然先用好話向他們通融。KC 從創15:16 補上時間的理由：神早就預告了亞摩利人的審判，只是要等他們的罪孽滿盈——那個時刻現在到了（見 [[以色列戰勝亞摩利王西宏互文（申2：24-37；3：1-7；詩135：10-12；136：17-22）]]）。

| | 亞摩利王西宏（v21-31） | 巴珊王噩（v33-35） |
| :--- | :--- | :--- |
| 以色列的動作 | 先差使者求借道 | 沒有差使者，直接迎戰 |
| 對方的動作 | 招聚眾民出到曠野，在雅雜爭戰 | 和他的眾民都出來，在以得來交戰 |
| 神的話 | 無記載 | 「不要怕他！因我已將他和他的眾民，並他的地，都交在你手中」（v34） |
| 結果 | 得了從亞嫩河到雅博河的地 | 殺了他和他的眾子並眾民，沒有留下一個 |

第24節有一個容易讀漏的限制：以色列人得地到了 [[亞捫人]]的境界就停了。CT 註「因為亞捫人的境界多有堅壘」，GT 丁良才《民數記註釋》則指出這是西宏當年打不下來的緣故，而以色列人不取亞捫人的地「卻另有別的緣故（申二18-19）」——那是神的禁令，不是打不動。同一段還交代了 [[摩押]]的舊帳：第26節說希實本本來是摩押的，是西宏從摩押先王手中奪去的。

第27-30節是本章第三首古歌，也是 [[基抹（摩押的神）|摩押國神基抹]]唯一一次在民數記出場。GT 丁良才《民數記註釋》註末句時只用了一句話：「意思說，基抹不能拯救敬拜自己的人。」

最後一仗打到 [[巴珊]]。CT 指出這是「位於雅博河以北，黑門山以南的高原(即今戈蘭高原)，境內牧草繁茂，盛產牛羊」，而巴珊王噩「他的身量高大，是最後一個利乏音人(申三11)」（見 [[利乏音人]]）。GT 丁良才《民數記註釋》說明戰局為何一面倒：「巴珊的城邑甚是堅固，巴珊王和他的百姓若不出來，以色列人必不敢靠自己的力量去攻擊他們。」噩自己走出堅城迎戰，結果全軍覆沒（見 [[以色列戰勝巴珊王噩互文（申3：1-11；詩135：10-12；136：17-22）]]）。

### 這一章在民數記裡的位置（v1-35）

GT《民數記串珠聖經註釋》把本章的三場仗連成一條線：以色列人的腳蹤由南部邊境跨越約但河東高原，由南至北到達北部的邊界，繞行迦南地一周，「無論是南部何珥瑪戰役、東部亞摩利人之役及北部巴珊之役均節節獲勝，神大能的引導逐步實現祂的應許」。

同一份註釋也把整章的節奏描述得很準：中段的行程「這一段旅程節奏加快，以色列人仿似直敲迦南地的門」。而 [[摩西]]在本章的角色只剩兩件事——為百姓禱告、照神的吩咐造銅蛇。GT 丁良才《民數記註釋》記下一個第一次：「按聖書所記，這是以色列人頭一次直接請求摩西為他們禱告。」同一則註釋把摩西以善勝惡的五次列成清單，本章第7節是最後一次。

KC 從結構上指出一件事：民數記的第三部分從對西宏的爭戰開始，場景轉到摩押平原——百姓已經不在曠野裡，卻也還沒有進地。這正是本章的位置：舊的一代已經死完，新的一代已經開始得地，而約但河還沒有過。
