# 亞雅崙谷

## 定義

亞雅崙谷是書10:12 約書亞禱告時月亮所在的方位：日頭在東邊的基遍，月亮在西邊的亞雅崙谷。STEP 顯示這個片語是 be./'E.mek（H6010R，簡要詞典義 e.meq: valley）接 'ai.ya.Lon（H357，簡要詞典義 ay.ya.lon: Aijalon）。

CT 的原文字義給「亞雅崙」鹿原，並說『亞雅崙谷』指從伯和崙隘口到亞雅崙平原之間的谷道，以色列人追擊亞摩利人聯軍在通過亞雅崙谷時正值黎明時分。GT《約書亞記研經資料》給的字義相同。

### 為什麼日月會同時出現

GT《丁道爾聖經注釋》說由這些天上光體的位置看來，當時正是一清早，太陽和月亮同時可以看得見。GT《約書亞記研經資料》說書10:12 基遍在東方、亞雅崙谷在西面，所以此時是日出月落（大清早）之時。GT《綜合解讀》講得更具體：從基遍到伯·和崙大約10公里，約書亞追趕到這裡的時候已經是黎明，站在伯·和崙隘口的山頂可以看見東面基遍初升的太陽，也可以看見掛在西面亞雅崙谷上空的下弦月。BH 說亞雅崙谷位於基遍以西、在亞摩利人撤退的路線上，當時日月同時可見。

### 這條谷道的軍事價值

GT《啟導本》說從基遍到亞雅崙平原為一條很長的谷道、稱伯和崙上坡，並說掃羅和約拿單在密抹打勝仗追趕非利士人也是走此谷道。
