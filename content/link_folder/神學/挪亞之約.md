# 挪亞之約

## 定義

挪亞之約是神在洪水前後與挪亞所立的約。創6:18 神說：我卻要與你立約，使挪亞和家人進入方舟；創8:21-22 神宣告不再因人的緣故咒詛地，並使稼穡、寒暑、冬夏、晝夜永不停息；創9:11、13 神與挪亞、他的後裔和一切活物立約，應許不再有洪水滅絕凡有血肉者，並以虹作記號。註釋稱它為神主動施予的無條件之約，又稱『彩虹之約』。

STEP 把創6:18 的 וַהֲקִמֹתִי 標為使動語態的『我要堅立』（H6965I），神所堅立的是 בְּרִיתִי（H1285，我的約）。

#### [[01 創世記/第9章|第9章]]
- 本章重點：神與挪亞、他的兒子與後裔，以及一切活物堅立永約，應許不再以洪水滅絕凡有血肉者或毀壞地，並以虹作記號。第9、11節的「堅立」（מֵקִים／וַהֲקִמֹתִי，H6965I）來自同一字根，都是使動語態。
- 與本章關聯：第9章完整展開第6章18節初次宣告的約；約由神主動承擔，涵蓋人類與受造界，使洪水後世界能在穩定秩序中延續。

## 主題發展

「約」是雙方互相同意締結、有約束力的關係；但在神與人的關係中，神是創造者、人是受造物，因此神人之約是**神對人的賞賜**，非對等條件交換。

### 約的五項內容

1. **尊重生命、保障生命** — 毀人生命者須以生命償還（九5-6）
2. **不再用全球性洪水刑罰人，不加重對地的咒詛**（八21；九9-16）
3. **自然界四季秩序常保**（八22）
4. **人可以吃肉**（九3-4），但不可吃帶血的肉
5. **預言經由閃的後代將有特別預備**（九26-27）

### 約的特性

1. **無所不包**：包括「一切活物」
2. **永遠的**：「永約」
3. **單方面施惠**：沒有要求人任何條件
4. **有記號**：「虹」
5. **給神看見就記念**：神降卑自己情願受約的拘束

### 立約的根據

- 不是根據人的情況（人從小時心裏懷著惡念，八21）
- 乃是根據神的祝福（神賜福給挪亞）
- 又是根據神的旨意（人照神形像造的）

本條目也牽涉的經文：賽54:9：確認挪亞之約。
