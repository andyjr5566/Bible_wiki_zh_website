# 希伯崙與底璧被攻取了幾次

## 定義

書10:36-39 已記約書亞攻取希伯崙和底璧、盡行殺滅；書11:21 又說約書亞從希伯崙、底璧剪除亞衲族人。可是書15:13-17 記迦勒從希伯崙趕出亞衲族三族長、俄陀聶攻取底璧，士1:10-15 又記一次。這些記載是同一件事的不同角度，還是城被攻下之後又失守、再打一次？

| 來源 | 解釋 |
|---|---|
| CT | 書15:14 是書10:37 的補充說明 |
| GT《啟導本》 | 約書亞曾攻陷希伯侖和底璧二城（書11:21），大概逃脫的亞衲族人回來重占，以致迦勒要再攻打 |
| GT《綜合解讀》 | 約書亞攻陷兩城（書10:36-39），可能因為沒有以色列人常駐，被亞衲族人重新佔據，所以迦勒需要再次攻打 |
| GT《串珠》 | 約書亞先前以閃電式手法攻取了底璧，這城可能後來失守，以致俄陀聶須再次攻取 |
| GT《雷氏研讀本》 | 俄陀聶在約書亞的閃電攻擊（書10:38-39）之後，向底璧進行第二次襲擊 |
| GT《聖經精讀本》 | 亞衲族似乎又重新佔領了被約書亞所征服之地；又因士1:11-15 也記了此事，暗示佔領底璧是在約書亞去世之後，本書作者是為了羅列猶大所得之地才在此記錄 |

多數 GT 註釋採先攻下、後失守、再攻取的讀法；CT 則把書15:14 當作書10 同一場戰事的補充。GT《聖經精讀本》另外提出時間上的問題：既然士師記把底璧之役放在約書亞死後，約書亞記在這裡記它，可能是照地理把資料放在猶大的段落裡。

## 按書卷累積

### 約書亞記

<!-- accumulation:約書亞記:15:start -->
#### [[06 約書亞記/第15章|第15章]]
- 本章重點：第13-17節迦勒趕出希伯崙的亞衲族、俄陀聶攻取底璧，而書10:36-39 已記約書亞攻取兩城。CT 說是書10 的補充；GT《啟導本》《綜合解讀》《串珠》《雷氏研讀本》說是失守後再攻；GT《聖經精讀本》並指出士1 暗示底璧之役在約書亞死後。
- 與本章關聯：本章是這個問題的主要來源：同一座城在書10、書11、書15、士1 都有被攻取的記錄。
