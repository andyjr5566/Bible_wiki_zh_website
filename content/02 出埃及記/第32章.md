1. 百姓見摩西遲延不下山，就大家聚集到[[亞倫]]那裡，對他說：起來！為我們做[[金牛犢事件|神像]]，可以在我們前面引路；因為領我們出埃及地的那個摩西，我們不知道他遭了什麼事。
2. [[亞倫]]對他們說：你們去摘下你們妻子、兒女耳上的金環，拿來給我。
3. 百姓就都摘下他們耳上的金環，拿來給[[亞倫]]。
4. [[亞倫]]從他們手裡接過來，鑄了一隻[[金牛犢事件|牛犢]]，用雕刻的器具做成。他們就說：以色列啊，這是領你出埃及地的神。
5. [[亞倫]]看見，就在[[金牛犢事件|牛犢]]面前築壇，且宣告說：明日要向耶和華守節。
6. 次日清早，百姓起來獻燔祭和平安祭，就坐下吃喝，起來玩耍。
7. 耶和華吩咐摩西說：下去吧，因為你的百姓，就是你從埃及地領出來的，已經敗壞了。
8. 他們快快偏離了我所吩咐的道，為自己鑄了一隻[[金牛犢事件|牛犢]]，向他下拜獻祭，說：以色列啊，這就是領你出埃及地的神。
9. 耶和華對摩西說：我看這百姓真是[[硬著頸項的百姓]]。
10. 你且由著我，我要向他們發烈怒，將他們滅絕，使你的後裔成為大國。
11. [[摩西為百姓代求（金牛犢）|摩西便懇求耶和華]]─他的神說：耶和華啊，你為什麼向你的百姓發烈怒呢？這百姓是你用大力和大能的手從埃及地領出來的。
12. 為什麼使埃及人議論說他領他們出去，是要降禍與他們，把他們殺在山中，將他們從地上除滅？求你轉意，不發你的烈怒；後悔，不降禍與你的百姓。
13. 求你記念你的僕人[[亞伯拉罕]]、[[以撒]]、以色列。你曾指著自己起誓說：我必使你們的後裔像天上的星那樣多，並且我所應許的這全地，必給你們的後裔，他們要永遠承受為業。
14. 於是耶和華後悔，不把所說的禍降與他的百姓。
15. 摩西轉身下山，手裡拿著兩塊法版。這版是兩面寫的，這面那面都有字，
16. 是神的工作，字是神寫的，刻在版上。
17. [[約書亞]]一聽見百姓呼喊的聲音，就對摩西說：在營裡有爭戰的聲音。
18. 摩西說：這不是人打勝仗的聲音，也不是人打敗仗的聲音，我所聽見的乃是人歌唱的聲音。
19. 摩西挨近營前就看見[[金牛犢事件|牛犢]]，又看見人跳舞，便發烈怒，[[摩西摔碎法版（廢約的象徵）|把兩塊版扔在山下摔碎了]]，
20. 又將他們所鑄的[[金牛犢事件|牛犢]]用火焚燒，磨得粉碎，撒在水面上，叫以色列人喝。
21. 摩西對[[亞倫]]說：這百姓向你做了什麼？你竟使他們陷在大罪裡！
22. [[亞倫]]說：求我主不要發烈怒。這百姓專於作惡，是你知道的。
23. 他們對我說：你為我們做[[金牛犢事件|神像]]，可以在我們前面引路；因為領我們出埃及地的那個摩西，我們不知道他遭了什麼事。
24. 我對他們說：凡有金環的可以摘下來，他們就給了我。我把金環扔在火中，這[[金牛犢事件|牛犢]]便出來了。
25. 摩西見百姓放肆（[[亞倫]]縱容他們，使他們在仇敵中間被譏刺），
26. 就站在營門中，說：[[利未人受聖職討罪|凡屬耶和華的，都要到我這裡來]]！於是[[利未人受聖職討罪|利未的子孫]]都到他那裡聚集。
27. 他對他們說：耶和華─以色列的神這樣說：你們各人把刀跨在腰間，在營中往來，從這門到那門，各人殺他的弟兄與同伴並鄰舍。
28. [[利未人受聖職討罪|利未的子孫]]照摩西的話行了。那一天百姓中被殺的約有三千。
29. 摩西說：今天你們要自潔，歸耶和華為聖，各人攻擊他的兒子和弟兄，使耶和華賜福與你們。
30. 到了第二天，摩西對百姓說：你們犯了大罪。我如今要上耶和華那裡去，[[摩西為百姓代求（金牛犢）|或者可以為你們贖罪]]。
31. 摩西回到耶和華那裡，說：唉！這百姓犯了大罪，為自己做了[[金牛犢事件|金像]]。
32. 倘或你肯赦免他們的罪……不然，求你[[從冊上塗抹（生命冊）|從你所寫的冊上塗抹我的名]]。
33. 耶和華對摩西說：誰得罪我，[[從冊上塗抹（生命冊）|我就從我的冊上塗抹誰的名]]。
34. 現在你去領這百姓，往我所告訴你的地方去，我的使者必在你前面引路；只是到我追討的日子，我必追討他們的罪。
35. 耶和華殺百姓的緣故，是因他們同[[亞倫]]做了[[金牛犢事件|牛犢]]。

## 本章整理

> [!important] 為什麼這一章非有不可？——KC：因為出35 會幕還是造了
>
> KC 開頭一句話定了整章的意義，而這句話是讀出32-34 的鑰匙：
>
> ==「在前面幾章我們看見神是誰。在這裡我們看見人、就是祂的百姓，是誰。==
>
> ==藉此我們學會更多地讚嘆神——因為儘管百姓犯了這樣的罪，會幕從出埃及記35章起還是造起來了。神來與一群這樣胡作非為的百姓同住。」==
>
> 出32 不是插曲，是背景。沒有這一章，出35-40 只是工程紀錄；有了這一章，出35-40 才是恩典。

### 山上與山下：同一時刻的兩幅畫面

本章的力量來自一個時間上的重疊——出25-31 神在山上啟示會幕，出32 百姓在山下鑄造牛犢，兩件事同時進行。四份來源反覆回到這個對照：

| | 西乃山：山上（出25-31） | 山下（出32） |
| :--- | :--- | :--- |
| 誰在行動 | 神向[[摩西]]啟示會幕的樣式 | 百姓催逼[[亞倫]]鑄造神像 |
| 材料 | 百姓甘心樂意獻上的金銀銅料 | 妻子兒女耳上的[[金環]] |
| 成品 | 神所指定的居所 | 人手所造的[[金牛犢事件]] |
| 敬拜形式 | 神所定的祭與節期 | 燔祭、平安祭、守節——形式完全照搬 |
| 中保的位置 | [[摩西]]在山上代求：[[摩西為百姓代求（金牛犢）]] | [[亞倫]]在山下向百姓妥協 |
| 結局 | [[法版]]是神的工作、神的字 | 法版在山腳下被摔碎：[[摩西摔碎法版（廢約的象徵）]] |

### 百姓拜金牛犢（v1-6）

[[摩西]]在山上四十晝夜遲延不下（出24:18），百姓便聚集到[[亞倫]]那裡，要求做神像在前面引路。GT《中文聖經註釋》從原文挖出兩層：「原文延遲的字根是『羞聇』」——對那些在曠野久候的百姓來說，摩西的遲延被解讀成一種不負責任的羞恥行為，否則就是遭遇了不測；而「大家聚集到亞倫那裏」的「到」字，「原文不用普通表示到達的 `al，而用含有反抗、攻擊、敵對意義的 `al，是形容出他們聚集到亞倫那裏嘈鬧的意思」。同一份來源並指出百姓「乃是以命令式的口吻，向亞倫要求兩件事」——「起來！」不是叫他站起來，而是嘈他「做些事呀」；「為我們作神像！」也是命令式，亞倫因此「無可奈何地，被動地，被百姓牽著鼻子走了」。CT 則指出這遲延本是對百姓的考驗，他們行事只憑眼見不憑信心，以看得見的神像代替看不見的神。KC 把摩西讀成升天之主的預表：因主遲延不歸，教會便失去盼望，轉而尋求可觸摸的宗教並與世界聯合。

[[亞倫]]沒有求問神便自作主張，要百姓摘下妻子兒女耳上的[[金環]]。GT《啟導本聖經腳註》指出這些金飾「當為以色列人出埃及時向埃及人要的金銀珠寶的一部分（十一2；十二35）」；GT《丁道爾聖經注釋》補上一個有趣的歷史觀察——「日後以色列男子有別於米甸的遠親，並不佩戴金子作為妝飾（士八24）」，但雅各時代的人都戴（創35:4）。GT《中文聖經註釋》則點出這些環子不只是首飾：古代中東的人戴金銀耳環或鼻環，「並不單在為裝飾，也有[[耳環作異教護身符|求神明保佑的含意]]」。CT 記下一個沒有成功的解讀：「有人說，亞倫可能故意以貴重的金飾使他們因捨不得而退縮。事實是，人們為著拜偶像，常常不惜花費巨資。」百姓「並沒有躊躇，立刻『就都摘下』」。

牛犢鑄成後百姓宣告「以色列啊，這是領你出埃及地的神」。BH 指出這是把神拯救的大工歸給人手所造之物，直接違反頭兩條誡命（參不可為自己雕刻偶像）；GT《舊約聖經背景註釋》從[[古代近東偶像崇拜|古代近東的背景]]補一個尺寸感——考古所出的公牛小像「長度都是只有三至七吋」，並指出所觸犯的是第二誡（不可造偶像）而非第一誡（不可有別神），因守節的名義仍是耶和華。GT 丁良才則把這句話的後續指出來：「後來耶羅波安製造金牛犢的時候，也說過這話（王上十二28），真是妄稱神的名。」

[[亞倫]]又在牛犢面前築壇，宣告「明日要向耶和華守節」。CT 指出這是混合敬拜的典型：外面的築壇、守節、獻祭看似合乎聖經，實際敬拜的對象已經改變。次日百姓獻燔祭平安祭後[[坐下吃喝起來玩耍|「坐下吃喝，起來玩耍」]]——這一句是全章的高峰，也是保羅在林前10:7 逐字引來警戒教會的一句。

> [!question] 為什麼「吃喝玩耍」算拜偶像？——KC 的分析很扎人
>
> 保羅在林前10:7 引這件事警戒信徒不可拜偶像，引的卻是「坐下吃喝，起來玩耍」。KC 抓住這個奇怪之處：
>
> ==「他們的拜偶像是什麼？緊接在後面就說了：吃、喝、玩耍。這些是錯的活動嗎？本身不是，但對以色列而言是錯的。」==
>
> 那病根在哪？KC 追到底：「那麼，吃、喝、玩耍的原因是什麼？是摩西去了那麼久。」
>
> 他接著把這個結構整個搬到今天：「主耶穌去了那麼久，看起來祂好像永遠不回來了。於是那念頭就悄悄爬進來：『我們就在這世界裡過得舒服點，照我們喜歡的方式過日子吧。我們也給自己造一個神，一個我們喜歡的、一個跟我們合得來的，人生就成了一場大派對！』但那是一場沒有真神的筵席。」
>
> ——所以拜偶像不必從「明知是罪的事」開始。KC：「把別的東西放在神和基督的位置上，就是拜偶像。那很容易發生。」

「玩耍」一字的字義，四份來源的落點比 KC 更重。CT 的〔原文字義〕只給中性的「笑，玩弄」，但 GT《丁道爾聖經注釋》說「譯作玩耍的希伯來動詞有『調情』的含義（參創二十六8）」，GT《中文聖經註釋》把字源交代得最清楚——「這玩耍的原文，是和創廿六8的『戲玩』，以及創卅九14和17的『戲弄』相同，含有性事的意義，特別是濫交的含義」，GT《串珠聖經註釋》一語斷定為「實行宗教上的縱淫」。GT《聖經精讀本》則指出整套流程的出處：「這一切是照埃及人的風俗。因為埃及人祭拜他們的神的時候，在其面前築壇之後，便開始吃喝、跳舞。」

CT 引高雅倫（Alan Cole）點出最尖銳的一層：==「本節形容的行徑對巴力崇拜者來說有宗教上的重要性，並沒有不道德的用意；但耶和華的看法就不同了……不瞭解耶和華的聖潔，便不能解釋摩西的反應為什麼如此暴烈，以色列接著要受的審判為什麼如此可怕。」==——這場聚會在當時的宗教環境裡是「正常」的，正是這種正常最致命。

KC 另有兩處讀得極銳利：

**[[耳環作異教護身符|耳環]]**：「他們樂意交出耳上的裝飾。那耳朵被剝去了它的裝飾——而那裝飾就是聽神的話。」

**守節**：「這節期成了蓋在邪惡胡鬧上面的一層敬虔的醬汁。在許多不同的色調裡，這個做法在掛名的基督教裡一再重演：異教的節日被淋上基督教的醬汁，邪惡的生活方式被宣告為敬虔之愛的表達。」

> [!question] 一個消失的名字：戶珥去了哪裡？
>
> 摩西上山前把爭訟交給亞倫和戶珥兩人處理（出24:14），戶珥又是出17:10-12 扶摩西手的人之一。可是整章金牛犢事件，戶珥一個字都沒出現，而且自出24:14 之後全本聖經再無他的名字。GT 的兩份來源給了方向相反的兩種解釋：
>
> **一、他是主謀。** GT《中文聖經註釋》：「其名字不在這裏出現，且在經文上自廿四14之後完全無影無蹤，則領導這事件，或出主意鑄造金牛犢的，可能就是他。為對他的錯誤厭棄，從此他的名字就失落了。」
>
> **二、他是殉道者。** GT 丁良才記下一個猶太傳說：「因戶珥在這事上，抵擋百姓，就被他們殺了，所以亞倫害怕。」——但丁良才自己隨即加一句：「這話未必是真的。」
>
> 兩說之所以值得並列，是因為它們同樣解釋了亞倫為何屈服：若戶珥是主謀，亞倫是被同工拖下水；若戶珥被殺，亞倫是被恐懼壓垮。而經文對此完全沉默。

### 神的忿怒與摩西第一次代求（v7-14）

神吩咐[[摩西]]趕快下去，稱以色列人為「你的百姓，就是你從埃及地領出來的」。CT 指出這連用兩個「你」字，與神一貫自稱「我的百姓」相反，表明神對百姓認賊作父的行為深惡痛絕；BH 認為這也是對摩西領導與代求職分的考驗。神稱他們是[[硬著頸項的百姓]]，BH 指出這是農業比喻——「The term "stiff-necked" is a metaphor derived from agriculture」，形容不肯受牽引駕馭的牛，從此成為聖經形容以色列頑梗悖逆的慣用語。

神說「你且由著我」，要向百姓發烈怒將他們滅絕，使摩西的後裔成為大國。CT 指出這是試驗摩西的存心，字裡行間反而敞開了邀請代求之門；GT《丁道爾聖經注釋》補一句很重的話：「這話對摩西來說必然是個真實的試探（就如主耶穌所受試探不是假的一樣），不然它就沒有意義了。神對亞伯拉罕（創十二2）和雅各（創三十五11）的應許雖會實現，神的子民卻不會稱為『以色列人』，而將叫作『摩西人』。」

[[摩西為百姓代求（金牛犢）|摩西的代求]]有三重根據，GT《串珠聖經註釋》與《啟導本》都作了整理：這百姓是神用大力和大能的手領出來的（把「你的百姓」還給神）、神的名聲不容埃及人譏議（參民14:13-16；申9:28）、神曾向[[亞伯拉罕]]、[[以撒]]、以色列指著自己起誓應許後裔與土地。GT《聖經精讀本》指出這第三重最硬：這約「以神的存在為依據，而立的約是永恆不變的（來6:13-18）」。

於是耶和華後悔，不把所說的禍降與祂的百姓（參[[神的後悔與憂傷]]）。GT《丁道爾聖經注釋》處理「後悔」的方式是把它放回條件句的邏輯裡：==「聖經明證神的應許和警告，始終是以人的回應作為條件；以西結書三十三章13～16節將這一點表達得最是清楚。」==——改變的不是神的本性與旨意，而是情況：摩西的[[代求]]成為新的因素。KC 從神的角度說同一件事：「神願意被懇求。祂在與百姓同行、與祂每一個兒女同行的路上，使用禱告、使用祂自己人的代求。」KC 並把摩西的兩重根據翻成信徒的兩重根據：第一是提醒神祂已把我們從世界贖出來，第二是祂在自己話語裡說過的——「不是因為祂忘了，而是要看見我們沒有忘」。

### 摩西下山摔碎法版與責問亞倫（v15-24）

[[摩西]]手拿兩塊[[法版]]下山，版是兩面寫的，是神的工作、神的字。[[約書亞]]聽見營中喧聲，以為是爭戰的聲音；摩西則分辨出既非勝仗亦非敗仗，乃是歌唱。CT 一句話點破：「摩西聽出是歌唱的聲音，不是打仗的聲音（他比約書亞成熟老練）。」

> [!note] KC 對約書亞聽錯的讀法
>
> 他先替約書亞說話：「他還年輕。摩西，那年長、成熟、剛從神面前下來的信徒，告訴他那不是爭戰的聲音，是歌唱的聲音。」然後把它變成一句警告：
>
> ==「年輕的信徒可能因著缺乏經驗，誤解神百姓的某些表現。他們以為在一場熱鬧喧騰的聚會裡，正在打屬靈的仗。而真正在進行的，是繞著金牛犢跳舞。」==
>
> ——KC 接著補上那個聚會的樣子：「宗教被操作成讓參與者最享受的樣子。整場事奉按他們自己的口味裝扮妝點。主的名被題起，祂卻沒有話語權。祂的話沒有被求問，更不用說被聽從。」

摩西挨近營前，看見牛犢與跳舞，便發烈怒[[摩西摔碎法版（廢約的象徵）|把法版摔碎在山下]]。CT 指出摩西的「發烈怒」與神的發烈怒（v10）用字相同，他是站在神的立場發義怒，而神並沒有責備他；GT 與 BH 一致指出摔碎法版不是隨意發脾氣，而是古代廢除盟約的典型象徵行動——百姓已違背條款，約宣告無效。

> [!important] 律法是在山下摔碎的，不是在山頂
>
> KC 讀摔碎法版，讀出一個位置上的對稱，而這個對稱一路通到十字架：
>
> ==「在石版上神把自己啟示給祂的百姓。百姓卻已經確保：神旨意的啟示對他們是不必要的。律法是在山腳下被摔碎的，不是在山頂上。」==
>
> 然後他把這個結構往前推一整部聖經：
>
> 「當主耶穌來的時候，神把自己完全顯明出來——這一次不是作立法者，而是在愛裡。但這啟示同樣被百姓毀掉了。主耶穌被拒絕。在下面，在地上，祂被一群祂想要救贖的百姓殺害。」
>
> 兩次啟示，兩次都是在「下面」被毀掉的。

摩西又將牛犢焚燒、磨粉、撒在水面上叫以色列人喝。CT 指出這是叫百姓自食罪行的苦果；GT《舊約聖經背景註釋》指出「烏加列文獻也曾使用『燒、磨、撒、喝』四部曲，作為一個神祇被徹底摧毀的表示」；GT《丁道爾聖經注釋》則從律法角度接上另一條線——把金屑灑在以色列人必須飲用的水中，「令人聯想到給嫌疑不貞之妻子喝的『苦水』（民五18～22）。以色列既是不忠於屬天『丈夫』耶和華，便必然要受咒詛（35節；參民五27）」。KC 讀出的是牧養用意：「他要把他們帶到一種深入內裡的醒悟，看見自己所行的愚昧。」

摩西隨後責問[[亞倫]]，亞倫先請「我主」息怒、諉過於百姓專於作惡，再以「我把金環扔在火中，這牛犢便出來了」推說偶像是神奇地自己出來的。GT《中文聖經註釋》的評語極不留情：「連三歲小孩子也不會相信的這話，年紀老大的亞倫卻講出來了」，並列出這番[[推諉罪責|掩飾]]的三個可能：「（一）是想推卸責任──首先諉過百姓（22節），現在又推說是出於神蹟。（二）是為同工戶珥作掩飾。（三）為要將摩西的高貴品質，藉亞倫的這詭辯彰顯出來。」CT 另從領袖責任的角度列出亞倫的四重失敗：看不出眾人意見的錯誤、即使看出也無勇氣申斥、反給眾人錯誤的指導、自己犯錯卻輕描淡寫地掩蓋。KC 則把亞倫接回創世記：「就像亞倫，也像亞當，我們都太快把自己錯誤行為的責任放到別人身上。」GT《聖經精讀本》補一個沒有走成的岔路：「這時候亞倫如果不進行申辯而是悔改的話，就會得到神的饒恕，而且避免這樣的羞恥。」他仍能存活，是因摩西也為他代求（申9:20）。

### 利未人受聖職討罪（v25-29）

摩西見百姓「放肆」，而經文點明是[[亞倫]]「縱容」他們。GT《中文聖經註釋》指出關鍵在原文：==「原文的放肆和縱容，是同一的字根。這是對亞倫的一個極嚴厲的指摘。」==CT 的〔原文字義〕同樣標明「『縱容』（原文與『放肆』同字）」。GT《聖經精讀本》另給一層字義：「放肆」源自希伯來文「釋放」一詞，有「顯出」、「露出」的意思——百姓表露的是自己的羞恥。其結果是使他們在仇敵（即埃及人，參12節）中間被譏刺，失去見證。

摩西站在營門中呼召「凡屬耶和華的，都要到我這裡來」，利未的子孫都聚集到他那裡。GT《中文聖經註釋》為利未人補了一段經文沒說的空白：百姓嘈鬧時他們有沒有參與、坐下吃喝起來玩耍時他們是否隨眾作惡，「經文也沒有交代。也許，他們是沉默的少數；見到眾人都偏離他們祖宗的神，甚至連亞倫也縱容這些人，他們只好閉口不言」。CT 則指出一個轉折：神原意要全體選民作祭司的國度，但因多數人事奉偶像，唯有肯出代價的[[利未人受聖職討罪|利未人]]配得祭司職分——從此神的子民與神的祭司分開了。

那天倒斃的約有三千人。GT《丁道爾聖經注釋》對這個數字有兩點觀察：「三千，人數不多，證實了這件事在歷史上的可靠性」；至於這些人是誰，「或許是祭偶者的頭目，但更有可能不過是碰巧在敬拜時……不幸首當其衝的人。他們未必比其他的人邪惡，根據路加福音十三章1～5節，這種『有限度的審判』是神的恩典，對其他人有警誡的作用」。CT 的判斷則相反，認為被殺的應當是那些堅不認錯、故意抵擋的死硬份子——兩說並存。

第29節摩西說「今天你們要自潔，歸耶和華為聖」，這句話的譯法本身有爭議。GT 指出原文直譯是「今天你們的手已滿了為神」，而「使手充滿」正是承接聖職的專門用語——利未人因看重神過於自己的兒子弟兄而承受祝福，日後摩西祝福十二支派時特別記念此事（申33:9），奠定他們作事奉支派的根基。丁良才並指出這裡的咒詛翻轉：利未當日「為保守自己和父家的名譽起見，發過血氣的熱心，就受了咒詛（創三十四25-27）。這時利未的後裔因顧神的榮耀卻發了純正的熱心，就使從前的咒詛變為祝福」。KC 的總結最實際：「他們的工作並不可喜，卻是必要的。」神的聖潔要求教會中的管教與對付罪惡，而這只能由把自己奉獻給主的人執行，其結果是祝福。

### 摩西再次代求與神的追討（v30-35）

到了第二天，[[摩西]]對百姓直言「你們犯了大罪」，並要上耶和華那裡去，「或者可以」為他們贖罪。GT《丁道爾聖經注釋》指出這種說法「在舊約的意思通常是死罪可免，但仍需受到較輕的管教（參撒下十二13大衛的情形）」。第32節那個沒說完的句子，GT《中文聖經註釋》認為不是抄寫的疏漏：「原文是驟斷的。明顯是有字漏掉或給刪掉，或者是表達摩西無法再說下去，而經過嗚咽或一段緘默後，才再說下去的。」

接著摩西說「不然，求你[[從冊上塗抹（生命冊）|從你所寫的冊上塗抹我的名]]」。GT《舊約聖經背景註釋》把這個意象放回古代近東：「神明的帳簿在古美索不達米亞是很普遍的概念，簿上所記的包括了某人註定的命運和賞罰。」GT《丁道爾聖經注釋》則指出這詞在以色列的來歷可能更平實：「這詞的原意大概來自民數記一章等人口調查的紀錄」，比喻「世上一切的活人」（詩69:28；賽4:3）。摩西是自願代死（GT 拿他與羅9:3 的保羅相比），也是再一次拒絕了第10節的誘惑。

但神回答「誰得罪我，我就從我的冊上塗抹誰的名」。GT《丁道爾聖經注釋》指出這句話為什麼必須如此：==「若不如是，神便違反了直接負責和以受苦作為刑罰，這兩個舊約一貫教導的模式……代受苦難的概念要等到約伯、耶利米，以及以賽亞書四十二至五十三章『受苦僕人』的例子中，才有更重大的應驗。」==GT 把結論說白：「摩西是人，他無法將贖價給神，他也贖不了人（詩四九7～9）。救贖乃神自己的工作。」KC 一句話同義：「Moses, however, cannot die instead of the people」——摩西不能代死，只有那位完全無罪的主耶穌能。

神仍命摩西去領百姓往應許之地，[[耶和華的使者]]必在前面引路，只是「到我追討的日子，我必追討他們的罪」。GT 指出延遲追討的用意是「為的是要人悔改（參看彼後三9）」；丁良才則指出「這話在民十四章上應驗了」，而即使在那時，「耶和華雖罰了許多人，祂總沒有把自己的百姓全然滅絕了」。

全章以[[耶和華擊打百姓的瘟疫|「耶和華殺百姓的緣故，是因他們同亞倫做了牛犢」]]作結。這一節的和合本譯法，兩份來源都指為誤譯：CT 的〔原文字義〕標出「殺」是「擊打，打」，GT《中文聖經註釋》說得更明白——「這裏的殺字，是錯譯。原文是『擊打』。這個字只用在神對人施行災禍的擊打上……但在通常的情形下，是使用瘟疫作擊打的方法。這大概就是現代中文譯本繙為『降下瘟疫』的原因。」至於是什麼瘟疫，GT《舊約聖經背景註釋》說經文沒有提到症狀，「無從稽考」。

KC 讀這最後一節，讀的卻是被留下的那些人：==「全民都犯了罪，卻沒有全民滅亡——這正是神恩典與憐憫的憑據。」==

### 跨章脈絡與預表整理

第32章位於西乃立約（出19-24）、會幕啟示（出25-31）與重新立約（出34）之間。[[金牛犢事件|金牛犢]]直接違反第二誡，摔碎的[[法版]]宣告西乃之約破裂，須待出34 神重寫法版、重申約言才得更新。本章的混合敬拜在王國時期由耶羅波安的金牛犢重演（王上12:28），連宣告的話語都如出一轍；保羅則在林前10:7 引「百姓坐下吃喝，起來玩耍」為教會的鑑戒。

[[摩西]]兩次[[代求]]完整刻畫了中保的職分，而它的界限也在同一章裡被劃清：

| | 第一次（v11-14） | 第二次（v30-32） |
| :--- | :--- | :--- |
| 地點與時機 | 在山上，審判宣告之後 | 在山下審判執行之後，再上山 |
| 訴求根據 | 神的救贖作為、神的名聲、向列祖起的誓 | 自己的名——「從你所寫的冊上塗抹我的名」 |
| 付上的代價 | 拒絕「使你的後裔成為大國」 | 願以己身代替百姓受罰 |
| 神的回應 | 「耶和華後悔，不把所說的禍降與他的百姓」 | 「誰得罪我，我就從我的冊上塗抹誰的名」 |
| 結果 | 成 | 不成——中保是人，贖不了人 |

第二次的「不成」不是失敗，而是本章最深的預表：正因為摩西「不得」代死，才顯出那位又真是人又真是神、能一次獻上永遠除罪的基督。GT 丁良才在第33節下把這條線列成十層對照（申18:15-18）：

| | 摩西與基督相同之處 |
| :--- | :--- |
| 一 | 父母都卑微 |
| 二 | 都在嬰兒時冒過大險 |
| 三 | 都被自己的弟兄棄絕（徒7:25；約1:11） |
| 四 | 都行了神蹟奇事 |
| 五 | 都做了立約的中保 |
| 六 | 都組織了新國（以色列國和天國） |
| 七 | 都傳了新律法（摩西的律法和基督的律法） |
| 八 | 都做了大首領（摩西救以色列人脫離法老的手，耶穌救信徒脫離魔鬼的手） |
| 九 | 都願意為弟兄犧牲自己——但神不讓摩西犧牲自己，卻讓耶穌犧牲了性命 |
| 十 | 都為百姓祈求，而且大有功效 |

十層之中，第九層正是分界線：前八層是相同，第九層是相同中的斷裂，而這斷裂就是福音。
