# 西緬支派人數銳減

## 定義

民數記26:14：「這就是西緬的各族，共有二萬二千二百名。」對照民1:23 的五萬九千三百名，少了三萬七千一百人——是十二支派中減幅最大的一個。

**減少的原因，各家指向同一個方向。**

- CT：「大概是因為他們中有多人受了米甸人的引誘，西緬支派的族長心利（參二十五14），也在其中。」
- GT 丁良才《民數記註釋》說法一致，並補上一句後續：「摩西臨終為以色列十二支派祝福的時候（申三十三章）沒有提到西緬支派。」
- GT《啟導本聖經註釋》把兩件事都算進去：「流便與西緬支派人數的減少也許與他們支持大坍、亞比蘭（十六章）以及心利（二十五章）的事件有關。心利事件中因瘟疫而死的二萬四千人，大半屬西緬支派。」
- KC：「西緬是損失最大的支派。這麼大的損失也可能是前一章那場瘟疫造成的，西緬在其中也負有嚴重的責任。」
- BH 同樣把它歸於毘珥的事，並說人數的減少提醒人違背神命令的後果。

**具體的落差有多大。** GT《聖經精讀本》給了比例：「這個人數比第一次被數點的人數減少了63%。這個支派在第一次數點時,人數在十二支派中占第三位,但現在是人數最少的支派。」

**後續影響。** GT《聖經精讀本》接著說：因為摩西臨終祝福把西緬排除在外，「他們在進入迦南地以後只能生活在猶大支派剩餘的土地上（書19:1）」。CT 在〔話中之光〕把這件事寫成一則教訓：「此次數點人數，西緬支派的人數減少了大半，很可能是在首領心利的帶領下，許多族人都參與邪淫的拜偶像活動，以致被瘟疫所滅(參民二十五8~9，14)。」

**CT 給的應用。** CT〔話中之光〕：「此事給我們教訓，在教會中不可盲目跟從領袖，切莫以為領袖錯了，只有領袖受罰；跟從錯誤領袖的人們，也必會受罰。」
