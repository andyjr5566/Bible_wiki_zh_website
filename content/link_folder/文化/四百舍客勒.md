# 四百舍客勒

## 定義

以弗崙向亞伯拉罕開出的麥比拉洞地價：「值四百舍客勒銀子的一塊田」（創廿三15），亞伯拉罕不還價，用「買賣通用的銀子」平足付清（16節）。這個數目遠超當時的土地行情——大衛買禾場五十舍客勒、耶利米購地十七舍客勒，一名奴隸約值二十舍客勒，一年工資約十舍客勒。以弗崙口頭上說要白送，開的卻是高價；亞伯拉罕仍照價付足，為的是取得無可爭議的永久產權、不給後人留下追討的口實，也顯明他不佔別人便宜的見證。靈意上「四百」＝四十乘十，被讀作完全的試煉之數（CT）。

## 主題發展

### 貴到什麼程度

GT《舊約背景註釋》把四百舍客勒換算成約七又四分之一磅銀子，並排出一組對照：

| 交易 | 價格 |
|---|---|
| 麥比拉田與洞（創二十三15） | 四百舍客勒銀子 |
| 暗利買撒瑪利亞城址（王上十六24） | 六千舍客勒銀子 |
| 大衛買聖殿地皮（代上二十一25） | 六百舍客勒金子 |
| 亞勞拿的禾場（撒下二十四24） | 五十舍客勒銀子 |
| 耶利米購置產業（耶三十二7、9） | 十七舍客勒銀子 |
| 僱工與匠人年收（背景註釋） | 約十舍客勒 |

背景註釋的結論不客氣：亞伯拉罕所付的價錢「與其說是得到什麼折扣，不如說是昂貴到荒謬的程度」——每年只有十舍客勒的僱工和匠人，窮其一生也無法賺得這麼多的金錢。GT《串珠聖經註釋》另引漢摩拉比法典佐證工價：當時一個工人的日薪為一舍客勒銀子。GT《創世記雷氏研讀本》則提醒舍客勒在此是一種砝碼（約五盎司或十五克），並認為「當時田地可賣得很高的價錢」——這是唯一沒有把價格判為溢價的來源。

### 他為什麼不還價

背景註釋給了法律上的理由：他想要付足全價，可能是因為折價或許會導致家債的問題，日後給以弗崙的繼承人收復土地的口實；同一份來源在別處也說，亞伯拉罕拒絕接受餽贈，正是因為那樣一來以弗崙死後他的繼承人就有追回土地的權利。CT 從動機面說同一件事：他知道那地是他的產業、後裔必要承受，「只是在那承受產業的日子來到之前，他不肯從別人身上佔便宜」。KC 把它接到見證上：亞伯拉罕在生意上也是可信的，他當著見證人付了價——「人是從我們在地上事務中的謹慎，來判斷我們的信仰」（林後八21；帖前四12）。

### 「四百」的靈意

CT 另有一層讀法：「銀子」代表代價和試煉，「四百」是四十乘十，代表完全的試煉。這是由數字引申的應用，與上面的行情分析屬不同層次。
