# 神與摩西面對面明說

## 定義

民12:6-8 是全本聖經對「神怎樣向人說話」分得最清楚的一段。神把先知與摩西分成兩種等級：

| | 一般先知（v6） | 摩西（v8） |
| :--- | :--- | :--- |
| 方式 | 在異象中顯現、在夢中說話 | 面對面說話 |
| 清晰度 | ——（需要解讀） | 明說，不用謎語 |
| 所見 | ——  | 必見耶和華的形像 |

**「面對面」的原文字面是「嘴對嘴」。** GT《聖經精讀本》：「字面上的意思是『嘴對嘴』，是指神與摩西相見的時候並不是通過中間通道，而是象朋友一樣自然對話的意思（出33:11）。」STEP 原文資料證實這個字面：第8節是 peh 'el- peh（H6310G，詞典義 lip／mouth）。

**STEP 另顯示第6與第8節用了一組近乎同形的字。** 第6節「異象」是 ba./mar.'Ah（H4759A，詞典義 vision），第8節「明說」是 u./mar.'Eh（H4758，詞典義 appearance）——兩個不同的 Strong 編號，拼寫卻只差一點。CT 給的原文字義正是「異象」景象，鏡子／「明說」眼前看到的。==先知得到的是「異象」，摩西得到的是「所見」。==

**「見我的形像」不等於看見神的本體。** GT 丁良才：「神叫摩西所看見的，是照著他所能容受的（出三十三21-23）。摩西卻沒有看見神的本體（出三十三20，約一18，西一15，提前六16）。」CT 也說「形像不是真體」。GT《啟導本聖經註釋》：「這當然不是指直接見到神未隱藏的面，而是一種可見的形狀。摩西曾要求見神的面，他見到了神的背。」STEP 顯示這個字是 te.mu.Nat（H8544，詞典義 likeness）。

**這段話的重點不在貶低先知，而在說明米利暗和亞倫錯在哪裡。** GT《民數記串珠聖經註釋》：「屬靈的權柄源於神親自的啟示（2），米利暗和亞倫所說的並沒有錯，可惜他們沒有分辨出他們得啟示的方法與摩西的有何不同。」

## 按書卷累積

### 民數記

<!-- accumulation:民數記:12:start -->
#### [[04 民數記/第12章|第12章]]
- 本章重點：第6至8節神親自界定兩種啟示：一般先知得的是異象與夢，摩西得的是面對面、明說、不用謎語，並且見神的形像。GT《聖經精讀本》指出「面對面」的原文字面是「嘴對嘴」，STEP 原文資料證實第8節正是 peh 到 peh。
- 與本章關聯：這段話是神對第2節那句「難道耶和華單與摩西說話，不也與我們說話嗎」的正面回答：神沒有否認祂也與他們說話，只是指出方式不同。GT《民數記串珠聖經註釋》因此說米利暗和亞倫「所說的並沒有錯，可惜他們沒有分辨出他們得啟示的方法與摩西的有何不同」——本章的裁決不在事實層面，而在等級層面。
<!-- accumulation:民數記:12:end -->

### 申命記

<!-- accumulation:申命記:34:start -->
#### [[05 申命記/第34章|第34章]]
- 本章重點：第10節「以後以色列中再沒有興起先知像摩西的。他是耶和華面對面所認識的。」STEP 顯示末句是 ye.da.O Yah.weh pa.Nim el pa.Nim（H3045 ya.da: to know 加 H6440H 重複，字面是臉對臉）。CT 說面對面喻指彼此親密的交往和友誼，並在話中之光說摩西可以與神直接說話（出三十三11），而約書亞則需要藉著祭司的烏陵和土明來尋求神的旨意（民二十七21）。GT《申命記雷氏研讀本》說神面對面與摩西說話（比較出三三11；民一二8），約書亞需要祭司幫助他去認識神的旨意；GT《啟導本聖經申命記註釋》說神直接向摩西說話、約書亞則須藉著祭司的烏陵和土明來尋求神的旨意，所以在摩西死後再沒有興起先知像摩西的；GT《聖經精讀本──申命記註解》說與其他先知不同，神對摩西好像人與朋友說話一般、面對面說話（出33:11），也使他親眼目睹神榮耀的臨在（出33:18~23）。KC 說摩西與神的相交也是獨一無二的。BH 說不同於其他藉異象或夢領受的先知，摩西是直接而親身地與神說話。
- 與本章關聯：民12:6-8 是這個說法的定義處，在一場爭競裡被逼出來；本章是它的結案處，成了摩西一生的蓋棺定論。CT 與 GT 都在這裡補上同一個實務對照——摩西直接聽，約書亞要靠烏陵土明。
<!-- accumulation:申命記:34:end -->

## 主題發展

這個說法在正典裡有一個定義處，也有一個結案處。

民12:6-8 是定義。米利暗和亞倫質疑摩西的獨特地位，神親自把先知與摩西分成兩種等級：對先知用異象與夢，對摩西是面對面明說。那一段是在爭議中被逼出來的說明。

申34:10 是結案。摩西死後，經文回頭給他一句總評：以後以色列中再沒有興起先知像摩西的，他是耶和華面對面所認識的。同一個說法，這次不是在辯論裡出現，而是作為一生的蓋棺定論。

CT 在申34:10 補上一個很具體的對照，說明這句話在實務上意味著什麼：摩西可以與神直接說話，而約書亞則需要藉著祭司的烏陵和土明來尋求神的旨意（民二十七21）。GT《啟導本聖經申命記註釋》說的是同一件事，並由此解釋為什麼摩西死後再沒有興起先知像摩西的。

從民12 到申34，這個說法走完了一個來回：先是用來平息一場爭競，最後成了整卷書收尾時對摩西唯一的最高評價。
